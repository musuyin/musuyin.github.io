#算法与数据结构

  • 2026-10-28

    算法索引

    按问题特征定位笔记，比按实现语言查找更适合复习。先在基础算法、数据结构、图论、数论、贪心和动态规划中选择主题，再阅读相应语言实现。

  • 2026-10-28

    二分查找

    二分通过判定性质持续缩小候选区间。先明确寻找首个或最后一个满足条件的位置，再把中点取整、边界更新和循环结束条件作为一套约定使用。

  • 2026-10-28

    复杂度与数组基础

    数据范围用于排除明显不可行的复杂度，但运行时间还受常数与评测环境影响。数组基础再补充下标、存储和转换约定，为后面的区间算法建立共同语言。

  • 2026-10-28

    滑动窗口

    滑动窗口维护连续区间及其摘要。正数和、字符频次和候选最大值对应不同状态，必须先证明左边界移动后哪些候选可以安全丢弃。

  • 2026-10-28

    双指针

    双指针利用指针移动的单调性避免回退。快慢指针常维护已处理前缀，对向指针利用有序性，同向双序列扫描则比较当前候选。

  • 2026-10-23

    高精度运算

    高精度加减乘除把整数拆为十进制位，再维护进位、借位或余数。手写算法用于理解位级计算，Java 的 BigInteger 则提供现成的大整数表示。

  • 2026-10-23

    位运算

    位运算用二进制结构表达局部操作。提取某一位、lowbit 和删除最低位的 1 是不同操作；异或消去法还依赖题目中的出现次数条件。

  • 2026-10-23

    贡献法

    贡献法从单个元素参与多少个结果出发计算总量。相邻边界和出现次数把重复枚举转成一次性计数，但需要说明每个结果是否恰好被统计一次。

  • 2026-10-23

    离散化与区间合并

    离散化保留坐标的相对顺序，把稀疏范围映射成紧凑下标；区间合并则在排序后维护当前覆盖范围。两者都不应混淆坐标值和数组下标。

  • 2026-10-23

    树状数组

    树状数组将前缀分成若干由 lowbit 决定的区间。查询向父区间回退，单点更新则沿所有覆盖该位置的管理节点向上累加。

  • 2026-10-23

    矩阵与分治

    矩阵模型把递推写成线性变换，分治把整体问题拆为可合并的小问题。稀疏矩阵与矩阵快速幂则分别利用非零元素少、重复乘方的结构。

  • 2026-10-23

    前缀和与差分

    前缀和把区间查询转换成端点差，差分把区间修改转换成边界增量。二维版本沿用同一思路，但必须用容斥处理重复覆盖。

  • 2026-10-23

    排序与选择

    快速排序通过划分后递归两侧建立全序，快速选择只追踪排名所在一侧；归并则通过有序子区间的合并组织比较。

  • 2026-08-18

    动态规划

    本篇从斐波那契与网格路径建立递推直觉，再列出背包和其他 DP 类型。复习已实现部分时，先定义状态与边界，再检查每个状态的前驱是否已经算好。

  • 2026-08-18

    贪心算法

    分发饼干先对需求和资源排序，再用最小的可用资源满足当前最小需求。阅读代码时关注两个指针分别何时移动，以及为何要保留较大的饼干。

  • 2026-08-14

    图论

    图搜索先明确节点、边和路径的表示，再决定按深度还是按层扩展。所有可达路径需要保留当前路径，并在递归退出时撤销本次选择。

  • 2026-07-30

    回溯算法

    回溯把枚举过程表示为一棵决策树。组合、排列、切割和子集问题的区别在于选择范围、顺序是否重要以及何时收集答案。

  • 2026-07-27

    树

    树的算法建立在遍历顺序之上。先掌握前中后序与层序，再看深度、高度、对称和完全二叉树问题；每个递归函数都应说明参数、返回值和空节点含义。

  • 2026-07-20

    栈与队列

    栈和队列的处理顺序不同，适合不同的待处理信息。括号和表达式用栈保留尚未匹配的结构，单调队列和堆则保留可能成为最优答案的候选。

  • 2026-06-01

    ACM 模式 IO

    Go 的 ACM 模式要自己处理标准输入输出。先确定题目按空白还是按行组织数据，再选 fmt 或 bufio；同一输入流的读取方式需要保持一致。

  • 2026-05-24

    字符串

    字符串题主要涉及原地反转、字符替换、词序调整与模式匹配。阅读 Go 实现时，始终确认代码是在处理字节下标还是字符，以及题目允许的字符范围。

  • 2026-05-11

    哈希表

    哈希题把反复查询转成集合或映射操作。先判断需要计数、去重还是查找补数，再决定数组、集合或字典是否合适；三数与四数问题还要处理重复答案。

  • 2026-04-08

    链表

    链表操作改变的是节点之间的引用。先理解节点定义与遍历，再用虚拟头节点统一插入删除的边界，用双指针解决距离、相交和环的问题。

  • 2026-03-31

    数组

    数组题可以按区间边界、指针移动、窗口维护和累计量分类。二分先确定区间开闭，双指针与滑动窗口先说明移动后仍成立的不变量。

  • 2025-11-12

    Hot100-Java

    Java Hot100 按常见数据结构与算法策略组织。每题先从题目约束中排除不可行复杂度，再说明不变量、递推或搜索空间，最后检查空输入、边界索引和溢出；保留题干与原 Java 实现。

  • 2025-08-30

    Hot100-Go

    Go Hot100 按数组、链表、哈希、栈、树、图与动态规划归类。复习时先复述状态或不变量，再解释实现为何满足题目的时间、空间限制；题干中的英文、Go 实现和已有复杂度约束均保留。

  • 2024-07-01

    Algorithms

    本课程笔记以连接性问题引入数据结构，再通过代价模型比较实现。学习时把 API、维护的不变量和操作成本连起来看，后续算法也沿用这一分析方式。

  • 2024-03-14

    JavaSE 数据结构

    Java 数据结构从字符串与集合语义展开，再解释数组、链表、哈希与树如何支撑这些语义。先掌握接口的操作约定，再看某个 JDK 版本的内部实现，避免把实现细节当作永久契约。

  • 2023-12-14

    数据结构

    数据结构通过维护特定不变量支持操作。阅读数组模拟链表、栈队列、Trie、并查集和堆时，应先说清每个数组的含义，再检查插入、删除或合并后的结构是否仍成立。

  • 2023-12-14

    动态规划

    动态规划先描述方案集合，再按最后一步或当前选择划分。背包、线性、区间与状态压缩问题的差别主要在状态维度、依赖关系和合法的计算顺序。

  • 2023-12-14

    基础算法

    基础算法的共同任务是减少重复工作：排序建立顺序，二分压缩候选范围，前缀和复用累计结果，双指针利用移动不变量。应先根据数据范围选复杂度，再核对模板中的区间约定。

  • 2023-12-14

    贪心算法

    贪心解法需要把局部选择与全局目标连接起来。区间问题关注排序与边界，Huffman 关注重复付出的代价，排序不等式则解释相邻交换为什么有利。

  • 2023-12-14

    数论

    数论模板的关键是成立条件。质因数分解支撑约数与欧拉函数，快速幂支撑模运算；逆元、同余方程和组合计数都需要先明确模数与互质关系。

  • 2023-12-14

    搜索与图论

    搜索用于枚举状态，图算法用于利用边关系求解。先区分 DFS、BFS 与拓扑排序，再按边权条件选择最短路算法，避免只凭模板名称套用。
