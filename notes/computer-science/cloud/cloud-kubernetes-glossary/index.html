理解主线

这份表按接口、网络、存储、对象、云产品和可靠性整理术语。缩写、kubectl 短名与产品名称属于不同类别，查表时先确认它在什么层提供什么能力。

表格中的“缩写或简称”优先使用行业通用缩写；没有通用缩写的产品或 Kubernetes 对象会明确标注“无通用缩写”，避免人为创造缩写。Kubernetes 的 kubectl 资源短名称会注明为“资源短名”。

容器与 Kubernetes 接口

缩写或简称 英文全称 中文名称 说明
CRI Container Runtime Interface 容器运行时接口 Kubernetes 通过 CRI 调用 containerd、CRI-O 等运行时管理镜像和容器。Docker Engine 不直接实现 CRI；旧版曾通过现已移除的 dockershim 接入。
CNI Container Network Interface 容器网络接口 为 Pod 配置网络接口、IP、路由和连通性；常见实现包括 Calico、Cilium、Flannel 和云厂商 VPC CNI。NetworkPolicy 是否生效取决于插件能力。
CSI Container Storage Interface 容器存储接口 让 Kubernetes 通过标准接口供应、挂载和管理外部存储，例如 EBS CSI、GCE PD CSI、Azure Disk CSI 和 Ceph CSI。

记忆：CRI 运行容器，CNI 接通网络，CSI 挂载存储。

网络

缩写或简称 英文全称 中文名称 说明
VPC Virtual Private Cloud 虚拟私有云 云上的逻辑隔离网络，通常包含子网、路由表、NAT、安全组和负载均衡器。不同云厂商的具体实现存在差异。
Subnet Subnet 子网 VPC 内的地址分段，常按可用区和公网/私网用途划分。子网本身是否“公网”通常取决于路由和公网地址配置。
CIDR Classless Inter-Domain Routing 无类别域间路由 使用 10.0.0.0/16 等前缀表示地址范围。规划时需要避免 VPC、Node、Pod、Service 和对等网络网段重叠。
ENI Elastic Network Interface 弹性网络接口 AWS 中可附加到 EC2 的虚拟网卡；Amazon VPC CNI 可借助 ENI 为 Pod 分配 VPC 地址。其他云有类似产品但名称不同。
NAT Network Address Translation 网络地址转换 转换源或目的地址。私网实例常通过 NAT Gateway 访问公网，但 NAT 通常不允许公网主动发起入站连接。
SG Security Group 安全组 云主机或网卡级有状态访问控制。规则修改会影响关联资源，应结合流向、协议、端口和来源判断。
NACL Network Access Control List 网络访问控制列表 AWS VPC 的子网级无状态规则，需要分别配置入站和出站；其他云产品名称可能不同。
LB Load Balancer 负载均衡器 在多个后端之间分发连接或请求，可能工作在四层或七层。云 LB 与 Kubernetes Service/Ingress 不是同一个对象，但常被控制器关联创建。
ALB Application Load Balancer 应用负载均衡器 AWS 的七层 HTTP/HTTPS 负载均衡产品，可按 Host、Path 等应用层条件路由。
NLB Network Load Balancer 网络负载均衡器 AWS 的四层负载均衡产品，主要处理 TCP、UDP 和 TLS 流量。
CLB Classic Load Balancer 经典负载均衡器 AWS 的上一代负载均衡产品；在其他云的语境中 CLB 也可能代表 Cloud Load Balancer，必须结合厂商判断。
GCLB Google Cloud Load Balancing Google Cloud 负载均衡 对 Google Cloud 负载均衡产品族的常见非正式简称，具体能力取决于所选 Application/Network Load Balancer 类型。
DNS Domain Name System 域名系统 把域名解析为地址或其他记录。Kubernetes 内通常由 CoreDNS 提供服务发现，云上还可能使用 Route 53、Cloud DNS 或 Private DNS Zone。
Ingress Ingress Kubernetes 入口规则 声明外部 HTTP/HTTPS 到 Service 的路由。只有部署对应 Ingress Controller 后规则才会生效；Ingress 不等同于云负载均衡器。
Gateway API Kubernetes Gateway API Kubernetes 网关 API 比 Ingress 角色划分和路由能力更丰富的流量管理 API，常用对象包括 GatewayClass、Gateway 和 HTTPRoute。
Service Service Kubernetes 服务 为一组后端 Pod 提供稳定的虚拟地址和服务发现，常见类型包括 ClusterIP、NodePort、LoadBalancer 和 ExternalName。

存储

缩写或简称 英文全称 中文名称 说明
PV PersistentVolume 持久卷 Kubernetes 中代表实际存储资源的集群级对象，可以静态创建或由 CSI 动态供应。
PVC PersistentVolumeClaim 持久卷声明 工作负载对容量、访问模式和 StorageClass 的存储请求；Pod 通常引用 PVC，而不是直接引用 PV。
SC StorageClass 存储类 SC 是常见简称，也是 kubectl 资源短名。它定义动态供应器、参数、回收策略和绑定模式。
EBS Amazon Elastic Block Store Amazon 弹性块存储 AWS 的块存储服务，常作为 EC2 或 EKS 的持久卷后端。
PD Persistent Disk 持久磁盘 Google Cloud 的块存储产品，现有产品文档也使用 Hyperdisk；在 GKE 中通常通过 CSI 接入。
Azure Disk（无通用缩写） Azure Disk Storage Azure 磁盘存储 Azure 的托管块存储，在 AKS 中通常通过 Azure Disk CSI Driver 使用。
EFS Amazon Elastic File System Amazon 弹性文件系统 AWS 托管的共享文件存储，可由多个客户端挂载。
Filestore（无通用缩写） Google Cloud Filestore Google Cloud 文件存储 Google Cloud 的托管文件存储服务，可作为共享文件系统使用。
Azure Files（无通用缩写） Azure Files Azure 文件存储 Azure 的托管文件共享服务，支持 SMB 和部分 NFS 场景。
S3 Amazon Simple Storage Service Amazon 简单存储服务 AWS 对象存储。对象存储的访问语义不同于 POSIX 文件系统，通常应通过 API/SDK 使用。
GCS Google Cloud Storage Google Cloud 对象存储 Google Cloud 的对象存储服务。
OSS Object Storage Service 对象存储服务 阿里云对象存储服务；OSS 在其他上下文也可能表示 Open Source Software，需要结合语境。
Blob Azure Blob Storage Azure Blob 对象存储 Azure 面向非结构化对象数据的存储服务。

Kubernetes 核心对象与能力

缩写或简称 英文全称 中文名称 说明
Pod Pod Pod / 容器组 Kubernetes 最小调度单位，可包含一个或多个共享网络和 Volume 的容器。Pod 是可替换实例，不应依赖其名称或 IP 永久不变。
Deployment Deployment 部署 声明式管理无状态应用，通过 ReplicaSet 维持副本并执行滚动更新和回滚。
RS ReplicaSet 副本集 维持符合 selector 的 Pod 副本数，通常由 Deployment 自动管理；rs 也是资源短名。
STS StatefulSet 有状态副本集 sts 是资源短名。为 Pod 提供稳定序号、网络身份和独立 PVC，适用于需要稳定身份的工作负载。
DS DaemonSet 守护进程集 ds 是资源短名。确保符合条件的 Node 上运行 Pod，常用于日志、监控、网络和存储 Agent。
Job Job 一次性任务 运行到成功完成的批处理工作负载，可配置并行度、重试和超时。
CronJob CronJob 定时任务 按 Cron 表达式创建 Job，需要关注时区、并发策略、错过调度和历史保留。
CM ConfigMap 配置映射 cm 是资源短名。保存非敏感配置，可作为环境变量或文件提供给 Pod。
Secret Secret 密钥对象 保存密码、Token 或证书等敏感数据。Base64 只是编码，不是加密；还需配合 RBAC、静态加密和外部密钥系统。
NS Namespace 命名空间 ns 是资源短名。用于资源命名、配额和策略范围划分，但本身不是完整的安全隔离边界。
RBAC Role-Based Access Control 基于角色的访问控制 Kubernetes 通过 Role/ClusterRole 定义权限，通过 RoleBinding/ClusterRoleBinding 绑定主体。
SA ServiceAccount 服务账号 Kubernetes 工作负载身份。Pod 可使用 SA Token 访问 API，也可通过工作负载身份映射云 IAM。
HPA Horizontal Pod Autoscaler Pod 水平自动扩缩器 根据 CPU、内存或自定义指标调整工作负载副本数。资源利用率指标依赖合理的 requests。
VPA Vertical Pod Autoscaler Pod 垂直自动扩缩器 Kubernetes 生态组件，根据历史使用量推荐或调整单个 Pod 的资源请求；不是所有集群默认安装。
PDB PodDisruptionBudget Pod 中断预算 限制通过 Eviction API 发起的自愿中断同时影响的可用副本数，不能阻止 Node 宕机等非自愿故障。

托管 Kubernetes 与 Serverless 容器

缩写或简称 英文全称 中文名称 说明
K8s Kubernetes Kubernetes 容器编排平台 K8s 用 8 表示首尾字母之间的八个字母，是 Kubernetes 的通用缩写。
EKS Amazon Elastic Kubernetes Service Amazon 弹性 Kubernetes 服务 AWS 托管 Kubernetes，控制面由 AWS 管理，计算层可使用托管节点组、自管 EC2 或 Fargate。
GKE Google Kubernetes Engine Google Kubernetes 引擎 Google Cloud 托管 Kubernetes，主要模式包括 Standard 和 Autopilot。
AKS Azure Kubernetes Service Azure Kubernetes 服务 Microsoft Azure 托管 Kubernetes，常结合 VM Scale Sets、Microsoft Entra ID 和 Workload Identity。
ACK Alibaba Cloud Container Service for Kubernetes 阿里云容器服务 Kubernetes 版 阿里云托管 Kubernetes 产品。
ASK Alibaba Cloud Serverless Kubernetes 阿里云 Serverless Kubernetes 旧产品名称和缩写，现通常称 ACK Serverless；Pod 可运行在 ECI 上，无需直接管理 ECS Node。
TKE Tencent Kubernetes Engine 腾讯云容器服务 腾讯云托管 Kubernetes 产品。
CCE Cloud Container Engine 云容器引擎 华为云托管 Kubernetes 产品。
CCI Cloud Container Instance 云容器实例 华为云 Serverless 容器实例产品，可用于按需运行容器工作负载。
ECI Elastic Container Instance 弹性容器实例 阿里云 Serverless 容器实例产品，ACK Serverless 或虚拟节点可将 Pod 调度到 ECI。
ECS Elastic Compute Service 弹性计算服务 阿里云虚拟机产品，ACK 节点常运行在 ECS 上；不同厂商的 ECS 含义可能不同。
EC2 Amazon Elastic Compute Cloud Amazon 弹性计算云 AWS 虚拟机服务，EKS Worker Node 常运行在 EC2 上。
Fargate AWS Fargate AWS Serverless 容器计算 为 ECS 和 EKS 提供无需直接管理服务器的容器计算能力，不是独立 Kubernetes 集群产品。
Autopilo GKE Autopilot GKE 自动驾驶模式 GKE 的托管运行模式，由 Google 管理 Node、扩缩容和部分安全配置，用户主要声明工作负载。
VMSS Virtual Machine Scale Sets 虚拟机规模集 Azure 的虚拟机组和自动扩缩能力，AKS Node Pool 通常基于 VMSS。
Virtual Node Virtual Node 虚拟节点 通过虚拟 kubelet 等方式在 Kubernetes 中呈现 Node 接口，实际 Pod 运行于 Serverless 容器平台。

云厂商速记：EKS 对应 AWS，GKE 对应 Google Cloud，AKS 对应 Azure，ACK/ACK Serverless 对应阿里云，TKE 对应腾讯云，CCE/CCI 对应华为云。

云身份、安全与基础设施即代码

缩写或简称 英文全称 中文名称 说明
IAM Identity and Access Management 身份与访问管理 云平台对身份、角色、策略和资源权限的统称；不同厂商的具体模型和产品名称不同。
RAM Resource Access Management 资源访问管理 阿里云身份与权限管理服务。不要与计算机内存 Random Access Memory 混淆。
CAM Cloud Access Management 云访问管理 腾讯云身份与访问管理服务。
Microsoft Entra ID（原 AAD） Microsoft Entra ID（formerly Azure Active Directory） Microsoft Entra 身份服务 Azure 的身份目录服务；旧文档常使用 AAD，即 Azure Active Directory。
IRSA IAM Roles for Service Accounts 服务账号的 IAM 角色 EKS 的工作负载身份方案，将 Kubernetes SA 与 AWS IAM Role 关联，避免在 Pod 中保存长期 AK/SK。
AK/SK Access Key / Secret Key 访问密钥 / 私密访问密钥 云 API 的长期凭据组合。生产工作负载优先使用短期角色凭据或 Workload Identity。
WI Workload Identity 工作负载身份 让 Kubernetes 工作负载基于 SA 获取云身份。GKE、Azure 等平台实现不同，配置时应以厂商文档为准。
MFA Multi-Factor Authentication 多因素认证 使用两种或更多不同类型的认证因素降低账号被盗风险。
KMS Key Management Service 密钥管理服务 托管加密密钥生命周期，可用于磁盘、对象、数据库和 Kubernetes Secret 静态加密。
TLS Transport Layer Security 传输层安全协议 为网络通信提供加密、完整性和服务端身份验证。
mTLS Mutual Transport Layer Security 双向传输层安全 TLS 双方都提供并验证证书，常用于内部服务身份认证和服务网格。
IaC Infrastructure as Code 基础设施即代码 通过声明式或编程式代码管理基础设施，例如 Terraform、CloudFormation、Bicep 和 ROS。
HCL HashiCorp Configuration Language HashiCorp 配置语言 Terraform 配置常用语言。
ARM Azure Resource Manager Azure 资源管理器 Azure 资源管理和部署控制面；ARM Template 是其 JSON 模板格式。不要与 ARM 处理器架构混淆。
ROS Resource Orchestration Service 资源编排服务 阿里云基础设施编排服务。
GitOps Git Operations Git 运维模式 以 Git 中的声明作为期望状态，由 Argo CD、Flux 等控制器持续比较并同步实际环境。

可观测性与交付

缩写或简称 英文全称 中文名称 说明
Prometheus Prometheus Prometheus 监控系统 以时间序列方式抓取和存储指标，使用 PromQL 查询，常用于 Kubernetes 监控和告警。
PromQL Prometheus Query Language Prometheus 查询语言 用于查询、聚合和计算 Prometheus 时间序列。
Grafana Grafana Grafana 可视化平台 对指标、日志和 Trace 等数据源进行查询、可视化和告警。
Loki Grafana Loki Grafana Loki 日志系统 以标签索引日志流，查询语言为 LogQL；应控制标签基数。
ELK Elasticsearch, Logstash, Kibana ELK 日志技术栈 Elasticsearch 存储检索、Logstash 处理日志、Kibana 查询和可视化。
EFK Elasticsearch, Fluentd, Kibana EFK 日志技术栈 使用 Fluentd 替代 Logstash 采集或处理日志；也常使用更轻量的 Fluent Bit。
OTel OpenTelemetry 开放遥测标准 提供 Metrics、Logs、Traces 的 API、SDK、语义约定和 Collector，避免观测数据被单一厂商锁定。
OTLP OpenTelemetry Protocol OpenTelemetry 协议 OpenTelemetry 组件之间传输遥测数据的协议，常基于 gRPC 或 HTTP。
Jaeger Jaeger Jaeger 分布式追踪系统 收集、存储和查询分布式 Trace，用于分析跨服务请求路径和耗时。
Tempo Grafana Tempo Grafana Tempo 追踪后端 Grafana 生态的分布式 Trace 存储与查询后端。
CI Continuous Integration 持续集成 频繁合并代码，并自动执行构建、检查和测试。
CD Continuous Delivery / Continuous Deployment 持续交付 / 持续部署 持续交付确保制品随时可发布；持续部署则将通过门禁的变更自动发布到生产。
Helm Helm Kubernetes 包管理器 使用 Chart 管理一组可复用、可参数化的 Kubernetes 资源模板。
Kustomize Kustomize Kubernetes 配置定制工具 通过 Base 和 Overlay 对原始 YAML 进行声明式叠加，已集成到 kubectl。
CRD CustomResourceDefinition 自定义资源定义 扩展 Kubernetes API 的对象 Schema，使集群可以存储和管理自定义资源。
Operator Kubernetes Operator Kubernetes 操作器 将领域运维知识编码到自定义控制器中，持续协调数据库、消息队列等复杂应用。
(Argo) CD (Argo) Continuous Delivery 持续交付 Argo CD 是面向 Kubernetes 的 GitOps 持续交付控制器；这里的 CD 指 Continuous Delivery。

可靠性工程常用术语

缩写或简称 英文全称 中文名称 说明
SRE Site Reliability Engineering 站点可靠性工程 使用软件工程方法解决运维、可靠性、容量和变更风险问题。
SLI Service Level Indicator 服务等级指标 对用户体验的具体测量，例如成功请求比例或延迟达标比例。
SLO Service Level Objective 服务等级目标 SLI 在指定时间窗口内应达到的内部可靠性目标。
SLA Service Level Agreement 服务等级协议 面向客户或外部主体的服务承诺，通常包含责任或补偿条款。
RPO Recovery Point Objective 恢复点目标 故障后可接受的数据丢失范围，决定备份或复制频率。
RTO Recovery Time Objective 恢复时间目标 故障发生后可接受的最长恢复时间。
MTTR Mean Time to Recovery / Restore 平均恢复时间 从故障发生或被发现到服务恢复的平均时间；使用时应明确起止口径。
MTBF Mean Time Between Failures 平均故障间隔 可修复系统相邻故障之间的平均运行时间。

分层判断

关键词或缩写 所属层次 判断重点
Network、IP、Subnet、VPC、CNI、Ingress、Gateway、LB 网络与流量层 地址规划、路由、名称解析、策略、入口和负载均衡。
PV、PVC、SC、CSI、EBS、PD、Disk、S3、GCS 存储与数据层 供应、挂载、访问模式、拓扑、备份与数据生命周期。
Pod、Deployment、STS、DS、Service、NS、RBAC Kubernetes 应用层 工作负载控制、服务发现、隔离、权限和期望状态。
EKS、GKE、AKS、ACK、TKE、CCE 托管 Kubernetes 产品层 厂商责任边界、控制面、Node、网络和身份集成。
Fargate、ECI、CCI、Autopilot、Virtual Node Serverless 容器计算层 无节点运维模式、调度限制、计费、启动速度和兼容性。
IAM、RAM、CAM、IRSA、WI、KMS、MFA 身份与安全层 身份来源、最小权限、短期凭据、密钥和审计。
IaC、HCL、ARM、ROS、Terraform 基础设施自动化层 声明式状态、变更计划、漂移、模块化和回滚。
GitOps、Argo CD、Flux、Helm、Kustomize、CI/CD 配置与交付层 制品、期望状态、同步、发布门禁和回退。
Prometheus、Grafana、Loki、ELK、EFK、OTel 可观测性层 指标、日志、Trace、告警、关联分析和数据保留。
SLI、SLO、SLA、RPO、RTO、MTTR 可靠性治理层 用户体验目标、错误预算、恢复目标和事件改进。
