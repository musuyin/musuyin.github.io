理解主线

从实例与类的关系开始，再比较继承、方法绑定与装饰器。classmethod 绑定类，staticmethod 不接收隐式实例，property 把访问封装为计算，Enum 则表达有限且可比较的成员集合。

内置类属性

  • dict : 类的属性（包含一个字典，由类的数据属性组成）
  • doc :类的文档字符串
  • name: 类名
  • module: 类定义所在的模块（类的全名是’main.className’，如果类位于一个导入模块 mymod 中，那么 className.module 等于 mymod）
  • bases : 类的所有父类构成元素（包含了一个由所有父类组成的元组）
  • del: 析构函数

继承

class Person:
    age = 0
class Employee(Person):
    salary = 0.0
  1. 如果在子类中需要父类的构造方法就需要显式的调用父类的构造方法，或者不重写父类的构造方法。详细说明可查看： python 子类继承父类构造函数说明。
  2. 在调用基类的方法时，需要加上父类的类名前缀，且需要带上 self 参数变量。区别在于类中调用普通函数时并不需要带上 self 参数
  3. Python 总是首先查找对应类型的方法，如果它不能在派生类中找到对应的方法，它才开始到父类中逐个查找。（先在本类中查找调用的方法，找不到才去父类中找）。

如果在继承元组中列了一个以上的类，那么它就被称作“多重继承” 。

继承检测

  • ​issubclass()​ - 布尔函数判断一个类是另一个类的子类或者子孙类，语法：issubclass(sub,sup)
  • ​isinstance(obj, Class)​ 布尔函数如果 obj 是 Class 类的实例对象或者是一个 Class 子类的实例对象则返回 true。

auto() 函数的作用

基本概念

auto() 是 Python enum 模块提供的一个函数，用于自动生成枚举成员的值。

没有 auto() 的情况

from enum import Enum

# ❌ 传统方式：手动指定值
class Hyperscaler(Enum):
    AWS = 1
    AZURE = 2
    GCP = 3
    CCLOUD = 4
    GDC = 5
    ALICLOUD = 6

问题：

  • 需要手动维护数字
  • 添加新成员时容易出错
  • 数字本身没有实际意义

使用 auto() 的情况

from enum import Enum, auto

# ✅ 使用 auto()：自动生成值
class Hyperscaler(Enum):
    AWS = auto()        # 自动赋值为 1
    AZURE = auto()      # 自动赋值为 2
    GCP = auto()        # 自动赋值为 3
    CCLOUD = auto()     # 自动赋值为 4
    GDC = auto()        # 自动赋值为 5
    ALICLOUD = auto()   # 自动赋值为 6

auto() 的工作原理

from enum import Enum, auto

class Hyperscaler(Enum):
    AWS = auto()        # 内部: AWS.value = 1
    AZURE = auto()      # 内部: AZURE.value = 2
    GCP = auto()        # 内部: GCP.value = 3

# 验证值
print(Hyperscaler.AWS.value)     # 输出: 1
print(Hyperscaler.AZURE.value)   # 输出: 2
print(Hyperscaler.GCP.value)     # 输出: 3

auto() 的默认规则

  1. 从 1 开始：第一个 auto() 默认生成 1
  2. 递增：后续每个 auto() 在前一个值基础上 +1
  3. 混合使用：可以和手动赋值混用
class Status(Enum):
    PENDING = auto()     # 1
    APPROVED = 10        # 手动指定 10
    REJECTED = auto()    # 11 (在 10 基础上 +1)
    COMPLETED = auto()   # 12

为什么使用 auto()？

在 context.py 中的使用场景：

@unique
class Hyperscaler(Enum):
    AWS = auto()
    AZURE = auto()
    GCP = auto()
    CCLOUD = auto()
    GDC = auto()
    ALICLOUD = auto()

原因：

  1. ✅ 枚举值本身不重要：我们只关心 Hyperscaler.AWS，不关心它的值是 1 还是 100
  2. ✅ 易于维护：添加新云平台时只需 NEWCLOUD = auto()
  3. ✅ 避免错误：不会因为手动编号重复而出错
  4. ✅ 代码清晰：表明这些值只是标识符，没有数值意义

实际使用示例

# context.py 中的使用
class Hyperscaler(Enum):
    AWS = auto()
    AZURE = auto()
    GCP = auto()

# 使用时我们关心的是枚举成员本身
hyperscaler = Hyperscaler.AWS

# 比较
if hyperscaler == Hyperscaler.AWS:
    print("This is AWS")  # ✅ 这样比较

# 我们不关心值
print(hyperscaler.value)  # 1 (但我们不关心这个数字)

@unique 装饰器

基本概念

@unique 是一个类装饰器，用于确保枚举类中所有成员的值都是唯一的。

没有 @unique 的情况

from enum import Enum

# ❌ 没有 @unique：可以有重复值
class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 1      # ⚠️ 和 RED 值相同，会成为 RED 的别名

print(Color.RED)   # Color.RED
print(Color.BLUE)  # Color.RED (BLUE 是 RED 的别名！)
print(Color.RED == Color.BLUE)  # True (意外！)

使用 @unique 的情况

from enum import Enum, unique

# ✅ 使用 @unique：强制值唯一
@unique
class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 1      # ❌ ValueError: duplicate values found in <enum 'Color'>: BLUE -> RED

在 context.py 中的应用

@unique
class Hyperscaler(Enum):
    AWS = auto()        # 1
    AZURE = auto()      # 2
    GCP = auto()        # 3
    CCLOUD = auto()     # 4
    GDC = auto()        # 5
    ALICLOUD = auto()   # 6
    # DUPLICATE = auto() # 如果不小心添加重复，@unique 会报错

作用：

  1. ✅ 防止手误：确保每个云平台都是唯一的
  2. ✅ 早期发现错误：在定义时就报错，而不是运行时
  3. ✅ 代码意图明确：告诉读者“这些值必须唯一”

实战示例：@unique 的价值

# 假设我们手动指定值（不使用 auto）
@unique
class Hyperscaler(Enum):
    AWS = 1
    AZURE = 2
    GCP = 3
    CCLOUD = 1  # ❌ ValueError: duplicate values found: CCLOUD -> AWS
    # @unique 立即捕获这个错误！

如果没有 @unique：

class Hyperscaler(Enum):
    AWS = 1
    CCLOUD = 1  # 不报错，但 CCLOUD 变成了 AWS 的别名

# 运行时会有意外行为
if hyperscaler == Hyperscaler.AWS:
    print("AWS")
# 即使 hyperscaler 是 CCLOUD，也会打印 "AWS"！

@classmethod 装饰器

基本概念

@classmethod 是一个方法装饰器，将方法变成类方法。

三种方法类型对比

class Example:
    class_variable = "I'm a class variable"

    # 1. 实例方法（Instance Method）
    def instance_method(self, value):
        """第一个参数是 self，代表实例本身"""
        self.value = value
        return f"Instance: {self.value}"

    # 2. 类方法（Class Method）
    @classmethod
    def class_method(cls, value):
        """第一个参数是 cls，代表类本身"""
        return f"Class: {cls.class_variable}, Value: {value}"

    # 3. 静态方法（Static Method）
    @staticmethod
    def static_method(value):
        """没有 self 或 cls，就是普通函数"""
        return f"Static: {value}"

# 使用
obj = Example()

# 实例方法：需要实例调用
obj.instance_method("test")  # ✅
Example.instance_method(obj, "test")  # ✅ 等价写法

# 类方法：可以通过类或实例调用
Example.class_method("test")  # ✅ 推荐
obj.class_method("test")      # ✅ 也可以

# 静态方法：可以通过类或实例调用
Example.static_method("test")  # ✅ 推荐
obj.static_method("test")      # ✅ 也可以

在 context.py 中的应用

@unique
class Hyperscaler(Enum):
    AWS = auto()
    AZURE = auto()
    GCP = auto()

    @classmethod
    def by_name(cls, name):
        """
        根据字符串名称获取枚举成员

        参数:
            cls: 类本身 (Hyperscaler)
            name: 字符串名称，如 "aws", "Azure", "GCP"

        返回:
            枚举成员，如 Hyperscaler.AWS
        """
        return cls[name.upper()]
        # cls 就是 Hyperscaler 类
        # cls[name.upper()] 等价于 Hyperscaler["AWS"]

为什么使用 @classmethod？

场景 1：工厂方法（Factory Method）

# context.py 中的实际使用
class Context:
    def __init__(self, name: str, data=None) -> None:
        self.name = name
        self.data = data if data else self._load_stencil()
        # 使用 Enum.by_name 类方法
        self.hyperscaler = Hyperscaler.by_name(self.data['hyperscaler'])
        #                  ^^^^^^^^^^^^^^^^^^^^
        #                  这是一个类方法调用

# stencil 文件中 hyperscaler: "aws"
# 通过 by_name 类方法转换为 Hyperscaler.AWS 枚举

如果没有 @classmethod，需要这样写：

# ❌ 没有类方法的笨拙写法
hyperscaler_str = self.data['hyperscaler']  # "aws"
if hyperscaler_str.upper() == "AWS":
    self.hyperscaler = Hyperscaler.AWS
elif hyperscaler_str.upper() == "AZURE":
    self.hyperscaler = Hyperscaler.AZURE
elif hyperscaler_str.upper() == "GCP":
    self.hyperscaler = Hyperscaler.GCP
# ... 每次添加新云平台都要加一个 elif

# ✅ 使用类方法的优雅写法
self.hyperscaler = Hyperscaler.by_name(self.data['hyperscaler'])
# 一行搞定，自动支持所有枚举成员

@classmethod 的关键特点

@unique
class Stage(Enum):
    DEV = auto()
    CANARY = auto()
    PROD = auto()

    @classmethod
    def by_name(cls, name):
        """
        cls 参数的魔法：
        - cls 不是字符串 "Stage"
        - cls 是实际的类对象 Stage
        - 可以用 cls 做任何类能做的事
        """
        return cls[name.upper()]
        # cls[...] 等价于 Stage[...]
        # 这是 Python Enum 的内置字典访问语法

# 使用示例
stage = Stage.by_name("dev")     # Stage.DEV
stage = Stage.by_name("canary")  # Stage.CANARY
stage = Stage.by_name("PROD")    # Stage.PROD

# 原理
Stage["DEV"]     # 直接访问：Stage.DEV
Stage["CANARY"]  # 直接访问：Stage.CANARY

实战示例：@classmethod vs 普通函数

# ❌ 如果不用 @classmethod，需要写成函数
def get_stage_by_name(name):
    return Stage[name.upper()]

# 使用时：
stage = get_stage_by_name("dev")

# ✅ 使用 @classmethod
class Stage(Enum):
    DEV = auto()

    @classmethod
    def by_name(cls, name):
        return cls[name.upper()]

# 使用时：
stage = Stage.by_name("dev")
# 优点：
# 1. 方法和类绑定，逻辑内聚
# 2. 命名空间清晰 (Stage.by_name)
# 3. 继承时子类自动获得

@staticmethod 装饰器

基本概念

@staticmethod 将方法变成静态方法，不需要 self 或 cls 参数。

在 context.py 中的应用

class Context:
    # 实例方法
    def get_name(self) -> str:
        return self.name

    # 静态方法
    @staticmethod
    def get_value(data: object, name: str, default=""):
        """python
        通过点号路径访问嵌套字典

        这是一个工具函数，不需要访问实例或类
        """
        return Context.get_nested(data, name.split('.'), default)

    @staticmethod
    def get_nested(data: object, keys: list, default=""):
        """递归访问嵌套字典"""
        if len(keys) > 1 and keys[0] in data:
            return Context.get_nested(data[keys[0]], keys[1:])
        if len(keys) == 1 and keys[0] in data:
            return data[keys[0]]
        return default

为什么使用 @staticmethod？

原因 1：工具函数，不需要实例数据

# get_value 是一个纯函数，不依赖实例状态
data = {
    "terraform": {
        "backend": {
            "type": "s3"
        }
    }
}

# 调用时不需要创建 Context 实例
value = Context.get_value(data, "terraform.backend.type")
# 输出: "s3"

# 也可以通过实例调用（但不推荐）
context = Context("test")
value = context.get_value(data, "terraform.backend.type")

原因 2：命名空间组织

# ❌ 如果不用 @staticmethod，需要写成模块级函数
# utils.py
def get_nested_value(data, keys, default=""):
    ...

# context.py
from utils import get_nested_value

class Context:
    def get(self, name: str, default=""):
        return get_nested_value(self.data, name.split('.'), default)

# ✅ 使用 @staticmethod
class Context:
    @staticmethod
    def get_nested(data, keys, default=""):
        ...

    def get(self, name: str, default=""):
        # 方法和类绑定，逻辑内聚
        return Context.get_nested(self.data, name.split('.'), default)

@classmethod vs @staticmethod

class Example:
    class_variable = "I'm a class variable"

    @classmethod
    def class_method(cls, value):
        """
        需要访问类本身时使用
        - 工厂方法
        - 需要访问类变量
        - 需要返回类的实例
        """
        return cls(value)  # 可以创建实例

    @staticmethod
    def static_method(value):
        """
        不需要访问类或实例时使用
        - 纯工具函数
        - 只是逻辑上属于这个类
        - 命名空间组织
        """
        return value.upper()  # 纯函数

# 使用场景示例
class Hyperscaler(Enum):
    AWS = auto()

    @classmethod
    def by_name(cls, name):
        # ✅ 需要 cls 来访问枚举成员
        return cls[name.upper()]

    # 假设有一个验证函数
    @staticmethod
    def is_valid_name(name):
        # ✅ 不需要 cls，只是验证字符串
        return name.upper() in ["AWS", "AZURE", "GCP"]

@property 装饰器

基本概念

@property 将方法变成属性，可以像访问属性一样调用方法。

在 context.py 中的应用

class Context:
    def __init__(self, name: str, data=None) -> None:
        self.name = name
        self.data = data

    @property
    def landscape_type(self):
        """
        Derive LandscapeType from the stencil name prefix.

        使用 @property 后，可以像属性一样访问
        """
        prefix_map = {
            "hc-": LandscapeType.HANACLOUD,
            "vault-": LandscapeType.VAULT,
            "di-": LandscapeType.DI,
        }
        for prefix, landscape_type in prefix_map.items():
            if self.name.startswith(prefix):
                return landscape_type
        raise ValueError(f"Cannot determine LandscapeType for '{self.name}'")

# 使用
context = Context("hc-ap10")

# ✅ 使用 @property：像属性一样访问（不需要括号）
landscape_type = context.landscape_type
# 等价于: landscape_type = context.landscape_type()，但更优雅

# ❌ 如果不用 @property，需要这样调用
# landscape_type = context.landscape_type()  # 需要括号

为什么使用 @property？

原因 1：计算属性（Computed Property）

class Context:
    def __init__(self, name: str) -> None:
        self.name = name

    @property
    def landscape_type(self):
        """
        每次访问时动态计算，不存储
        """
        if self.name.startswith("hc-"):
            return LandscapeType.HANACLOUD
        elif self.name.startswith("di-"):
            return LandscapeType.DI
        # ...

# 优点：
# 1. 不需要存储 landscape_type，节省内存
# 2. 总是返回最新计算结果
# 3. 使用时像普通属性

context = Context("hc-ap10")
print(context.landscape_type)  # LandscapeType.HANACLOUD

原因 2：封装计算逻辑

# ❌ 没有 @property：外部需要知道计算逻辑
class Context:
    def __init__(self, name: str) -> None:
        self.name = name

context = Context("hc-ap10")
# 调用者需要知道如何判断
if context.name.startswith("hc-"):
    landscape_type = LandscapeType.HANACLOUD

# ✅ 使用 @property：封装计算逻辑
class Context:
    @property
    def landscape_type(self):
        # 计算逻辑封装在类内部
        if self.name.startswith("hc-"):
            return LandscapeType.HANACLOUD

context = Context("hc-ap10")
landscape_type = context.landscape_type  # 简洁清晰

@property 的 Getter/Setter 模式

class Context:
    def __init__(self, name: str) -> None:
        self._name = name  # 私有属性

    @property
    def name(self):
        """Getter：读取属性"""
        return self._name

    @name.setter
    def name(self, value):
        """Setter：设置属性时的验证"""
        if not value:
            raise ValueError("Name cannot be empty")
        self._name = value

    @name.deleter
    def name(self):
        """Deleter：删除属性时的处理"""
        print(f"Deleting name: {self._name}")
        del self._name

# 使用
context = Context("test")

# Getter
print(context.name)  # "test"

# Setter
context.name = "new-name"  # 调用 setter，会验证

# Deleter
del context.name  # 调用 deleter

@dataclass (Python 3.7+)

from dataclasses import dataclass

# ❌ 传统方式：手动写 __init__

        self.y = y

@dataclass

@abstractmethod

from abc import ABC, abstractmethod

class Account(ABC):
    """抽象基类"""

    @abstractmethod
    def login(self, vault_client):
        """抽象方法：子类必须实现"""
        pass

    @abstractmethod
    def logout(self):
        """抽象方法：子类必须实现"""
        pass

class AccountAws(Account):
    def login(self, vault_client):
        # ✅ 必须实现
        print("AWS login")

    def logout(self):
        # ✅ 必须实现
        print("AWS logout")

# ❌ 如果不实现抽象方法，实例化时会报错
class AccountBroken(Account):
    pass

# TypeError: Can't instantiate abstract class AccountBroken
# account = AccountBroken()

@functools.lru_cache（缓存装饰器）

from functools import lru_cache

class Context:
    @lru_cache(maxsize=128)
    @staticmethod
    def get_value(data, name, default=""):
        """
        缓存函数结果，相同输入直接返回缓存
        """
        print(f"Computing for {name}")
        return Context.get_nested(data, name.split('.'), default)

# 第一次调用
Context.get_value(data, "terraform.backend")  # 打印 "Computing..."

# 第二次调用：直接返回缓存，不打印
Context.get_value(data, "terraform.backend")  # 直接返回

实战示例

完整示例：context.py 中的模式

from enum import Enum, auto, unique

# 1. @unique + auto()：定义枚举
@unique
class Hyperscaler(Enum):
    AWS = auto()        # 自动赋值 1
    AZURE = auto()      # 自动赋值 2
    GCP = auto()        # 自动赋值 3

    # 2. @classmethod：类方法
    @classmethod
    def by_name(cls, name):
        """根据字符串获取枚举成员"""
        return cls[name.upper()]

# 3. @staticmethod：静态方法
class Context:
    def __init__(self, name: str) -> None:
        self.name = name

    @staticmethod
    def get_value(data: dict, name: str, default=""):
        """通过点号路径访问嵌套字典（工具函数）"""
        return Context.get_nested(data, name.split('.'), default)

    @staticmethod
    def get_nested(data: dict, keys: list, default=""):
        """递归访问嵌套字典"""
        if len(keys) > 1 and keys[0] in data:
            return Context.get_nested(data[keys[0]], keys[1:])
        if len(keys) == 1 and keys[0] in data:
            return data[keys[0]]
        return default

    # 4. @property：属性
    @property
    def landscape_type(self):
        """计算属性：根据名称判断类型"""
        if self.name.startswith("hc-"):
            return "HANACLOUD"
        elif self.name.startswith("di-"):
            return "DI"
        return "UNKNOWN"

# 使用示例
# 1. 枚举
hyperscaler = Hyperscaler.by_name("aws")  # Hyperscaler.AWS
print(hyperscaler.value)  # 1

# 2. 静态方法
data = {"terraform": {"backend": {"type": "s3"}}}
backend_type = Context.get_value(data, "terraform.backend.type")
print(backend_type)  # "s3"

# 3. 属性
context = Context("hc-ap10")
print(context.landscape_type)  # "HANACLOUD"

记忆技巧

  • auto()：auto = automatic（自动），自动生成枚举值
  • @unique：unique = 唯一，确保枚举值唯一
  • @classmethod：第一个参数是 cls（class）
  • @staticmethod：static = 静态，不需要实例或类
  • @property：property = 属性，像属性一样访问
