阅读线索

这是一份 React 页面组件的分段阅读说明。按依赖导入、主组件、导航与 Hero、主体内容、导出的顺序，可以把页面外观对应回组件结构。

引入 React

import React from 'react'

  • React 是一个 前端框架，用来写网页。

  • 它的核心思想是：一个页面就是很多小组件拼起来的。

  • 这里 React 本身用来告诉浏览器：我们写的这些东西是“组件”。

引入一些自定义组件

import { Billing, Business, CardDeal, Clients, CTA, Footer, Hero, Navbar, Stats, Testimonials } from './components'

  • ./components 是一个文件夹，里面放了很多小的“积木块”，比如：

    • Navbar → 顶部导航栏

    • Hero → 页面最上面的宣传大图/标题区

    • Stats → 数据展示区（比如多少用户）

    • Business → 介绍业务

    • Billing → 账单/支付相关介绍

    • CardDeal → 卡片式的优惠或方案

    • Testimonials → 用户评价

    • Clients → 合作伙伴的 logo

    • CTA → “Call To Action”，号召性按钮，比如“立即注册”

    • Footer → 页脚

👉 这些就是网页的一块一块区域，你可以理解成“乐高积木”，把它们拼起来就是一个完整页面。

引入样式

import styles from './style'

  • 这个 style.js 文件里写了一些通用的样式规则。

  • 它不是传统的 CSS 文件，而是把 Tailwind CSS 这样的工具封装了一下，方便调用。

  • 例如 styles.boxWidth 就可能是“页面内容最大宽度 1200px 居中显示”。

写一个主组件 App

const App = () => { return ( ... ) }

  • 这里 App 是整个网站的主入口，所有东西都拼在里面。

  • React 的语法长得像 HTML，但其实是 JSX（JavaScript + XML），就是“在 JS 里写标签”。

页面结构

<div className='bg-primary w-full overflow-hidden'>

  • 这个最外层的 <div> 就是整个网页的背景容器。

  • bg-primary w-full overflow-hidden 这些是 Tailwind CSS 的类名：

    • bg-primary → 背景色用主题色

    • w-full → 宽度占满整个屏幕

    • overflow-hidden → 超出部分不显示

分：导航栏

<div className={`${styles.paddingX} ${styles.flexCenter}`}> <div className={`${styles.boxWidth}`}> <Navbar/> </div> </div>

  • 外面两层 <div> 只是用来控制位置和宽度。

  • 里面 <Navbar/> 就是导航栏组件。

分：Hero 区域

<div className={`bg-primary ${styles.flexStart}`}> <div className={`${styles.boxWidth}`}> <Hero/> </div> </div>

  • Hero 通常是网站首页的“头图”，带标题、按钮的那一块。

分：主体内容

<div className={`bg-primary ${styles.paddingX} ${styles.flexStart}`}> <div className={`${styles.boxWidth}`}> <Stats/> <Business/> <Billing/> <CardDeal/> <Testimonials/> <Clients/> <CTA/> <Footer/> </div> </div>

  • 这就是剩下的主要内容：

    • Stats → 数据展示

    • Business → 业务介绍

    • Billing → 支付功能

    • CardDeal → 优惠方案

    • Testimonials → 用户评价

    • Clients → 合作伙伴

    • CTA → 行动按钮

    • Footer → 页脚

导出 App

export default App

  • 这句话意思是：App 组件可以被别的地方使用。

  • 比如在 index.js 里会写：

    import App from './App'

    然后 ReactDOM.render(<App/>, document.getElementById('root'))
    就能把整个网站渲染到浏览器。
