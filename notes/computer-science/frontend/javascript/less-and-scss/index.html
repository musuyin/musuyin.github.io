LESS 与 SCSS 对照

2026-08-06

阅读线索

这份笔记的主体是 LESS，包含变量、嵌套、Mixin、继承以及 React 中的引入方式；SCSS 主要出现在最后的对照中。阅读时应以代码扩展名和语法为准。

.less 是 LESS（Leaner Style Sheets） 文件的后缀喵！它是一种 CSS 预处理器，类似于 SCSS（Sass），可以让 CSS 代码更简洁、更强大喵！✨

.less 的作用

LESS 扩展了 CSS，让它支持：

  • 变量（像 JS 一样存值）
  • 嵌套（像 Vue/React 组件一样写 CSS）
  • Mixin（混入） （类似函数，可以复用样式）
  • 运算（可以做加减乘除）
  • 继承（减少代码重复）

.less vs .css

LESS 其实就是 CSS 的升级版，但需要编译成普通的 CSS 才能在浏览器中使用喵！

普通 CSS：

.button {
  background-color: blue;
  color: white;
  padding: 10px;
}

LESS 版本（更简洁）

@main-color: blue;

.button {
  background-color: @main-color;
  color: white;
  padding: 10px;
}

这里的 @main-color 是变量，可以在整个文件里重复使用！✨

LESS 的核心语法

变量

LESS 允许使用 @变量名 定义变量，避免重复写相同的值喵！

@primary-color: #3498db;
@padding-size: 10px;

.button {
  background-color: @primary-color;
  padding: @padding-size;
}

嵌套

LESS 允许像 Vue/React 组件那样 嵌套 CSS，更清晰喵！

.nav {
  background: #333;
  color: white;
  
  a {
    color: inherit;
    text-decoration: none;
    
    &:hover {
      color: yellow;
    }
  }
}

& 代表 父选择器，&:hover 就相当于 .nav a:hover。

Mixin（混入，可复用）

Mixin 类似函数，可以定义一组样式，然后在不同地方复用喵！

// 定义 Mixin
.border-radius(@radius) {
  border-radius: @radius;
  -webkit-border-radius: @radius;
  -moz-border-radius: @radius;
}

// 使用 Mixin
.box {
  width: 100px;
  height: 100px;
  background: red;
  .border-radius(10px); // 复用 border-radius
}

继承（extend ）

LESS 允许一个类 继承另一个类的样式：

.button {
  padding: 10px;
  background: blue;
  color: white;
}

.primary-button {
  &:extend(.button); // 继承 .button 样式
  font-weight: bold;
}

React 项目如何使用 LESS

在 React 项目中，吾们可以安装 less 并在组件中引入 .less 文件：

安装 LESS

npm install less

在 React 组件中引入 .less

import "./styles.less";

function App() {
  return <button className="btn">点击我喵！</button>;
}

export default App;

创建 styles.less

.btn {
  background: @main-color;
  padding: 10px;
  border: none;
  color: white;
}

@main-color: purple;

这样，React 组件就能使用 LESS 样式喵！✨(ฅ´ω`ฅ)

LESS vs SCSS（Sass）

LESS 和 SCSS（Sass）都很流行，但有些不同喵：

特性 LESS SCSS（Sass）
变量 @variable $variable
兼容 CSS ✅ 完全兼容 ✅ 完全兼容
主要使用者 早期Ant Design等 Vue、React主流框架

结论：

  • LESS 比较简单，适合 老项目 或 Ant Design（因为它默认使用 LESS）。
  • SCSS（Sass）更强大，现代 Vue/React 项目大多数用 SCSS。

总结

✅ .less 是 CSS 预处理器，让 CSS 代码更灵活喵！
✅ 支持变量、嵌套、Mixin、继承，可以减少代码重复。
✅ 在 Vue 和 React 项目中，都可以直接使用 LESS 进行样式管理喵！
