朴素贝叶斯法

2026-03-23

#统计学习#机器学习

阅读线索

朴素贝叶斯先估计类别先验与条件分布，再用条件独立性把联合条件概率拆成乘积。平滑处理零频次问题，但不会把独立性假设自动变成事实。

朴素贝叶斯法（Naive Bayes）是基于贝叶斯定理与条件独立性假设的分类方法，属于生成模型。

“朴素”的含义：假设各特征在给定类别下条件独立，这一假设在现实中往往不成立，但简化了计算且效果出奇地好。

比喻：判断一封邮件是否是垃圾邮件，假设“打折”和“促销”这两个词的出现彼此独立（只要类别相同），分别计算概率然后相乘。

学习与分类

基本原理

训练数据集由 P(X,Y)P(X, Y)P(X,Y) 独立同分布产生：

T={(x1,y1),(x2,y2),…,(xN,yN)}T = \{(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)\}T={(x1​,y1​),(x2​,y2​),…,(xN​,yN​)}

朴素贝叶斯通过训练数据学习联合概率分布 P(X,Y)P(X, Y)P(X,Y)：

  1. 学习先验概率：P(Y=ck),k=1,2,…,KP(Y = c_k), \quad k = 1, 2, \dots, KP(Y=ck​),k=1,2,…,K
  2. 学习条件概率（利用条件独立性假设）：
P(X=x∣Y=ck)=P(X(1)=x(1),…,X(n)=x(n)∣Y=ck)=∏j=1nP(X(j)=x(j)∣Y=ck)P(X = x | Y = c_k) = P(X^{(1)} = x^{(1)}, \dots, X^{(n)} = x^{(n)} | Y = c_k) = \prod_{j=1}^{n} P(X^{(j)} = x^{(j)} | Y = c_k)P(X=x∣Y=ck​)=P(X(1)=x(1),…,X(n)=x(n)∣Y=ck​)=j=1∏n​P(X(j)=x(j)∣Y=ck​)

参数估计

极大似然估计

先验概率的极大似然估计：

P(Y=ck)=∑i=1N1[yi=ck]N,k=1,2,…,KP(Y = c_k) = \frac{\sum_{i=1}^{N} \mathbf{1}[y_i = c_k]}{N}, \quad k = 1, 2, \dots, KP(Y=ck​)=N∑i=1N​1[yi​=ck​]​,k=1,2,…,K

条件概率的极大似然估计（对第 jjj 个特征，取值为 ajla_{jl}ajl​）：

P(X(j)=ajl∣Y=ck)=∑i=1N1[xi(j)=ajl,yi=ck]∑i=1N1[yi=ck]P(X^{(j)} = a_{jl} | Y = c_k) = \frac{\sum_{i=1}^{N} \mathbf{1}[x_i^{(j)} = a_{jl}, y_i = c_k]}{\sum_{i=1}^{N} \mathbf{1}[y_i = c_k]}P(X(j)=ajl​∣Y=ck​)=∑i=1N​1[yi​=ck​]∑i=1N​1[xi(j)​=ajl​,yi​=ck​]​

问题：若某个特征值在某类中从未出现，则该条件概率为 0，导致整个乘积为 0，使分类失效。

贝叶斯估计（拉普拉斯平滑）

为解决零概率问题，用贝叶斯估计（等价于拉普拉斯平滑）：

Pλ(X(j)=ajl∣Y=ck)=∑i=1N1[xi(j)=ajl,yi=ck]+λ∑i=1N1[yi=ck]+SjλP_\lambda(X^{(j)} = a_{jl} | Y = c_k) = \frac{\sum_{i=1}^{N} \mathbf{1}[x_i^{(j)} = a_{jl}, y_i = c_k] + \lambda}{\sum_{i=1}^{N} \mathbf{1}[y_i = c_k] + S_j \lambda}Pλ​(X(j)=ajl​∣Y=ck​)=∑i=1N​1[yi​=ck​]+Sj​λ∑i=1N​1[xi(j)​=ajl​,yi​=ck​]+λ​

其中 SjS_jSj​ 是第 jjj 个特征的取值个数，λ≥0\lambda \geq 0λ≥0。

  • λ=0\lambda = 0λ=0：退化为极大似然估计
  • λ=1\lambda = 1λ=1：拉普拉斯平滑（最常用）

先验概率的贝叶斯估计：

Pλ(Y=ck)=∑i=1N1[yi=ck]+λN+KλP_\lambda(Y = c_k) = \frac{\sum_{i=1}^{N} \mathbf{1}[y_i = c_k] + \lambda}{N + K\lambda}Pλ​(Y=ck​)=N+Kλ∑i=1N​1[yi​=ck​]+λ​

特点总结

特点 说明
优点 算法简单，学习和预测效率高，所需估计参数少
缺点 条件独立性假设往往不成立，精度可能较低
适用场景 文本分类（垃圾邮件过滤）、实时预测（需要快速响应）
模型类型 生成模型（学习联合分布 P(X,Y)P(X,Y)P(X,Y)）
