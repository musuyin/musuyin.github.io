决策树

2026-03-30

#统计学习#机器学习

阅读线索

决策树通过特征测试划分输入空间，叶节点给出类别或预测值。生成、特征选择和剪枝分别处理划分方式、局部收益及复杂度控制。

决策树模型

分类决策树模型是一种描述对实例进行分类的树形结构。

决策树由以下内容组成：

  • 结点（node）
    • 内部结点（internal node）：表示一个特征或属性
    • 叶结点（leaf node）：表示一个类
  • 有向边（directed edge）

分类过程：从根结点开始，对实例某一特征进行测试，根据测试结果分配到子结点；递归测试，直至到达叶结点，将实例归入该叶结点对应的类。

if-then 规则

决策树的路径（或其对应的 if-then 规则集合）具有互斥并完备的特性：每一个实例都被且仅被一条路径或规则覆盖。

条件概率分布

决策树表示给定特征条件下类的条件概率分布。

  • 特征空间被划分为互不相交的单元（cell）/ 区域（region）
  • 每个单元定义一个类的概率分布
  • 决策树的一条路径对应一个单元

设 XXX 为特征随机变量，YYY 为类随机变量，条件概率分布为 P(Y∣X)P(Y|X)P(Y∣X)。各叶结点上条件概率往往偏向某一类，决策时将实例分到概率最大的类。

决策树学习

决策树学习的本质是从训练数据集中归纳出一组分类规则。

  • 目标：与训练数据矛盾较小，同时具有良好的泛化能力
  • 指标：损失函数（通常是正则化的极大似然函数）
  • 策略：以损失函数最小化为目标

由于最优决策树是 NP 完全问题，采用启发式方法，得到次最优决策树。

递归选择最优特征

  1. 所有训练数据在根结点，选择最优特征
  2. 根据最优特征将训练数据分割为若干子集：
    • 子集能被正确分类 → 构建叶结点
    • 子集不能被正确分类 → 选新的最优特征，继续分割
  3. 递归直到所有子集都被正确分类或没有更好的特征

特征选择

特征选择问题

特征选择的目标：选择对训练数据有较强分类能力的特征，使树尽量小。

关键指标：信息增益和信息增益比。

信息增益

信息增益（Information Gain）表示特征 AAA 对训练数据集 DDD 的分类能力：

g(D,A)=H(D)−H(D∣A)g(D, A) = H(D) - H(D | A)g(D,A)=H(D)−H(D∣A)

信息增益比

信息增益偏向取值多的特征（极端情况：用 ID 作为特征，信息增益最大但毫无意义）。

决策树生成

ID3 算法

ID3 算法以信息增益为特征选择准则，递归构建决策树。

算法流程：

  1. 若 DDD 中所有实例属于同一类 CkC_kCk​，则该结点为叶结点，返回类 CkC_kCk​
  2. 若 A=∅A = \emptysetA=∅（特征集为空），则返回训练数据中实例数最多的类
  3. 计算 AAA 中每个特征的信息增益，选择信息增益最大的特征 AgA_gAg​
  4. 若 AgA_gAg​ 的信息增益小于阈值 ε\varepsilonε，则置为叶结点
  5. 对 AgA_gAg​ 的每个取值 aia_iai​，划分子集 DiD_iDi​，递归建子树

缺点：只能处理离散特征，容易过拟合，倾向选取取值多的特征。

C4.5 算法

C4.5 算法是 ID3 的改进：

  • 使用信息增益比代替信息增益
  • 可以处理连续特征（二分法：枚举阈值，选择信息增益比最大的切分点）
  • 使用剪枝处理过拟合

决策树剪枝

剪枝是解决过拟合的主要手段。

剪枝策略

  • 预剪枝（Pre-pruning）：在树的生成过程中，提前停止分裂（简单但可能欠拟合）
  • 后剪枝（Post-pruning）：先生成完整的树，再自底向上剪枝（更常用）

后剪枝步骤：

  1. 生成完整决策树
  2. 从叶结点开始，自底向上对每个内部结点计算：
    • 剪枝前的损失函数值 Cα(Tt)C_\alpha(T_t)Cα​(Tt​)
    • 剪枝后（将该结点变为叶结点）的损失函数值 Cα(Tb)C_\alpha(T_b)Cα​(Tb​)
  3. 若 Cα(Tb)≤Cα(Tt)C_\alpha(T_b) \leq C_\alpha(T_t)Cα​(Tb​)≤Cα​(Tt​)，则剪枝
  4. 递归直到不能再剪

CART 算法

CART（Classification And Regression Tree）既可用于分类，也可用于回归，生成二叉树。

CART 生成

基尼指数（Gini Index）衡量数据集的不纯度：

Gini(D)=∑k=1Kpk(1−pk)=1−∑k=1Kpk2\text{Gini}(D) = \sum_{k=1}^{K} p_k(1 - p_k) = 1 - \sum_{k=1}^{K} p_k^2Gini(D)=k=1∑K​pk​(1−pk​)=1−k=1∑K​pk2​

基尼指数越小，数据集纯度越高（与熵的含义类似，但计算更快）。

每次选择使条件基尼指数最小的特征和切分点。
