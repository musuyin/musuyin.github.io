提升方法

2026-04-20

#统计学习#机器学习

阅读线索

提升方法逐步添加弱学习器来改进整体模型。AdaBoost 通过样本权重和分类器系数组织加法模型，回归提升树与梯度提升则根据损失产生新的拟合目标。

提升方法（Boosting）是将弱学习器组合为强学习器的集成方法。

核心思想：通过改变训练数据的权重分布，反复学习多个弱分类器，然后将这些弱分类器组合成一个强分类器。

比喻：就像组建一个专家委员会——每个专家（弱分类器）只擅长某一方面，但联合投票决策后，整体准确率大幅提升。 与简单投票（Bagging）不同的是，Boosting 中的专家是有侧重点的——下一个专家重点关注上一个专家犯错的地方。

AdaBoost 算法

AdaBoost（Adaptive Boosting）是最经典的提升算法。

AdaBoost 与加法模型

前向分步算法

AdaBoost 可以理解为加法模型（Additive Model）+ 前向分步算法（Forward Stagewise Algorithm）。

加法模型：

f(x)=∑m=1Mβmb(x;γm)f(x) = \sum_{m=1}^{M} \beta_m b(x; \gamma_m)f(x)=m=1∑M​βm​b(x;γm​)

前向分步算法每轮只优化当前步的损失，固定之前的参数：

(βm,γm)=arg⁡min⁡β,γ∑i=1NL(yi,fm−1(xi)+βb(xi;γ))(\beta_m, \gamma_m) = \arg\min_{\beta, \gamma} \sum_{i=1}^{N} L\left(y_i, f_{m-1}(x_i) + \beta b(x_i; \gamma)\right)(βm​,γm​)=argβ,γmin​i=1∑N​L(yi​,fm−1​(xi​)+βb(xi​;γ))

AdaBoost = 前向分步算法 + 指数损失函数 L(y,f)=e−yfL(y, f) = e^{-yf}L(y,f)=e−yf

提升树

基本概念

提升树（Boosting Tree）以决策树（通常是 CART）作为基学习器的提升方法。

fM(x)=∑m=1MT(x;Θm)f_M(x) = \sum_{m=1}^{M} T(x; \Theta_m)fM​(x)=m=1∑M​T(x;Θm​)

其中 T(x;Θm)T(x; \Theta_m)T(x;Θm​) 是第 mmm 棵决策树，Θm\Theta_mΘm​ 是其参数。

回归提升树

对于回归问题，使用平方误差损失。每轮拟合的是当前模型的残差：

rmi=yi−fm−1(xi)r_{mi} = y_i - f_{m-1}(x_i)rmi​=yi​−fm−1​(xi​)

即下一棵树学习的目标是纠正上一轮的错误。

梯度提升树（GBDT）

当损失函数不是平方误差（如分类问题）时，使用负梯度近似残差：

rmi=−[∂L(yi,f(xi))∂f(xi)]f=fm−1r_{mi} = -\left[ \frac{\partial L(y_i, f(x_i))}{\partial f(x_i)} \right]_{f = f_{m-1}}rmi​=−[∂f(xi​)∂L(yi​,f(xi​))​]f=fm−1​​

GBDT（Gradient Boosting Decision Tree）是目前最常用的机器学习算法之一，XGBoost、LightGBM 均基于此思想。

Bagging vs Boosting

Bagging Boosting
训练方式 并行，独立训练 串行，依赖前一轮
数据采样 有放回随机采样 调整权值分布
关注点 减小方差（Variance） 减小偏差（Bias）
代表算法 随机森林 AdaBoost、GBDT
过拟合风险 较低 若迭代轮数过多会过拟合
