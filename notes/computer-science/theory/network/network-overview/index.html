计算机网络概述

2024-09-13

#计算机网络

阅读线索

网络概述从端系统、接入网络和核心交换建立整体结构，再用时延、吞吐量和分层解释数据怎样穿过网络。分组交换与电路交换的资源分配方式不同。

什么是因特网

具体构成

计算机网络是用通信设备和线路将分散在不同地点的多个计算机互联，并按照网络协议进行数据通信，实现资源共享的计算机集合。

三个核心要素：

  • 多个计算机：为用户提供服务的端系统
  • 通信子网：通信设备（路由器、交换机）和传输线路
  • 一系列协议：保证数据通信正确进行

因特网是全球最大的计算机网络，将遍布全世界的数十亿设备互联。这些设备统称为主机（host）或端系统（end system）。

通信链路与分组交换

端系统通过**通信链路（communication link）和分组交换机（packet switch）**连接在一起。

  • 通信链路：由同轴电缆、铜线、光纤、无线电频谱等物理媒体组成，用**传输速率（transmission rate，bps）**衡量
  • 分组（packet）：发送端将数据分段并附上首部字节后形成的数据包
  • 分组交换机：接收入链路上的分组，并从出链路转发出去
    • 路由器（router）：用于网络核心
    • 链路层交换机（link-layer switch）：用于接入网
  • 从源到目的地经过的一系列链路和交换机，称为路径（path/route）

ISP 与协议

  • 端系统通过**ISP（Internet Service Provider，因特网服务提供商）**接入因特网
    • 各 ISP 之间通过高速光纤互联，形成层次化结构（较低层 ISP → 较高层 ISP）
  • 所有因特网部件都运行协议（protocol），控制信息的接收和发送
    • TCP（Transmission Control Protocol，传输控制协议）
    • IP（Internet Protocol，网际协议）：定义路由器和端系统间分组的格式
  • 因特网标准由 **IETF（因特网工程任务组）**制定，文档称为 RFC（Request For Comment）

服务角度描述

从服务角度看，因特网是为分布式应用程序提供服务的基础设施。

  • 分布式应用程序：涉及多个相互交换数据的端系统的应用，运行在端系统上（不在网络核心中）
  • 端系统提供套接字接口（socket interface），规定了应用程序如何请求因特网将数据交付给目的地程序

什么是协议

**协议（protocol）**定义了在两个或多个通信实体之间交换的报文的格式和顺序，以及报文发送/接收时所采取的动作。

三要素：

要素 含义
语法 数据与控制信息的结构或格式，信号电平
语义 控制信息的含义、动作与差错控制
时序 事件顺序、速度匹配

网络边缘

端系统

  • 位于因特网边缘的设备，也称主机（host），负责运行应用程序
  • 两种应用模型：
    • 客户/服务器（C/S）：客户发送请求，服务器响应
    • P2P（Peer-to-Peer）：通信在对等实体间直接进行

接入网络

接入网将端系统物理连接到边缘路由器（edge router）（端系统通往远程主机路径上的第一台路由器）。

家庭接入

DSL（数字用户线）
  • 利用现有电话线（双绞铜线），通过 DSLAM（数字用户线接入复用器） 交换数据
  • 同一条线路用**频分复用（FDM）**同时承载数据和电话信号：
    • 高速下行：50kHz～1MHz
    • 中速上行：4kHz～50kHz
    • 普通电话：0～4kHz
  • 上下行速率不同，称为不对称接入（如 55Mbps 下行 / 15Mbps 上行）

电缆因特网接入（HFC）
  • 利用有线电视基础设施，由光纤连接电缆头端到地区枢纽，再由同轴电缆入户
  • 混合光纤同轴电缆（Hybrid Fiber Coax，HFC）系统
  • 使用电缆调制解调器（cable modem），同样是不对称接入

FTTH（光纤到户）
  • 提供更高速率，从本地中心局直接拉光纤到家
  • 光纤分布方案：
    • AON（主动光纤网络）：本质是交换式以太网
    • PON（被动光纤网络）：共享一根光纤到接近家庭处才分叉

企业接入

以太网（Ethernet）
  • 通过以太网交换机连接，速率从 10Mbps 到 10Gbps

广域无线接入

3G、4G、5G 蜂窝网络

物理媒体

比特通过发射器-接收器对，以电磁波或光脉冲形式通过**物理媒体（physical medium）**传播。

类型 描述
导引型媒体 电波沿固体媒体传播（光缆、铜线、同轴电缆）
非导引型媒体 电波在空气中传播（无线局域网、卫星）

常见媒体：

  • 双绞铜线（UTP）：最常见，用于 LAN，速率 10Mbps～10Gbps
  • 同轴电缆：两个同心导体，可作共享媒体，用于有线电视
  • 光纤：极高速（数十～数百 Gbps），抗干扰，衰减低，适合长途传输
  • 陆地无线电信道：穿墙、移动、长距离，受路径损耗和多径衰落影响
  • 卫星无线电信道：地球同步卫星（高时延 ≈270ms）或 LEO 近地轨道卫星

网络核心

网络核心是由互联因特网端系统的分组交换机和链路构成的网状网络。

核心功能：路由（routing）和转发（forwarding）

移动数据的两种基本方法：电路交换和分组交换。

分组交换

端系统将长报文划分为较小的分组（packet），每个分组独立通过路由器和链路传输到目的地。

存储转发传输

多数分组交换机使用存储转发（store-and-forward）：必须接收完整个分组后，才能向下一跳转发。

比喻：就像收快递，快递站必须收到整个包裹才会转发，而不是零件到一个转发一个。

  • 通过 NNN 条速率为 RRR 的链路（有 N−1N-1N−1 台路由器）发送 1 个 LLL 比特的分组：
d端到端=N⋅LRd_{\text{端到端}} = N \cdot \frac{L}{R}d端到端​=N⋅RL​
  • 发送 PPP 个分组：
d端到端=(N+P−1)⋅LRd_{\text{端到端}} = (N + P - 1) \cdot \frac{L}{R}d端到端​=(N+P−1)⋅RL​

排队时延与分组丢失

  • 每台路由器有输出缓存（output buffer），用于暂存等待转发的分组
  • 若缓存已满，新到达分组将被丢弃（丢包，packet loss）

转发表与路由选择协议

  • 每台路由器有转发表（forwarding table），将目的地址（或前缀）映射到输出链路
  • 路由选择协议（routing protocol）：自动计算最短路径并配置转发表

电路交换

通信前，网络在发送方和接收方之间建立一条专用电路（circuit），预留恒定带宽。

比喻：像打电话，通话前需要先“拨号建立连接”，整个通话期间这条线路专属于你。

特点：通话期间带宽确保、传输速率恒定，但空闲时段浪费资源。

电路复用

链路中的电路通过以下方式实现：

复用方式 全称 原理
FDM 频分多路复用 每条连接独占一段频率（带宽）
TDM 时分多路复用 时间分为帧，每帧内每条连接占一个时隙
CDM 码分多路复用 每用户使用不同的正交码片序列同时传输

分组交换 vs 电路交换

对比 分组交换 电路交换
资源使用 按需分配，可能排队 预先预留，可能浪费
实时性 可能有时延抖动 恒定速率，适合实时
效率 高（统计复用） 低（预留未用带宽）

网络的网络（ISP 层级结构）

因特网的 ISP 是分层次的：

  • 接入 ISP：直接服务用户
  • 区域 ISP：汇聚接入 ISP
  • 第一层（Tier-1）ISP：国际骨干 ISP，位于顶层，不向任何人付费
  • PoP（存在点）：提供商网络中的路由器群组，供客户 ISP 连接
  • 多宿（multi-home）：ISP 同时连接多个上游提供商，提高可靠性
  • 对等（peering）：同层 ISP 直接互联，流量不经过上层 ISP，通常无结算
  • IXP（因特网交换点）：多个 ISP 汇聚对等的地点

网络结构 5：在上述基础上，还有内容提供商网络（如 Google、Meta）绕开 Tier-1 ISP，直接与低层 ISP 对等，降低成本。

分组交换网中的时延、丢包和吞吐量

四种时延

分组从一个节点到下一个节点，经历四种时延：

时延类型 定义 量级
处理时延 检查分组首部、确定输出链路所需时间 微秒级
排队时延 在输出队列中等待传输的时间 微秒～毫秒
传输时延 将分组所有比特推向链路所需时间，dtrans=L/Rd_{trans} = L/Rdtrans​=L/R 毫秒级
传播时延 比特从链路起点传播到终点，dprop=d/sd_{prop} = d/sdprop​=d/s 毫秒级（广域网）

类比：传输时延 = 把货物装上火车的时间；传播时延 = 火车行驶的时间。

节点总时延：

dnodal=dproc+dqueue+dtrans+dpropd_{\text{nodal}} = d_{\text{proc}} + d_{\text{queue}} + d_{\text{trans}} + d_{\text{prop}}dnodal​=dproc​+dqueue​+dtrans​+dprop​

端到端时延（NNN 条链路，N−1N-1N−1 台路由器，忽略排队时延）：

dend-end=N(dproc+dtrans+dprop)d_{\text{end-end}} = N(d_{\text{proc}} + d_{\text{trans}} + d_{\text{prop}})dend-end​=N(dproc​+dtrans​+dprop​)

排队时延与流量强度

令 aaa 为分组到达速率（pkt/s），LLL 为分组大小（bits），RRR 为链路速率（bps），则：

流量强度 La/RLa/RLa/R：

  • La/R>1La/R > 1La/R>1：队列无限增长，时延趋向无穷大 → 不可接受
  • La/R≤1La/R \leq 1La/R≤1：时延取决于到达流量的性质（周期性 vs 突发性）

设计原则：流量强度不能大于 1！

吞吐量

  • 瞬时吞吐量：某时刻主机 B 接收文件的速率（bps）
  • 平均吞吐量：FFF 比特文件传输用时 TTT 秒，则平均吞吐量 = F/TF/TF/T bps

瓶颈链路（bottleneck link）：决定端到端吞吐量的链路，即速率最低的那段链路。

吞吐量=min⁡{R1,R2,…,RN}\text{吞吐量} = \min\{R_1, R_2, \ldots, R_N\}吞吐量=min{R1​,R2​,…,RN​}

协议层次及服务模型

分层体系结构

网络为何要分层？——就像快递公司分拣、运输、派送各司其职，每层只关心自己这一层的任务。

  • 协议分层：每个协议属于一个层次，每层向上提供服务（垂直），层内实现协议功能（水平）
  • 各层协议合称协议栈（protocol stack）

因特网五层协议栈

应用层

  • 网络应用及其协议所在层，信息分组称为报文（message）
  • 常见协议：HTTP（Web）、SMTP（邮件）、FTP（文件传输）、DNS

传输层

  • 在应用程序端点之间传送应用层报文，分组称为报文段（segment）
  • 两种协议：
    • TCP：面向连接、可靠传输、流量控制、拥塞控制
    • UDP：无连接、尽力而为、不可靠

网络层

  • 将**数据报（datagram）**从一台主机移动到另一台主机
  • 核心协议：IP（定义数据报格式及路由）；路由选择协议决定转发路径
  • 主要功能：路由（routing）、转发（forwarding）

链路层

  • 负责将数据报通过单条链路从一个节点移动到下一个节点，分组称为帧（frame）
  • 示例：以太网（Ethernet）、WiFi、DOCSIS
  • 主要功能：组帧、物理寻址（MAC）、流量/差错控制、媒体访问控制

物理层

  • 将帧中一个个比特从一个节点移动到下一个节点
  • 依赖具体的物理媒体（铜线、光纤等）
  • 传输模式：单工 / 半双工 / 全双工

OSI 七层模型

OSI 在五层基础上多了两层：

层 功能
表示层 数据格式转换、加密/解密、压缩/解压缩
会话层 对话控制、同步（在数据流中插入同步点）

因特网的协议栈没有单独的表示层和会话层，其功能由应用层实现。

封装（Encapsulation）

数据从发送端向下流经各层，每层添加首部（header）；到达接收端后再逐层解封。

应用层报文 M
  ↓ + 传输层首部 Ht → 传输层报文段
  ↓ + 网络层首部 Hn → 网络层数据报
  ↓ + 链路层首部 Hl → 链路层帧
  • 每层分组由首部字段和**有效载荷字段（payload）**组成，有效载荷来自上一层
  • 路由器只实现物理层、链路层、网络层；链路层交换机只实现物理层和链路层
