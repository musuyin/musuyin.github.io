字符串匹配与哈希

2026-10-28

#KMP#Trie#哈希表

阅读线索

KMP 通过模式串的前缀结构复用匹配结果，字符串哈希通过数值摘要快速比较。前者依赖 next 定义，后者还需要认识碰撞与数值范围。

KMP

给定文本串 text 和模式串 pattern，返回模式串第一次出现的位置，不存在时返回 −1-1−1。

前缀函数

prefix[i] 表示模式串前缀 pattern[0..i] 的最长相等真前缀与真后缀长度。匹配失败时，不需要把文本指针回退，只把模式指针退到较短的可复用前缀。

例如已经匹配 pattern[0..j-1]，下一个字符失败，则令 j = prefix[j - 1] 继续比较。每次回退都会缩短当前匹配长度，总复杂度为 O(n+m)O(n+m)O(n+m)。

int kmpSearch(String text, String pattern) {
    int[] prefix = prefixFunction(pattern);
    for (int i = 0, j = 0; i < text.length(); i++) {
        while (j > 0 && text.charAt(i) != pattern.charAt(j)) {
            j = prefix[j - 1];
        }
        if (text.charAt(i) == pattern.charAt(j)) {
            j++;
        }
        if (j == pattern.length()) {
            return i - pattern.length() + 1;
        }
    }
    return -1;
}

int[] prefixFunction(String pattern) {
    int[] prefix = new int[pattern.length()];
    for (int i = 1, j = 0; i < pattern.length(); i++) {
        while (j > 0 && pattern.charAt(i) != pattern.charAt(j)) {
            j = prefix[j - 1];
        }
        if (pattern.charAt(i) == pattern.charAt(j)) {
            j++;
        }
        prefix[i] = j;
    }
    return prefix;
}

Trie 字典树

维护一个只包含小写字母的字符串集合，支持插入字符串和查询某个字符串出现的次数。

思路

Trie 的边表示字符，从根到某个节点的路径表示一个前缀。共享前缀只存储一次，终止计数放在字符串最后一个字符对应的节点上。插入和查询复杂度均为字符串长度。

class Trie {
    private final int[][] next;
    private final int[] terminalCount;
    private int size;

    Trie(int totalCharacters) {
        next = new int[totalCharacters + 1][26];
        terminalCount = new int[totalCharacters + 1];
    }

    void insert(String word) {
        int node = 0;
        for (int i = 0; i < word.length(); i++) {
            int letter = word.charAt(i) - 'a';
            if (next[node][letter] == 0) {
                next[node][letter] = ++size;
            }
            node = next[node][letter];
        }
        terminalCount[node]++;
    }

    int count(String word) {
        int node = 0;
        for (int i = 0; i < word.length(); i++) {
            node = next[node][word.charAt(i) - 'a'];
            if (node == 0) {
                return 0;
            }
        }
        return terminalCount[node];
    }
}

最大异或对

给定 NNN 个非负整数，从中选择两个数，使二者异或值最大。

思路

把每个整数从最高位到最低位插入二进制 Trie。查询 xxx 时，每一位优先走与 xxx 当前位相反的分支，使答案的该位为 111；若不存在才走相同分支。高位的选择优先级高于所有低位。

int maximumXorPair(int[] nums) {
    int[][] next = new int[nums.length * 31 + 1][2];
    int size = 0;
    for (int x : nums) {
        int node = 0;
        for (int bit = 30; bit >= 0; bit--) {
            int value = x >>> bit & 1;
            if (next[node][value] == 0) {
                next[node][value] = ++size;
            }
            node = next[node][value];
        }
    }
    int answer = 0;
    for (int x : nums) {
        int node = 0;
        int value = 0;
        for (int bit = 30; bit >= 0; bit--) {
            int current = x >>> bit & 1;
            int desired = current ^ 1;
            if (next[node][desired] != 0) {
                value |= 1 << bit;
                node = next[node][desired];
            } else {
                node = next[node][current];
            }
        }
        answer = Math.max(answer, value);
    }
    return answer;
}

哈希冲突

整数哈希通常先通过 Math.floorMod(value, bucketCount) 映射到桶。冲突处理有两种常见方式：

  • 拉链法：每个桶保存一条链，适合删除和动态扩容。
  • 开放寻址法：发生冲突后继续探测其他槽位，缓存局部性更好，但需要控制装载因子。
class ChainedIntSet {
    private final List<Integer>[] buckets;

    @SuppressWarnings("unchecked")
    ChainedIntSet(int bucketCount) {
        buckets = new List[bucketCount];
        for (int i = 0; i < bucketCount; i++) {
            buckets[i] = new ArrayList<>();
        }
    }

    void add(int value) {
        List<Integer> bucket = buckets[Math.floorMod(value, buckets.length)];
        if (!bucket.contains(value)) {
            bucket.add(value);
        }
    }

    boolean contains(int value) {
        return buckets[Math.floorMod(value, buckets.length)].contains(value);
    }
}

class OpenAddressIntSet {
    private final int[] values;
    private final boolean[] used;

    OpenAddressIntSet(int capacity) {
        values = new int[capacity];
        used = new boolean[capacity];
    }

    void add(int value) {
        int index = find(value);
        values[index] = value;
        used[index] = true;
    }

    boolean contains(int value) {
        int index = find(value);
        return used[index];
    }

    private int find(int value) {
        int index = Math.floorMod(value, values.length);
        while (used[index] && values[index] != value) {
            index = (index + 1) % values.length;
        }
        return index;
    }
}

字符串前缀哈希

把字符串视为 PPP 进制数。令 h(i)h(i)h(i) 为前 iii 个字符的哈希，p(i)=Pip(i)=P^ip(i)=Pi，则左闭右开子串 [l,r)[l,r)[l,r) 的哈希为：

hash(l,r)=h(r)−h(l)×p(r−l)hash(l,r)=h(r)-h(l) \times p(r-l)hash(l,r)=h(r)−h(l)×p(r−l)

构造后可以 O(1)O(1)O(1) 比较两个等长子串。使用 long 的自然溢出等价于对 2642^{64}264 取模，仍存在极低概率碰撞。

class StringHasher {
    private static final long BASE = 131;
    private final long[] prefix;
    private final long[] power;

    StringHasher(String text) {
        prefix = new long[text.length() + 1];
        power = new long[text.length() + 1];
        power[0] = 1;
        for (int i = 0; i < text.length(); i++) {
            prefix[i + 1] = prefix[i] * BASE + text.charAt(i);
            power[i + 1] = power[i] * BASE;
        }
    }

    long hash(int left, int right) {
        return prefix[right] - prefix[left] * power[right - left];
    }
}

哈希表常见应用

两数之和

给定数组和目标值，返回两个元素之和等于目标值的下标。每个元素只能使用一次，题目保证存在唯一答案。

int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> index = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (index.containsKey(complement)) {
            return new int[]{index.get(complement), i};
        }
        index.put(nums[i], i);
    }
    throw new IllegalStateException();
}

Go 实现

func twoSum(nums []int, target int) []int {
	mp := make(map[int]int)
	for idx, num := range nums {
		if id, ok := mp[num]; ok {
			return []int{id, idx}
		}
		mp[target-num] = idx
	}
	panic("题目保证存在两数之和答案")
}

有效的字母异位词

判断两个只包含小写字母的字符串是否互为字母异位词。

boolean isAnagram(String first, String second) {
    if (first.length() != second.length()) {
        return false;
    }
    int[] count = new int[26];
    for (int i = 0; i < first.length(); i++) {
        count[first.charAt(i) - 'a']++;
        count[second.charAt(i) - 'a']--;
    }
    for (int value : count) {
        if (value != 0) {
            return false;
        }
    }
    return true;
}

Go 实现

func isAnagram(s string, t string) bool {
	if len(s) != len(t) {
		return false
	}
	cnts := make([]int, 26)
	for i := 0; i < len(s); i++ {
		cnts[s[i]-'a']++
		cnts[t[i]-'a']--
	}

	for i := 0; i < len(cnts); i++ {
		if cnts[i] != 0 {
			return false
		}
	}
	return true
}

两个数组的交集

返回两个整数数组的交集，每个元素在答案中只出现一次，顺序不限。

思路

先把第一个数组放入集合，遍历第二个数组时把命中的元素放入结果集合。两个集合分别完成查询和去重。

复杂度

  • 时间复杂度：期望 O(n+m)O(n+m)O(n+m)。
  • 空间复杂度：O(n+m)O(n+m)O(n+m)。
int[] arrayIntersection(int[] first, int[] second) {
    Set<Integer> values = new HashSet<>();
    for (int value : first) values.add(value);
    Set<Integer> intersection = new HashSet<>();
    for (int value : second) {
        if (values.contains(value)) intersection.add(value);
    }
    int[] answer = new int[intersection.size()];
    int index = 0;
    for (int value : intersection) answer[index++] = value;
    return answer;
}

Go 实现

func intersection(nums1 []int, nums2 []int) []int {
	cnt := make(map[int]int, len(nums1))
	var ret []int
	for _, num := range nums1 {
		cnt[num] = 1
	}
	for _, num := range nums2 {
		if cnt[num] == 1 {
			ret = append(ret, num)
			cnt[num] = 2
		}
	}
	return ret
}

四数相加

给定四个长度均为 nnn 的整数数组，统计满足 ai+bj+ck+dl=0a_i+b_j+c_k+d_l=0ai​+bj​+ck​+dl​=0 的下标四元组数量。

思路

把四重枚举拆成两组。哈希表记录每个 ai+bja_i+b_jai​+bj​ 的出现次数，再枚举 ck+dlc_k+d_lck​+dl​ 并查询其相反数。

复杂度

  • 时间复杂度：O(n2)O(n^2)O(n2)。
  • 空间复杂度：O(n2)O(n^2)O(n2)。
long fourSumCount(int[] first, int[] second, int[] third, int[] fourth) {
    Map<Integer, Integer> pairCount = new HashMap<>();
    for (int a : first) {
        for (int b : second) pairCount.merge(a + b, 1, Integer::sum);
    }
    long answer = 0;
    for (int c : third) {
        for (int d : fourth) answer += pairCount.getOrDefault(-c - d, 0);
    }
    return answer;
}

Go 实现：四数相加 II

func fourSumCount(nums1 []int, nums2 []int, nums3 []int, nums4 []int) int {
	n := len(nums1)
	mp := make(map[int]int, n*n)
	for i := 0; i < n; i++ {
		for j := 0; j < n; j++ {
			mp[-nums1[i]-nums2[j]]++
		}
	}

	ret := 0
	for k := 0; k < n; k++ {
		for l := 0; l < n; l++ {
			ret += mp[nums3[k]+nums4[l]]
		}
	}

	return ret
}

快乐数

对正整数反复计算各位数字的平方和，若最终到达 1，它就是快乐数。判断给定整数是否为快乐数。

思路

哈希集合记录出现过的状态。到达 1 时成功；遇到重复状态时说明进入不包含 1 的循环。第一次变换后数值至多为位数乘以 81，状态规模迅速缩小。

复杂度

  • 共访问 ttt 个状态、每个状态最多 ddd 位时，时间复杂度为 O(td)O(td)O(td)。
  • 空间复杂度：O(t)O(t)O(t)。

Go 实现

var SqrtMap = []int{0, 1, 4, 9, 16, 25, 36, 49, 64, 81}

func isHappy(n int) bool {
	exist := make(map[int]struct{})
	for n != 1 {
		if _, ok := exist[n]; ok {
			return false
		}
		exist[n] = struct{}{}
		n = calcu(n)
	}
	return true
}

func calcu(x int) int {
	ret := 0
	for x != 0 {
		ret += SqrtMap[x%10]
		x /= 10
	}
	return ret
}

赎金信

两个字符串只包含小写英文字母。判断能否使用 magazine 中的字符组成 ransomNote，每个字符只能使用一次。

思路

对每个字母计算可用数量减去所需数量；全部非负时能够构造。

复杂度

  • 时间复杂度：O(n+m)O(n+m)O(n+m)。
  • 空间复杂度：O(1)O(1)O(1)，字母表大小固定为 26。

Go 实现

func canConstruct(ransomNote string, magazine string) bool {
	if len(ransomNote) > len(magazine) {
		return false
	}
	cnt := make([]int, 26)
	for i := 0; i < len(ransomNote); i++ {
		cnt[ransomNote[i]-'a']--
	}
	for i := 0; i < len(magazine); i++ {
		cnt[magazine[i]-'a']++
	}
	for i := 0; i < 26; i++ {
		if cnt[i] < 0 {
			return false
		}
	}
	return true
}
