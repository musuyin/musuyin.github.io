平衡树与多路查找树

2026-10-26

#AVL 树#红黑树#B 树

阅读线索

平衡查找树通过高度约束控制访问成本，多路树则让一个节点容纳多个键与孩子。旋转和节点调整应同时保持有序性与各自结构约束。

AVL 树

AVL 树是任意节点左右子树高度差不超过一的二叉搜索树。插入后从插入点向根回溯，找到第一个失衡节点并旋转。

失衡形态 处理
LL 对失衡节点右旋
RR 对失衡节点左旋
LR 左孩子左旋，再对失衡节点右旋
RL 右孩子右旋，再对失衡节点左旋 
static class AvlNode {
    int value;
    int height = 1;
    AvlNode left;
    AvlNode right;

    AvlNode(int value) {
        this.value = value;
    }
}

AvlNode insertAvl(AvlNode root, int value) {
    if (root == null) return new AvlNode(value);
    if (value < root.value) root.left = insertAvl(root.left, value);
    else if (value > root.value) root.right = insertAvl(root.right, value);
    else throw new IllegalArgumentException("duplicate value");
    updateHeight(root);
    int balance = avlHeight(root.left) - avlHeight(root.right);
    if (balance > 1 && value < root.left.value) return rotateRight(root);
    if (balance < -1 && value > root.right.value) return rotateLeft(root);
    if (balance > 1) {
        root.left = rotateLeft(root.left);
        return rotateRight(root);
    }
    if (balance < -1) {
        root.right = rotateRight(root.right);
        return rotateLeft(root);
    }
    return root;
}

AvlNode rotateLeft(AvlNode root) {
    AvlNode newRoot = root.right;
    root.right = newRoot.left;
    newRoot.left = root;
    updateHeight(root);
    updateHeight(newRoot);
    return newRoot;
}

AvlNode rotateRight(AvlNode root) {
    AvlNode newRoot = root.left;
    root.left = newRoot.right;
    newRoot.right = root;
    updateHeight(root);
    updateHeight(newRoot);
    return newRoot;
}

void updateHeight(AvlNode node) {
    node.height = Math.max(avlHeight(node.left), avlHeight(node.right)) + 1;
}

int avlHeight(AvlNode node) {
    return node == null ? 0 : node.height;
}

复杂度

  • 时间复杂度：单次搜索、插入或删除均为 O(log⁡n)O(\log n)O(logn)。
  • 空间复杂度：递归实现为 O(log⁡n)O(\log n)O(logn)。

红黑树

红黑树通过颜色约束限制最长根叶路径不超过最短路径的两倍：

  • 节点为红色或黑色，根与空叶节点为黑色。
  • 红色节点不能有红色孩子。
  • 从任一节点到其所有空叶节点的路径包含相同数量的黑色节点。

插入先按二叉搜索树插入红色节点，再用变色和旋转消除“红父红子”；删除则修复被移除黑节点造成的黑高不足。搜索、插入、删除的最坏复杂度都是 O(log⁡n)O(\log n)O(logn)。Java 的 TreeMap 和 TreeSet 使用红黑树。

B 树与 B+ 树

B 树是面向外存的多路平衡查找树。一个节点保存多个有序关键字和多个孩子，所有叶子位于同一层。节点容量通常按磁盘页设计，使一次读盘获得尽可能多的分支信息。

             [17 | 35]
           /     |      \
      [3 | 9] [20 | 28] [41 | 52]

插入先进入叶节点，溢出时从中间关键字分裂并向父节点提升；删除造成关键字不足时，优先向兄弟借关键字，否则与兄弟合并。

B+ 树与 B 树的主要区别：

对比 B 树 B+ 树
数据位置 内部节点和叶节点 只在叶节点
内部关键字 同时保存记录 只作索引
范围查询 需要树上跳转 叶节点链表顺序扫描
单节点扇出 相对较小 相对较大

B+ 树更适合数据库索引和连续范围查询。
