#链表

阅读线索

链表题用引用连接维护结构。虚拟头节点统一首部边界，快慢指针表达相对距离，反转和交换则先保存节点再重连，避免丢失后缀。

链表题的关键不是记住代码，而是先明确当前指针指向哪个节点、下一步要保留哪个引用。涉及头节点删除或插入时，虚拟头节点可以统一边界。

class ListNode {
    int val;
    ListNode next;

    ListNode(int val) {
        this.val = val;
    }
}

删除指定元素

删除单链表中所有值等于 value 的节点，返回新的头节点。

思路

增加虚拟头节点，使删除原头节点与删除中间节点采用同一逻辑。令 current 指向待检查节点的前驱：若下一个节点需要删除，就跨过它；否则向后移动。

ListNode removeElements(ListNode head, int value) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode current = dummy;
    while (current.next != null) {
        if (current.next.val == value) {
            current.next = current.next.next;
        } else {
            current = current.next;
        }
    }
    return dummy.next;
}

Go 实现：移除链表元素

func removeElements(head *ListNode, val int) *ListNode {
	var dummyNode *ListNode = &ListNode{Val: -1, Next: head}
	for cur := dummyNode; cur != nil; cur = cur.Next {
		// 需要注意，可能会有连续的多个结点需要删除
		for cur.Next != nil && cur.Next.Val == val {
			cur.Next = cur.Next.Next
		}
	}
	return dummyNode.Next
}

设计链表

设计链表，支持按下标读取、头插、尾插、在指定下标前插入及按下标删除。下标从零开始；非法读取返回 −1-1−1，非法插入或删除不执行操作。

思路

Java 版本使用单链表、虚拟头节点和 size。所有按下标修改都先找到目标位置的前驱节点，因此头部操作不需要单独改变 head；Go 版本使用双向链表与头尾哨兵。

class MyLinkedList {
    private final ListNode dummy = new ListNode(0);
    private int size;

    int get(int index) {
        if (index < 0 || index >= size) {
            return -1;
        }
        return predecessor(index).next.val;
    }

    void addAtHead(int value) {
        addAtIndex(0, value);
    }

    void addAtTail(int value) {
        addAtIndex(size, value);
    }

    void addAtIndex(int index, int value) {
        if (index < 0 || index > size) {
            return;
        }
        ListNode previous = predecessor(index);
        ListNode node = new ListNode(value);
        node.next = previous.next;
        previous.next = node;
        size++;
    }

    void deleteAtIndex(int index) {
        if (index < 0 || index >= size) {
            return;
        }
        ListNode previous = predecessor(index);
        previous.next = previous.next.next;
        size--;
    }

    private ListNode predecessor(int index) {
        ListNode current = dummy;
        for (int i = 0; i < index; i++) {
            current = current.next;
        }
        return current;
    }
}

Go 实现

Go 使用双向链表与头尾哨兵；头插、尾插为 O(1)O(1)O(1)，按下标操作最坏为 O(n)O(n)O(n)。非法下标按接口约定处理。

type MyLinkedList struct {
	head *Node
	tail *Node
	len  int
}

type Node struct {
	Val  int
	Prev *Node
	Next *Node
}

func Constructor() MyLinkedList {
	dummyHead := &Node{}
	dummyTail := &Node{}
	dummyHead.Next = dummyTail
	dummyTail.Prev = dummyHead
	return MyLinkedList{head: dummyHead, tail: dummyTail, len: 0}
}

func (this *MyLinkedList) Get(index int) int {
	if index < 0 || index >= this.len {
		return -1
	}
	cur := this.head.Next
	for i := 0; i < index; i++ {
		cur = cur.Next
	}
	return cur.Val
}

func (this *MyLinkedList) AddAtHead(val int) {
	this.AddAtIndex(0, val)
}

func (this *MyLinkedList) AddAtTail(val int) {
	this.AddAtIndex(this.len, val)
}

func (this *MyLinkedList) AddAtIndex(index int, val int) {
	if index < 0 || index > this.len {
		return
	}

	cur := this.head
	for i := 0; i < index; i++ {
		cur = cur.Next
	}
	newNode := &Node{Val: val, Prev: cur, Next: cur.Next}
	cur.Next.Prev = newNode
	cur.Next = newNode
	this.len++
}

func (this *MyLinkedList) DeleteAtIndex(index int) {
	if index < 0 || index >= this.len {
		return
	}
	cur := this.head
	for i := 0; i < index; i++ {
		cur = cur.Next
	}
	deleteNode := cur.Next
	cur.Next = deleteNode.Next
	deleteNode.Next.Prev = cur
	this.len--
}

反转链表

反转一个单链表并返回新的头节点。

思路

遍历时同时维护已经反转的前缀 previous 和尚未处理的后缀 current。修改 current.next 前必须先保存原来的后继。

ListNode reverseList(ListNode head) {
    ListNode previous = null;
    ListNode current = head;
    while (current != null) {
        ListNode next = current.next;
        current.next = previous;
        previous = current;
        current = next;
    }
    return previous;
}

Go 实现：翻转链表

func reverseList(head *ListNode) *ListNode {
	var prev *ListNode
	for curr := head; curr != nil; {
		tmp := curr.Next
		curr.Next = prev
		prev = curr
		curr = tmp
	}
	return prev
}

两两交换节点

将链表中相邻节点两两交换，不能只交换节点中的值。

思路

令 previous 指向每一对节点的前驱。保存第一、第二个节点后重连三条边，再把 previous 移到这一对的末尾。

ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode previous = dummy;
    while (previous.next != null && previous.next.next != null) {
        ListNode first = previous.next;
        ListNode second = first.next;
        first.next = second.next;
        second.next = first;
        previous.next = second;
        previous = first;
    }
    return dummy.next;
}

Go 实现：两两交换链表中的结点

func swapPairs(head *ListNode) *ListNode {
	dummyHead := &ListNode{Next: head}

	for prev, cur := dummyHead, head; cur != nil && cur.Next != nil; prev, cur = cur, cur.Next {
		nxt := cur.Next
		prev.Next = nxt
		cur.Next = nxt.Next
		nxt.Next = cur
	}
	return dummyHead.Next
}

删除倒数节点

删除链表的倒数第 nnn 个节点，返回链表头节点。

思路

快指针先从虚拟头节点前进 n+1n+1n+1 步，再让快慢指针同步移动。快指针到达空指针时，慢指针恰好位于待删除节点的前驱。

ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode fast = dummy;
    ListNode slow = dummy;
    for (int i = 0; i <= n; i++) {
        fast = fast.next;
    }
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}

Go 实现：删除链表的倒数第 N 个结点

Go 令快指针先走 nnn 步，随后同步前进到快指针的后继为空；慢指针仍指向待删除节点的前驱。题目保证 1≤n≤1\le n\le1≤n≤ 链表长度。

func removeNthFromEnd(head *ListNode, n int) *ListNode {
	dummyHead := &ListNode{Next: head}
	slow, fast := dummyHead, dummyHead
	for i := 0; i < n; i++ {
		fast = fast.Next
	}
	for fast != nil && fast.Next != nil {
		slow = slow.Next
		fast = fast.Next
	}
	slow.Next = slow.Next.Next
	return dummyHead.Next
}

链表相交

给定两个单链表，返回二者开始相交的节点；若不相交则返回 null。相交按节点引用判断，而不是按值判断。

思路

指针走完自己的链表后转向另一条链表。两者都走过 lenA+lenBlenA+lenBlenA+lenB 个节点后，长度差被抵消，会在交点或共同的 null 相遇。

ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode a = headA;
    ListNode b = headB;
    while (a != b) {
        a = a == null ? headB : a.next;
        b = b == null ? headA : b.next;
    }
    return a;
}

Go 实现

func getIntersectionNode(headA, headB *ListNode) *ListNode {
	curA, curB := headA, headB
	for curA != curB {
		if curA == nil {
			curA = headB
		} else {
			curA = curA.Next
		}
		if curB == nil {
			curB = headA
		} else {
			curB = curB.Next
		}
	}
	return curA
}

环形链表入口

判断单链表是否有环；若有环，返回环的入口节点，否则返回 null。

思路

快指针每次走两步，慢指针每次走一步。有环时二者必在环内相遇。设头到入口距离为 xxx、入口到相遇点距离为 yyy、环中剩余距离为 zzz，相遇条件可推出从头节点与相遇点各出发一个一步指针，它们会在入口相遇。

ListNode detectCycle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    do {
        if (fast == null || fast.next == null) {
            return null;
        }
        slow = slow.next;
        fast = fast.next.next;
    } while (slow != fast);

    ListNode entry = head;
    while (entry != slow) {
        entry = entry.next;
        slow = slow.next;
    }
    return entry;
}

Go 实现：环形链表 II

func detectCycle(head *ListNode) *ListNode {
	slow, fast := head, head
	for fast != nil && fast.Next != nil {
		slow = slow.Next
		fast = fast.Next.Next
		if slow == fast {
			ret := head
			for ; ret != slow; ret, slow = ret.Next, slow.Next {
			}
			return ret
		}
	}
	return nil
}
