栈队列与表达式

2026-10-28

#栈#队列

阅读线索

表达式计算把数字和待决运算符分别管理，括号控制局部求值边界。栈和队列的模拟题则用操作次序解释为什么能得到目标接口。

栈按后进先出处理最近尚未完成的任务，队列按先进先出维护等待顺序。Java 中优先使用 ArrayDeque，不要用遗留的 Stack。

数组模拟栈与队列

栈

栈顶指针 top 指向下一个可写位置。入栈后递增，出栈前递减，栈空条件为 top == 0。

复杂度

  • 入栈、出栈、查看栈顶和判空的时间复杂度均为 O(1)O(1)O(1)。
  • 空间复杂度：O(c)O(c)O(c)，ccc 为数组容量。
class ArrayStack {
    private final int[] data;
    private int top;

    ArrayStack(int capacity) {
        data = new int[capacity];
    }

    void push(int value) {
        data[top++] = value;
    }

    int pop() {
        return data[--top];
    }

    int peek() {
        return data[top - 1];
    }

    boolean isEmpty() {
        return top == 0;
    }
}

队列

普通数组队列使用左闭右开区间 [head,tail)[head,tail)[head,tail)。入队写入 tail 后递增，出队读取 head 后递增。需要复用空间时将下标对容量取模形成循环队列。

复杂度

  • 入队、出队、查看队首和判空的时间复杂度均为 O(1)O(1)O(1)。
  • 空间复杂度：O(c)O(c)O(c)，ccc 为数组容量。
class ArrayQueue {
    private final int[] data;
    private int head;
    private int tail;

    ArrayQueue(int capacity) {
        data = new int[capacity];
    }

    void offer(int value) {
        data[tail++] = value;
    }

    int poll() {
        return data[head++];
    }

    int peek() {
        return data[head];
    }

    boolean isEmpty() {
        return head == tail;
    }
}

用栈实现队列

仅使用两个栈实现队列的入队、出队、查看队首和判空操作。

思路

input 负责接收新元素；只有 output 为空时，才把 input 中的元素全部倒入 output。每个元素至多在两个栈间移动一次，均摊复杂度为 O(1)O(1)O(1)。

复杂度

  • 入队时间复杂度为 O(1)O(1)O(1)；出队与查看队首均摊为 O(1)O(1)O(1)，单次最坏为 O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
class QueueByStacks {
    private final Deque<Integer> input = new ArrayDeque<>();
    private final Deque<Integer> output = new ArrayDeque<>();

    void offer(int value) {
        input.push(value);
    }

    int poll() {
        moveIfNeeded();
        return output.pop();
    }

    int peek() {
        moveIfNeeded();
        return output.peek();
    }

    boolean isEmpty() {
        return input.isEmpty() && output.isEmpty();
    }

    private void moveIfNeeded() {
        if (output.isEmpty()) {
            while (!input.isEmpty()) {
                output.push(input.pop());
            }
        }
    }
}

用队列实现栈

仅使用队列实现栈的压栈、弹栈、查看栈顶和判空操作。

思路

新元素入队后，把此前的所有元素依次移到队尾，使新元素始终位于队首。之后弹栈和查看栈顶就是队列的出队与查看队首。

复杂度

  • 压栈时间复杂度为 O(n)O(n)O(n)；弹栈、查看栈顶和判空为 O(1)O(1)O(1)。
  • 空间复杂度：O(n)O(n)O(n)。
class StackByQueue {
    private final Deque<Integer> queue = new ArrayDeque<>();

    void push(int value) {
        queue.offer(value);
        for (int i = 1; i < queue.size(); i++) {
            queue.offer(queue.poll());
        }
    }

    int pop() {
        return queue.remove();
    }

    int top() {
        return queue.element();
    }

    boolean isEmpty() {
        return queue.isEmpty();
    }
}

	var ret int
	if this.flag {
		sz := this.firstQueue.size - 1
		for i := 0; i < sz; i++ {
			this.secondQueue.push(this.firstQueue.pop())
		}
		ret = this.firstQueue.pop()

		for i := 0; i < sz; i++ {
			this.firstQueue.push(this.secondQueue.pop())
		}
		ret = this.secondQueue.pop()
	}
	this.flag = !this.flag
	return ret
}

		}

中缀表达式求值

计算只包含非负整数、括号以及 +、-、*、/ 的合法中缀表达式。除法按 Java 整数除法处理。

思路

使用数字栈和运算符栈：

  • 数字直接解析后入栈。
  • 左括号直接入栈，右括号触发计算直到匹配左括号。
  • 新运算符到来时，先计算栈顶优先级不低于它的运算符，再把新运算符入栈。

每个数字和运算符只进出栈一次，时间复杂度为 O(n)O(n)O(n)。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
int evaluateInfix(String expression) {
    Deque<Integer> numbers = new ArrayDeque<>();
    Deque<Character> operators = new ArrayDeque<>();
    for (int i = 0; i < expression.length();) {
        char c = expression.charAt(i);
        if (c == ' ') {
            i++;
        } else if (Character.isDigit(c)) {
            int value = 0;
            while (i < expression.length() && Character.isDigit(expression.charAt(i))) {
                value = value * 10 + expression.charAt(i++) - '0';
            }
            numbers.push(value);
        } else if (c == '(') {
            operators.push(c);
            i++;
        } else if (c == ')') {
            while (operators.peek() != '(') {
                calculateTop(numbers, operators);
            }
            operators.pop();
            i++;
        } else {
            while (!operators.isEmpty() && operators.peek() != '('
                    && precedence(operators.peek()) >= precedence(c)) {
                calculateTop(numbers, operators);
            }
            operators.push(c);
            i++;
        }
    }
    while (!operators.isEmpty()) {
        calculateTop(numbers, operators);
    }
    return numbers.pop();
}

void calculateTop(Deque<Integer> numbers, Deque<Character> operators) {
    int right = numbers.pop();
    int left = numbers.pop();
    char operator = operators.pop();
    int result = switch (operator) {
        case '+' -> left + right;
        case '-' -> left - right;
        case '*' -> left * right;
        case '/' -> left / right;
        default -> throw new IllegalArgumentException();
    };
    numbers.push(result);
}

int precedence(char operator) {
    return operator == '+' || operator == '-' ? 1 : 2;
}

有效的括号

给定只包含圆括号、方括号和花括号的字符串，判断括号顺序是否合法。

思路

遇到左括号时把对应的右括号压栈；遇到右括号时，它必须等于当前栈顶。这样无需额外维护括号映射。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
boolean isValidBrackets(String text) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : text.toCharArray()) {
        if (c == '(') stack.push(')');
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}

删除相邻重复项

反复删除字符串中相邻且相同的两个字符，直到无法继续，返回最终字符串。

思路

栈保存已经处理的稳定前缀。当前字符等于栈顶时弹出，否则压栈。用字符数组模拟栈可以直接构造答案。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
String removeAdjacentDuplicates(String text) {
    char[] stack = new char[text.length()];
    int top = 0;
    for (char c : text.toCharArray()) {
        if (top > 0 && stack[top - 1] == c) {
            top--;
        } else {
            stack[top++] = c;
        }
    }
    return new String(stack, 0, top);
}

func removeDuplicates(s string) string {
	st := NewCharStack()
	for i := 0; i < len(s); i++ {
		c := s[i]
		if !st.isEmpty() && c == st.top() {
			st.pop()
			continue
		}
		st.push(c)
	}

	retCs := make([]byte, st.size)
	for i := st.size - 1; i >= 0; i-- {
		retCs[i] = st.pop()
	}
	return string(retCs)
}

中缀表达式转后缀表达式

输入已经按数字、括号和运算符切分的合法中缀表达式，输出对应的后缀表达式。

思路

  • 数字直接写入结果。
  • 左括号入栈；右括号弹出到对应左括号。
  • 普通运算符到来时，先弹出所有优先级不低于它的栈顶运算符。

每个记号只进出栈一次。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
List<String> infixToPostfix(List<String> tokens) {
    List<String> output = new ArrayList<>();
    Deque<String> operators = new ArrayDeque<>();
    for (String token : tokens) {
        if (Character.isDigit(token.charAt(0))) {
            output.add(token);
        } else if (token.equals("(")) {
            operators.push(token);
        } else if (token.equals(")")) {
            while (!operators.peek().equals("(")) output.add(operators.pop());
            operators.pop();
        } else {
            while (!operators.isEmpty() && !operators.peek().equals("(")
                    && postfixPrecedence(operators.peek()) >= postfixPrecedence(token)) {
                output.add(operators.pop());
            }
            operators.push(token);
        }
    }
    while (!operators.isEmpty()) output.add(operators.pop());
    return output;
}

int postfixPrecedence(String operator) {
    return operator.equals("+") || operator.equals("-") ? 1 : 2;
}

逆波兰表达式求值

后缀表达式只包含整数及 +、-、*、/，求表达式值，除法向零截断。

思路

数字入栈；遇到运算符时先弹出右操作数，再弹出左操作数，计算后把结果压回栈。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
int evaluatePostfix(String[] tokens) {
    Deque<Integer> numbers = new ArrayDeque<>();
    for (String token : tokens) {
        if (token.length() > 1 || Character.isDigit(token.charAt(0))) {
            numbers.push(Integer.parseInt(token));
            continue;
        }
        int right = numbers.pop();
        int left = numbers.pop();
        numbers.push(switch (token.charAt(0)) {
            case '+' -> left + right;
            case '-' -> left - right;
            case '*' -> left * right;
            case '/' -> left / right;
            default -> throw new IllegalArgumentException();
        });
    }
    return numbers.pop();
}

}

验证出栈序列

给定互不相同的入栈序列和候选出栈序列，判断能否通过合法压栈、弹栈操作得到。

思路

按入栈顺序模拟压栈；只要栈顶等于当前待弹出元素就立即弹出。最终全部匹配则序列合法。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。
boolean validStackSequence(int[] pushed, int[] popped) {
    Deque<Integer> stack = new ArrayDeque<>();
    int popIndex = 0;
    for (int value : pushed) {
        stack.push(value);
        while (!stack.isEmpty() && stack.peek() == popped[popIndex]) {
            stack.pop();
            popIndex++;
        }
    }
    return popIndex == popped.length;
}

分组队列

每个人属于一个团队。新成员入队时，若队列中已有队友，就排在最后一名队友之后；否则排到整个队尾。支持入队和从队首出队。

思路

外层队列保存当前出现团队的顺序，每个团队再维护成员队列。团队从空变为非空时才进入外层队列；团队最后一名成员出队后才从外层队列移除。

复杂度

  • 时间复杂度：入队和出队的期望复杂度均为 O(1)O(1)O(1)。
  • 空间复杂度：O(n+t)O(n+t)O(n+t)，其中 nnn 是队列中的人数，ttt 是团队数。
static class TeamQueue {
    private final int[] teamOf;
    private final Deque<Integer> activeTeams = new ArrayDeque<>();
    private final Map<Integer, Deque<Integer>> members = new HashMap<>();

    TeamQueue(int[] teamOf) {
        this.teamOf = teamOf;
    }

    void offer(int person) {
        int team = teamOf[person];
        Deque<Integer> queue = members.computeIfAbsent(team, key -> new ArrayDeque<>());
        if (queue.isEmpty()) activeTeams.offer(team);
        queue.offer(person);
    }

    int poll() {
        int team = activeTeams.element();
        Deque<Integer> queue = members.get(team);
        int person = queue.remove();
        if (queue.isEmpty()) activeTeams.remove();
        return person;
    }
}
