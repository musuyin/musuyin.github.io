二叉搜索树

2026-10-28

#二叉搜索树#Java

阅读线索

BST 用整棵左右子树的大小关系支持搜索。修改、裁剪和构造都必须保持这个全局约束；复杂度依赖树高，普通 BST 可能退化。

二叉搜索树满足：左子树所有值小于根，右子树所有值大于根，左右子树也分别满足该性质。中序遍历得到严格递增序列。

树高为 hhh 时，搜索、插入和删除均为 O(h)O(h)O(h)；平衡时 h=O(log⁡n)h=O(\log n)h=O(logn)，退化成链时 h=O(n)h=O(n)h=O(n)。

static class TreeNode {
    int value;
    TreeNode left;
    TreeNode right;

    TreeNode(int value) {
        this.value = value;
    }
}

搜索与插入

沿目标值可能存在的一侧下降。插入到空位置后，递归返回时重新连接沿途子树。

复杂度

  • 时间复杂度：O(h)O(h)O(h)。
  • 空间复杂度：迭代搜索为 O(1)O(1)O(1)，递归插入为 O(h)O(h)O(h)。

Java 实现

TreeNode searchBst(TreeNode root, int target) {
    TreeNode current = root;
    while (current != null && current.value != target) {
        current = target < current.value ? current.left : current.right;
    }
    return current;
}

TreeNode insertBst(TreeNode root, int value) {
    if (root == null) return new TreeNode(value);
    if (value < root.value) root.left = insertBst(root.left, value);
    else if (value > root.value) root.right = insertBst(root.right, value);
    else throw new IllegalArgumentException("duplicate value");
    return root;
}

Go 实现：二叉搜索树中的搜索

func searchBST(root *TreeNode, val int) *TreeNode {
	if root == nil {
		return nil
	}
	if root.Val == val {
		return root
	} else if root.Val < val {
		return searchBST(root.Right, val)
	} else {
		return searchBST(root.Left, val)
	}
}

删除节点

删除指定值并保持二叉搜索树性质，题目保证节点值互不相同。

思路

  • 没有孩子：直接删除。
  • 只有一个孩子：让孩子接替当前位置。
  • 有两个孩子：使用右子树最小节点作为后继，复制其值后再从右子树删除该后继。

复杂度

  • 时间复杂度：O(h)O(h)O(h)。
  • 空间复杂度：O(h)O(h)O(h)。

Java 实现

TreeNode deleteBst(TreeNode root, int key) {
    if (root == null) return null;
    if (key < root.value) {
        root.left = deleteBst(root.left, key);
    } else if (key > root.value) {
        root.right = deleteBst(root.right, key);
    } else {
        if (root.left == null) return root.right;
        if (root.right == null) return root.left;
        TreeNode successor = root.right;
        while (successor.left != null) successor = successor.left;
        root.value = successor.value;
        root.right = deleteBst(root.right, successor.value);
    }
    return root;
}

修剪二叉搜索树

只保留闭区间 [low,high][low,high][low,high] 内的节点。

思路

若根值小于 low，根及左子树都不合法，只需修剪右子树；大于 high 时对称处理。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)。

Java 实现

TreeNode trimBst(TreeNode root, int low, int high) {
    if (root == null) return null;
    if (root.value < low) return trimBst(root.right, low, high);
    if (root.value > high) return trimBst(root.left, low, high);
    root.left = trimBst(root.left, low, high);
    root.right = trimBst(root.right, low, high);
    return root;
}

构造与转换

有序数组取中点即可让左右子树规模尽量接近。累加树按“右子树、根、左子树”的顺序遍历，维护所有更大节点的后缀和。

复杂度

  • 有序数组构造：时间复杂度 O(n)O(n)O(n)，空间复杂度 O(log⁡n)O(\log n)O(logn)。
  • 累加树转换：时间复杂度 O(n)O(n)O(n)，空间复杂度 O(h)O(h)O(h)。

Java 实现

TreeNode sortedArrayToBst(int[] values) {
    return buildBalancedBst(values, 0, values.length);
}

TreeNode buildBalancedBst(int[] values, int left, int right) {
    if (left == right) return null;
    int middle = left + (right - left) / 2;
    TreeNode root = new TreeNode(values[middle]);
    root.left = buildBalancedBst(values, left, middle);
    root.right = buildBalancedBst(values, middle + 1, right);
    return root;
}

TreeNode greaterSumTree(TreeNode root) {
    int[] suffixSum = new int[1];
    convertGreaterTree(root, suffixSum);
    return root;
}

void convertGreaterTree(TreeNode node, int[] suffixSum) {
    if (node == null) return;
    convertGreaterTree(node.right, suffixSum);
    suffixSum[0] += node.value;
    node.value = suffixSum[0];
    convertGreaterTree(node.left, suffixSum);
}

验证与中序统计

验证时给每个节点传递严格的取值区间。最小差值来自中序序列中的相邻元素，只需保留前一个值；差值统计假设树中至少有两个节点。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)。

Java 实现

boolean validBst(TreeNode root) {
    return validBstRange(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

boolean validBstRange(TreeNode node, long lower, long upper) {
    if (node == null) return true;
    if (node.value <= lower || node.value >= upper) return false;
    return validBstRange(node.left, lower, node.value)
            && validBstRange(node.right, node.value, upper);
}

long minimumDifference(TreeNode root) {
    long[] state = {Long.MIN_VALUE, Long.MAX_VALUE};
    minimumDifferenceInorder(root, state);
    return state[1];
}

void minimumDifferenceInorder(TreeNode node, long[] state) {
    if (node == null) return;
    minimumDifferenceInorder(node.left, state);
    if (state[0] != Long.MIN_VALUE) {
        state[1] = Math.min(state[1], (long) node.value - state[0]);
    }
    state[0] = node.value;
    minimumDifferenceInorder(node.right, state);
}

Go 实现：验证二叉搜索树

检查中序序列严格递增，使用前一个节点是否存在表示边界，int 的最小值和最大值也可成为合法节点。时间 O(n)O(n)O(n)，空间 O(h)O(h)O(h)。

func isValidBST(root *TreeNode) bool {
	var previous *TreeNode
	var visit func(*TreeNode) bool
	visit = func(node *TreeNode) bool {
		if node == nil {
			return true
		}
		if !visit(node.Left) {
			return false
		}
		if previous != nil && previous.Val >= node.Val {
			return false
		}
		previous = node
		return visit(node.Right)
	}
	return visit(root)
}

最近公共祖先

二叉搜索树中，若两个目标都小于根就进入左子树，都大于根就进入右子树；第一次位于两者值域之间的节点就是最近公共祖先。

复杂度

  • 时间复杂度：O(h)O(h)O(h)。
  • 空间复杂度：O(1)O(1)O(1)。

Java 实现

TreeNode lowestCommonAncestorBst(TreeNode root, TreeNode first, TreeNode second) {
    int low = Math.min(first.value, second.value);
    int high = Math.max(first.value, second.value);
    TreeNode current = root;
    while (current.value < low || current.value > high) {
        current = current.value < low ? current.right : current.left;
    }
    return current;
}
