二叉树性质与构造

2026-10-28

#二叉树#树的构造#Java

阅读线索

树的性质题需要区分完全、完美和一般二叉树。构造题则用遍历序列定位根与左右范围，路径类题需要说明每层递归保留的局部信息。

Go 节点定义

各实现代码块独立使用，共享以下节点类型；字段沿用 Go 题目平台的命名。

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}
type NaryNode struct {
	Val      int
	Children []*NaryNode
}
type NextNode struct {
	Val   int
	Left  *NextNode
	Right *NextNode
	Next  *NextNode
}

节点定义

static class TreeNode {
    int value;
    TreeNode left;
    TreeNode right;

    TreeNode(int value) {
        this.value = value;
    }
}

深度与节点数量

最大深度取左右子树较大值，最小深度必须区分只有一个孩子的节点，不能把空子树误认为更短路径。

int maximumDepth(TreeNode root) {
    if (root == null) return 0;
    return Math.max(maximumDepth(root.left), maximumDepth(root.right)) + 1;
}

int minimumDepth(TreeNode root) {
    if (root == null) return 0;
    if (root.left == null) return minimumDepth(root.right) + 1;
    if (root.right == null) return minimumDepth(root.left) + 1;
    return Math.min(minimumDepth(root.left), minimumDepth(root.right)) + 1;
}

int countTreeNodes(TreeNode root) {
    if (root == null) return 0;
    return countTreeNodes(root.left) + countTreeNodes(root.right) + 1;
}

完全二叉树中，若从最左链和最右链得到的高度相同，当前子树是完美二叉树，节点数为 2h−12^h-12h−1；否则递归计算左右子树。

int countCompleteTreeNodes(TreeNode root) {
    if (root == null) return 0;
    int leftHeight = 0;
    int rightHeight = 0;
    for (TreeNode node = root; node != null; node = node.left) leftHeight++;
    for (TreeNode node = root; node != null; node = node.right) rightHeight++;
    if (leftHeight == rightHeight) return (int) ((1L << leftHeight) - 1);
    return countCompleteTreeNodes(root.left) + countCompleteTreeNodes(root.right) + 1;
}

复杂度

  • 普通二叉树的深度与节点计数：时间复杂度 O(n)O(n)O(n)，空间复杂度 O(h)O(h)O(h)。
  • 完全二叉树节点计数：时间复杂度 O(log⁡2n)O(\log^2 n)O(log2n)，空间复杂度 O(log⁡n)O(\log n)O(logn)。

Go 实现：二叉树的最大深度

func maxDepth(root *TreeNode) int {
	if root == nil {
		return 0
	}
	return 1 + max(maxDepth(root.Left), maxDepth(root.Right))
}

Go 实现：二叉树的最小深度

import (
	"math"
)

func minDepth(root *TreeNode) int {
	if root == nil {
		return 0
	} else if root.Left == nil && root.Right == nil {
		return 1
	}
	var curMin int = math.MaxInt
	if root.Left != nil {
		curMin = min(curMin, minDepth(root.Left))
	}
	if root.Right != nil {
		curMin = min(curMin, minDepth(root.Right))
	}

	return 1 + curMin
}

Go 实现：完全二叉树

func countNodes(root *TreeNode) int {
	var ret int = 0
	if root == nil {
		return ret
	}

	var maxLeft, maxRight int = 0, 0
	for l := root; l != nil; l = l.Left {
		maxLeft++
	}
	for r := root; r != nil; r = r.Right {
		maxRight++
	}

	if maxLeft == maxRight {
		return (1 << maxLeft) - 1
	}
	return countNodes(root.Left) + countNodes(root.Right) + 1
}

相同、对称与平衡

后序计算平衡高度时用 -1 表示子树已经失衡，使每个节点只访问一次。

boolean sameTree(TreeNode first, TreeNode second) {
    if (first == null || second == null) return first == second;
    return first.value == second.value
            && sameTree(first.left, second.left)
            && sameTree(first.right, second.right);
}

boolean symmetricTree(TreeNode root) {
    return root == null || mirrorEqual(root.left, root.right);
}

boolean mirrorEqual(TreeNode first, TreeNode second) {
    if (first == null || second == null) return first == second;
    return first.value == second.value
            && mirrorEqual(first.left, second.right)
            && mirrorEqual(first.right, second.left);
}

boolean balancedTree(TreeNode root) {
    return balancedHeight(root) >= 0;
}

int balancedHeight(TreeNode node) {
    if (node == null) return 0;
    int left = balancedHeight(node.left);
    if (left < 0) return -1;
    int right = balancedHeight(node.right);
    if (right < 0 || Math.abs(left - right) > 1) return -1;
    return Math.max(left, right) + 1;
}

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)。

Go 实现：对称二叉树

func isSymmetric(root *TreeNode) bool {
	if root == nil {
		return true
	}
	return isSymmetricHelper(root.Left, root.Right)
}

func isSymmetricHelper(left, right *TreeNode) bool {
	if left == nil && right == nil {
		return true
	} else if left != nil && right == nil || left == nil && right != nil {
		return false
	}

	return left.Val == right.Val && isSymmetricHelper(left.Left, right.Right) && isSymmetricHelper(left.Right, right.Left)
}

Go 实现：平衡二叉树

func isBalanced(root *TreeNode) bool {
	_, balanced := isBalancedHelper(root)
	return balanced
}

func isBalancedHelper(root *TreeNode) (int, bool) {
	if root == nil {
		return 0, true
	}
	leftHeight, leftBalanced := isBalancedHelper(root.Left)
	rightHeight, rightBalanced := isBalancedHelper(root.Right)

	if !leftBalanced || !rightBalanced || leftHeight-rightHeight > 1 || rightHeight-leftHeight > 1 {
		return 0, false
	}

	return max(leftHeight, rightHeight) + 1, true
}

根据遍历序列构造二叉树

给定无重复元素的中序序列和后序序列，恢复二叉树。

思路

后序序列末尾是根节点；根在中序序列中的位置把节点划分为左右子树。预先建立“值到中序下标”的映射，避免每层线性查找。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

TreeNode buildFromInorderPostorder(int[] inorderValues, int[] postorderValues) {
    Map<Integer, Integer> inorderIndex = new HashMap<>();
    for (int i = 0; i < inorderValues.length; i++) {
        inorderIndex.put(inorderValues[i], i);
    }
    return buildInPost(inorderValues, 0, inorderValues.length, postorderValues,
            0, postorderValues.length, inorderIndex);
}

TreeNode buildInPost(int[] inorderValues, int inLeft, int inRight,
                     int[] postorderValues, int postLeft, int postRight,
                     Map<Integer, Integer> inorderIndex) {
    if (inLeft == inRight) return null;
    int rootValue = postorderValues[postRight - 1];
    int rootIndex = inorderIndex.get(rootValue);
    int leftSize = rootIndex - inLeft;
    TreeNode root = new TreeNode(rootValue);
    root.left = buildInPost(inorderValues, inLeft, rootIndex, postorderValues,
            postLeft, postLeft + leftSize, inorderIndex);
    root.right = buildInPost(inorderValues, rootIndex + 1, inRight, postorderValues,
            postLeft + leftSize, postRight - 1, inorderIndex);
    return root;
}

Go 实现：从中序与后序遍历序列构造二叉树

func buildTree(inorder []int, postorder []int) *TreeNode {
	positions := make(map[int]int, len(inorder))
	for i, value := range inorder {
		positions[value] = i
	}
	var build func(int, int, int, int) *TreeNode
	build = func(il, ir, pl, pr int) *TreeNode {
		if il == ir {
			return nil
		}
		value := postorder[pr-1]
		index := positions[value]
		leftSize := index - il
		return &TreeNode{
			Val:   value,
			Left:  build(il, index, pl, pl+leftSize),
			Right: build(index+1, ir, pl+leftSize, pr-1),
		}
	}
	return build(0, len(inorder), 0, len(postorder))
}

最大二叉树

数组中的最大值作为根，其左侧和右侧分别递归构造左右子树。

思路

在当前区间中寻找最大值作为根，再递归处理它左右两侧的区间。

复杂度

  • 时间复杂度：最坏为 O(n2)O(n^2)O(n2)，单调数组会让每层只缩短一个元素。
  • 空间复杂度：最坏为 O(n)O(n)O(n)。

Java 实现

TreeNode maximumBinaryTree(int[] values) {
    return buildMaximumTree(values, 0, values.length);
}

TreeNode buildMaximumTree(int[] values, int left, int right) {
    if (left == right) return null;
    int maximum = left;
    for (int i = left + 1; i < right; i++) {
        if (values[i] > values[maximum]) maximum = i;
    }
    TreeNode root = new TreeNode(values[maximum]);
    root.left = buildMaximumTree(values, left, maximum);
    root.right = buildMaximumTree(values, maximum + 1, right);
    return root;
}

Go 实现

func constructMaximumBinaryTree(nums []int) *TreeNode {
	return constructMaximumBinaryTreeHelper(nums, 0, len(nums)-1)
}

func constructMaximumBinaryTreeHelper(nums []int, ml, mr int) *TreeNode {
	if ml > mr {
		return nil
	} else if ml == mr {
		return &TreeNode{
			Val: nums[ml],
		}
	}
	var maxIdx int = ml
	var maxVal int = nums[ml]
	for i := ml + 1; i <= mr; i++ {
		if maxVal < nums[i] {
			maxIdx = i
			maxVal = nums[i]
		}
	}

	return &TreeNode{
		Val:   maxVal,
		Left:  constructMaximumBinaryTreeHelper(nums, ml, maxIdx-1),
		Right: constructMaximumBinaryTreeHelper(nums, maxIdx+1, mr),
	}
}

修改二叉树

翻转操作交换每个节点的左右子树；合并操作在两个节点都存在时累加值，否则直接复用非空子树。

复杂度

  • 时间复杂度：O(n)O(n)O(n)，nnn 为访问到的节点数。
  • 空间复杂度：O(h)O(h)O(h)。

Java 实现

TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode temporary = invertTree(root.left);
    root.left = invertTree(root.right);
    root.right = temporary;
    return root;
}

TreeNode mergeTrees(TreeNode first, TreeNode second) {
    if (first == null) return second;
    if (second == null) return first;
    first.value += second.value;
    first.left = mergeTrees(first.left, second.left);
    first.right = mergeTrees(first.right, second.right);
    return first;
}

Go 实现：翻转二叉树

func invertTree(root *TreeNode) *TreeNode {
	if root == nil {
		return root
	}

	root.Left, root.Right = invertTree(root.Right), invertTree(root.Left)
	return root
}

Go 实现：合并二叉树

Java 在第一棵树上修改；Go 对重叠位置创建新节点，对只有一方存在的位置复用原子树。

func mergeTrees(root1 *TreeNode, root2 *TreeNode) *TreeNode {
	if root1 == nil && root2 == nil {
		return nil
	} else if root1 == nil {
		return root2
	} else if root2 == nil {
		return root1
	}
	return &TreeNode{
		Val:   root1.Val + root2.Val,
		Left:  mergeTrees(root1.Left, root2.Left),
		Right: mergeTrees(root1.Right, root2.Right),
	}
}

最近公共祖先

给定二叉树中的两个节点，返回它们的最近公共祖先。

思路

后序遍历返回当前子树是否找到目标。若左右子树分别找到一个目标，当前节点就是最近公共祖先；若只找到一侧，则把该侧结果向上传递。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)。

Java 实现

TreeNode lowestCommonAncestor(TreeNode root, TreeNode first, TreeNode second) {
    if (root == null || root == first || root == second) return root;
    TreeNode left = lowestCommonAncestor(root.left, first, second);
    TreeNode right = lowestCommonAncestor(root.right, first, second);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}

N 叉树的最大深度

给定 N 叉树，返回根到最深叶子路径上的节点数；空树深度为 0。

思路

当前节点的深度等于所有孩子子树深度的最大值加一。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)，来自递归栈。

Go 实现

func naryMaxDepth(root *NaryNode) int {
	if root == nil {
		return 0
	}
	theMax := 0
	for _, node := range root.Children {
		theMax = max(theMax, naryMaxDepth(node))
	}
	return theMax + 1
}
