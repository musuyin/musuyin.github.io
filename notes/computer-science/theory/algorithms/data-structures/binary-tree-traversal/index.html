2026-10-28

#二叉树#树的遍历#Java

阅读线索

前中后序描述根节点的处理时机，层序按队列逐层推进。迭代实现应说明显式栈保存的工作，Go 切片则还要注意 append 后长度如何传回。

Go 节点定义

各实现代码块独立使用，共享以下节点类型；字段沿用 Go 题目平台的命名。

type TreeNode struct {
	Val   int
	Left  *TreeNode
	Right *TreeNode
}
type NaryNode struct {
	Val      int
	Children []*NaryNode
}
type NextNode struct {
	Val   int
	Left  *NextNode
	Right *NextNode
	Next  *NextNode
}

二叉树基础

二叉树的每个节点至多有两个孩子。由 nnn 个节点构成的不同二叉树形态数量是卡特兰数：

Cn=1n+1(2nn)C_n=\frac{1}{n+1}\binom{2n}{n}Cn​=n+11​(n2n​)
类型 条件
满二叉树 每个节点的度为零或二
完美二叉树 除叶子外每个节点都有两个孩子，且叶子在同一层
完全二叉树 除最后一层外均填满，最后一层从左到右连续
平衡二叉树 任意节点左右子树高度差不超过一

链式存储是算法题最常见的表示：

static class TreeNode {
    int value;
    TreeNode left;
    TreeNode right;

    TreeNode(int value) {
        this.value = value;
    }
}

static class NaryNode {
    int value;
    List<NaryNode> children = new ArrayList<>();

    NaryNode(int value) {
        this.value = value;
    }
}

普通树还可以使用双亲数组或孩子兄弟表示法：

普通树节点                  孩子兄弟表示
node                        node
├── child A                 ├── firstChild -> child A
├── child B                 └── nextSibling -> sibling
└── child C

孩子兄弟表示把普通树转换成二叉链式结构：左指针指向第一个孩子，右指针指向下一个兄弟。

深度优先遍历

前序、中序、后序只取决于根节点相对左右子树的访问位置。递归写法直接体现定义；迭代写法显式维护尚未处理的节点。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)，hhh 为树高，不计返回结果。

Java 实现

List<Integer> preorder(TreeNode root) {
    List<Integer> answer = new ArrayList<>();
    if (root == null) return answer;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        answer.add(node.value);
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    return answer;
}

List<Integer> inorder(TreeNode root) {
    List<Integer> answer = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode current = root;
    while (current != null || !stack.isEmpty()) {
        while (current != null) {
            stack.push(current);
            current = current.left;
        }
        current = stack.pop();
        answer.add(current.value);
        current = current.right;
    }
    return answer;
}

List<Integer> postorder(TreeNode root) {
    List<Integer> answer = new ArrayList<>();
    postorderDfs(root, answer);
    return answer;
}

void postorderDfs(TreeNode node, List<Integer> answer) {
    if (node == null) return;
    postorderDfs(node.left, answer);
    postorderDfs(node.right, answer);
    answer.add(node.value);
}

Go 实现：二叉树的前序遍历（递归）

递归在访问孩子前记录根；迭代先压右孩子、再压左孩子。切片传参复制切片头，append 后的新长度需通过返回值、指针或闭包传回调用方。

func preorderRecursive(root *TreeNode) []int {
	var ret []int
	preorderHelper(root, &ret)
	return ret
}

func preorderHelper(cur *TreeNode, ret *[]int) {
	if cur == nil {
		return
	}
	*ret = append(*ret, cur.Val)
	preorderHelper(cur.Left, ret)
	preorderHelper(cur.Right, ret)
}

Go 实现：二叉树的前序遍历（迭代）

递归在访问孩子前记录根；迭代先压右孩子、再压左孩子。切片传参复制切片头，append 后的新长度需通过返回值、指针或闭包传回调用方。

func preorderIterative(root *TreeNode) []int {
	var ret []int
	var stack []*TreeNode
	var top int = 0
	if root == nil {
		return ret
	}

	stack = append(stack, root)
	top++
	for top > 0 {
		cur := stack[top-1]
		stack = stack[:top-1]
		top--
		ret = append(ret, cur.Val)
		if cur.Right != nil {
			stack = append(stack, cur.Right)
			top++
		}
		if cur.Left != nil {
			stack = append(stack, cur.Left)
			top++
		}
	}
	return ret
}

层序遍历

队列中始终保存下一批待访问节点。每层开始时记录队列长度，就能把结果按层分组。锯齿遍历只改变本层写入答案的下标，不改变节点入队顺序。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(w)O(w)O(w)，www 为树的最大宽度，不计返回结果。

Java 实现

List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> answer = new ArrayList<>();
    if (root == null) return answer;
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.remove();
            level.add(node.value);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        answer.add(level);
    }
    return answer;
}

List<List<Integer>> zigzagLevelOrder(TreeNode root) {
    List<List<Integer>> answer = levelOrder(root);
    for (int level = 1; level < answer.size(); level += 2) {
        Collections.reverse(answer.get(level));
    }
    return answer;
}

Go 实现：二叉树的层序遍历

func levelOrder(root *TreeNode) [][]int {
	var ret [][]int = make([][]int, 0)
	if root == nil {
		return ret
	}

	var queue []*TreeNode = make([]*TreeNode, 0)
	queue = append(queue, root)
	for len(queue) > 0 {
		sz := len(queue)
		var layer []int = make([]int, 0)

		for range sz {
			cur := queue[0]
			queue = queue[1:]

			layer = append(layer, cur.Val)
			if cur.Left != nil {
				queue = append(queue, cur.Left)
			}
			if cur.Right != nil {
				queue = append(queue, cur.Right)
			}
		}
		ret = append(ret, layer)
	}
	return ret
}

Go 实现：二叉树的层序遍历 II

反转自顶向下的各层结果，得到自底向上的层序结果。

func levelOrderBottom(root *TreeNode) [][]int {
	var ret [][]int = make([][]int, 0)
	if root == nil {
		return ret
	}

	var queue []*TreeNode = make([]*TreeNode, 0)
	queue = append(queue, root)
	for len(queue) > 0 {
		sz := len(queue)
		var layer []int = make([]int, 0)
		for range sz {
			cur := queue[0]
			queue = queue[1:]

			layer = append(layer, cur.Val)
			if cur.Left != nil {
				queue = append(queue, cur.Left)
			}
			if cur.Right != nil {
				queue = append(queue, cur.Right)
			}
		}
		ret = append(ret, layer)
	}

	for l, r := 0, len(ret)-1; l < r; l, r = l+1, r-1 {
		ret[l], ret[r] = ret[r], ret[l]
	}
	return ret
}

Go 实现：二叉树的层平均值

逐层累加再除以本层节点数；使用 float64 累加避免 int 求和溢出。空树返回空结果。

func averageOfLevels(root *TreeNode) []float64 {
	var ret []float64
	if root == nil {
		return ret
	}
	var queue []*TreeNode

	queue = append(queue, root)
	for size := len(queue); size > 0; size = len(queue) {
		var sum float64
		for range size {
			cur := queue[0]
			queue = queue[1:]
			sum += float64(cur.Val)
			if cur.Left != nil {
				queue = append(queue, cur.Left)
			}
			if cur.Right != nil {
				queue = append(queue, cur.Right)
			}
		}
		ret = append(ret, float64(sum)/float64(size))
	}
	return ret
}

Go 实现：N 叉树的层序遍历

func naryLevelOrder(root *NaryNode) [][]int {
	var ret [][]int
	if root == nil {
		return ret
	}
	var queue []*NaryNode
	queue = append(queue, root)

	for size := len(queue); size > 0; size = len(queue) {
		var layer []int
		for range size {
			cur := queue[0]
			queue = queue[1:]
			layer = append(layer, cur.Val)
			for _, node := range cur.Children {
				queue = append(queue, node)
			}
		}
		ret = append(ret, layer)
	}
	return ret
}

Go 实现：在每个树中找最大值

每层最大值从该层第一个节点开始更新，不用固定常量限制合法数值。

func largestValues(root *TreeNode) []int {
	var ret []int
	if root == nil {
		return ret
	}

	var queue []*TreeNode
	queue = append(queue, root)
	for len(queue) > 0 {
		sz := len(queue)
		var layerMax int = queue[0].Val
		for range sz {
			cur := queue[0]
			queue = queue[1:]

			layerMax = max(layerMax, cur.Val)
			if cur.Left != nil {
				queue = append(queue, cur.Left)
			}
			if cur.Right != nil {
				queue = append(queue, cur.Right)
			}
		}
		ret = append(ret, layerMax)
	}
	return ret
}

Go 实现：填充每个节点的下一个右侧节点指针

按层连接相邻节点。题目保证 Next 初始为空，每层末尾无需额外赋值。

func connect(root *NextNode) *NextNode {
	if root == nil {
		return root
	}
	var queue []*NextNode
	queue = append(queue, root)

	for size := len(queue); size > 0; size = len(queue) {
		var prev *NextNode = nil
		for range size {
			cur := queue[0]
			queue = queue[1:]

			if prev != nil {
				prev.Next = cur
			}
			prev = cur

			if cur.Left != nil {
				queue = append(queue, cur.Left)
			}
			if cur.Right != nil {
				queue = append(queue, cur.Right)
			}
		}
	}

	return root
}

序列化与反序列化

把二叉树编码成字符串，并能够无歧义地恢复原树。

思路

前序遍历遇到空指针时写入 #。空节点标记保留了左右子树边界，因此反序列化时按同一顺序读取即可唯一恢复。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

String serializeTree(TreeNode root) {
    StringBuilder output = new StringBuilder();
    serializePreorder(root, output);
    return output.toString();
}

void serializePreorder(TreeNode node, StringBuilder output) {
    if (node == null) {
        output.append("#,");
        return;
    }
    output.append(node.value).append(',');
    serializePreorder(node.left, output);
    serializePreorder(node.right, output);
}

TreeNode deserializeTree(String data) {
    Deque<String> tokens = new ArrayDeque<>(Arrays.asList(data.split(",")));
    return deserializePreorder(tokens);
}

TreeNode deserializePreorder(Deque<String> tokens) {
    String token = tokens.remove();
    if (token.equals("#")) return null;
    TreeNode node = new TreeNode(Integer.parseInt(token));
    node.left = deserializePreorder(tokens);
    node.right = deserializePreorder(tokens);
    return node;
}

根到叶子的路径

所有路径

返回二叉树所有从根到叶子的路径。

思路

路径保存当前递归链上的节点。到达叶子时复制路径，返回父节点前撤销当前选择。

复杂度

  • 时间复杂度：O(nh)O(nh)O(nh)，复制每条根到叶路径的长度至多为 hhh。
  • 空间复杂度：O(h)O(h)O(h)，不计答案空间。

Java 实现

List<List<Integer>> allRootToLeafPaths(TreeNode root) {
    List<List<Integer>> answer = new ArrayList<>();
    collectTreePaths(root, new ArrayList<>(), answer);
    return answer;
}

void collectTreePaths(TreeNode node, List<Integer> path,
                      List<List<Integer>> answer) {
    if (node == null) return;
    path.add(node.value);
    if (node.left == null && node.right == null) {
        answer.add(new ArrayList<>(path));
    } else {
        collectTreePaths(node.left, path, answer);
        collectTreePaths(node.right, path, answer);
    }
    path.remove(path.size() - 1);
}

Go 实现：二叉树的所有路径

import (
	"strconv"
	"strings"
)

const Arrow = "->"

func binaryTreePaths(root *TreeNode) []string {
	var ret []string
	if root == nil {
		return ret
	}
	var path []string
	dfs(root, &path, &ret)
	return ret
}

func dfs(cur *TreeNode, path *[]string, ret *[]string) {
	*path = append(*path, strconv.Itoa(cur.Val))
	if cur.Left == nil && cur.Right == nil {
		*ret = append(*ret, strings.Join(*path, Arrow))
		*path = (*path)[:len(*path)-1]
		return
	}
	if cur.Left != nil {
		dfs(cur.Left, path, ret)
	}
	if cur.Right != nil {
		dfs(cur.Right, path, ret)
	}
	*path = (*path)[:len(*path)-1]
}

路径总和

判断是否存在一条根到叶子的路径，其节点值之和等于目标值。

思路

递归向下时从目标值中减去当前节点值。只有到达叶子且剩余值恰好等于叶子值才算成功。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(h)O(h)O(h)。

Java 实现

boolean hasPathSum(TreeNode root, long target) {
    if (root == null) return false;
    if (root.left == null && root.right == null) return target == root.value;
    long remaining = target - root.value;
    return hasPathSum(root.left, remaining) || hasPathSum(root.right, remaining);
}

Go 实现

func hasPathSum(root *TreeNode, targetSum int) bool {
	if root == nil {
		return false
	}
	sum := targetSum - root.Val
	if root.Left == nil && root.Right == nil && sum == 0 {
		return true
	}

	var left, right bool = false, false
	if root.Left != nil {
		left = hasPathSum(root.Left, sum)
	}
	if root.Right != nil {
		right = hasPathSum(root.Right, sum)
	}

	return left || right
}

遍历应用

左叶子之和用深度优先遍历判断“当前节点的左孩子是否为叶子”；最底层最左值按层遍历，并记录每层第一个节点。

复杂度

  • 左叶子之和：时间复杂度 O(n)O(n)O(n)，空间复杂度 O(h)O(h)O(h)。
  • 最底层最左值：时间复杂度 O(n)O(n)O(n)，空间复杂度 O(w)O(w)O(w)。

Java 实现

int sumOfLeftLeaves(TreeNode root) {
    if (root == null) return 0;
    int answer = 0;
    if (root.left != null && root.left.left == null && root.left.right == null) {
        answer += root.left.value;
    }
    return answer + sumOfLeftLeaves(root.left) + sumOfLeftLeaves(root.right);
}

int bottomLeftValue(TreeNode root) {
    Deque<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    int answer = root.value;
    while (!queue.isEmpty()) {
        int size = queue.size();
        answer = queue.element().value;
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.remove();
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
    }
    return answer;
}

Go 实现：左叶子之和

func sumOfLeftLeaves(root *TreeNode) int {
	var ret int = 0
	if root == nil || (root.Left == nil && root.Right == nil) {
		return ret
	}
	return leftLeavesDfs(root, false)
}

func leftLeavesDfs(cur *TreeNode, isLeft bool) int {
	if isLeft && cur.Left == nil && cur.Right == nil {
		return cur.Val
	}
	var sum int = 0
	if cur.Left != nil {
		sum += leftLeavesDfs(cur.Left, true)
	}
	if cur.Right != nil {
		sum += leftLeavesDfs(cur.Right, false)
	}
	return sum
}

Go 实现：找树左下角的值

var maxDepth, leftValue int

func findBottomLeftValue(root *TreeNode) int {
	maxDepth, leftValue = 1, root.Val
	bottomLeftDfs(root, 1)
	return leftValue
}

func bottomLeftDfs(cur *TreeNode, depth int) {
	if cur == nil {
		return
	}
	if cur.Left == nil && cur.Right == nil {
		if depth > maxDepth {
			maxDepth = depth
			leftValue = cur.Val
		}
		return
	}

	bottomLeftDfs(cur.Left, depth+1)
	bottomLeftDfs(cur.Right, depth+1)
}
