#并查集

阅读线索

并查集通过代表元维护集合划分。路径压缩改变父指针以缩短查找，按大小合并限制树高，集合统计信息则应由当前代表元统一保存。

并查集维护不相交集合，核心操作是查找代表元与合并集合。路径压缩把查找路径上的节点直接连接到根；按集合大小合并可以避免树过深。二者同时使用时，单次操作的均摊复杂度接近常数。

基础模板

class UnionFind {
    private final int[] parent;
    private final int[] size;

    UnionFind(int n) {
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
    }

    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    boolean union(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA == rootB) {
            return false;
        }
        if (size[rootA] < size[rootB]) {
            int temporary = rootA;
            rootA = rootB;
            rootB = temporary;
        }
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
        return true;
    }

    boolean connected(int a, int b) {
        return find(a) == find(b);
    }

    int componentSize(int x) {
        return size[find(x)];
    }
}

连通块大小

初始有 nnn 个互不连通的点，支持合并两个点所在的连通块、判断两点是否连通，以及查询某点所在连通块的点数。

思路

只有根节点的 size 有意义。合并两个不同根时，把较小集合的根挂到较大集合的根，并累加大小；查询时先找到代表元。基础模板已经完整支持这些操作。

食物链

有 NNN 只动物，关系只有同类、捕食和被捕食三种。依次给出“同类”或“前者吃后者”的陈述，统计与此前信息冲突或编号非法的陈述数量。

关系表示

distance[x] 表示 xxx 到其父节点的关系，模 333 后：

  • 000：同类。
  • 111：xxx 吃父节点。
  • 222：xxx 被父节点吃。

路径压缩时累加关系。若 xxx 和 yyy 已在同一集合，可由 (distance[x] - distance[y]) mod 3 检查陈述；否则合并两棵树，并计算新根到父根应满足的关系。

class FoodChainUnionFind {
    private final int[] parent;
    private final int[] distance;

    FoodChainUnionFind(int n) {
        parent = new int[n + 1];
        distance = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }

    int find(int x) {
        if (parent[x] != x) {
            int previousParent = parent[x];
            parent[x] = find(previousParent);
            distance[x] = Math.floorMod(distance[x] + distance[previousParent], 3);
        }
        return parent[x];
    }

    boolean accept(int type, int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        int required = type == 1 ? 0 : 1;
        if (rootX == rootY) {
            return Math.floorMod(distance[x] - distance[y], 3) == required;
        }
        parent[rootX] = rootY;
        distance[rootX] = Math.floorMod(required - distance[x] + distance[y], 3);
        return true;
    }
}

敌对关系

每个人的敌人可能成为自己的朋友。维护若干“aaa 与 bbb 敌对”的约束，并判断新增约束是否产生矛盾。

扩展域并查集

为每个元素建立两个节点：x 表示 xxx 所属集合，x + n 表示 xxx 的敌对集合。声明 aaa 与 bbb 敌对时合并：

  • aaa 与 bbb 的敌对域。
  • bbb 与 aaa 的敌对域。

若新增关系前 aaa 与 bbb 已在同一集合，则产生矛盾。

boolean addEnemyConstraint(UnionFind unionFind, int n, int a, int b) {
    if (unionFind.connected(a, b)) {
        return false;
    }
    unionFind.union(a, b + n);
    unionFind.union(b, a + n);
    return true;
}
