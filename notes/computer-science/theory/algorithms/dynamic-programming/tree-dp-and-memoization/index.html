阅读线索

树形 DP 先合并孩子的信息，再决定父节点状态；记忆化搜索按依赖递归计算并缓存结果。舞会依靠选或不选的相邻约束，滑雪依靠高度严格下降保证无环。

树形动态规划通常在后序遍历中先求子树状态，再合并到父节点。记忆化搜索则按递归依赖自然地计算状态，并缓存已经求出的结果。

没有上司的舞会

一家公司中 NNN 名职员的上下级关系构成一棵树，每名职员有一个快乐指数。职员不愿与自己的直接上司同时参加舞会，求合法邀请方案的最大快乐指数之和。

状态表示

  • f(u,0)f(u,0)f(u,0)：从以 uuu 为根的子树中选择人员，且不选择 uuu 的所有方案，属性为最大快乐指数。
  • f(u,1)f(u,1)f(u,1)：从以 uuu 为根的子树中选择人员，且选择 uuu 的所有方案，属性为最大快乐指数。

状态计算

对 uuu 的每个直接下属 vvv：

  • 不选择 uuu 时，vvv 可以选也可以不选，取二者最大值。
  • 选择 uuu 时，所有直接下属都不能选。
f(u,0)=∑v∈child(u)max⁡(f(v,0),f(v,1))f(u,1)=hu+∑v∈child(u)f(v,0)\begin{aligned} f(u,0)&=\sum_{v \in child(u)}\max(f(v,0),f(v,1))\\ f(u,1)&=h_u+\sum_{v \in child(u)}f(v,0) \end{aligned}f(u,0)f(u,1)​=v∈child(u)∑​max(f(v,0),f(v,1))=hu​+v∈child(u)∑​f(v,0)​

每棵子树之间没有人员重叠，可以独立取最优后求和。后序遍历保证计算父节点前，所有子节点状态已经求出。

int maxPartyHappiness(int[] happiness, int[][] children, int root) {
    int[][] f = new int[happiness.length][2];
    calculateParty(root, happiness, children, f);
    return Math.max(f[root][0], f[root][1]);
}

void calculateParty(int employee, int[] happiness, int[][] children, int[][] f) {
    f[employee][1] = happiness[employee];
    for (int subordinate : children[employee]) {
        calculateParty(subordinate, happiness, children, f);
        f[employee][0] += Math.max(f[subordinate][0], f[subordinate][1]);
        f[employee][1] += f[subordinate][0];
    }
}

滑雪

给定一个 R×CR \times CR×C 的整数矩阵，每次可以向上下左右相邻区域移动，但只能移动到高度更低的位置。求能够经过的最大区域数量。

状态表示

f(x,y)f(x,y)f(x,y) 表示从位置 (x,y)(x,y)(x,y) 出发的所有严格下降路径，属性为最大路径长度。

状态计算

按第一步移动到的相邻位置 (nx,ny)(nx,ny)(nx,ny) 划分。只有相邻位置更低时，该子集才存在：

f(x,y)=1+max⁡(nx,ny){f(nx,ny)∣hnx,ny<hx,y}f(x,y)=1+\max_{(nx,ny)}\{f(nx,ny)\mid h_{nx,ny}<h_{x,y}\}f(x,y)=1+(nx,ny)max​{f(nx,ny)∣hnx,ny​<hx,y​}

若没有更低的相邻位置，路径只包含当前格，长度为 111。高度严格下降保证状态依赖无环；记忆化后每个格子只计算一次，时间复杂度为 O(RC)O(RC)O(RC)。

int longestSkiPath(int[][] height) {
    int[][] memo = new int[height.length][height[0].length];
    int answer = 0;
    for (int row = 0; row < height.length; row++) {
        for (int column = 0; column < height[0].length; column++) {
            answer = Math.max(answer, ski(row, column, height, memo));
        }
    }
    return answer;
}

int ski(int row, int column, int[][] height, int[][] memo) {
    if (memo[row][column] != 0) {
        return memo[row][column];
    }
    int[] dr = {-1, 0, 1, 0};
    int[] dc = {0, 1, 0, -1};
    int best = 1;
    for (int direction = 0; direction < 4; direction++) {
        int nextRow = row + dr[direction];
        int nextColumn = column + dc[direction];
        if (nextRow >= 0 && nextRow < height.length
                && nextColumn >= 0 && nextColumn < height[0].length
                && height[nextRow][nextColumn] < height[row][column]) {
            best = Math.max(best, 1 + ski(nextRow, nextColumn, height, memo));
        }
    }
    memo[row][column] = best;
    return best;
}
