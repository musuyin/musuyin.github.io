最优二叉搜索树

2026-10-23

#动态规划#二叉搜索树

阅读线索

本篇只考虑成功查找概率给定的最优二叉搜索树。选择根以后，两侧子树的所有节点都多访问一层，因此转移要增加整个区间的概率和。

给定已经有序的 nnn 个关键字及其成功查找概率 pip_ipi​，构造二叉搜索树，使期望查找代价 ∑pi(depth⁡i+1)\sum p_i(\operatorname{depth}_i+1)∑pi​(depthi​+1) 最小。

状态表示

  • 集合：f(i,j)f(i,j)f(i,j) 表示使用关键字区间 [i,j][i,j][i,j] 构造的所有二叉搜索树。
  • 属性：这些树的最小加权查找代价。

状态计算

按根节点 kkk 划分集合。区间 [i,k−1][i,k-1][i,k−1] 和 [k+1,j][k+1,j][k+1,j] 分别构成左右子树；它们所有节点的深度相对独立子树都增加一，因此额外增加区间概率和 w(i,j)w(i,j)w(i,j)：

f(i,j)=min⁡i≤k≤j{f(i,k−1)+f(k+1,j)+w(i,j)}f(i,j)=\min_{i\le k\le j}\{f(i,k-1)+f(k+1,j)+w(i,j)\}f(i,j)=i≤k≤jmin​{f(i,k−1)+f(k+1,j)+w(i,j)}

不同根节点对应的树集合互不重叠，并覆盖所有可能的二叉搜索树。

初始化与计算顺序

空区间代价为零。按区间长度从小到大计算，保证左右子区间已经得到答案。

复杂度

  • 时间复杂度：O(n3)O(n^3)O(n3)。
  • 空间复杂度：O(n2)O(n^2)O(n2)。

Java 实现

double optimalBstCost(double[] probability) {
    int n = probability.length;
    double[] prefix = new double[n + 1];
    for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + probability[i];
    double[][] cost = new double[n][n];
    for (int length = 1; length <= n; length++) {
        for (int left = 0; left + length <= n; left++) {
            int right = left + length - 1;
            cost[left][right] = Double.POSITIVE_INFINITY;
            double weight = prefix[right + 1] - prefix[left];
            for (int root = left; root <= right; root++) {
                double leftCost = root == left ? 0 : cost[left][root - 1];
                double rightCost = root == right ? 0 : cost[root + 1][right];
                cost[left][right] = Math.min(cost[left][right],
                        leftCost + rightCost + weight);
            }
        }
    }
    return cost[0][n - 1];
}
