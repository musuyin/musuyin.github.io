#动态规划

阅读线索

动态规划的核心是定义能封闭转移的状态。基础题从最后一步划分方案，计数时要求不重不漏，优化时则需要证明被覆盖的状态以后不再使用。

动态规划处理的是一类具有重叠子问题和最优子结构的问题。分析时先定义状态，再寻找能够完整覆盖状态集合的划分依据。

分析框架

状态表示

用 f(i,j)f(i,j)f(i,j) 表示一个集合及其属性：

  • 集合：当前状态包含哪些合法方案，限制条件分别由哪些下标表达。
  • 属性：从集合中求最大值、最小值、方案数或是否可行。

状态定义必须能区分影响后续决策的信息。信息不足会导致无法转移，信息冗余则会增加状态数量。

状态计算

选择一个确定的分类依据，将 f(i,j)f(i,j)f(i,j) 对应的集合划分成若干子集。常见依据包括：

  • 最后一步从哪里转移而来。
  • 当前物品是否选择、选择多少件。
  • 最后一个元素或最后一个分界点。
  • 根节点是否选择。

求方案数时，划分必须不重不漏；求最大值或最小值时可以有重叠，但不能遗漏可能产生最优解的方案。

初始化与计算顺序

  • 初始化描述规模最小的问题，例如空前缀、空集合和单元素区间。
  • 非法状态应与合法状态区分，最大值问题通常初始化为负无穷，最小值问题通常初始化为正无穷。
  • 计算顺序必须保证转移所依赖的状态已经求出。
  • 时间复杂度通常等于状态数量乘以单个状态的转移代价。

爬楼梯

有一段包含 nnn 级台阶的楼梯，每次可以爬 111 级或 222 级。求到达第 nnn 级台阶共有多少种不同的方法。

状态表示

f(i)f(i)f(i) 表示到达第 iii 级台阶的所有方案，属性为方案数。

状态计算

按最后一步的长度划分：

  • 最后走 111 级，之前位于第 i−1i-1i−1 级，共有 f(i−1)f(i-1)f(i−1) 种方案。
  • 最后走 222 级，之前位于第 i−2i-2i−2 级，共有 f(i−2)f(i-2)f(i−2) 种方案。

两个集合互斥且覆盖全部方案，因此：

f(i)=f(i−1)+f(i−2)f(i)=f(i-1)+f(i-2)f(i)=f(i−1)+f(i−2)

初始化为 f(0)=1f(0)=1f(0)=1、f(1)=1f(1)=1f(1)=1。只依赖前两个状态，可将空间压缩为 O(1)O(1)O(1)。

int climbStairs(int n) {
    int previous = 1;
    int current = 1;
    for (int i = 1; i <= n; i++) {
        int next = previous + current;
        previous = current;
        current = next;
    }
    return previous;
}

Go 实现

func climbStairs(n int) int {
	if n <= 2 {
		return n
	}
	var f []int = make([]int, n+1)
	f[1], f[2] = 1, 2
	for i := 3; i <= n; i++ {
		f[i] = f[i-1] + f[i-2]
	}
	return f[n]
}

不同路径

一个机器人位于 m×nm \times nm×n 网格的左上角，每次只能向右或向下移动一步。求到达右下角的不同路径数。

状态表示

f(i,j)f(i,j)f(i,j) 表示从左上角走到格子 (i,j)(i,j)(i,j) 的所有路径，属性为方案数。

状态计算

按最后一步的方向划分：最后一步只能从上方或左方到达，两个集合互斥且没有遗漏。

f(i,j)=f(i−1,j)+f(i,j−1)f(i,j)=f(i-1,j)+f(i,j-1)f(i,j)=f(i−1,j)+f(i,j−1)

第一行和第一列均只有一种走法。压缩为一维后，更新前的 f[j] 表示上方状态，f[j - 1] 表示本行左侧状态。

int uniquePaths(int m, int n) {
    int[] f = new int[n];
    Arrays.fill(f, 1);
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            f[j] += f[j - 1];
        }
    }
    return f[n - 1];
}

整数拆分

给定正整数 nnn，将它拆分为至少两个正整数之和，使这些整数的乘积最大，返回最大乘积。

状态表示

f(i)f(i)f(i) 表示将整数 iii 拆分后得到的所有乘积，属性为最大值。

状态计算

按拆出的第一项 jjj 划分。剩余的 i−ji-ji−j 可以不再拆，也可以继续按最优方式拆分：

f(i)=max⁡1≤j<i{j(i−j),;j⋅f(i−j)}f(i)=\max_{1 \le j<i}\left\{j(i-j),;j \cdot f(i-j)\right\}f(i)=1≤j<imax​{j(i−j),;j⋅f(i−j)}
int integerBreak(int n) {
    int[] f = new int[n + 1];
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j < i; j++) {
            f[i] = Math.max(f[i], Math.max(j * (i - j), j * f[i - j]));
        }
    }
    return f[n];
}

不同的二叉搜索树

给定整数 nnn，求由互不相同的键 111 到 nnn 组成的结构不同的二叉搜索树数量。

状态表示

f(i)f(i)f(i) 表示由连续的 iii 个有序键构成二叉搜索树的所有方案，属性为方案数。键的具体取值不影响结构，只与键的数量有关。

状态计算

按根节点在有序序列中的位置 jjj 划分。根为第 jjj 个键时，左子树有 j−1j-1j−1 个键，右子树有 i−ji-ji−j 个键，两边可以独立组合：

f(i)=∑j=1if(j−1)f(i−j)f(i)=\sum_{j=1}^{i}f(j-1)f(i-j)f(i)=j=1∑i​f(j−1)f(i−j)

不同根节点对应的集合互斥。空树是组合时的单位元，因此 f(0)=1f(0)=1f(0)=1。

int numTrees(int n) {
    int[] f = new int[n + 1];
    f[0] = 1;
    for (int nodes = 1; nodes <= n; nodes++) {
        for (int root = 1; root <= nodes; root++) {
            f[nodes] += f[root - 1] * f[nodes - root];
        }
    }
    return f[n];
}

组合总和

给定一个由不同正整数组成的数组 nums 和目标整数 target，求元素总和等于 target 的排列数量。数组中的元素可以重复使用，不同顺序视为不同方案。

状态表示

f(i)f(i)f(i) 表示总和恰好为 iii 的所有排列，属性为方案数。

状态计算

按排列的最后一个数 xxx 划分。删掉最后的 xxx 后，前缀总和为 i−xi-xi−x：

f(i)=∑x∈nums,,x≤if(i−x)f(i)=\sum_{x \in nums,,x \le i}f(i-x)f(i)=x∈nums,,x≤i∑​f(i−x)

因为顺序不同算不同方案，所以先枚举总和，再枚举最后选择的数。空排列是构造其他排列的起点，初始化 f(0)=1f(0)=1f(0)=1。

int combinationSum4(int[] nums, int target) {
    int[] f = new int[target + 1];
    f[0] = 1;
    for (int sum = 1; sum <= target; sum++) {
        for (int x : nums) {
            if (x <= sum) {
                f[sum] += f[sum - x];
            }
        }
    }
    return f[target];
}

斐波那契数

给定非负整数 nnn，求 F(n)F(n)F(n)：F(0)=0F(0)=0F(0)=0、F(1)=1F(1)=1F(1)=1，F(n)=F(n−1)+F(n−2)F(n)=F(n-1)+F(n-2)F(n)=F(n−1)+F(n−2)。以下实现要求结果能用 int 表示。

状态表示

f(i)f(i)f(i) 表示第 iii 个斐波那契数，属性为数值。

状态计算

按定义递推：f(i)=f(i−1)+f(i−2)f(i)=f(i-1)+f(i-2)f(i)=f(i−1)+f(i−2)。

初始化与计算顺序

f(0)=0f(0)=0f(0)=0、f(1)=1f(1)=1f(1)=1，从小到大计算；n=0,1n=0,1n=0,1 直接返回边界值。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Go 实现

func fib(n int) int {
	if n == 0 {
		return 0
	} else if n == 1 {
		return 1
	}
	var f []int = make([]int, n+1)
	f[0], f[1] = 0, 1

	for i := 2; i <= n; i++ {
		f[i] = f[i-1] + f[i-2]
	}
	return f[n]
}

使用最小花费爬楼梯

cost[i] 是从第 iii 级台阶继续爬升的费用，每次爬一或两级。可以免费站到下标 0 或 1 的台阶，求到达下标 nnn 的楼顶的最小费用。

状态表示

f(i)f(i)f(i) 包含所有到达下标 iii 的位置、尚未支付该位置费用的路径，属性为最小累计费用。

状态计算

按最后一步划分：从 i−1i-1i−1 或 i−2i-2i−2 出发，支付对应起点的费用。

f(i)=min⁡(f(i−1)+cost[i−1],f(i−2)+cost[i−2])f(i)=\min(f(i-1)+cost[i-1],f(i-2)+cost[i-2])f(i)=min(f(i−1)+cost[i−1],f(i−2)+cost[i−2])

初始化与计算顺序

f(0)=f(1)=0f(0)=f(1)=0f(0)=f(1)=0，从 i=2i=2i=2 正序计算到 nnn，返回 f(n)f(n)f(n)。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Go 实现

func minCostClimbingStairs(cost []int) int {
	n := len(cost)
	var f []int = make([]int, n+1)

	for i := 2; i <= n; i++ {
		f[i] = min(f[i-1]+cost[i-1], f[i-2]+cost[i-2])
	}
	return f[n]
}
