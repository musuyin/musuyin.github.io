计数与数位动态规划

2026-10-23

#动态规划#数位动态规划

阅读线索

计数 DP 按互斥类别累加方案，数位问题则把整数按位或按最高位分类。整数划分、放苹果和数字出现次数虽然形式不同，都要解释为何没有重复计数。

计数问题要求集合划分不重不漏，否则重复方案会直接改变答案。数位统计则常把区间问题转成两个前缀问题，再按某一数位上的数字分类统计。

整数划分

一个正整数 nnn 可以表示成若干正整数之和，不考虑各项顺序。给定 nnn，求不同划分方案数，答案对 109+710^9+7109+7 取模。

状态表示

把整数 111 到 nnn 视为可以无限使用的物品，体积等于数值。f(i,j)f(i,j)f(i,j) 表示只使用不超过 iii 的正整数、总和恰好为 jjj 的所有组合，属性为方案数。

状态计算

按正整数 iii 是否至少使用一次划分：

  • 不使用 iii：f(i−1,j)f(i-1,j)f(i−1,j)。
  • 至少使用一次 iii：去掉一个 iii 后仍可继续使用 iii，对应 f(i,j−i)f(i,j-i)f(i,j−i)。
f(i,j)=f(i−1,j)+f(i,j−i)f(i,j)=f(i-1,j)+f(i,j-i)f(i,j)=f(i−1,j)+f(i,j−i)

压缩成一维后，先枚举整数再正序枚举总和。这个顺序使不同排列归入同一个组合。初始化 f(0)=1f(0)=1f(0)=1，表示凑出总和为零的空方案。

int countIntegerPartitions(int n) {
    int mod = 1_000_000_007;
    int[] f = new int[n + 1];
    f[0] = 1;
    for (int value = 1; value <= n; value++) {
        for (int sum = value; sum <= n; sum++) {
            f[sum] = (f[sum] + f[sum - value]) % mod;
        }
    }
    return f[n];
}

也可以定义 g(i,j)g(i,j)g(i,j) 为“总和为 iii 且恰好由 jjj 个正整数构成”的方案数，并按最小项是否为 111 划分：

g(i,j)=g(i−1,j−1)+g(i−j,j)g(i,j)=g(i-1,j-1)+g(i-j,j)g(i,j)=g(i−1,j−1)+g(i−j,j)

第一项对应至少有一个 111，删除一个 111；第二项对应所有项都大于 111，将每一项同时减 111。最终答案为 ∑j=1ng(n,j)\sum_{j=1}^{n}g(n,j)∑j=1n​g(n,j)。

放苹果

将 mmm 个相同的苹果放入 nnn 个相同的盘子，允许空盘，求不同的分法数量。

交换盘子的顺序不产生新方案。例如 (0,1,2)(0,1,2)(0,1,2) 和 (2,0,1)(2,0,1)(2,0,1) 是同一种分法。

状态表示

  • 集合：f(m,n)f(m,n)f(m,n) 表示将 mmm 个相同的苹果放入 nnn 个相同盘子的所有合法方案，允许空盘。
  • 属性：方案数。也就是把 mmm 划分成至多 nnn 个正整数的方案数。

题目未给出数据范围。以下保留原递归实现，适用于较小输入，并假设结果可以用 Go 的 int 表示；不自行添加取模规则。

状态计算

按是否存在空盘划分，两个集合互斥，且覆盖全部方案：

  • 至少有一个空盘：删除一个空盘，得到 f(m,n−1)f(m,n-1)f(m,n−1)。这里不是“恰好一个空盘”，剩下的盘子仍可为空。由于盘子相同，删除哪个空盘不产生区别；反过来补一个空盘可唯一恢复原方案，因此无需乘以 nnn。
  • 所有盘子非空：每个盘子先取走一个苹果，得到 f(m−n,n)f(m-n,n)f(m−n,n)。剩下的盘子允许为空；反过来给每个盘子加一个苹果可唯一恢复原方案。

当 m≥n≥1m \ge n \ge 1m≥n≥1 时：

f(m,n)=f(m,n−1)+f(m−n,n)f(m,n)=f(m,n-1)+f(m-n,n)f(m,n)=f(m,n−1)+f(m−n,n)

当 n>mn>mn>m 时，最多只有 mmm 个盘子非空，多余空盘不影响方案数，因此 f(m,n)=f(m,m)f(m,n)=f(m,m)f(m,n)=f(m,m)；m=0m=0m=0 单独按边界处理。

例如 m=4,n=3m=4,n=3m=4,n=3 时，共有 (0,0,4)(0,0,4)(0,0,4)、(0,1,3)(0,1,3)(0,1,3)、(0,2,2)(0,2,2)(0,2,2)、(1,1,2)(1,1,2)(1,1,2) 四种方案。其中前三种存在空盘，最后一种所有盘子非空。

初始化与计算顺序

  • f(0,n)=1f(0,n)=1f(0,n)=1（n≥1n \ge 1n≥1）：没有苹果时，全部盘子为空，只有一种方案。
  • f(1,n)=1f(1,n)=1f(1,n)=1（n≥1n \ge 1n≥1）、f(m,1)=1f(m,1)=1f(m,1)=1（m≥0m \ge 0m≥0）：只有一种分法。
  • 代码按 m≥0,n≥1m \ge 0,n \ge 1m≥0,n≥1 的输入约定处理；m < 0 或 n <= 0 返回零，不作为题目规定的合法输入。若扩展到零个盘子，需要另行定义 f(0,0)=1f(0,0)=1f(0,0)=1。

递归先处理边界，再处理 n>mn>mn>m 的剪枝，最后计算两个子状态。每次递归都使 m+nm+nm+n 减小，因此能够终止。

复杂度

  • 时间复杂度：原递归会重复计算相同状态，O(2m+n)O(2^{m+n})O(2m+n) 是宽松上界，不是紧确界。
  • 空间复杂度：O(m+n)O(m+n)O(m+n)，来自递归调用栈。

如果输入较大，可以缓存每个 (m,n)(m,n)(m,n) 的结果。令 k=min⁡(m,n)k=\min(m,n)k=min(m,n)，对 m≥1m \ge 1m≥1，记忆化后的状态数至多为 O(mk)O(mk)O(mk)，时间复杂度为 O(mk)O(mk)O(mk)，缓存空间为 O(mk)O(mk)O(mk)，另需递归栈空间。更大结果还需要使用大整数。

Go 实现

原代码实际是 Go，代码块应使用 go，而不是 javascript。保留单组输入的完整程序及原递推：

package main

import "fmt"

func main() {
	var m, n int
	fmt.Scan(&m, &n)
	fmt.Println(work(m, n))
}

func work(m, n int) int {
	if m < 0 || n <= 0 {
		return 0
	}
	if m <= 1 || n == 1 {
		return 1
	}
	// 多余的空盘不影响方案数。
	if n > m {
		return work(m, m)
	}
	return work(m, n-1) + work(m-n, n)
}

数字出现次数

给定两个正整数 aaa 和 bbb，统计闭区间 [a,b][a,b][a,b] 中数字 000 到 999 分别出现了多少次。例如 a=1024,b=1032a=1024,b=1032a=1024,b=1032 时，需要统计这九个整数的十进制表示。

状态表示

定义 count(n,d)count(n,d)count(n,d) 为整数 111 到 nnn 的十进制表示中，数字 ddd 出现的总次数，属性为计数。区间答案通过前缀差得到：

answer(a,b,d)=count(max⁡(a,b),d)−count(min⁡(a,b)−1,d)answer(a,b,d)=count(\max(a,b),d)-count(\min(a,b)-1,d)answer(a,b,d)=count(max(a,b),d)−count(min(a,b)−1,d)

状态计算

枚举十进制位权 factor=1,10,100,…factor=1,10,100,\ldotsfactor=1,10,100,…，把 nnn 相对当前位拆成：

n=higher×(10×factor)+current×factor+lowern=higher \times (10 \times factor)+current \times factor+lowern=higher×(10×factor)+current×factor+lower

对非零数字 ddd：

  • current < d：当前位为 ddd 的完整循环有 higher 个，贡献 higher×factorhigher \times factorhigher×factor。
  • current == d：再加当前未完整循环中的 lower+1lower+1lower+1。
  • current > d：再多一个完整的 factor。

数字 000 不能统计前导零。当前位存在时，最高部分必须至少为 111，所以完整循环数从 higher 调整为 higher - 1；当 higher == 0 时，该位尚不存在，不产生贡献。

long[] countDigitsInRange(int a, int b) {
    int left = Math.min(a, b);
    int right = Math.max(a, b);
    long[] answer = new long[10];
    for (int digit = 0; digit <= 9; digit++) {
        answer[digit] = countDigit(right, digit) - countDigit(left - 1, digit);
    }
    return answer;
}

long countDigit(int n, int digit) {
    if (n <= 0) {
        return 0;
    }
    long count = 0;
    for (long factor = 1; factor <= n; factor *= 10) {
        long lower = n % factor;
        long current = n / factor % 10;
        long higher = n / (factor * 10);
        if (digit != 0) {
            count += higher * factor;
            if (current > digit) {
                count += factor;
            } else if (current == digit) {
                count += lower + 1;
            }
        } else if (higher > 0) {
            count += (higher - 1) * factor;
            if (current > 0) {
                count += factor;
            } else if (current == 0) {
                count += lower + 1;
            }
        }
    }
    return count;
}
