#动态规划#区间动态规划

阅读线索

区间 DP 通过最后一次分割或两端选择连接子区间。石子合并、取数游戏和移除盒子分别展示固定合并费用、角色交换及额外状态的必要性。

区间动态规划以一段连续区间作为状态，通常按最后一次合并的分界点、根节点或两端选择划分集合。计算时先枚举较短区间，再枚举较长区间。

石子合并

有 NNN 堆石子排成一行，每次只能合并相邻的两堆，代价为两堆石子的质量之和。求将所有石子合并成一堆的最小总代价。

状态表示

f(l,r)f(l,r)f(l,r) 表示把第 lll 堆到第 rrr 堆合并成一堆的所有方案，属性为最小总代价。

状态计算

按最后一次合并前左右两堆的分界点 kkk 划分：左边为 [l,k][l,k][l,k]，右边为 [k+1,r][k+1,r][k+1,r]。不同 kkk 对应不同的最后一次合并，完整覆盖所有方案。最后一次合并的代价固定为区间石子总量：

f(l,r)=min⁡l≤k<r{f(l,k)+f(k+1,r)+S(r)−S(l−1)}f(l,r)=\min_{l \le k<r}\left\{f(l,k)+f(k+1,r)+S(r)-S(l-1)\right\}f(l,r)=l≤k<rmin​{f(l,k)+f(k+1,r)+S(r)−S(l−1)}

单堆无需合并，初始化 f(i,i)=0f(i,i)=0f(i,i)=0。按区间长度递增计算，时间复杂度为 O(n3)O(n^3)O(n3)。

int mergeStones(int[] stones) {
    int n = stones.length;
    int[] prefix = new int[n + 1];
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + stones[i];
    }
    int[][] f = new int[n][n];
    for (int length = 2; length <= n; length++) {
        for (int left = 0; left + length <= n; left++) {
            int right = left + length - 1;
            f[left][right] = Integer.MAX_VALUE;
            int sum = prefix[right + 1] - prefix[left];
            for (int middle = left; middle < right; middle++) {
                f[left][right] = Math.min(f[left][right],
                        f[left][middle] + f[middle + 1][right] + sum);
            }
        }
    }
    return f[0][n - 1];
}

取数游戏

两名玩家轮流从正整数序列的左端或右端取走一个数并得到对应分数，直到序列为空。双方都采用最优策略，求两人的最终得分。

状态表示

f(l,r)f(l,r)f(l,r) 表示面对区间 [l,r][l,r][l,r] 时，当前玩家相对另一名玩家能够取得的最大分差，属性为最大值。

只记录当前玩家的总分无法表达对方随后最优选择的影响；分差在玩家交换后会自动取反，因此能封闭转移。

状态计算

按当前玩家取左端还是右端划分：

f(l,r)=max⁡(al−f(l+1,r),ar−f(l,r−1))f(l,r)=\max\left(a_l-f(l+1,r),a_r-f(l,r-1)\right)f(l,r)=max(al​−f(l+1,r),ar​−f(l,r−1))

选择一个端点后，对手成为剩余区间的当前玩家，因此要减去对手能取得的最大分差。初始化 f(i,i)=aif(i,i)=a_if(i,i)=ai​。若总分为 sumsumsum、最终分差为 ddd，两人得分分别是 (sum+d)/2(sum+d)/2(sum+d)/2 与 (sum−d)/2(sum-d)/2(sum−d)/2。

int[] optimalGameScores(int[] nums) {
    int n = nums.length;
    int[][] f = new int[n][n];
    int sum = 0;
    for (int i = 0; i < n; i++) {
        f[i][i] = nums[i];
        sum += nums[i];
    }
    for (int length = 2; length <= n; length++) {
        for (int left = 0; left + length <= n; left++) {
            int right = left + length - 1;
            f[left][right] = Math.max(
                    nums[left] - f[left + 1][right],
                    nums[right] - f[left][right - 1]);
        }
    }
    int difference = f[0][n - 1];
    return new int[]{(sum + difference) / 2, (sum - difference) / 2};
}

移除盒子

给定一排带颜色的盒子，每轮可以移除连续的 kkk 个同色盒子并获得 k2k^2k2 分，求移除全部盒子能够得到的最大总分。

状态表示

只用 f(l,r)f(l,r)f(l,r) 不足以描述区间外同色盒子对当前区间的影响。定义 f(l,r,k)f(l,r,k)f(l,r,k)：移除区间 [l,r][l,r][l,r]，并把区间右侧与 boxes[r] 同色的 kkk 个盒子视为和它相连时，能够取得的最大分数。

  • 集合：所有移除 [l,r][l,r][l,r] 以及右侧 kkk 个同色盒子的顺序。
  • 属性：最大得分。

状态计算

按 boxes[r] 最终如何被移除划分：

  • 直接把它和右侧 kkk 个盒子一起移除，得 f(l,r−1,0)+(k+1)2f(l,r-1,0)+(k+1)^2f(l,r−1,0)+(k+1)2。
  • 枚举 i<ri<ri<r 且 boxes[i] == boxes[r]，先移除中间的 [i+1,r−1][i+1,r-1][i+1,r−1]，再让位置 iii 与右侧盒子合并，得 f(l,i,k+1)+f(i+1,r−1,0)f(l,i,k+1)+f(i+1,r-1,0)f(l,i,k+1)+f(i+1,r−1,0)。

先合并区间末尾已经连续同色的盒子，可以减少等价状态。

int removeBoxes(int[] boxes) {
    int n = boxes.length;
    int[][][] memo = new int[n][n][n];
    return removeBoxes(boxes, 0, n - 1, 0, memo);
}

int removeBoxes(int[] boxes, int left, int right, int joined, int[][][] memo) {
    if (left > right) {
        return 0;
    }
    while (left < right && boxes[right] == boxes[right - 1]) {
        right--;
        joined++;
    }
    if (memo[left][right][joined] != 0) {
        return memo[left][right][joined];
    }
    int best = removeBoxes(boxes, left, right - 1, 0, memo)
            + (joined + 1) * (joined + 1);
    for (int i = left; i < right; i++) {
        if (boxes[i] == boxes[right]) {
            best = Math.max(best,
                    removeBoxes(boxes, left, i, joined + 1, memo)
                            + removeBoxes(boxes, i + 1, right - 1, 0, memo));
        }
    }
    memo[left][right][joined] = best;
    return best;
}

加分二叉树

一棵二叉树的中序遍历固定为 1,2,…,n1,2,\ldots,n1,2,…,n，第 iii 个节点的分数为 did_idi​。非叶子子树的加分为“左子树加分乘右子树加分，再加根节点分数”，空子树加分为 111，叶子加分为节点自身分数。求最高加分及对应树的前序遍历。

状态表示

f(l,r)f(l,r)f(l,r) 表示中序遍历为区间 [l,r][l,r][l,r] 的所有二叉树，属性为最高加分。另用 root(l,r)root(l,r)root(l,r) 记录取得最高分时的根节点。

状态计算

按根节点 kkk 划分。固定根以后，[l,k−1][l,k-1][l,k−1] 必须构成左子树，[k+1,r][k+1,r][k+1,r] 必须构成右子树，两棵子树可以独立取最优：

f(l,r)=max⁡l≤k≤r{f(l,k−1)f(k+1,r)+dk}f(l,r)=\max_{l \le k \le r}\{f(l,k-1)f(k+1,r)+d_k\}f(l,r)=l≤k≤rmax​{f(l,k−1)f(k+1,r)+dk​}

不同根节点对应互斥集合。单节点区间按题意初始化为自身分数；空区间在转移中取 111。从 root 表按“根、左、右”递归即可还原前序遍历。

final class BonusTreeResult {
    final long score;
    final List<Integer> preorder;

    BonusTreeResult(long score, List<Integer> preorder) {
        this.score = score;
        this.preorder = preorder;
    }
}

BonusTreeResult bonusTree(int[] value) {
    int n = value.length;
    long[][] f = new long[n][n];
    int[][] root = new int[n][n];
    for (int i = 0; i < n; i++) {
        f[i][i] = value[i];
        root[i][i] = i;
    }
    for (int length = 2; length <= n; length++) {
        for (int left = 0; left + length <= n; left++) {
            int right = left + length - 1;
            for (int k = left; k <= right; k++) {
                long leftScore = k == left ? 1 : f[left][k - 1];
                long rightScore = k == right ? 1 : f[k + 1][right];
                long candidate = leftScore * rightScore + value[k];
                if (candidate > f[left][right]) {
                    f[left][right] = candidate;
                    root[left][right] = k;
                }
            }
        }
    }
    List<Integer> preorder = new ArrayList<>();
    buildPreorder(0, n - 1, root, preorder);
    return new BonusTreeResult(f[0][n - 1], preorder);
}

void buildPreorder(int left, int right, int[][] root, List<Integer> preorder) {
    if (left > right) {
        return;
    }
    int k = root[left][right];
    preorder.add(k + 1);
    buildPreorder(left, k - 1, root, preorder);
    buildPreorder(k + 1, right, root, preorder);
}
