股票问题

2026-10-23

#动态规划

阅读线索

股票 DP 的状态必须表达持有情况和交易限制。单次、多次、冷冻期与手续费改变的是允许的买卖来源，不能只替换最后的利润表达式。

股票问题的状态除了天数，还必须记录交易次数或收盘后是否持有股票。当天的状态由前一天的状态转移而来。

单次交易

给定每天的股票价格 prices，最多完成一笔买卖，求最大利润。买入必须发生在卖出之前。

状态表示

  • f(i,0)f(i,0)f(i,0)：处理完前 iii 天且不持有股票的方案，属性为最大现金。
  • f(i,1)f(i,1)f(i,1)：处理完前 iii 天且持有股票的方案，属性为最大现金。

状态计算

按第 iii 天是否发生交易划分：

f(i,0)=max⁡(f(i−1,0),f(i−1,1)+pi)f(i,1)=max⁡(f(i−1,1),−pi)\begin{aligned} f(i,0)&=\max(f(i-1,0),f(i-1,1)+p_i)\\ f(i,1)&=\max(f(i-1,1),-p_i) \end{aligned}f(i,0)f(i,1)​=max(f(i−1,0),f(i−1,1)+pi​)=max(f(i−1,1),−pi​)​

持有状态只能来自“继续持有”或“第一次买入”，因此买入时使用 −pi-p_i−pi​，不会开始第二笔交易。

int maxProfitOnce(int[] prices) {
    int cash = 0;
    int hold = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        cash = Math.max(cash, hold + prices[i]);
        hold = Math.max(hold, -prices[i]);
    }
    return cash;
}

不限交易次数

给定每天的股票价格，可以完成任意多笔交易，但同一时刻最多持有一股，求最大利润。

状态表示

f(i,0)f(i,0)f(i,0) 与 f(i,1)f(i,1)f(i,1) 分别表示处理完前 iii 天后不持有和持有股票的方案集合，属性为最大现金。

状态计算

与单次交易的区别是，买入前可以保留之前交易得到的现金：

f(i,0)=max⁡(f(i−1,0),f(i−1,1)+pi)f(i,1)=max⁡(f(i−1,1),f(i−1,0)−pi)\begin{aligned} f(i,0)&=\max(f(i-1,0),f(i-1,1)+p_i)\\ f(i,1)&=\max(f(i-1,1),f(i-1,0)-p_i) \end{aligned}f(i,0)f(i,1)​=max(f(i−1,0),f(i−1,1)+pi​)=max(f(i−1,1),f(i−1,0)−pi​)​
int maxProfitUnlimited(int[] prices) {
    int cash = 0;
    int hold = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        int previousCash = cash;
        cash = Math.max(cash, hold + prices[i]);
        hold = Math.max(hold, previousCash - prices[i]);
    }
    return cash;
}

至多两次交易

给定每天的股票价格，最多完成两笔交易，且再次买入前必须卖出已有股票，求最大利润。

状态表示

用四个状态表示一天结束后的方案集合，属性均为最大现金：

状态 集合
buy1 已完成第一次买入，当前持有
sell1 已完成第一次卖出，当前不持有
buy2 已完成第二次买入，当前持有
sell2 已完成第二次卖出，当前不持有

状态计算

每个状态按“今天不操作”或“今天完成对应交易”划分：

buy1=max⁡(buy1,−p)sell1=max⁡(sell1,buy1+p)buy2=max⁡(buy2,sell1−p)sell2=max⁡(sell2,buy2+p)\begin{aligned} buy_1&=\max(buy_1,-p)\\ sell_1&=\max(sell_1,buy_1+p)\\ buy_2&=\max(buy_2,sell_1-p)\\ sell_2&=\max(sell_2,buy_2+p) \end{aligned}buy1​sell1​buy2​sell2​​=max(buy1​,−p)=max(sell1​,buy1​+p)=max(buy2​,sell1​−p)=max(sell2​,buy2​+p)​
int maxProfitTwice(int[] prices) {
    int buy1 = -prices[0];
    int sell1 = 0;
    int buy2 = -prices[0];
    int sell2 = 0;
    for (int price : prices) {
        buy1 = Math.max(buy1, -price);
        sell1 = Math.max(sell1, buy1 + price);
        buy2 = Math.max(buy2, sell1 - price);
        sell2 = Math.max(sell2, buy2 + price);
    }
    return sell2;
}

至多若干次交易

给定每天的股票价格和整数 kkk，最多完成 kkk 笔交易，求最大利润。

状态表示

  • buy(j)buy(j)buy(j)：至多完成 j−1j-1j−1 次卖出并完成第 jjj 次买入后，最大现金。
  • sell(j)sell(j)sell(j)：至多完成 jjj 次卖出后，最大现金。

状态计算

对每个 jjj，按今天是否执行第 jjj 次买入或卖出划分：

buy(j)=max⁡(buy(j),sell(j−1)−p)sell(j)=max⁡(sell(j),buy(j)+p)\begin{aligned} buy(j)&=\max(buy(j),sell(j-1)-p)\\ sell(j)&=\max(sell(j),buy(j)+p) \end{aligned}buy(j)sell(j)​=max(buy(j),sell(j−1)−p)=max(sell(j),buy(j)+p)​
int maxProfitK(int k, int[] prices) {
    int[] buy = new int[k + 1];
    int[] sell = new int[k + 1];
    Arrays.fill(buy, Integer.MIN_VALUE / 2);
    for (int price : prices) {
        for (int j = 1; j <= k; j++) {
            buy[j] = Math.max(buy[j], sell[j - 1] - price);
            sell[j] = Math.max(sell[j], buy[j] + price);
        }
    }
    return sell[k];
}

含冷冻期

给定每天的股票价格，可以完成任意多笔交易。卖出股票后的第二天不能买入，求最大利润。

状态表示

按一天结束后的实际状态划分：

状态 集合 属性
hold 收盘后持有股票的方案 最大现金
sold 当天刚卖出股票的方案 最大现金
rest 收盘后不持有且不处于“刚卖出”的方案 最大现金

状态计算

  • hold：昨天已经持有，或昨天处于 rest 且今天买入。
  • sold：昨天持有，今天卖出。
  • rest：昨天已经休息，或昨天刚卖出而今天进入冷冻期。
holdi=max⁡(holdi−1,resti−1−pi)soldi=holdi−1+piresti=max⁡(resti−1,soldi−1)\begin{aligned} hold_i&=\max(hold_{i-1},rest_{i-1}-p_i)\\ sold_i&=hold_{i-1}+p_i\\ rest_i&=\max(rest_{i-1},sold_{i-1}) \end{aligned}holdi​soldi​resti​​=max(holdi−1​,resti−1​−pi​)=holdi−1​+pi​=max(resti−1​,soldi−1​)​
int maxProfitWithCooldown(int[] prices) {
    int hold = -prices[0];
    int sold = Integer.MIN_VALUE / 2;
    int rest = 0;
    for (int i = 1; i < prices.length; i++) {
        int previousHold = hold;
        int previousSold = sold;
        int previousRest = rest;
        hold = Math.max(previousHold, previousRest - prices[i]);
        sold = previousHold + prices[i];
        rest = Math.max(previousRest, previousSold);
    }
    return Math.max(sold, rest);
}

含手续费

给定每天的股票价格和每笔交易手续费 fee，可以完成任意多笔交易，求扣除手续费后的最大利润。

状态表示

f(i,0)f(i,0)f(i,0) 和 f(i,1)f(i,1)f(i,1) 分别表示第 iii 天结束后不持有和持有股票的方案，属性为最大现金。

状态计算

按当天是否买入或卖出划分。手续费在卖出时统一扣除：

f(i,0)=max⁡(f(i−1,0),f(i−1,1)+pi−fee)f(i,1)=max⁡(f(i−1,1),f(i−1,0)−pi)\begin{aligned} f(i,0)&=\max(f(i-1,0),f(i-1,1)+p_i-fee)\\ f(i,1)&=\max(f(i-1,1),f(i-1,0)-p_i) \end{aligned}f(i,0)f(i,1)​=max(f(i−1,0),f(i−1,1)+pi​−fee)=max(f(i−1,1),f(i−1,0)−pi​)​
int maxProfitWithFee(int[] prices, int fee) {
    int cash = 0;
    int hold = -prices[0];
    for (int i = 1; i < prices.length; i++) {
        int previousCash = cash;
        cash = Math.max(cash, hold + prices[i] - fee);
        hold = Math.max(hold, previousCash - prices[i]);
    }
    return cash;
}
