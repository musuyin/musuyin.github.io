#动态规划#背包问题

阅读线索

背包题先明确物品可选次数和容量含义。二维状态直接表达前 i 件物品，一维实现则通过遍历方向决定读到上一层还是本层状态。

背包模板

背包模型通常用“物品范围”和“容量”定义状态，再按当前物品的选择数量划分集合。一维优化后的容量遍历方向由依赖关系决定：

  • 依赖上一层的 f[j - v]，容量倒序，避免同一物品被重复选择。
  • 依赖本层的 f[j - v]，容量正序，允许同一种物品继续参与转移。

零一背包

有 NNN 件物品和容量为 VVV 的背包，每件物品只能使用一次。第 iii 件物品的体积为 viv_ivi​、价值为 wiw_iwi​。选择若干物品，在总体积不超过 VVV 的条件下最大化总价值。

状态表示

f(i,j)f(i,j)f(i,j) 表示只考虑前 iii 件物品、总体积不超过 jjj 的所有选法，属性为最大价值。

状态计算

按是否选择第 iii 件物品划分，两个子集互斥且覆盖全部选法：

f(i,j)=max⁡(f(i−1,j),f(i−1,j−vi)+wi)f(i,j)=\max\left(f(i-1,j),f(i-1,j-v_i)+w_i\right)f(i,j)=max(f(i−1,j),f(i−1,j−vi​)+wi​)

压缩成一维后，容量必须倒序枚举。

int zeroOneKnapsack(int capacity, int[] volume, int[] value) {
    int[] f = new int[capacity + 1];
    for (int i = 0; i < volume.length; i++) {
        for (int j = capacity; j >= volume[i]; j--) {
            f[j] = Math.max(f[j], f[j - volume[i]] + value[i]);
        }
    }
    return f[capacity];
}

初始化与计算顺序

f(0,j)=0f(0,j)=0f(0,j)=0，没有物品时任意容量都允许空方案；f(i,0)=0f(i,0)=0f(i,0)=0，体积为正时零容量只能不选物品。预算是“不超过”，因此无需把未花完预算的状态设为不可达。

朴素转移只依赖上一层，层内容量可以按任意顺序计算。优化后的二维转移依赖本层较小容量，必须先枚举物品，再正序枚举容量。

一维数组对应哪一层

处理第 iii 种物品之前，f[j] 保存 f(i−1,j)f(i-1,j)f(i−1,j)。处理容量 jjj 时，目标位置尚未更新，因此赋值右侧原来的 f[j] 就是“不选当前物品”的候选。

由于 j−vi<jj-v_i<jj−vi​<j，源位置属于哪一层取决于它是否已在本轮更新：

同样的赋值语句 f[j] = max(f[j], f[j - v_i] + w_i)，在正序时还原为：

f(i,j)=max⁡(f(i−1,j),f(i,j−vi)+wi)f(i,j)=\max\left(f(i-1,j),f(i,j-v_i)+w_i\right)f(i,j)=max(f(i−1,j),f(i,j−vi​)+wi​)

在倒序时还原为：

f(i,j)=max⁡(f(i−1,j),f(i−1,j−vi)+wi)f(i,j)=\max\left(f(i-1,j),f(i-1,j-v_i)+w_i\right)f(i,j)=max(f(i−1,j),f(i−1,j−vi​)+wi​)

应先确定二维依赖，再选择循环方向。正序时若源容量小于 viv_ivi​，它没有在本轮被更新，但这个容量无法容纳当前物品，故本层与上一层的值相同，仍满足依赖。

例如只有一种物品，体积为 222、价值为 333，容量为 444：

  • 正序先更新 f[2]=3，再用这个新值更新 f[4]=6，相当于购买两件。
  • 倒序先更新 f[4]=3，此时 f[2] 仍为上一层的 0；之后才更新 f[2]=3，最多购买一件。

Java 实现

朴素数量枚举

价值使用 long，乘法在运算前提升类型。循环用 j / v 限定数量，保证 k * v 不超过容量。

long completeKnapsackNaive(int capacity, int[] volume, int[] value) {
    int n = volume.length;
    long[][] f = new long[n + 1][capacity + 1];
    for (int i = 1; i <= n; i++) {
        int v = volume[i - 1];
        int w = value[i - 1];
        for (int j = 0; j <= capacity; j++) {
            for (int k = 0; k <= j / v; k++) {
                f[i][j] = Math.max(f[i][j],
                        f[i - 1][j - k * v] + (long) k * w);
            }
        }
    }
    return f[n][capacity];
}

优化二维转移
long completeKnapsackTwoDimensional(int capacity, int[] volume, int[] value) {
    int n = volume.length;
    long[][] f = new long[n + 1][capacity + 1];
    for (int i = 1; i <= n; i++) {
        int v = volume[i - 1];
        int w = value[i - 1];
        for (int j = 0; j <= capacity; j++) {
            f[i][j] = f[i - 1][j];
            if (j >= v) {
                f[i][j] = Math.max(f[i][j], f[i][j - v] + w);
            }
        }
    }
    return f[n][capacity];
}

优化一维转移

        for (int j = volume[i]; j <= capacity; j++) {
            f[j] = Math.max(f[j], f[j - volume[i]] + value[i]);
        }
    }
    return f[capacity];
}

多重背包

有 NNN 种物品和容量为 VVV 的背包。第 iii 种物品最多有 sis_isi​ 件，每件体积为 viv_ivi​、价值为 wiw_iwi​，求最大总价值。

状态表示

f(i,j)f(i,j)f(i,j) 表示只考虑前 iii 种物品、总体积不超过 jjj 的选法，属性为最大价值。

状态计算

按第 iii 种物品选择 kkk 件划分，其中 0≤k≤si0 \le k \le s_i0≤k≤si​。直接转移需要枚举数量。二进制拆分把 sis_isi​ 件分成数量为 1,2,4,…1,2,4,\ldots1,2,4,… 的若干组，这些组能组合出 000 到 sis_isi​ 的任意数量，再按零一背包处理。

int multipleKnapsack(int capacity, int[] volume, int[] value, int[] count) {
    int[] f = new int[capacity + 1];
    for (int i = 0; i < volume.length; i++) {
        int remaining = count[i];
        for (int group = 1; remaining > 0; group <<= 1) {
            int amount = Math.min(group, remaining);
            remaining -= amount;
            int groupVolume = amount * volume[i];
            int groupValue = amount * value[i];
            for (int j = capacity; j >= groupVolume; j--) {
                f[j] = Math.max(f[j], f[j - groupVolume] + groupValue);
            }
        }
    }
    return f[capacity];
}

int groupKnapsack(int capacity, int[][] volume, int[][] value) {
    int[] f = new int[capacity + 1];
    for (int i = 0; i < volume.length; i++) {
        for (int j = capacity; j >= 0; j--) {
            for (int k = 0; k < volume[i].length; k++) {
                if (volume[i][k] <= j) {
                    f[j] = Math.max(f[j], f[j - volume[i][k]] + value[i][k]);
                }
            }
        }
    }
    return f[capacity];
}

砝码称重

有一架天平和 NNN 个砝码，重量依次为 W1,W2,…,WNW_1,W_2,\ldots,W_NW1​,W2​,…,WN​。砝码可以放在天平两边，求能够称出的不同正整数重量数量。

状态计算

按第 iii 个砝码的放置方式划分：不用、放在左侧、放在右侧，对应重量差不变、增加 wiw_iwi​、减少 wiw_iwi​。三个集合覆盖所有方案。

int countWeighable(int[] weights) {
    int sum = Arrays.stream(weights).sum();
    int offset = sum;
    boolean[] f = new boolean[2 * sum + 1];
    f[offset] = true;
    for (int weight : weights) {
        boolean[] next = new boolean[2 * sum + 1];
        for (int difference = -sum; difference <= sum; difference++) {
            if (f[difference + offset]) {
                next[difference + offset] = true;
                next[difference + weight + offset] = true;
                next[difference - weight + offset] = true;
            }
        }
        f = next;
    }
    int answer = 0;
    for (int difference = 1; difference <= sum; difference++) {
        if (f[difference + offset]) {
            answer++;
        }
    }
    return answer;
}

子集的和

将集合 {1,2,…,N}{1,2,\ldots,N}{1,2,…,N} 划分为两个元素和相等的子集，求不同划分的数量。交换两个子集不产生新方案。

状态表示

状态计算

按是否选择整数 iii 划分：f(i,j)=f(i−1,j)+f(i−1,j−i)f(i,j)=f(i-1,j)+f(i-1,j-i)f(i,j)=f(i−1,j)+f(i−1,j−i)。总和为奇数时无解；总和为偶数时统计和为一半的子集。每次划分会分别以两个子集被统计两次，因此最终除以 222。

long countEqualPartitions(int n) {
    int sum = n * (n + 1) / 2;
    if ((sum & 1) == 1) {
        return 0;
    }
    int target = sum / 2;
    long[] f = new long[target + 1];
    f[0] = 1;
    for (int x = 1; x <= n; x++) {
        for (int j = target; j >= x; j--) {
            f[j] += f[j - x];
        }
    }
    return f[target] / 2;
}

倍数问题

给定 nnn 个整数和正整数 KKK，从中选择恰好三个数，使三数之和是 KKK 的倍数且总和最大。数据保证有解。

状态表示

状态计算

处理当前数 xxx 时，按是否选择它划分。选择时从 f(c−1,r)f(c-1,r)f(c−1,r) 转移到 f(c,(r+x) mod K)f(c,(r+x) \bmod K)f(c,(r+x)modK)。选择数量必须倒序枚举，保证每个数只用一次。

long maxMultipleSum(int[] nums, int k) {
    long unreachable = Long.MIN_VALUE / 4;
    long[][] f = new long[4][k];
    for (long[] row : f) {
        Arrays.fill(row, unreachable);
    }
    f[0][0] = 0;
    for (int x : nums) {
        int remainder = Math.floorMod(x, k);
        for (int count = 3; count >= 1; count--) {
            for (int r = 0; r < k; r++) {
                if (f[count - 1][r] != unreachable) {
                    int next = (r + remainder) % k;
                    f[count][next] = Math.max(f[count][next], f[count - 1][r] + x);
                }
            }
        }
    }
    return f[3][0];
}

最后一块石头的重量

给定若干石头的重量，每次粉碎两块重量分别为 x≤yx \le yx≤y 的石头；若重量不同则剩下 y−xy-xy−x。求最终剩余石头的最小可能重量。

状态表示

所有操作等价于把石头分成两组，答案是两组重量和之差。f(i,j)f(i,j)f(i,j) 表示只使用前 iii 块石头能否凑出重量 jjj，属性为可行性。

状态计算

按是否把当前石头放入较轻的一组划分。只需寻找不超过总重量一半的最大可达重量 jjj，答案为 sum−2jsum-2jsum−2j。

int lastStoneWeightII(int[] stones) {
    int sum = Arrays.stream(stones).sum();
    int target = sum / 2;
    boolean[] f = new boolean[target + 1];
    f[0] = true;
    for (int stone : stones) {
        for (int j = target; j >= stone; j--) {
            f[j] |= f[j - stone];
        }
    }
    for (int j = target; j >= 0; j--) {
        if (f[j]) {
            return sum - 2 * j;
        }
    }
    throw new IllegalStateException();
}

int findTargetSumWays(int[] nums, int target) {
    int sum = Arrays.stream(nums).sum();
    if (Math.abs(target) > sum || ((sum + target) & 1) == 1) {
        return 0;
    }
    int positive = (sum + target) / 2;
    int[] f = new int[positive + 1];
    f[0] = 1;
    for (int x : nums) {
        for (int j = positive; j >= x; j--) {
            f[j] += f[j - x];
        }
    }
    return f[positive];
}

f(k,i,j)=max⁡(f(k−1,i,j),f(k−1,i−zerok,j−onek)+1)f(k,i,j)=\max(f(k-1,i,j),f(k-1,i-zero_k,j-one_k)+1)f(k,i,j)=max(f(k−1,i,j),f(k−1,i−zerok​,j−onek​)+1)
int findMaxForm(String[] strs, int m, int n) {
    int[][] f = new int[m + 1][n + 1];
    for (String s : strs) {
        int zeros = 0;
        for (int i = 0; i < s.length(); i++) {
            zeros += s.charAt(i) == '0' ? 1 : 0;
        }
        int ones = s.length() - zeros;
        for (int i = m; i >= zeros; i--) {
            for (int j = n; j >= ones; j--) {
                f[i][j] = Math.max(f[i][j], f[i - zeros][j - ones] + 1);
            }
        }
    }
    return f[m][n];
}

String countImpossibleBunTotals(int[] sizes) {
    int divisor = 0;
    for (int size : sizes) {
        divisor = gcd(divisor, size);
    }
    if (divisor != 1) {
        return "INF";
    }
    boolean[] f = new boolean[10001];
    f[0] = true;
    for (int size : sizes) {
        for (int total = size; total < f.length; total++) {
            f[total] |= f[total - size];
        }
    }
    int answer = 0;
    for (int total = 1; total < f.length; total++) {
        answer += f[total] ? 0 : 1;
    }
    return String.valueOf(answer);
}

int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

boolean wordBreak(String s, List<String> words) {
    boolean[] f = new boolean[s.length() + 1];
    f[0] = true;
    for (int i = 1; i <= s.length(); i++) {
        for (String word : words) {
            int start = i - word.length();
            if (start >= 0 && f[start] && s.startsWith(word, start)) {
                f[i] = true;
            }
        }
    }
    return f[s.length()];
}

购物单

王强有 nnn 元预算，从 mmm 件物品中选择若干件，使总价格不超过预算且满意度最大。

物品分为主件和附件：主件至多有两个附件，附件没有自己的附件。购买附件必须同时购买所属主件，每件物品只能购买一次。

第 iii 件物品的价格为正整数 viv_ivi​，重要度 wiw_iwi​ 为 111 到 555 的整数，满意度为所有已购物品的 viwiv_iw_ivi​wi​ 之和。

输入参数 q[i] 为 0 表示主件，否则表示所属主件的编号。物品编号从 1 开始，数组下标从 0 开始；附件可以先于主件输入。返回最大满意度。

状态表示

把一个主件及其附件视为一组。f(i,j)f(i,j)f(i,j) 的集合是只考虑前 iii 组、总价格不超过 jjj 的合法购买方案，属性为最大满意度。

设主件为 MMM，两个附件为 A,BA,BA,B，每组的非空合法组合如下：

组合 总价格 满意度
MMM vMv_MvM​ vMwMv_Mw_MvM​wM​
M+AM+AM+A vM+vAv_M+v_AvM​+vA​ vMwM+vAwAv_Mw_M+v_Aw_AvM​wM​+vA​wA​

没有附件时只有第一种组合，一个附件时有前两种。每组至多选一个组合，也可以整组不选，因此转化为分组背包。

状态计算

按当前组“不购买”或“购买第 kkk 个组合”划分。记组合价格为 ci,kc_{i,k}ci,k​，满意度为 si,ks_{i,k}si,k​：

f(i,j)=max⁡(f(i−1,j),max⁡k: ci,k≤j{f(i−1,j−ci,k)+si,k})f(i,j)=\max\left(f(i-1,j),\max_{k:\,c_{i,k}\le j}\{f(i-1,j-c_{i,k})+s_{i,k}\}\right)f(i,j)=max(f(i−1,j),k:ci,k​≤jmax​{f(i−1,j−ci,k​)+si,k​})

每个合法方案在当前组中都有唯一的附件子集，因此枚举这些组合不会遗漏。不同组合互斥，不能把每个组合当作独立的零一背包物品，否则可能在同一组中重复购买主件。

实现用二进制掩码枚举附件子集：主件始终选中，第 bbb 位为 1 表示选择第 bbb 个附件。全部输入数组已经提供，建立附件关系时不要求主件先于附件出现。

初始化与计算顺序

  • 初始化 f(0,j)=0f(0,j)=0f(0,j)=0：预算是“不超过”，任何容量都允许什么也不买，无需将未花完预算的状态设为不可达。
  • 一维数组 f[j] 在处理当前组前保存上一组的答案；保留原值表示不选当前组。
  • 循环顺序必须是“组 → 容量倒序 → 当前组的组合”。组合价格为正，故 j - cost < j，较小容量尚未被当前组更新，所有候选均从上一组转移。
  • 若先枚举组合，再对容量倒序，后一个组合可能读取前一个组合更新过的状态，导致重复选择同一主件。
  • 最终返回 f[n]，不要求花完预算。

原代码核对

原代码的组合枚举和转移顺序正确。提前创建主件节点、之后通过 setNode 填入信息不会清空附件列表，因此也能处理附件先输入的情况。

整理后的实现删除了 main 中未使用的 nodes，用附件编号表替代节点结构，并通过子集枚举统一处理零到两个附件，省去单独的组计数。满意度乘法先提升为 long，组合价格也用 long 累加，避免先在 int 中溢出再转换。

题面未提供预算、物品数量的上界，也未说明价格为某个数的倍数；以下保留按整数预算的动态规划，不进行价格缩放。实际提交时需根据完整数据范围判断时间和空间是否可接受。

复杂度

设主件数量为 ggg，每个主件最多有两个附件，因而每组至多四个组合。

  • 时间复杂度：O(m+gn)O(m+gn)O(m+gn)。建组扫描 mmm 件物品，每组枚举预算和至多四个组合，这是依赖预算数值的伪多项式算法。
  • 空间复杂度：O(m+n)O(m+n)O(m+n)。附件关系占 O(m)O(m)O(m)，动态规划数组占 O(n)O(n)O(n)，当前组的组合占 O(1)O(1)O(1)。

long shoppingList(int budget, int m, int[] price, int[] importance, int[] q) {
    int[][] attachments = new int[m + 1][2];
    int[] attachmentCount = new int[m + 1];
    for (int id = 1; id <= m; id++) {
        int mainId = q[id - 1];
        if (mainId != 0) {
            attachments[mainId][attachmentCount[mainId]++] = id;
        }
    }

    long[] f = new long[budget + 1];
    for (int id = 1; id <= m; id++) {
        if (q[id - 1] != 0) {
            continue;
        }
        int count = attachmentCount[id];
        int combinations = 1 << count;
        long[] costs = new long[combinations];
        long[] values = new long[combinations];
        for (int mask = 0; mask < combinations; mask++) {
            costs[mask] = price[id - 1];
            values[mask] = (long) price[id - 1] * importance[id - 1];
            for (int bit = 0; bit < count; bit++) {
                if ((mask & (1 << bit)) != 0) {
                    int accessory = attachments[id][bit] - 1;
                    costs[mask] += price[accessory];
                    values[mask] += (long) price[accessory] * importance[accessory];
                }
            }
        }
        for (int capacity = budget; capacity >= 0; capacity--) {
            for (int k = 0; k < combinations; k++) {
                if (costs[k] <= capacity) {
                    int remaining = capacity - (int) costs[k];
                    f[capacity] = Math.max(f[capacity], f[remaining] + values[k]);
                }
            }
        }
    }
    return f[budget];
}
