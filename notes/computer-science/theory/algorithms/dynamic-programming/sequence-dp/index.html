#动态规划

阅读线索

线性 DP 沿序列、前缀或网格顺序递推。数字三角形固定到达位置，LIS 固定结尾，公共子序列同时记录两个前缀；这些限定决定了可用的转移。

线性动态规划按照序列或网格中的自然顺序计算状态，常见划分依据是最后一个元素、最后一步或两个前缀的末尾字符。

数字三角形

给定一个 nnn 层数字三角形，从顶部出发，每次移动到下一层的左下方或右下方，求到达底层时路径上的最大数字和。三角形中的数可能为负数。

状态表示

f(i,j)f(i,j)f(i,j) 表示从顶点走到第 iii 层第 jjj 个位置的所有路径，属性为最大路径和。

状态计算

按进入 (i,j)(i,j)(i,j) 的最后一步划分：

  • 从左上方 (i−1,j−1)(i-1,j-1)(i−1,j−1) 到达。
  • 从右上方 (i−1,j)(i-1,j)(i−1,j) 到达。

两个集合互斥且覆盖所有路径：

f(i,j)=max⁡(f(i−1,j−1),f(i−1,j))+ai,jf(i,j)=\max(f(i-1,j-1),f(i-1,j))+a_{i,j}f(i,j)=max(f(i−1,j−1),f(i−1,j))+ai,j​

因为存在负数，非法位置初始化为负无穷。压缩成一维后从右向左更新，避免覆盖上一层状态。

int maxTrianglePath(int[][] triangle) {
    int n = triangle.length;
    int negativeInfinity = Integer.MIN_VALUE / 4;
    int[] f = new int[n + 1];
    Arrays.fill(f, negativeInfinity);
    f[0] = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j >= 1; j--) {
            f[j] = Math.max(f[j - 1], f[j]) + triangle[i][j - 1];
        }
        f[0] = negativeInfinity;
    }
    return Arrays.stream(f).max().orElseThrow();
}

最长上升子序列

给定长度为 NNN 的整数序列，求数值严格单调递增的子序列的最大长度。

状态表示

f(i)f(i)f(i) 表示所有以 aia_iai​ 结尾的严格上升子序列，属性为最大长度。

状态计算

按倒数第二个元素的位置 jjj 划分。只有 j<ij<ij<i 且 aj<aia_j<a_iaj​<ai​ 时，才能把 aia_iai​ 接在相应子序列末尾：

f(i)=max⁡(1,max⁡j<i,,aj<ai{f(j)+1})f(i)=\max\left(1,\max_{j<i,,a_j<a_i}\{f(j)+1\}\right)f(i)=max(1,j<i,,aj​<ai​max​{f(j)+1})

记录取得最大值时的 jjj，即可沿前驱数组还原一条最长上升子序列。朴素复杂度为 O(n2)O(n^2)O(n2)。

int lengthOfLisQuadratic(int[] nums) {
    int[] f = new int[nums.length];
    int answer = 0;
    for (int i = 0; i < nums.length; i++) {
        f[i] = 1;
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                f[i] = Math.max(f[i], f[j] + 1);
            }
        }
        answer = Math.max(answer, f[i]);
    }
    return answer;
}

最小结尾优化

令 tails[len - 1] 表示长度为 len 的上升子序列中，末尾元素的最小值。末尾越小，越容易接上后续元素。对每个数二分查找第一个大于等于它的位置并替换，复杂度为 O(nlog⁡n)O(n \log n)O(nlogn)。这一数组用于维护最优结尾，并不一定是原序列的一条子序列。

int lengthOfLis(int[] nums) {
    int[] tails = new int[nums.length];
    int size = 0;
    for (int x : nums) {
        int left = 0;
        int right = size;
        while (left < right) {
            int middle = left + (right - left) / 2;
            if (tails[middle] < x) {
                left = middle + 1;
            } else {
                right = middle;
            }
        }
        tails[left] = x;
        if (left == size) {
            size++;
        }
    }
    return size;
}

合唱队形

音乐课上，nnn 位同学排成一排。删除尽可能少的同学，保持剩余同学的相对位置，使队形严格先升后降。

若留下 kkk 人，必须存在内部山峰 iii，满足 1<i<k1<i<k1<i<k，且 h1<⋯<hi>hi+1>⋯>hkh_1<\cdots<h_i>h_{i+1}>\cdots>h_kh1​<⋯<hi​>hi+1​>⋯>hk​。相同身高不能接在同一条严格上升或下降链中。

输出最少出列人数。所给题面未说明数据范围和无解时的输出约定；下面按严格题面实现，无合法队形时显式报错。

状态表示

  • 集合：left[i] 包含所有以原队伍第 iii 位同学结尾的严格递增子序列；right[i] 包含所有以他开头、向右延伸的严格递减子序列。
  • 属性：两个集合分别取最大长度，都包含第 iii 位同学自身。

状态必须固定端点。不能把 left[i] 理解成“前 iii 个元素中任意最长递增子序列”，否则该序列可能不以第 iii 位同学结尾，无法与右侧拼成同一个山峰。

状态计算

左侧按倒数第二位同学 jjj 划分，右侧按第二位同学 jjj 划分：

left[i]=max⁡(1,max⁡j<i, hj<hi(left[j]+1))left[i]=\max\left(1,\max_{j<i,\ h_j<h_i}(left[j]+1)\right)left[i]=max(1,j<i, hj​<hi​max​(left[j]+1))
right[i]=max⁡(1,max⁡j>i, hj<hi(right[j]+1))right[i]=\max\left(1,\max_{j>i,\ h_j<h_i}(right[j]+1)\right)right[i]=max(1,j>i, hj​<hi​max​(right[j]+1))

固定山峰后，左侧所有下标都小于 iii，右侧所有下标都大于 iii，两部分可独立选取，拼接时不会改变相对位置。山峰被计算两次，所以保留人数为：

left[i]+right[i]−1left[i]+right[i]-1left[i]+right[i]−1

严格题面要求山峰两侧各至少有一位同学，因此只枚举 left[i] >= 2 且 right[i] >= 2 的位置。只排除原数组的首尾位置还不够：中间同学也可能没有更矮的左侧或右侧同学。

answer=n−max⁡i: left[i]≥2, right[i]≥2(left[i]+right[i]−1)answer=n-\max_{i:\ left[i]\ge2,\ right[i]\ge2}(left[i]+right[i]-1)answer=n−i: left[i]≥2, right[i]≥2max​(left[i]+right[i]−1)

删除人数最少等价于保留人数最多。任意合法队形都有某个山峰，枚举所有合法山峰就不会遗漏最优解。

初始化与计算顺序

两个状态都初始化为 1，表示仅选择自己。left 从左向右计算，right 从右向左计算，保证所依赖的状态已经求出。

原代码未检查山峰两侧长度，因此会把纯递增、纯递减或单人队列算作合法队形。例如 [1, 2, 3] 原代码输出 0，但严格定义下根本不存在合唱队形。平台通过不能证明这项边界符合题面。

示例与边界

原队伍身高 结论
[1, 3, 2, 4, 3, 1] 保留 [1, 3, 4, 3, 1]，出列一人
[1, 2, 2, 1] 相同身高不能连续保留在严格链中，出列一人
[1, 2, 3]、[3, 2, 1]、[2, 2, 2] 无合法内部山峰，显式报错

复杂度

  • 时间复杂度：O(n2)O(n^2)O(n2)，两次双重循环。
  • 空间复杂度：O(n)O(n)O(n)，两个长度数组。

这是所给方案的复杂度，未据此推断平台的数据范围。大规模数据可分别用二分维护递增链的最小结尾，计算每个固定端点的长度，将时间降为 O(nlog⁡n)O(n\log n)O(nlogn)。

Go 实现

package main

import (
	"bufio"
	"fmt"
	"os"
)

func minChoirRemoval(heights []int) int {
	n := len(heights)
	left := make([]int, n)
	right := make([]int, n)
	for i := 0; i < n; i++ {
		left[i] = 1
		for j := 0; j < i; j++ {
			if heights[j] < heights[i] {
				left[i] = max(left[i], left[j]+1)
			}
		}
	}
	for i := n - 1; i >= 0; i-- {
		right[i] = 1
		for j := i + 1; j < n; j++ {
			if heights[j] < heights[i] {
				right[i] = max(right[i], right[j]+1)
			}
		}
	}
	best := 0
	for i := 0; i < n; i++ {
		if left[i] >= 2 && right[i] >= 2 {
			best = max(best, left[i]+right[i]-1)
		}
	}
	if best == 0 {
		panic("不存在山峰两侧均非空的合唱队形；题面未定义无解输出")
	}
	return n - best
}

func main() {
	in := bufio.NewReader(os.Stdin)
	var n int
	fmt.Fscan(in, &n)
	heights := make([]int, n)
	for i := range heights {
		fmt.Fscan(in, &heights[i])
	}
	fmt.Println(minChoirRemoval(heights))
}

代码使用 Go 1.21 起内置的 max；其他整合代码中存在 Go 1.22 的整数 range 语法，编译校验统一使用 Go 1.22 或更新版本。

最长公共子序列

给定字符串 AAA 和 BBB，求同时作为二者子序列的字符串的最大长度。子序列不要求连续。

状态表示

f(i,j)f(i,j)f(i,j) 表示 AAA 的前 iii 个字符与 BBB 的前 jjj 个字符形成的所有公共子序列，属性为最大长度。

状态计算

按照公共子序列是否使用两个前缀的末尾字符划分：

  • 不使用 AiA_iAi​，由 f(i−1,j)f(i-1,j)f(i−1,j) 覆盖。
  • 不使用 BjB_jBj​，由 f(i,j−1)f(i,j-1)f(i,j−1) 覆盖。
  • 同时使用二者，仅当 Ai=BjA_i=B_jAi​=Bj​，由 f(i−1,j−1)+1f(i-1,j-1)+1f(i−1,j−1)+1 转移。

前两个集合有重叠，但求最大值时重叠不影响结果；所有可能的公共子序列都被覆盖。

int longestCommonSubsequence(String a, String b) {
    int[][] f = new int[a.length() + 1][b.length() + 1];
    for (int i = 1; i <= a.length(); i++) {
        for (int j = 1; j <= b.length(); j++) {
            f[i][j] = Math.max(f[i - 1][j], f[i][j - 1]);
            if (a.charAt(i - 1) == b.charAt(j - 1)) {
                f[i][j] = Math.max(f[i][j], f[i - 1][j - 1] + 1);
            }
        }
    }
    return f[a.length()][b.length()];
}

最长公共子串

给定字符串 AAA 和 BBB，求同时作为二者子串的字符串的最大长度。子串要求连续。

状态表示

  • 集合：f(i,j)f(i,j)f(i,j) 对应两个前缀中，同时以 AiA_iAi​ 和 BjB_jBj​ 结尾的公共子串。
  • 属性：最大长度；不存在非空匹配时记为 000。

这里不是两个前缀中任意公共子串的最大长度，而是两个前缀的最长公共后缀长度。结尾固定，才能保证追加字符后仍然连续。

状态计算

按两个末尾字符是否相同讨论：

  • 若 Ai=BjA_i=B_jAi​=Bj​，去掉最后一个字符，剩余部分必须同时以 Ai−1A_{i-1}Ai−1​ 和 Bj−1B_{j-1}Bj−1​ 结尾，因此得到 f(i−1,j−1)+1f(i-1,j-1)+1f(i−1,j−1)+1。
  • 若 Ai≠BjA_i\ne B_jAi​=Bj​，不存在同时以这两个字符结尾的非空公共子串，当前状态必须为 000。
f(i,j)={f(i−1,j−1)+1,Ai=Bj0,Ai≠Bjf(i,j)=\begin{cases} f(i-1,j-1)+1, & A_i=B_j\\ 0, & A_i\ne B_j \end{cases}f(i,j)={f(i−1,j−1)+1,0,​Ai​=Bj​Ai​=Bj​​

与最长公共子序列相比，不能从 f(i−1,j)f(i-1,j)f(i−1,j) 或 f(i,j−1)f(i,j-1)f(i,j−1) 转移，因为跳过字符会破坏当前状态的结尾约束。连续性使转移更简单，但需要同时改变状态定义。

最长公共子串可能在任意位置结束，所以答案是所有状态的最大值，而不是仅取 f(n,m)f(n,m)f(n,m)。

初始化与计算顺序

f(0,j)=f(i,0)=0f(0,j)=f(i,0)=0f(0,j)=f(i,0)=0，空前缀不含非空公共子串。按 iii、jjj 从小到大计算，保证左上角 f(i−1,j−1)f(i-1,j-1)f(i−1,j−1) 已求出；每次匹配后更新全局最大值。

示例与边界

  • A="abcX"、B="abcY"：答案为 3，但 f(4,4)=0f(4,4)=0f(4,4)=0，说明必须取全局最大值。
  • A="abc"、B="ac"：答案为 1；"ac" 在 A 中不连续，不能作为公共子串。
  • 任一字符串为空，或二者没有相同字符：答案为 0。

复杂度

设两个字符串分别有 nnn、mmm 个 Unicode 码点。

  • 时间复杂度：O(nm+n+m)O(nm+n+m)O(nm+n+m)，包括字符串转换与状态计算。
  • 空间复杂度：O(nm+n+m)O(nm+n+m)O(nm+n+m)，包括二维状态数组与字符数组。

Go 实现

题面未限定字符范围，这里转为 []rune，按 Unicode 码点比较并计数。例如 "你好" 与 "你们" 的答案为 1。这里的字符指码点，不进行 Unicode 规范化或字素簇分割。

func work(s, t string) int {
    a, b := []rune(s), []rune(t)
    n, m := len(a), len(b)
    // f[i][j]：同时以 a[i-1]、b[j-1] 结尾的公共子串最大长度。
    f := make([][]int, n+1)
    for i := 0; i <= n; i++ {
        f[i] = make([]int, m+1)
    }

    ret := 0
    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if a[i-1] == b[j-1] {
                f[i][j] = f[i-1][j-1] + 1
                ret = max(ret, f[i][j])
            } else {
                f[i][j] = 0
            }
        }
    }
    return ret
}

最短编辑距离

给定字符串 AAA 和 BBB，每次可以插入、删除或替换一个字符，求把 AAA 变成 BBB 的最少操作次数。

状态表示

f(i,j)f(i,j)f(i,j) 表示把 AAA 的前 iii 个字符变成 BBB 的前 jjj 个字符的所有操作序列，属性为最少操作次数。

状态计算

按最后一次操作划分：

  • 删除 AiA_iAi​：f(i−1,j)+1f(i-1,j)+1f(i−1,j)+1。
  • 在末尾插入 BjB_jBj​：f(i,j−1)+1f(i,j-1)+1f(i,j−1)+1。
  • 匹配或替换末尾字符：f(i−1,j−1)+[Ai≠Bj]f(i-1,j-1)+[A_i \ne B_j]f(i−1,j−1)+[Ai​=Bj​]。
f(i,j)=min⁡{f(i−1,j)+1f(i,j−1)+1f(i−1,j−1)+[Ai≠Bj]f(i,j)=\min\begin{cases} f(i-1,j)+1\\ f(i,j-1)+1\\ f(i-1,j-1)+[A_i \ne B_j] \end{cases}f(i,j)=min⎩⎨⎧​f(i−1,j)+1f(i,j−1)+1f(i−1,j−1)+[Ai​=Bj​]​
int editDistance(String source, String target) {
    int[][] f = new int[source.length() + 1][target.length() + 1];
    for (int i = 0; i <= source.length(); i++) {
        f[i][0] = i;
    }
    for (int j = 0; j <= target.length(); j++) {
        f[0][j] = j;
    }
    for (int i = 1; i <= source.length(); i++) {
        for (int j = 1; j <= target.length(); j++) {
            int replace = f[i - 1][j - 1]
                    + (source.charAt(i - 1) == target.charAt(j - 1) ? 0 : 1);
            f[i][j] = Math.min(replace, Math.min(f[i - 1][j] + 1, f[i][j - 1] + 1));
        }
    }
    return f[source.length()][target.length()];
}

编辑距离查询

给定 nnn 个长度不超过 101010 的字符串和 mmm 次查询。每次给出一个字符串和操作次数上限，求给定字符串中有多少个能在限制内通过插入、删除或替换变成查询字符串。

状态表示

对每个候选串与查询串计算编辑距离，状态定义与最短编辑距离相同，属性为最少操作次数。

状态计算

每一对字符串独立计算，统计距离不超过限制的候选串。

int countWithinEditDistance(String[] words, String query, int limit) {
    int answer = 0;
    for (String word : words) {
        if (editDistance(word, query) <= limit) {
            answer++;
        }
    }
    return answer;
}

乌龟棋

一维棋盘有 NNN 个带分数的格子，棋子从第一个格子出发。给定若干张步长为 111、222、333 或 444 的卡片，每张必须使用一次，求通过调整卡片顺序能够得到的最大分数。

状态表示

f(a,b,c,d)f(a,b,c,d)f(a,b,c,d) 表示分别使用了 a,b,c,da,b,c,da,b,c,d 张四种卡片的所有排列，属性为最大得分。当前位置由已用卡片数量唯一确定：

position=1+a+2b+3c+4dposition=1+a+2b+3c+4dposition=1+a+2b+3c+4d

状态计算

按最后使用的卡片类型划分。四个子集互斥且覆盖全部排列；转移后统一加上当前落点分数。

int turtleChess(int[] score, int[] cardCount) {
    int[][][][] f = new int[cardCount[1] + 1][cardCount[2] + 1]
            [cardCount[3] + 1][cardCount[4] + 1];
    f[0][0][0][0] = score[0];
    for (int a = 0; a <= cardCount[1]; a++) {
        for (int b = 0; b <= cardCount[2]; b++) {
            for (int c = 0; c <= cardCount[3]; c++) {
                for (int d = 0; d <= cardCount[4]; d++) {
                    if (a + b + c + d == 0) {
                        continue;
                    }
                    int position = a + 2 * b + 3 * c + 4 * d;
                    int best = 0;
                    if (a > 0) best = Math.max(best, f[a - 1][b][c][d]);
                    if (b > 0) best = Math.max(best, f[a][b - 1][c][d]);
                    if (c > 0) best = Math.max(best, f[a][b][c - 1][d]);
                    if (d > 0) best = Math.max(best, f[a][b][c][d - 1]);
                    f[a][b][c][d] = best + score[position];
                }
            }
        }
    }
    return f[cardCount[1]][cardCount[2]][cardCount[3]][cardCount[4]];
}

子序列计数

给定字符串 source 和模式串 key，求 key 作为 source 的子序列出现的次数。子序列按所选择的下标序列区分。

状态表示

f(i,j)f(i,j)f(i,j) 表示使用 source 的前 iii 个字符形成 key 的前 jjj 个字符的方案，属性为方案数。

状态计算

按是否选择 source[i - 1] 划分：

  • 不选择：继承 f(i−1,j)f(i-1,j)f(i−1,j)。
  • 选择：仅当它等于 key[j - 1]，增加 f(i−1,j−1)f(i-1,j-1)f(i−1,j−1)。

压缩成一维后，jjj 必须倒序更新，避免同一个源字符被使用多次。空模式串只有一种形成方式，初始化 f(0)=1f(0)=1f(0)=1。

long countSubsequences(String source, String key) {
    long[] f = new long[key.length() + 1];
    f[0] = 1;
    for (int i = 0; i < source.length(); i++) {
        for (int j = key.length(); j >= 1; j--) {
            if (source.charAt(i) == key.charAt(j - 1)) {
                f[j] += f[j - 1];
            }
        }
    }
    return f[key.length()];
}
