状态压缩动态规划

2026-10-23

#动态规划#状态压缩

阅读线索

状态压缩把小规模集合编码为二进制位。棋盘覆盖关注相邻列的兼容，Hamilton 路径关注已访问集合和终点，覆盖糖果则关注口味并集。

状态压缩动态规划用一个整数的二进制位表示集合或一列网格的占用情况。适用于元素数量较少，但需要记录整个子集的题目。

蒙德里安的梦想

使用若干个 1×21 \times 21×2 长方形完整覆盖 N×MN \times MN×M 棋盘，求不同覆盖方案数。输入包含多组数据，1≤N,M≤111 \le N,M \le 111≤N,M≤11。

状态表示

先确定横放骨牌，再用竖放骨牌填补剩余位置。f(c,mask)f(c,mask)f(c,mask) 表示已经处理完前 ccc 列，且有横放骨牌从第 ccc 列伸入第 c+1c+1c+1 列、占用情况为 mask 的所有方案，属性为方案数。

状态计算

设上一列伸入当前列的状态为 previous，当前列伸入下一列的状态为 next。按 previous 划分 f(c+1,next)f(c+1,next)f(c+1,next) 的方案集合。合法转移必须满足：

  • (previous & next) == 0，同一格不能被两个横放骨牌重复占用。
  • previous | next 中每段连续的空位长度均为偶数，才能用竖放骨牌填满。

所有转移确定后，剩余空位的竖放方式唯一，因此划分不重不漏。初始状态为 f(0,0)=1f(0,0)=1f(0,0)=1，答案为 f(M,0)f(M,0)f(M,0)。

long countDominoTilings(int rows, int columns) {
    int stateCount = 1 << rows;
    boolean[] valid = new boolean[stateCount];
    for (int mask = 0; mask < stateCount; mask++) {
        int emptyLength = 0;
        valid[mask] = true;
        for (int row = 0; row < rows; row++) {
            if ((mask & (1 << row)) != 0) {
                if ((emptyLength & 1) == 1) {
                    valid[mask] = false;
                }
                emptyLength = 0;
            } else {
                emptyLength++;
            }
        }
        if ((emptyLength & 1) == 1) {
            valid[mask] = false;
        }
    }
    long[][] f = new long[columns + 1][stateCount];
    f[0][0] = 1;
    for (int column = 0; column < columns; column++) {
        for (int previous = 0; previous < stateCount; previous++) {
            for (int next = 0; next < stateCount; next++) {
                if ((previous & next) == 0 && valid[previous | next]) {
                    f[column + 1][next] += f[column][previous];
                }
            }
        }
    }
    return f[columns][0];
}

最短 Hamilton 路径

给定一张 nnn 个点的带权无向图，点编号为 000 到 n−1n-1n−1。求从点 000 到点 n−1n-1n−1，不重不漏地经过每个点恰好一次的最短路径，n≤20n \le 20n≤20。

状态表示

f(mask,j)f(mask,j)f(mask,j) 表示从点 000 出发，已经访问的点集恰好为 mask，且终点为 jjj 的所有路径，属性为最短长度。状态必须满足 mask 包含点 000 和点 jjj。

状态计算

按到达 jjj 前的倒数第二个点 kkk 划分。删除最后一步 k→jk \to jk→j 后，访问集合变为 mask 去掉 jjj：

f(mask,j)=min⁡k∈mask,,k≠j{f(mask∖{j},k)+wk,j}f(mask,j)=\min_{k \in mask,,k \ne j}\{f(mask\setminus\{j\},k)+w_{k,j}\}f(mask,j)=k∈mask,,k=jmin​{f(mask∖{j},k)+wk,j​}

不同 kkk 对应不同的最后一条边，完整覆盖所有路径。初始化 f(1,0)=0f(1,0)=0f(1,0)=0，其余状态为正无穷。

int shortestHamiltonPath(int[][] distance) {
    int n = distance.length;
    int[][] f = new int[1 << n][n];
    int infinity = Integer.MAX_VALUE / 4;
    for (int[] row : f) {
        Arrays.fill(row, infinity);
    }
    f[1][0] = 0;
    for (int mask = 1; mask < 1 << n; mask++) {
        for (int end = 0; end < n; end++) {
            if ((mask & (1 << end)) == 0) {
                continue;
            }
            int previousMask = mask ^ (1 << end);
            for (int previous = 0; previous < n; previous++) {
                if ((previousMask & (1 << previous)) != 0) {
                    f[mask][end] = Math.min(f[mask][end],
                            f[previousMask][previous] + distance[previous][end]);
                }
            }
        }
    }
    return f[(1 << n) - 1][n - 1];
}

毕业旅行

从城市 000 出发，访问其他每座城市恰好一次后回到城市 000。给定任意两座城市之间的票价，求最小总花费。

状态表示

f(mask,j)f(mask,j)f(mask,j) 表示从城市 000 出发，访问集合恰好为 mask 且当前位于城市 jjj 的所有路线，属性为最小花费。

状态计算

与最短 Hamilton 路径相同，按倒数第二座城市划分。求出访问全部城市的状态后，再枚举最后所在城市 jjj，加上返回城市 000 的费用：

answer=min⁡j>0{f(2n−1,j)+wj,0}answer=\min_{j>0}\{f(2^n-1,j)+w_{j,0}\}answer=j>0min​{f(2n−1,j)+wj,0​}
int shortestTour(int[][] cost) {
    int n = cost.length;
    int infinity = Integer.MAX_VALUE / 4;
    int[][] f = new int[1 << n][n];
    for (int[] row : f) {
        Arrays.fill(row, infinity);
    }
    f[1][0] = 0;
    for (int mask = 1; mask < 1 << n; mask++) {
        for (int end = 0; end < n; end++) {
            if ((mask & (1 << end)) == 0) {
                continue;
            }
            int previousMask = mask ^ (1 << end);
            for (int previous = 0; previous < n; previous++) {
                if ((previousMask & (1 << previous)) != 0) {
                    f[mask][end] = Math.min(f[mask][end],
                            f[previousMask][previous] + cost[previous][end]);
                }
            }
        }
    }
    int answer = infinity;
    int full = (1 << n) - 1;
    for (int end = 1; end < n; end++) {
        answer = Math.min(answer, f[full][end] + cost[end][0]);
    }
    return answer;
}

糖果

有 MMM 种口味和 NNN 包糖果，每包糖果包含若干已知口味。求至少购买多少包才能覆盖全部口味；若无法覆盖全部口味，返回 −1-1−1。

状态表示

用二进制位表示已经覆盖的口味。f(i,mask)f(i,mask)f(i,mask) 表示只考虑前 iii 包糖果、覆盖口味集合为 mask 的方案，属性为最少购买包数。

状态计算

按是否购买第 iii 包划分：

  • 不购买，状态保持为 mask。
  • 购买，状态变为 mask | packageMask[i]，包数加一。

使用滚动数组时，每处理一包都从上一层复制，确保同一包不会被重复选择。

int minimumCandyPackages(int flavorCount, int[] packageMasks) {
    int stateCount = 1 << flavorCount;
    int infinity = packageMasks.length + 1;
    int[] f = new int[stateCount];
    Arrays.fill(f, infinity);
    f[0] = 0;
    for (int packageMask : packageMasks) {
        int[] next = f.clone();
        for (int mask = 0; mask < stateCount; mask++) {
            int merged = mask | packageMask;
            next[merged] = Math.min(next[merged], f[mask] + 1);
        }
        f = next;
    }
    return f[stateCount - 1] == infinity ? -1 : f[stateCount - 1];
}
