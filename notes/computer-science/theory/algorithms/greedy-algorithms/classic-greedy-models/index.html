#贪心算法

阅读线索

经典贪心模型通过保留更强候选避免穷举：匹配题节省资源，摆动序列保留峰谷，跳跃问题维护可达范围。每次替换都应说明不会损失后续选择。

贪心算法每一步选择当前最有利的方案。可靠的解法需要说明局部选择为何不会排除全局最优解，常用证明方法包括交换论证、反证法和排序不等式。

分发饼干

每个孩子有胃口值，每块饼干有尺寸。一块饼干至多分给一个孩子，尺寸不小于胃口才满足，求最多满足多少个孩子。

思路

同时升序排序。优先用当前最小且足够的饼干满足胃口最小的孩子，不浪费更大的饼干。

int findContentChildren(int[] greed, int[] cookies) {
    Arrays.sort(greed);
    Arrays.sort(cookies);
    int child = 0;
    for (int cookie : cookies) {
        if (child < greed.length && cookie >= greed[child]) child++;
    }
    return child;
}

Go 实现

import (
	"sort"
)

type SortSlice []int

func (this *SortSlice) Less(a, b int) bool {
	return (*this)[a] < (*this)[b]
}

func (this *SortSlice) Swap(a, b int) {
	(*this)[a], (*this)[b] = (*this)[b], (*this)[a]
}

func (this *SortSlice) Len() int {
	return len(*this)
}

func findContentChildren(g []int, s []int) int {
	var ret int = 0
	sg, ss := SortSlice(g), SortSlice(s)
	sort.Sort(&sg)
	sort.Sort(&ss)

	for i, j := 0, 0; i < sg.Len() && j < ss.Len(); j++ {
		if sg[i] <= ss[j] {
			i++
			ret++
		}
	}
	return ret
}

若干次取反后的最大数组和

给定整数数组，必须执行 kkk 次操作，每次选择一个元素取相反数，求最终数组和的最大值。

思路

按绝对值从大到小处理，优先把负数变正，因为收益为 2∣x∣2|x|2∣x∣。处理完负数后若还剩奇数次操作，只能让绝对值最小的元素再取反一次。

long largestSumAfterKNegations(int[] nums, int k) {
    Integer[] values = Arrays.stream(nums).boxed().toArray(Integer[]::new);
    Arrays.sort(values, (a, b) -> Integer.compare(Math.abs(b), Math.abs(a)));
    long sum = 0;
    for (int i = 0; i < values.length; i++) {
        if (values[i] < 0 && k > 0) {
            values[i] = -values[i];
            k--;
        }
        sum += values[i];
    }
    if ((k & 1) == 1) sum -= 2L * Math.abs(values[values.length - 1]);
    return sum;
}

摆动序列

求给定序列的最长摆动子序列长度，相邻差值必须正负交替。

思路

只保留方向发生变化的峰与谷。平坡不产生新摆动；当新差值与上一个有效差值方向相反时，答案增加。局部替换为更高的峰或更低的谷不会降低后续延伸能力。

int wiggleMaxLength(int[] nums) {
    if (nums.length < 2) return nums.length;
    int previousDifference = 0;
    int answer = 1;
    for (int i = 1; i < nums.length; i++) {
        int difference = nums[i] - nums[i - 1];
        if (difference > 0 && previousDifference <= 0
                || difference < 0 && previousDifference >= 0) {
            answer++;
            previousDifference = difference;
        }
    }
    return answer;
}

股票不限交易次数

给定每天的股票价格，可以完成任意多笔交易但不能同时持有多股，求最大利润。

思路

所有上升区间的利润可以拆成相邻两天的正差值之和。只要明天价格更高，就把当天到次日的收益计入。

int maxStockProfit(int[] prices) {
    int answer = 0;
    for (int i = 1; i < prices.length; i++) {
        answer += Math.max(0, prices[i] - prices[i - 1]);
    }
    return answer;
}

跳跃游戏

数组元素表示从当前位置最多能向后跳多少步，判断能否从下标 000 到达最后一个下标。

思路

维护已经可达位置能够覆盖的最远下标。只有当前下标不超过覆盖范围时才能继续扩展。

boolean canJump(int[] nums) {
    int farthest = 0;
    for (int i = 0; i <= farthest && i < nums.length; i++) {
        farthest = Math.max(farthest, i + nums[i]);
    }
    return farthest >= nums.length - 1;
}

最少跳跃次数

数组元素表示最大跳跃长度，题目保证能够到达终点，求最少跳跃次数。

思路

把当前一次跳跃能够覆盖的区间看作 BFS 的一层。扫描这一层时维护下一层最远边界；到达当前边界后必须增加一次跳跃，并把边界扩展到下一层最远位置。

int minimumJumps(int[] nums) {
    int jumps = 0;
    int currentEnd = 0;
    int farthest = 0;
    for (int i = 0; i < nums.length - 1; i++) {
        farthest = Math.max(farthest, i + nums[i]);
        if (i == currentEnd) {
            jumps++;
            currentEnd = farthest;
        }
    }
    return jumps;
}

最大子数组和

给定整数数组，求和最大的连续非空子数组。

思路

若当前前缀和为负，它只会拖累后续子数组，应从当前元素重新开始。维护以当前位置结尾的最大和与全局答案。

int maximumSubarraySum(int[] nums) {
    int endingHere = nums[0];
    int answer = nums[0];
    for (int i = 1; i < nums.length; i++) {
        endingHere = Math.max(nums[i], endingHere + nums[i]);
        answer = Math.max(answer, endingHere);
    }
    return answer;
}

加油站

环形路线上每个站点提供一定汽油，到下一站消耗一定汽油。若存在唯一可完成一圈的起点，返回其下标，否则返回 −1-1−1。

思路

总汽油少于总消耗时无解。扫描过程中若从候选起点到当前位置的油量和变负，则这段区间内任何位置都不能作为起点，下一位置成为新候选。

int canCompleteCircuit(int[] gas, int[] cost) {
    int total = 0;
    int current = 0;
    int start = 0;
    for (int i = 0; i < gas.length; i++) {
        int difference = gas[i] - cost[i];
        total += difference;
        current += difference;
        if (current < 0) {
            start = i + 1;
            current = 0;
        }
    }
    return total < 0 ? -1 : start;
}
