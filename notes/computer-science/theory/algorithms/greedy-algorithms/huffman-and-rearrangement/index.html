Huffman 与排序不等式

2026-10-23

#贪心算法#Huffman 树

阅读线索

本篇用重复代价和相邻交换解释贪心排序。Huffman 让小权值承担更多层，排队等待按服务时间累加贡献，中位数则利用左右配对处理绝对距离。

合并果子

有若干堆果子，每次合并两堆，代价为两堆重量之和。不断合并直到只剩一堆，求最小总代价。

思路

每次选择当前最小的两堆合并。较早合并的重量会在后续代价中重复出现，因此应让较小重量承担更多层，这正是 Huffman 树的构造过程。用小根堆动态取出最小两项。

long minimumMergeCost(int[] weights) {
    PriorityQueue<Long> heap = new PriorityQueue<>();
    for (int weight : weights) heap.offer((long) weight);
    long answer = 0;
    while (heap.size() > 1) {
        long merged = heap.remove() + heap.remove();
        answer += merged;
        heap.offer(merged);
    }
    return answer;
}

排队打水

nnn 个人共用一个水龙头，第 iii 个人接水需要 tit_iti​ 时间。安排接水顺序，使所有人的等待时间之和最小。

思路

按接水时间升序。若相邻两人耗时 a>ba>ba>b 却让 aaa 在前，交换后二人及其后所有人的总等待时间不会增加；对逆序对不断交换即可得到升序最优。第 iii 个接水时间会被后面 n−i−1n-i-1n−i−1 个人等待。

long minimumWaitingTime(int[] times) {
    Arrays.sort(times);
    long answer = 0;
    for (int i = 0; i < times.length; i++) {
        answer += (long) times[i] * (times.length - i - 1);
    }
    return answer;
}

货仓选址

数轴上有 nnn 家商店，在某个整数位置建一座货仓，使货仓到所有商店的距离之和最小。

思路

将位置排序后选择中位数。最左与最右位置构成一对，货仓位于二者之间时这对距离和固定；逐层配对后，中位数同时位于所有配对区间内。

long minimumWarehouseDistance(int[] positions) {
    Arrays.sort(positions);
    int median = positions[positions.length / 2];
    long answer = 0;
    for (int position : positions) answer += Math.abs((long) position - median);
    return answer;
}

耍杂技的牛

每头牛有重量 wiw_iwi​ 和承受能力 sis_isi​。把牛叠成一列，一头牛的风险为它上方所有牛的总重量减去自身承受能力。安排顺序，使最大风险最小。

思路

按 wi+siw_i+s_iwi​+si​ 升序排列。考虑相邻两头牛 a,ba,ba,b：若 wa+sa>wb+sbw_a+s_a>w_b+s_bwa​+sa​>wb​+sb​ 却让 aaa 在前，交换二者不会增加这两头牛中的最大风险，其他牛风险不变，因此消除所有逆序后得到最优顺序。

long minimumMaximumRisk(int[][] cows) {
    Arrays.sort(cows, Comparator.comparingLong(cow -> (long) cow[0] + cow[1]));
    long weightAbove = 0;
    long answer = Long.MIN_VALUE;
    for (int[] cow : cows) {
        answer = Math.max(answer, weightAbove - cow[1]);
        weightAbove += cow[0];
    }
    return answer;
}
