区间贪心

2026-10-23

#贪心算法#区间

阅读线索

区间问题要先明确端点相接是否算重叠。选点和最多不相交区间按结束时间决策，分组维护可复用组，覆盖则在可选集合内延伸最远边界。

区间问题的贪心关键是确定排序方式和局部选择的不变量。证明通常使用交换论证：把某个最优解的第一次选择替换为贪心选择，不会让后续可选空间变差。

区间选点

给定若干闭区间，在数轴上选择尽量少的点，使每个区间内至少包含一个被选点。

思路

按右端点升序处理。若当前区间已经包含上一个选点，无需新增；否则选择当前区间右端点。任何覆盖当前区间的解都可以把其选点右移到该右端点，不会降低对后续区间的覆盖能力。

int minimumPoints(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[1]));
    int answer = 0;
    long selected = Long.MIN_VALUE;
    for (int[] interval : intervals) {
        if (selected < interval[0]) {
            selected = interval[1];
            answer++;
        }
    }
    return answer;
}

最大不相交区间数量

给定若干闭区间，选择数量最多的两两不相交区间。端点重合视为相交。

思路

同样按右端点升序，每次选择当前能够选择且结束最早的区间，为后续保留最大的可用范围。其答案与区间选点相同，但问题解释不同。

int maximumDisjointIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[1]));
    int answer = 0;
    long previousEnd = Long.MIN_VALUE;
    for (int[] interval : intervals) {
        if (interval[0] > previousEnd) {
            answer++;
            previousEnd = interval[1];
        }
    }
    return answer;
}

区间分组

将若干闭区间分成尽量少的组，使同一组内的区间两两不相交。

思路

按左端点升序处理，用小根堆保存每组最后一个区间的右端点：

  • 最早结束的组仍与当前区间相交时，其他组也无法复用，只能新建一组。
  • 否则复用最早结束的组，并更新该组右端点。

堆的最大大小就是同时相交区间的最大数量，也是最少分组数。

int minimumIntervalGroups(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[0]));
    PriorityQueue<Integer> groupEnds = new PriorityQueue<>();
    for (int[] interval : intervals) {
        if (!groupEnds.isEmpty() && groupEnds.peek() < interval[0]) {
            groupEnds.poll();
        }
        groupEnds.offer(interval[1]);
    }
    return groupEnds.size();
}

区间覆盖

给定目标区间 [start,end][start,end][start,end] 和若干区间，选择尽量少的区间完整覆盖目标区间；无法覆盖时返回 −1-1−1。

思路

按左端点升序。每一步扫描所有左端点不大于当前覆盖位置的区间，选择其中右端点最远的一个。任何可行解的下一段都来自这些候选，把它替换为最远者不会缩短覆盖范围。

int minimumCover(int[][] intervals, int start, int end) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[0]));
    int answer = 0;
    int index = 0;
    int covered = start;
    while (covered < end) {
        int farthest = covered;
        while (index < intervals.length && intervals[index][0] <= covered) {
            farthest = Math.max(farthest, intervals[index][1]);
            index++;
        }
        if (farthest == covered) return -1;
        covered = farthest;
        answer++;
    }
    return answer;
}

合并区间

合并所有互相重叠的闭区间，返回合并后的互不重叠区间。

思路

按左端点升序。当前区间与结果中的最后一个区间重叠时扩展右端点，否则开始一个新区间。

int[][] mergeIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[0]));
    List<int[]> merged = new ArrayList<>();
    for (int[] interval : intervals) {
        if (merged.isEmpty() || merged.get(merged.size() - 1)[1] < interval[0]) {
            merged.add(interval.clone());
        } else {
            int[] last = merged.get(merged.size() - 1);
            last[1] = Math.max(last[1], interval[1]);
        }
    }
    return merged.toArray(int[][]::new);
}

最少箭数引爆气球

每个气球占据一个闭区间，一支垂直箭可以引爆所有包含该横坐标的气球，求引爆全部气球的最少箭数。

思路

这就是区间选点。按右端点排序，当前气球不包含上一支箭时，在它的右端点发射新箭。

int minimumArrows(int[][] balloons) {
    Arrays.sort(balloons, Comparator.comparingInt(balloon -> balloon[1]));
    int arrows = 0;
    long position = Long.MIN_VALUE;
    for (int[] balloon : balloons) {
        if (position < balloon[0]) {
            position = balloon[1];
            arrows++;
        }
    }
    return arrows;
}

删除最少重叠区间

删除最少数量的区间，使剩余区间两两不重叠。端点相接不视为重叠。

思路

先用按右端点排序的贪心求最大不重叠区间数量，答案等于总区间数减去保留数量。

int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[1]));
    int kept = 0;
    long previousEnd = Long.MIN_VALUE;
    for (int[] interval : intervals) {
        if (interval[0] >= previousEnd) {
            kept++;
            previousEnd = interval[1];
        }
    }
    return intervals.length - kept;
}
