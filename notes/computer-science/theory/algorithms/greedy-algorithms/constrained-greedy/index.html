贪心约束与构造

2026-10-23

#贪心算法#构造

阅读线索

构造型贪心需要按约束影响的方向确定处理顺序。字母分段维护最远出现位置，糖果合并两个方向需求，身高重建优先安排高个，树上摄像头则后序决策。

划分字母区间

将字符串划分成尽量多的片段，使每个字母至多出现在一个片段中，返回各片段长度。

思路

先记录每个字符最后出现的位置。扫描当前片段时，右边界必须覆盖片段内所有字符的最后位置；当下标到达该边界时，当前片段可以安全结束。

List<Integer> partitionLabels(String text) {
    int[] last = new int[26];
    for (int i = 0; i < text.length(); i++) last[text.charAt(i) - 'a'] = i;
    List<Integer> answer = new ArrayList<>();
    int start = 0;
    int end = 0;
    for (int i = 0; i < text.length(); i++) {
        end = Math.max(end, last[text.charAt(i) - 'a']);
        if (i == end) {
            answer.add(end - start + 1);
            start = i + 1;
        }
    }
    return answer;
}

分发糖果

一排孩子各有评分。每人至少得到一颗糖，相邻孩子中评分更高者必须得到更多糖，求最少糖果总数。

思路

约束来自左右两个方向：

  • 从左向右满足“比左邻评分高”的约束。
  • 从右向左满足“比右邻评分高”的约束。

每个位置取两个方向需求的最大值，就是同时满足全部约束的最小值。

int candy(int[] ratings) {
    int n = ratings.length;
    int[] candies = new int[n];
    Arrays.fill(candies, 1);
    for (int i = 1; i < n; i++) {
        if (ratings[i] > ratings[i - 1]) candies[i] = candies[i - 1] + 1;
    }
    for (int i = n - 2; i >= 0; i--) {
        if (ratings[i] > ratings[i + 1]) {
            candies[i] = Math.max(candies[i], candies[i + 1] + 1);
        }
    }
    return Arrays.stream(candies).sum();
}

根据身高重建队列

每个人由 [height, k] 表示，k 是排在此人前面且身高不低于此人的人数。重建满足所有约束的队列。

思路

先按身高降序、k 升序排序。处理当前人时，已插入者都不矮于它，因此直接插入下标 k 就满足约束；后来插入的更矮者不会影响它。

int[][] reconstructQueue(int[][] people) {
    Arrays.sort(people, (a, b) -> a[0] == b[0]
            ? Integer.compare(a[1], b[1])
            : Integer.compare(b[0], a[0]));
    List<int[]> queue = new LinkedList<>();
    for (int[] person : people) queue.add(person[1], person);
    return queue.toArray(int[][]::new);
}

监控二叉树

在二叉树节点上安装摄像头。每个摄像头监控其父节点、自身和直接子节点，求监控全部节点的最少摄像头数量。

状态

后序遍历返回三种状态：

  • 0：当前节点未被覆盖。
  • 1：当前节点安装摄像头。
  • 2：当前节点已被子节点的摄像头覆盖。

空节点视为已覆盖，避免在叶子下方安装摄像头。若任一子节点未覆盖，当前节点必须安装；若任一子节点安装，当前节点已覆盖；否则当前节点留给父节点覆盖。

class CameraTreeNode {
    CameraTreeNode left;
    CameraTreeNode right;
}

int minimumCameraCover(CameraTreeNode root) {
    int[] cameras = new int[1];
    if (cameraState(root, cameras) == 0) cameras[0]++;
    return cameras[0];
}

int cameraState(CameraTreeNode node, int[] cameras) {
    if (node == null) return 2;
    int left = cameraState(node.left, cameras);
    int right = cameraState(node.right, cameras);
    if (left == 0 || right == 0) {
        cameras[0]++;
        return 1;
    }
    if (left == 1 || right == 1) return 2;
    return 0;
}
