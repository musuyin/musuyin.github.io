欧拉函数与模运算

2026-10-23

#数论#欧拉函数#快速幂

阅读线索

质因数分解给出欧拉函数，互质条件连接欧拉定理与逆元，裴蜀定理则说明整数线性组合的可达范围。每个公式都应与其前提一起记忆。

欧拉函数

φ(n)\varphi(n)φ(n) 表示 111 到 nnn 中与 nnn 互质的整数数量。若 nnn 的不同质因数为 p1,p2,…,pkp_1,p_2,\ldots,p_kp1​,p2​,…,pk​，利用容斥原理可得：

φ(n)=n∏i=1k(1−1pi)\varphi(n)=n\prod_{i=1}^{k}\left(1-\frac1{p_i}\right)φ(n)=ni=1∏k​(1−pi​1​)

计算时写成 result = result / prime * (prime - 1)，避免浮点误差。

long eulerPhi(long n) {
    long result = n;
    long remaining = n;
    for (long prime = 2; prime <= remaining / prime; prime++) {
        if (remaining % prime == 0) {
            result = result / prime * (prime - 1);
            while (remaining % prime == 0) remaining /= prime;
        }
    }
    if (remaining > 1) result = result / remaining * (remaining - 1);
    return result;
}

筛法求欧拉函数

线性筛可以同时求出 111 到 nnn 的欧拉函数：

  • 若 iii 是质数，φ(i)=i−1\varphi(i)=i-1φ(i)=i−1。
  • 若质数 ppp 能整除 iii，φ(pi)=pφ(i)\varphi(pi)=p\varphi(i)φ(pi)=pφ(i)。
  • 否则 ppp 与 iii 互质，φ(pi)=(p−1)φ(i)\varphi(pi)=(p-1)\varphi(i)φ(pi)=(p−1)φ(i)。
int[] phiSieve(int n) {
    int[] phi = new int[n + 1];
    boolean[] composite = new boolean[n + 1];
    List<Integer> primes = new ArrayList<>();
    phi[1] = 1;
    for (int value = 2; value <= n; value++) {
        if (!composite[value]) {
            primes.add(value);
            phi[value] = value - 1;
        }
        for (int prime : primes) {
            if ((long) prime * value > n) break;
            composite[prime * value] = true;
            if (value % prime == 0) {
                phi[prime * value] = phi[value] * prime;
                break;
            }
            phi[prime * value] = phi[value] * (prime - 1);
        }
    }
    return phi;
}

快速幂

计算 baseexponent mod modulusbase^{exponent} \bmod modulusbaseexponentmodmodulus。

思路

把指数写成二进制。当前位为 111 时把对应幂乘入答案，每轮将底数平方、指数右移。复杂度为 O(log⁡exponent)O(\log exponent)O(logexponent)。乘法前转为 long，避免两个 int 相乘先溢出。

long modularPower(long base, long exponent, long modulus) {
    long answer = 1 % modulus;
    base = Math.floorMod(base, modulus);
    while (exponent > 0) {
        if ((exponent & 1) == 1) {
            answer = answer * base % modulus;
        }
        base = base * base % modulus;
        exponent >>= 1;
    }
    return answer;
}

费马逆元

给定质数 ppp 和不被 ppp 整除的整数 aaa，求 aaa 在模 ppp 意义下的乘法逆元。

费马小定理给出 ap−1≡1(modp)a^{p-1} \equiv 1 \pmod pap−1≡1(modp)，因此：

a−1≡ap−2(modp)a^{-1} \equiv a^{p-2} \pmod pa−1≡ap−2(modp)
long modularInversePrime(long value, long primeModulus) {
    return modularPower(value, primeModulus - 2, primeModulus);
}

逆元只在 aaa 与模数互质时存在；快速幂公式 ap−2a^{p-2}ap−2 还要求模数为质数。

欧拉定理

当 gcd⁡(a,n)=1\gcd(a,n)=1gcd(a,n)=1 时：

aφ(n)≡1(modn)a^{\varphi(n)} \equiv 1 \pmod naφ(n)≡1(modn)

它把费马小定理推广到合数模数，也常用于指数降幂。使用前必须验证底数与模数互质；否则不能直接套用。

裴蜀定理

对任意整数 a,ba,ba,b，存在整数 x,yx,yx,y 使：

ax+by=gcd⁡(a,b)ax+by=\gcd(a,b)ax+by=gcd(a,b)

因此线性方程 ax+by=cax+by=cax+by=c 有整数解，当且仅当 gcd⁡(a,b)\gcd(a,b)gcd(a,b) 能整除 ccc。对多个整数同样成立：它们能线性组合出的所有整数，恰好是其最大公约数的倍数。
