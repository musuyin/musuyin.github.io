阅读线索

Java 动态规划题按递推、股票状态、背包和序列等模型展开。每次先写状态集合与属性，再解释转移的划分依据、初始化和顺序，最后才压缩空间。

具有两个性质：

  • 最优子结构
  • 重叠子问题

分析技巧

DP：

  • 状态表示
    • 集合
    • 属性：要求的值
  • 状态计算：找每种方案最后一个不同点

优化技巧

  1. 空间优化：
  • 如果状态转移只依赖于前一个状态，可以使用滚动数组减少空间复杂度。
  • 例如，斐波那契数列中只需保存前两个状态。
  1. 状态压缩：
  • 将多维状态压缩为一维，减少空间开销。
  • 例如，背包问题中可以将二维数组压缩为一维数组。
  1. 剪枝：
  • 在搜索过程中提前排除不可能的状态，减少计算量。

爬楼梯

leetcode.cn/problems/climbing-stairs/description/

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

class Solution {
    public int climbStairs(int n) {
        if (n == 1) {
            return 1;
        }
        int[] f = new int[n + 1];
        f[1] = 1;
        f[2] = 2;
        for (int i = 3; i <= n; i++) {
            f[i] = f[i - 1] + f[i - 2];
        }
        return f[n];
    }
}

不同路径

leetcode.cn/problems/unique-paths/description/

一个机器人位于一个 m x n 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

class Solution {
    public int uniquePaths(int m, int n) {
        // f[i][j] 向下走i步，向右走j步的所有方案
        // count
        // f[i][j] = f[i - 1][j] + f[i][j - 1]
        m--;
        n--;
        int[][] f = new int[m + 1][n + 1];
        // 初始化
        for (int i = 0; i <= m; i++) {
            f[i][0] = 1;
        }
        for (int i = 0; i <= n; i++) {
            f[0][i] = 1;
        }
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                f[i][j] = f[i - 1][j] + f[i][j - 1];
            }
        }
        return f[m][n];
    }
}

整数拆分

leetcode.cn/problems/integer-break/description/

给定一个正整数 n ，将其拆分为 k 个 正整数 的和（ k >= 2 ），并使这些整数的乘积最大化。

返回 你可以获得的最大乘积 。

class Solution {
    public int integerBreak(int n) {
        // f[i] 数值为i的数的所有拆分方案
        // max multiple
        // 拆法：1. 拆两个数：j * (i - j)；2. 拆三个数及以上：j * f[i - j]
        // f[i] = max(f[i-1]*1, f[i-2]*2, ..., (i-1)*(1), (i-2)*2, ...)
        int[] f = new int[n + 1];
        f[1] = f[2] = 1;
        for (int i = 3; i <= n; i++) {
            for (int j = 1; j < i; j++) {
                f[i] = Math.max((i - j) * j, f[i]);
                f[i] = Math.max(f[i - j] * j, f[i]);
            }
        }
        return f[n];
    }
}

不同的二叉搜索树

leetcode.cn/problems/unique-binary-search-trees/description/

给你一个整数 n ，求恰由 n 个节点组成且节点值从 1 到 n 互不相同的 二叉搜索树 有多少种？返回满足题意的二叉搜索树的种数。

  • 对于根节点为 1：其子树为 n=0 和 n=2 的情况

    • 左子树 0 个节点 * 右子树 2 个节点：1*2

  • 对于根节点为 2：其子树为 n=1 和 n=1 的情况

    • 左子树 1 个节点 * 右子树 1 个节点：1*1

  • 对于根节点为 3：其子树为 n=2 和 n=0 的情况

    • 左子树 2 个节点 * 右子树 0 个节点：2*1

  • f[3]=f[0]∗f[2]+f[1]∗f[1]+f[2]∗f[0]f[3]=f[0]*f[2]+f[1]*f[1]+f[2]*f[0]f[3]=f[0]∗f[2]+f[1]∗f[1]+f[2]∗f[0]

  • 扩展到 nnn 个节点，就是分别以每个节点为根节点，小于当前根节点的节点在左子树，大于的在右子树，由此得到 f[left]f[left]f[left] 和 f[right]f[right]f[right]

class Solution {
    public int numTrees(int n) {
        // f[i] 由i个节点组成的二叉搜索树的所有组合
        // count
        // 要注意满足二叉搜索树的性质，而不能只考虑构成二叉树
        // f[i] = f[0]*f[i-1] + f[1]*f[i-2] + ... + f[i-1]*f[0] = sum(f[j-1] * f[i-j])
        int[] f = new int[n + 1];
        f[0] = 1;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                f[i] += f[j - 1] * f[i - j];
            }
        }
        return f[n];
    }
}

组合总和 IV

leetcode.cn/problems/combination-sum-iv/

给你一个由 不同 整数组成的数组 nums ，和一个目标整数 target 。请你从 nums 中找出并返回总和为 target 的元素组合的个数。题目数据保证答案符合 32 位整数范围。

  • 其实就是爬楼梯问题，区别在于由 nums 提供多个步长
  • 或者也可以视为完全背包问题
class Solution {
    public int combinationSum4(int[] nums, int target) {
        int[] f = new int[target + 1];
        f[0] = 1;
        for (int i = 0; i <= target; i++) {
            for (int j = 0; j < nums.length; j++) {
                if (i >= nums[j]) {
                    f[i] += f[i - nums[j]];
                }
            }
        }
        return f[target];
    }
}

买卖股票的最佳时机 I

leetcode.cn/problems/best-time-to-buy-and-sell-stock/

You are given an array prices where prices[i] is the price of a given stock on the i<sup>th</sup> day.

You want to maximize your profit by choosing a single day to buy one stock and choosing a different day in the future to sell that stock.

Return the maximum profit you can achieve from this transaction. If you cannot achieve any profit, return 0.

  • f[i][0]f[i][0]f[i][0]：当前这天持有股票时，所有的买卖方案；f[i][1]f[i][1]f[i][1]：当前这天不持有股票时，所有的买卖方案

    • 持有和不持有表示状态，不表示买卖的行为。如果还需要表示行为，则需要更多状态，但是现在可以用两个状态来表示所有方案

  • 属性：max value

  • 对于 f[i][0]f[i][0]f[i][0]

    • f[i][0]=f[i−1][0]f[i][0]=f[i-1][0]f[i][0]=f[i−1][0]：前一天持有股票：f[i−1][0]f[i-1][0]f[i−1][0]，也就是继承上一天的股票（不管上一天的股票时什么时候买的）
    • f[i][0]=−prices[i]f[i][0]=-prices[i]f[i][0]=−prices[i]：即第 iii 天买入了股票，要注意买入卖出操作只能各执行一次，初始化为 −prices[i]-prices[i]−prices[i]，表示不继承之前的所有买卖操作

  • 对于 f[i][1]f[i][1]f[i][1]

    • f[i][1]=f[i−1][0]+prices[i]f[i][1]=f[i-1][0]+prices[i]f[i][1]=f[i−1][0]+prices[i]：前一天持有股票：f[i−1][0]f[i-1][0]f[i−1][0]，即第 iii 天卖出了股票
    • f[i][1]=f[i−1][1]f[i][1]=f[i-1][1]f[i][1]=f[i−1][1]：前一天不持有股票：f[i−1][1]f[i-1][1]f[i−1][1]，即继承上一天的没有买入股票的状态（或者是之前就卖出了）
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[][] f = new int[n][2];
        f[0][0] = -prices[0];
        f[0][1] = 0;
        for (int i = 1; i < n; i++) {
            f[i][0] = Math.max(f[i - 1][0], -prices[i]);
            f[i][1] = Math.max(f[i - 1][1], f[i - 1][0] + prices[i]);
        }
        return Math.max(f[n - 1][0], f[n - 1][1]);
    }
}

买卖股票的最佳时机 II

https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/…

You are given an integer array prices where prices[i] is the price of a given stock on the i<sup>th</sup> day.

On each day, you may decide to buy and/or sell the stock. You can only hold at most one share of the stock at any time. However, you can buy it then immediately sell it on the same day.

Find and return the maximum profit you can achieve.

  • f[i][0]f[i][0]f[i][0]：当前这天持有股票时，所有的买卖方案；f[i][1]f[i][1]f[i][1]：当前这天不持有股票时，所有的买卖方案

  • 属性：max value

  • 对于 f[i][0]f[i][0]f[i][0]

    • f[i][0]=f[i−1][0]f[i][0]=f[i-1][0]f[i][0]=f[i−1][0]：前一天持有股票：f[i−1][0]f[i-1][0]f[i−1][0]，也就是继承上一天的股票（不管上一天的股票时什么时候买的）
    • f[i][0]=f[i−1][1]−prices[i]f[i][0]=f[i-1][1]-prices[i]f[i][0]=f[i−1][1]−prices[i]：即第 iii 天买入了股票，注意买入卖出操作的执行次数不受限制，初始化为 f[i−1][1]−prices[i]f[i-1][1]-prices[i]f[i−1][1]−prices[i]，表示要继承之前的所有买卖操作

  • 对于 f[i][1]f[i][1]f[i][1]

    • f[i][1]=f[i−1][0]+prices[i]f[i][1]=f[i-1][0]+prices[i]f[i][1]=f[i−1][0]+prices[i]：前一天持有股票：f[i−1][0]f[i-1][0]f[i−1][0]，即第 iii 天卖出了股票
    • f[i][1]=f[i−1][1]f[i][1]=f[i-1][1]f[i][1]=f[i−1][1]：前一天不持有股票：f[i−1][1]f[i-1][1]f[i−1][1]，即继承上一天的没有买入股票的状态（或者是之前就卖出了）
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[][] f = new int[n][2];
        f[0][0] = -prices[0];
        f[0][1] = 0;
        for (int i = 1; i < n; i++) {
            f[i][0] = Math.max(f[i - 1][0], f[i - 1][1] - prices[i]);
            f[i][1] = Math.max(f[i - 1][1], f[i - 1][0] + prices[i]);
        }
        return Math.max(f[n - 1][0], f[n - 1][1]);
    }
}

买卖股票的最佳时机 III

https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii…

You are given an array prices where prices[i] is the price of a given stock on the i<sup>th</sup> day.

Find the maximum profit you can achieve. You may complete at most two transactions.

Note: You may not engage in multiple transactions simultaneously (i.e., you must sell the stock before you buy again).

难点在于要控制交易的次数，需要更多状态来表示

  • f[i][0]f[i][0]f[i][0]：不操作；f[i][1]f[i][1]f[i][1]：第一次持有；f[i][2]f[i][2]f[i][2]：第一次不持有；f[i][3]f[i][3]f[i][3]：第二次持有；f[i][4]f[i][4]f[i][4]：第二次不持有

    • f[i][0]f[i][0]f[i][0] 的状态可以不用列

  • 属性：max value

  • 不操作：f[i][0]=f[i−1][0]f[i][0]=f[i-1][0]f[i][0]=f[i−1][0]

  • 第一次持有：f[i][1]=max⁡{f[i−1][1],f[i−1][0]−prices[i]}f[i][1]=\max{f[i-1][1],f[i-1][0]-prices[i]}f[i][1]=max{f[i−1][1],f[i−1][0]−prices[i]}

    • 前一天已经持有：f[i][1]=f[i−1][1]f[i][1]=f[i-1][1]f[i][1]=f[i−1][1]
    • 前一天未持有，当天买入：f[i][1]=f[i−1][0]−prices[i]f[i][1]=f[i-1][0]-prices[i]f[i][1]=f[i−1][0]−prices[i]

  • 第一次不持有：f[i][2]=max⁡{f[i−1][1]+prices[i],f[i−1][2]}f[i][2]=\max{f[i-1][1]+prices[i],f[i-1][2]}f[i][2]=max{f[i−1][1]+prices[i],f[i−1][2]}

    • 前一天已经持有，当天卖出：f[i][2]=f[i−1][1]+prices[i]f[i][2]=f[i-1][1]+prices[i]f[i][2]=f[i−1][1]+prices[i]
    • 前一天未持有：f[i][2]=f[i−1][2]f[i][2]=f[i-1][2]f[i][2]=f[i−1][2]

第二次持有必须在第一次卖出之后

  • 第二次持有：f[i][3]=max⁡{f[i−1][3],f[i−1][2]−prices[i]}f[i][3]=\max{f[i-1][3], f[i-1][2]-prices[i]}f[i][3]=max{f[i−1][3],f[i−1][2]−prices[i]}

    • 前一天第一次持有：当天不可能第二次持有，略去
    • 前一天第一次不持有：即当天第二次买入，之前已经卖过一次了，f[i][3]=f[i−2]−prices[i]f[i][3]=f[i-2]-prices[i]f[i][3]=f[i−2]−prices[i]
    • 前一天第二次持有：保持前一天状态，f[i][3]=f[i−1][3]f[i][3]=f[i-1][3]f[i][3]=f[i−1][3]
    • 前一天第二次不持有：必须先持有了再卖，略去

  • 第二次不持有：f[i][4]=max⁡{f[i−1][4],f[i−1][3]+prices[i]}f[i][4]=\max{f[i-1][4],f[i-1][3]+prices[i]}f[i][4]=max{f[i−1][4],f[i−1][3]+prices[i]}

    • 前一天不持有：延续，f[i][4]=f[i−1][4]f[i][4]=f[i-1][4]f[i][4]=f[i−1][4]
    • 前一天第二次持有：f[i][4]=f[i−1][3]+prices[i]f[i][4]=f[i-1][3]+prices[i]f[i][4]=f[i−1][3]+prices[i]

每一次的操作都建立在前一次操作的基础上

class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[][] f = new int[n][5];
        f[0][0] = f[0][2] = f[0][4] = 0;
        f[0][1] = f[0][3] = -prices[0];
        for (int i = 1; i < n; i++) {
            f[i][1] = Math.max(f[i - 1][1], -prices[i]);
            f[i][2] = Math.max(f[i - 1][2], f[i - 1][1] + prices[i]);
            f[i][3] = Math.max(f[i - 1][3], f[i - 1][2] - prices[i]);
            f[i][4] = Math.max(f[i - 1][4], f[i - 1][3] + prices[i]);
        }
		// 第二次卖出已经包含了第一次卖出的最大值的情况
		return f[n - 1][4];
    }
}

买卖股票的最佳时机 IV

https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/…

You are given an integer array prices where prices[i] is the price of a given stock on the i<sup>th</sup> day, and an integer k.

Find the maximum profit you can achieve. You may complete at most k transactions: i.e. you may buy at most k times and sell at most k times.

Note: You may not engage in multiple transactions simultaneously (i.e., you must sell the stock before you buy again).

直接参考 买卖股票的最佳时机 III 即可，使用滚动数组优化

class Solution {
    public int maxProfit(int k, int[] prices) {
        int n = prices.length;
        int m = k * 2 + 1;
        int[] f = new int[m];
        // init
        for (int i = 1; i < m; i += 2) {
            f[i] = -prices[0];
        }
        // dp
        for (int i = 1; i < n; i++) {
            for (int j = 1, u = -1; j < m; j++, u = -u) {
                // f[j]: 前一天的当前操作
                // f[j - 1]: 前一天的上一次操作
                f[j] = Math.max(f[j], f[j - 1] + u * prices[i]);
            }
        }
        return f[m - 1];
    }
}

背包问题

  1. 如果转移时只需要用到本层和上一层的数据，那么可以使用滚动数组优化为一维

  2. 如果用到本层数据，需要从小到大枚举

  3. 如果用到上一层数据，需要从大到小枚举

0-1 背包

01 背包

有 N 件物品和一个容量是 V 的背包。每件物品只能使用一次。

第 i 件物品的体积是 vi，价值是 wi。

求解将哪些物品装入背包，可使这些物品的总体积不超过背包容量，且总价值最大。
输出最大价值。

DP:

  • 状态表示 f(i, j)

    • 集合：所有只考虑前 iii 个物品，且总体积不超过 jjj 的选项的集合

    • 属性：max

      • 最终答案：f(N, V)

  • 状态计算：f(i, j) = max(f(i - 1, j), f(i - 1, j - v[i]) + w[i])

    • 选第 iii 个物品：所有包含第 iii 个物品的选项集合，其实需要找的就是变化的部分的最大值，即：从 111~i−1i-1i−1 中选择，且总体积小于等于 j−v[i]j-v[i]j−v[i] 的选项集合

      当 j<v[i]j < v[i]j<v[i] 时，该分支不存在

      • 变化的部分：包含前 i−1i-1i−1 个物品的不同选项
      • 不变的部分：都需要包含第 iii 个物品

    • 不选第 iii 个物品：需要满足从 111~i−1i-1i−1 中选择，且总体积小于等于 jjj 的所有选项集合

二维朴素写法
import java.util.*;
public class Main {
    static final int N = 1010;
    // f[i][j] 表示只对于前i个物品且使用j的背包空间，选取的所有方案中的最大值
    static int[][] f = new int[N][N];
    static int[] w = new int[N];

倍数问题

众所周知，小葱同学擅长计算，尤其擅长计算一个数是否是另外一个数的倍数。

但小葱只擅长两个数的情况，当有很多个数之后就会比较苦恼。

现在小葱给了你 n 个数，希望你从这 n 个数中找到三个数，使得这三个数的和是 K 的倍数，且这个和最大。

数据保证一定有解。

对于三个数 a, b, c，它们的和对 K 取模的结果为 (a % K + b % K + c % K) % K == 0。因此，我们可以将问题转化为：从所有数的模 K 余数中，选择三个余数，使得它们的和模 K 为 0，并且对应的原数的和最大。

  1. 计算每个数的余数：对于每个数，计算它对 K 取模的结果，并将数按其余数分类。我们可以维护一个字典或数组，其中每个余数对应一个列表，列表中存储所有具有该余数的数，并按从大到小排序，以便我们可以快速获取最大的几个数。

  2. 枚举可能的余数组合：我们需要找到三个余数 r1, r2, r3，使得 (r1 + r2 + r3) % K == 0。为了最大化 a + b + c，我们应该在每个余数对应的列表中选取最大的数。

  3. 处理余数组合：

  • 对于三个余数 r1, r2, r3，我们需要检查是否可以从对应的余数列表中取出至少一个数。例如，如果 r1 == r2 == r3，那么对应的列表中至少需要有 3 个数。
  • 对于每个有效的余数组合，计算对应的最大可能的和，即最大的 a (余数 r1) + 最大的 b (余数 r2) + 最大的 c (余数 r3)，前提是这些数可以取自各自的余数列表。
  1. 遍历所有可能的余数组合：由于 K 的范围是 1 到 10^3，余数的范围是 0 到 K-1。因此，三重循环遍历所有可能的余数组合的复杂度是 O(K^3)，对于 K=10^3 是 10^9，这在时间上是不可行的。因此，我们需要优化：
  • 可以预先计算所有可能的两个余数的和，然后对于第三个余数，检查是否存在前两个余数的和与之互补。这样可以将复杂度降低到 O(K^2)。
  • 具体来说，对于每个 r1 和 r2，计算 (r1 + r2) % K，然后 r3 = (K - (r1 + r2) % K) % K。然后检查 r3 是否存在对应的数。
  1. 维护前几大的数：对于每个余数 r，我们只需要维护前三个最大的数，因为最多只需要从同一个余数中选取三个数（例如，当 r1 = r2 = r3 时）。

public class Main {
    static final int N = 1010, INF = 0x3f3f3f3f;
    static LinkedList<Integer>[] a = new LinkedList[N];
    static int[][] f = new int[4][N];
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        for (int i = 0; i < m; i++) {
            a[i] = new LinkedList<>();
        }
        for (int i = 0; i < n; i++) {
            int x = sc.nextInt();
            a[mod(x, m)].add(x);
        }
        for (int i = 0; i <= 3; i++) {
            Arrays.fill(f[i], -INF);
        }

        // 遍历所有的余数
        for (int i = 0; i < m; i++) {
            // 取出前3个最大的（不一定有3个）

            Collections.reverse(a[i]);

                for (int j = 3; j >= 1; j--) {

                    }
                }
            }
        }

最后一块石头的重量 II

leetcode.cn/problems/last-stone-weight-ii/

有一堆石头，用整数数组 stones 表示。其中 stones[i] 表示第 i 块石头的重量。

每一回合，从中选出任意两块石头，然后将它们一起粉碎。假设石头的重量分别为 x 和 y，且 x <= y。那么粉碎的可能结果如下：

  • 如果 x == y，那么两块石头都会被完全粉碎；
  • 如果 x != y，那么重量为 x 的石头将会完全粉碎，而重量为 y 的石头新重量为 y-x。

最后，最多只会剩下一块 石头。返回此石头 最小的可能重量 。如果没有石头剩下，就返回 0。

  • 其实就是要使数组分为两部分，且令两部分的和值尽可能相近 -> sum/2
  • 那就将问题转换成类子集的和问题，区别在于是要求出能够满足的最大的容量（[0,sum/2][0,sum/2][0,sum/2]）
class Solution {
    public int lastStoneWeightII(int[] stones) {
        int n = stones.length;
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += stones[i];
        }
        // 能凑成 sum/2 则必然能凑出 (sum+1)/2，所以取 sum/2 即可
        int len = sum / 2;
        boolean[] f = new boolean[len + 1];
        // f[i][j] 只用前i个石头，凑出重量为j的所有方案
        // boolean
        // 用第i个 || 不用第i个
        // f[i][j] = f[i][j - stones[i]] || f[i-1][j]
        // 一维优化: f[j] = f[j - stones[i]] || f[j]; 从后往前
        f[0] = true;
        for (int i = 0; i < n; i++) {
            for (int j = len; j >= stones[i]; j--) {
                f[j] = f[j] || f[j - stones[i]];
            }
        }
        for (int i = len; i >= 0; i--) {
            if (f[i]) {
                return (sum - i) - i;
            }
        }
        return 0;
    }
}

            sum += nums[i];

public class Main {
    static final int N = 10010;
    static int[] a = new int[N];
    static boolean[] dp = new boolean[N];
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int d = 0, amax = 0;
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
            amax = Math.max(amax, a[i]);
            if (i == 0) {
                d = a[i];
            } else {
                d = gcd(d, a[i]);
            }
        }
        // 最大公约数不为1
        if (d != 1) {
            System.out.println("INF");
            return;
        }
        // dp
        dp[0] = true;
        for (int i = 0; i < n; i++) {
            // 需要用到本层数据，从小到大
            for (int j = a[i]; j < N; j++) {
                dp[j] = dp[j] || dp[j - a[i]];
            }
        }
        // 记录凑不出的数目
        int res = 0;
        // 记录能连续凑出的数目
        int count = 0;
        for (int i = 0; i < N; i++) {
            if (!dp[i]) {
                res++;
                count = 0;
            } else {
                count++;
            }
            if (count == amax) {
                break;
            }
        }
        System.out.println(res);
    }
    private static int gcd(int a, int b) {
        return b != 0 ? gcd(b, a % b) : a;
    }
}

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int n = s.length();
        boolean[] f = new boolean[n + 1];
        f[0] = true;
        for (int i = 1; i <= n; i++) {
            for (String w :wordDict) {
                int len = w.length();
                if (i >= len) {
                    f[i] = f[i] || (f[i - len] && s.substring(i - len, i).equals(w));
                }
            }
        }
        return f[n];
    }
}

多重背包问题

有 N 种物品和一个容量是 V 的背包。

第 i 种物品最多有 si 件，每件体积是 vi，价值是 wi。

求解将哪些物品装入背包，可使物品体积总和不超过背包容量，且价值总和最大。
输出最大价值。

  • 将多重背包拆分成 01 背包即可
import java.util.*;
public class Main {
    static final int N = 10010;
    static int[] f = new int[N];
    static int[] v = new int[N];
    static int[] w = new int[N];
    static int end = 1;
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int V = sc.nextInt();
        // 将多重背包拆分成01背包
        for (int i = 1; i <= n; i++) {
            int tempV = sc.nextInt();
            int tempW = sc.nextInt();
            int s = sc.nextInt();
            for (int j = 0; j < s; j++, end++) {
                v[end] = tempV;
                w[end] = tempW;
            }
        }
        // dp
        for (int i = 1; i <= end; i++) {
            for (int j = V; j >= v[i]; j--) {
                f[j] = Math.max(f[j], f[j - v[i]] + w[i]);
            }
        }
        System.out.println(f[V]);
    }
}

import java.util.*;

                w[i][j] = sc.nextInt();

import java.util.*;
public class Main {
    static final int N = 110;
    static int[] w = new int[N];
    static int[][] f = new int[N][N];
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int sum = 0;
        for (int i = 0; i < n; i++) {
            w[i] = sc.nextInt();
            sum += w[i];
        }
        // 先枚举长度
        for (int len = 1; len <= n; len++) {
            // 再枚举起点
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;
                if (j == i) {
                    f[i][j] = w[i] - f[i + 1][j];
                } else {
                    f[i][j] = Math.max(w[i] - f[i + 1][j], w[j] - f[i][j - 1]);
                }
            }
        }
        // A + B = sum; A - B = d
        int d = f[0][n - 1];

解析

为什么选用最大得分差？

  • 如果当前玩家取走一个数，那么对手会在剩下的子数组中取数。（零和游戏）
  • 当前得分差 = 当前玩家取走的数 - 对手在剩下子数组中的得分。
  • 注意：这个得分差是相对的，当前玩家是交替的

当 i == j 时，dp[i][j] = nums[i]，因为只有一个数，当前玩家只能取走它。

dp[0][0] = 4
dp[1][1] = 7
dp[2][2] = 2
dp[3][3] = 9
dp[4][4] = 5
dp[5][5] = 2

计算 dp[0][1]：

当前玩家可以选择 nums[0] 或 nums[1]。

  • 如果取 nums[0]，对手在 nums[1..1] 中取数，得分差为 4 - 7 = -3。
  • 如果取 nums[1]，对手在 nums[0..0] 中取数，得分差为 7 - 4 = 3。 当前玩家会选择最大值，因此 dp[0][1] = 3。

计算 dp[1][2]：

当前玩家可以选择 nums[1] 或 nums[2]。

  • 如果取 nums[1]，对手在 nums[2..2] 中取数，得分差为 7 - 2 = 5。
  • 如果取 nums[2]，对手在 nums[1..1] 中取数，得分差为 2 - 7 = -5。 当前玩家会选择最大值，因此 dp[1][2] = 5。

最终结果：

通过逐步填充 dp 表，最终得到 dp[0][5] = 7，表示玩家一比玩家二多得 7 分。 总和为 4 + 7 + 2 + 9 + 5 + 2 = 29，因此：

  • 玩家一的得分为 (29 + 7) / 2 = 18。
  • 玩家二的得分为 (29 - 7) / 2 = 11。

蒙德里安的梦想

求把 N×M 的棋盘分割成若干个 1×2 的长方形，有多少种方案。

例如当 N=2，M=4 时，共有 5 种方案。当 N=2，M=3 时，共有 3 种方案。

核心：

  • 先放横的，再放竖的（横的放完之后，可以自动填充竖的）

  • 因此总方案数 = 只放横方块的合法方案数

  • 如何判断方案合法

    • 摆完横方块之后，剩余的位置能否填充满竖方块
    • 按列来看，每一列内部所有连续的空位置为偶数个

DP：

  • 状态表示：f[i][j]

    • 集合：已经将前 i−1i-1i−1 列摆好，并且从第 i−1i-1i−1 列伸出到第 ii i 列的状态是 jj j 的所有方案

      • 即接下来摆放的方块不会在前 i−1i-1i−1 列中
      • 用 jj j 表示在第 iii 列中，包含从第 i−1i-1i−1 延伸过来的横方块的摆放方式（类似二进制，即状态压缩）

    • 属性：count

  • 状态计算：f[i][j]=∑k=0n2−1f[i−1][k]f[i][j]=\sum_{k=0}^{n^2-1} f[i-1][k]f[i][j]=∑k=0n2−1​f[i−1][k]

    • 最近的不同点在于从第 i−2i-2i−2 延伸到 i−1i-1i−1 的横方块的摆放方式

    • 设 n=5n=5n=5

      • 若从第 i−2i-2i−2 列到第 i−1i-1i−1 列只有第 kkk 行有延伸：k=00100k=00100k=00100

      • 判断 jjj 和 kkk 不矛盾

        • 不能同时放 -> j&k==0j&amp;k==0j&k==0
        • 空着的位置能够被竖方块填满 -> 所有连续空着的位置长度为偶数

      • 结果为 f[m,0]f[m,0]f[m,0]，即摆好了前 m−1m-1m−1 列，且第 m−1m-1m−1 列无横方块延伸到第 mmm 列

  • 本质是“状态压缩 DP” ，利用二进制数表示一列的状态。

  • 预处理合法状态转移，枚举可能的摆法。

  • 时间复杂度近似 O(m⋅2n)O(m \cdot 2^n)O(m⋅2n)，适用于小范围的 n,mn, mn,m。

import java.util.*;
public class Main {
    static final int N = 12, M = 1 << N;
    static long[][] f;
    static boolean[] st = new boolean[M];
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        while (n != 0 && m != 0) {
            // 预处理st，即通过查阅st[k]可以快速知道f[i][k]能否满足连续的空位置长度均为偶数
            for (int i = 0; i < 1 << n; i++) {
                // i表示所有可能的方案
                // cnt表示连续空格子数
                int cnt = 0;
                st[i] = true;
                for (int j = 0; j < n; j++) {
                    // j用来计算i的第j位是0还是1
                    if ((i >> j & 1) != 0) {
                        // 为1，非空位置
                        if ((cnt & 1) == 1) {
                            // cnt为奇数
                            st[i] = false;
                        }
                        cnt = 0;
                    } else {
                        cnt++;
                    }
                }
                if ((cnt & 1) == 1) {
                    st[i] = false;
                }
            }
            f = new long[N][M];
            f[0][0] = 1L;
            for (int i = 1; i <= m; i++) {
                for (int j = 0; j < 1 << n; j++) {
                    // f[i]的状态j
                    for (int k = 0; k < 1 << n; k++) {
                        // f[i-1]的状态k
                        if ((j & k) == 0 && st[j | k]) {
                            // 两个状态不能在第i-1列重叠
                            // j | k = 两个状态合并后，在第i-1列的状态，判断是否合法
                            f[i][j] += f[i - 1][k];
                        }
                    }
                }
            }
            System.out.println(f[m][0]);
            n = sc.nextInt();
            m = sc.nextInt();
        }
    }
}
