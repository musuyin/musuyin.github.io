贪心算法

阅读线索

贪心题必须说明每次选择保留了哪些后续可能性。资源匹配、局部替换、覆盖范围和区间排序是常见模型，不能把样例通过当成正确性证明。

理论基础

局部最优 => 全局最优

纸币分配

容易和 DP 和回溯弄混，注意：当大的金额是小的金额的倍数时，可以使用贪心来分配

贪心思维

分发饼干

leetcode.cn/problems/assign-cookies/description/

假设你是一位很棒的家长，想要给你的孩子们一些小饼干。但是，每个孩子最多只能给一块饼干。

对每个孩子 i，都有一个胃口值 g[i]，这是能让孩子们满足胃口的饼干的最小尺寸；并且每块饼干 j，都有一个尺寸 s[j]。如果 s[j] >= g[i]，我们可以将这个饼干 j 分配给孩子 i ，这个孩子会得到满足。你的目标是满足尽可能多的孩子，并输出这个最大数值。

贪心：尽可能用最相近的饼干大小去喂

  • 最大的饼干给胃口最大的
  • 或最小的饼干给胃口最小的
import java.util.Arrays;

class Solution {
    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);

        int i = 0, j = 0;
        int res = 0;
        while (i < g.length && j < s.length) {
            if (s[j] >= g[i]) {
                res++;
                j++;
                i++;
            } else {
                j++;
            }
        }
        return res;
    }
}

k 次取反后最大化的数组和

leetcode.cn/problems/maximize-sum-of-array-after-k-negations/des…

给你一个整数数组 nums 和一个整数 k ，按以下方法修改该数组：

  • 选择某个下标 i 并将 nums[i] 替换为 -nums[i] 。

重复这个过程恰好 k 次。可以多次选择同一个下标 i 。

以这种方式修改数组后，返回数组 可能的最大和。

  • 优先对负数进行取反

    • 优先对绝对值最大的负数进行取反

  • 全部负数取反后，选取最小的正数进行取反

import java.util.*;
class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        int n = nums.length;
        Arrays.sort(nums);

        // 尽可能把所有负数变为正数
        for (int i = 0; k > 0 && i < n; i++) {
            if (nums[i] >= 0) {
                break;
            }
            nums[i] = -nums[i];
            k--;
        }
        System.out.println(Arrays.toString(nums));
        // 为奇数，绝对值最小的数取反
        if (k % 2 == 1) {
            int t = 0;
            for (int i = 0; i < n; i++) {
                if (nums[t] > nums[i]) {
                    t = i;
                }
            }
            nums[t] = -nums[t];
        }
        // 为偶数，不操作
        int res = 0;
        for (int j = 0; j < n; j++) {
            res += nums[j];
        }
        return res;
    }
}

摆动序列

leetcode.cn/problems/wiggle-subsequence/description/

如果连续数字之间的差严格地在正数和负数之间交替，则数字序列称为摆动序列 。 第一个差（如果存在的话）可能是正数或负数。仅有一个元素或者含两个不等元素的序列也视作摆动序列。

  • 例如， [1, 7, 4, 9, 2, 5] 是一个 摆动序列 ，因为差值 (6, -3, 5, -7, 3) 是正负交替出现的。
  • 相反，[1, 4, 7, 2, 5] 和 [1, 7, 4, 5, 5] 不是摆动序列，第一个序列是因为它的前两个差值都是正数，第二个序列是因为它的最后一个差值为零。

子序列 可以通过从原始序列中删除一些（也可以不删除）元素来获得，剩下的元素保持其原始顺序。

给你一个整数数组 nums ，返回 nums 中作为 摆动序列 的 最长子序列的长度 。

  • 局部最优：极大极小值

  • 证明：局部-> 全局

    • 设 nnn 个元素中取到了 kkk 个摆动
    • 假设不取极大值或极小值，那么该值必然在“单调坡”上，不妨设该数为 x，且 x 位于一个单调递增的坡上
    • 而在下一个单调递减的坡上，如果取极大值，那么必然会有一个摆动；如果不取极大值，则可能取不到这个摆动（该单调递减段的极小值大于 x），即最后结果 ≤k\leq k≤k
    • 所以全局最优就是取极大值极小值

  • 找极值

    • 判断该点与该点两侧的点的差值是否为相反数

  • 平坡处理

    1. 去除相邻重复元素

    2. 判断该点与该点两侧的点的差值是否满足 leftDif >= 0 && rightDif < 0 || leftDif <= 0 && rightDif > 0

      等号都在 leftDif 这侧，是为了保证每次摆动次数增加都是加在平坡的端点

  • 首位元素（主要是针对数组长度为 2 的情况）

    • 在首部延伸一个和第一个元素相同的值来构造一个平坡，使得数组中至少有 3 个元素，能够计算 leftDif 和 rightDif
    • 在尾部则默认存在一个坡度，即 result = 1，而最后一个元素就不进行操作了

  • 单调中出现平坡

    • leftDif 不要跟着 rightDif 实时更新，只需要在摆动出现的时候更新即可

不去除平坡

class Solution {
    public int wiggleMaxLength(int[] nums) {
        if (nums.length == 1) {
            return 1;
        }
        int leftDif = 0, rightDif;  // 首部延伸，leftDif初始为nums[0] - nums[0] = 0
        int result = 1;     // 尾部默认有1个坡度
        for (int i = 0; i < nums.length - 1; i++) {
            rightDif = nums[i + 1] - nums[i];
            if (leftDif >= 0 && rightDif < 0 || leftDif <= 0 && rightDif > 0) {
                result++;
                leftDif = rightDif;     // leftDif只在出现摆动的时候才更新
            }
        }
        return result;
    }
}

去除平坡

class Solution {
    public int wiggleMaxLength(int[] nums) {
        int len = removeDuplicate(nums);
        if (len == 1) {
            return 1;
        }
        int leftDif = 0, rightDif;
        int result = 1;
        for (int i = 0; i < len - 1; i++) {
            rightDif = nums[i + 1] - nums[i];
            // 因为已经去除平坡了，所以不需要考虑两者都等于0的情况
            if (leftDif * rightDif <= 0) {
                result++;
                leftDif = rightDif;
            }
        }
        return result;
    }

    // 去除相邻重复元素
    private int removeDuplicate(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (fast > 0 && nums[fast - 1] == nums[fast]) {
                continue;
            }
            nums[slow++] = nums[fast];
        }
        return slow;
    }
}

买卖股票的最佳时机 II

leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/descript…

给你一个整数数组 prices ，其中 prices[i] 表示某支股票第 i 天的价格。

在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。你也可以先购买，然后在 同一天 出售。

返回 你能获得的 最大 利润 。

  • 假设在第 iii 天买入，第 jjj 天卖出 (i<=j)(i <= j)(i<=j)，可以得到利润为 p[j]−p[i]p[j]-p[i]p[j]−p[i]
  • 对于该利润可以分解为 p[j]−p[i]=(p[j]−p[j−1])+(p[j−1]−p[j−2])+...+(p[i+1]−p[i])p[j]-p[i]=(p[j]-p[j-1])+(p[j-1]-p[j-2])+…+(p[i+1]-p[i])p[j]−p[i]=(p[j]−p[j−1])+(p[j−1]−p[j−2])+…+(p[i+1]−p[i])
  • 对于每一项，都是相当于前一天买并在这一天卖出，那么只需要计算出每两天的差值，计算所有正数和即为答案
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[] dif = new int[n];
        for (int i = 1; i < n; i++) {
            dif[i] = prices[i] - prices[i - 1];
        }
        int res = 0;
        for (int i = 1; i < n; i++) {
            if (dif[i] > 0) {
                res += dif[i];
            }
        }
        return res;
    }
}

跳跃游戏

leetcode.cn/problems/jump-game/description/

给你一个非负整数数组 nums ，你最初位于数组的 第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true ；否则，返回 false 。

  • 只需要看最大能否延伸到末尾即可，不需要在意具体走的步长
class Solution {
    public boolean canJump(int[] nums) {
        int n = nums.length;
        if (n == 1) {
            return true;
        }
        int front = 0;
        for (int i = 0; front < n && i < n; i++) {
            if (front >= i) {
                front = Math.max(front, i + nums[i]);
            } else {
                return false;
            }
        }
        return true;
    }
}

跳跃游戏 II

leetcode.cn/problems/jump-game-ii/description/

给定一个长度为 n 的 0 索引整数数组 nums。初始位置为 nums[0]。

每个元素 nums[i] 表示从索引 i 向后跳转的最大长度。换句话说，如果你在 nums[i] 处，你可以跳转到任意 nums[i + j] 处:

  • 0 <= j <= nums[i]
  • i + j < n

返回到达 nums[n - 1] 的最小跳跃次数。生成的测试用例可以到达 nums[n - 1]。

  • 同跳跃游戏，维护能到达的最远的距离
  • 假设跳跃了 xxx 次之后还没有到达终点，而跳跃了 x+1x+1x+1 后到达终点，那么最小步数一定为 x+1x+1x+1

class Solution {
    public int jump(int[] nums) {
        int n = nums.length;
        if (n == 1) {
            return 0;
        }
        int count = 0;
        int front = 0;
        int i = 0;
        while (i < n - 1) {
			// 每次找到能够延伸的最大长度
            int update = front;
            while (i <= front) {
                update = Math.max(update, i + nums[i]);
                i++;
            }
			// 一次最大延伸即为一步
            count++;
            front = update;
            if (front >= n - 1) {
				// 事实上由于给定数据，最后必然会在此处终结
                return count;
            }
        }
        return -1;
    }
}

多路归并

鱼塘钓鱼

www.acwing.com/problem/content/1264/

T总=T路程+T钓鱼T_总=T_{路程}+T_{钓鱼}T总​=T路程​+T钓鱼​

先利用贪心思想简化问题：

  1. 不可能出现来回钓鱼的情况 -> 最优解中一定不会出现重复路线 -> 路线只可能从左到右

    1. 假设出现了这样的情况，那么去除了重复的路线后，一定会得到更优的结果
    2. 只需要规定最终走到哪里停下即可，然后选取最大值

  2. 路线确定 -> T路程T_{\text{路程}}T路程​ 确定 -> T钓鱼T_{\text{钓鱼}}T钓鱼​ 确定（设为 ccc），仅需要进行鱼塘分配，而且不用受顺序的影响（只是分配停留时间）

    1. 因此只需要在如图矩阵中选出 ccc 个最大值即可 -> 多路归并

import java.util.*;

public class Main {
    static final int N = 110;
    static int[] fir = new int[N];
    static int[] dec = new int[N];
    static int[] dis = new int[N];
    static int[] spends;
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        for (int i = 1; i <= n; i++) {
            fir[i] = sc.nextInt();
        }
        for (int i = 1; i <= n; i++) {
            dec[i] = sc.nextInt();
        }
        for (int i = 2; i <= n; i++) {
            dis[i] = sc.nextInt();
        }
        int T = sc.nextInt();

        // 前缀和来计算耗时之和
        for (int i = 2; i <= n; i++) {
            dis[i] = dis[i - 1] + dis[i];
        }

        // 遍历终点
        int result = 0;
        for (int i = 1; i <= n; i++) {
            result = Math.max(result, work(i, T - dis[i]));
        }
        System.out.println(result);
    }

    private static int get(int k) {
        return Math.max(0, fir[k] - dec[k] * spends[k]);
    }

    private static int work(int n, int T) {
        int res = 0;
        spends = new int[n + 1];

        // 多路归并
        for (int i = 0; i < T; i++) {
            int t = 1;
            for (int j = 2; j <= n; j++) {
                if (get(t) < get(j)) {
                    t = j;
                }
            }
            res += get(t);
            spends[t]++;
        }
        return res;
    }
}

技能升级

www.acwing.com/problem/content/4659/

实际上就是 NNN 个等差数列

  • 正确性：从大到小排序，求前 MMM 个数的和

    • 每次需要从 NNN 个等差数列中寻找 MMM 个最大值

      • 暴力：MNMNMN

      • 堆优化：MlogN+NlogNMlogN + NlogNMlogN+NlogN

        仍然超时

  • 优化：MMM 远大于 NNN，从优化 MMM 的角度出发。

    • 二分优化：

      • 记 xxx 为从大到小数第 MMM 个数，那么大于等于 xxx 的数的个数必然大于等于 MMM 个

        且有大于等于 x+1x+1x+1 的数的个数小于 MMM

      • 关键在于能否快速求出 xxx，以及 xxx 之前所有数的和

      • 二段性证明：在数轴上取 ttt

        • 当 x≤tx \leq tx≤t 时，≥x\geq x≥x 的数的个数一定 ≥m\geq m≥m 个
        • 当 x≥tx \geq tx≥t 时，≥x\geq x≥x 的数的个数不一定 ≥m\geq m≥m 个

        故 xxx 具有二段性

      • check() 如何实现？-> 能否快速判断大于等于 xxx 的数的个数有多少个

        • 对于每个等差数列，解关于 nnn 的不等式 a−nb≥xa-nb \geq xa−nb≥x，即 n=⌊a−xb⌋+1n=\lfloor \frac{a-x}{b} \rfloor+1n=⌊ba−x​⌋+1，只需要 O(1)O(1)O(1) 即可判断一个数列
        • 对于 NNN 个数列，需要 O(N)O(N)O(N) 的时间

      • 故二分的时间复杂度为 O(NlogN)O(NlogN)O(NlogN)

    • 求总和优化：

      • 等差数列求和即可 -> O(N)O(N)O(N)
import java.util.*;

public class Main {
    static final int N = 100010;
    static int[] a = new int[N], b = new int[N];
    static int n, m;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        m = sc.nextInt();
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
            b[i] = sc.nextInt();
        }

        // x有可能取0，最大值为1000000
        int l = 0, r = 1000000;
        while (l < r) {
            int mid = l + r + 1 >> 1;
            if (check(mid)) {
                l = mid;
            } else {
                r = mid - 1;
            }
        }

        // 现在的l(或r)是这样的一个数：所有大于等于l的数的个数大于等于m
        // 且大于等于l+1的数的个数一定小于m
        // 现在只需要统计l之前所有数的总和即可
        long res = 0;
        // 取数的总个数，用来判断是否取了超出m个的数
        long cnt = 0;
        for (int i = 0; i < n; i++) {
            // 运用等差数列的求和公式
            if (a[i] >= l) {
                // 项数
                int c = (a[i] - l) / b[i] + 1;
                cnt += c;
                // 尾项（注意b读入的时候是正数，但实际上是减去这个数，所以要负号）
                int end = a[i] - (c - 1) * b[i];
                // 求和公式
                res += ((long) (a[i] + end)) * c / 2;
            }
        }

        // 因为l取的是最大的一个能使所有大于等于l的数的个数大于等于m的数
        // 可能出现cnt > m的情况，所以还要减去这一部分
        res -= (cnt - m) * l;
        System.out.println(res);
    }

    // 计算大于等于x的所有数的个数是否大于等于m
    private static boolean check(int x) {
        long res = 0;
        // 通过等差数列性质求，a-nb >= x -> n = [(a-x)/b]+1
        for (int i = 0; i < n; i++) {
            // 首项必须大于等于x才行
            if (a[i] >= x) {
                res += (a[i] - x) / b[i] + 1;
            }
        }
        return res >= m;
    }
}

最大子数组和

leetcode.cn/problems/maximum-subarray/description/

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

  • 因为是要求连续子数组，所以如果当前子数组和为负数时，直接舍弃
class Solution {
    public int maxSubArray(int[] nums) {
        int sum = 0;
        int res = -0x3f3f3f3f;
        for (int i = 0; i < nums.length; i++) {
            sum += nums[i];
            res = Math.max(res, sum);
            if (sum < 0) {
                sum = 0;
            }
        }
        return res;
    }
}

加油站

https://leetcode.cn/problems/gas-station/description/

在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 gas[i] 升。

你有一辆油箱容量无限的的汽车，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 gas 和 cost ，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 -1 。如果存在解，则 保证 它是 唯一 的。

  • 计算连续子序列区间和 curSum，当 curSum < 0 时，即不能通行，在该点之后的一个点再重新开始走
  • 可以证明：如果总和大于等于 0，那么必然能走完全程
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int n = gas.length;
        int[] d = new int[n];
        int sum = 0;
        for (int i = 0; i < n; i++) {
            d[i] = gas[i] - cost[i];
            sum += d[i];
        }
        // 如果总和大于等于0，那么必然能走完全程
        if (sum < 0) {
            return -1;
        }

        int curSum = 0, res = 0;
        for (int i = 0; i < n; i++) {
            curSum += d[i];
            if (curSum < 0) {
                res = i + 1;
                curSum = 0;
            }
        }
        return res == n ? -1 : res;
    }
}

import java.util.*;

public class Main {
    static final int N = 100010;
    static Pair[] pairs = new Pair[N];

    static class Pair implements Comparable<Pair> {

                maxNoMilk = Math.max(maxNoMilk, left - right);

                maxHasMilk = Math.max(maxHasMilk, right - left);
            }
        }

划分字母区域

leetcode.cn/problems/partition-labels/

给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。

返回一个表示每个字符串片段的长度的列表。

import java.util.*;

class Solution {

    public List<Integer> partitionLabels(String s) {
        ArrayList<int[]> intervals = work(s);
        Collections.sort(intervals, (a, b) -> {
            if (a[0] == b[0]) {
                return a[1] - b[1];
            }
            return a[0] - b[0];
        });

        List<Integer> res = new ArrayList<>();
        int left = intervals.get(0)[0], right = intervals.get(0)[1];
        // 区间合并
        for (int[] each : intervals) {
            if (each[0] <= right) {
                right = Math.max(right, each[1]);
            } else {
                // new interval
                res.add(right - left + 1);
                right = each[1];
                left = each[0];
            }
        }
        res.add(right - left + 1);
        return res;
    }

    private ArrayList<int[]> work(String s) {
        ArrayList<int[]> intervals = new ArrayList<>();
        int len = s.length();
        for (int i = 0; i < 26; i++) {
            char c = (char) (i + (int) 'a');
            int l = 0, r = len - 1;
            while (l < len && s.charAt(l) != c) {
                l++;
            }
            while (r >= 0 && s.charAt(r) != c) {
                r--;
            }
            if (l == len) {
                continue;
            }
            intervals.add(new int[] {l, r});
        }
        return intervals;
    }
}

import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        int n = points.length;
        Arrays.sort(points, (a, b) -> {
            if (a[0] == b[0]) {
                return a[1] > b[1] ? 1 : -1;
            }
            return a[0] > b[0] ? 1 : -1;
        });

        int l = points[0][0], r = points[0][1];
        int res = 1;
        for (int i = 1; i < n; i++) {
            if (points[i][0] > r) {
                res++;
                l = points[i][0];
                r = points[i][1];
            } else {
                // union
                l = points[i][0];
                r = Math.min(points[i][1], r);
            }
        }

        return res;
    }
}

import java.util.Arrays;

class Solution {
    public int eraseOverlapIntervals(int[][] intervals) {
        int n = intervals.length;
        Arrays.sort(intervals, (a, b) -> {
            if (a[0] == b[0]) {
                return a[1] - b[1];
            }
            return a[0] - b[0];
        });

        int res = 0;
        int right = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            if (intervals[i][0] < right) {
                res++;
                right = Math.min(intervals[i][1], right);
            } else {
                right = intervals[i][1];
            }
        }
        return res;
    }

分发糖果

leetcode.cn/problems/candy/description/

n 个孩子站成一排。给你一个整数数组 ratings 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

  • 每个孩子至少分配到 1 个糖果。
  • 相邻两个孩子评分更高的孩子会获得更多的糖果。

请你给每个孩子分发糖果，计算并返回需要准备的 最少糖果数目 。

  1. 如果同时考虑两侧，可能会彼此失顾

  2. 先只看一边遍历，再看另外一边遍历

    1. 右比左高，从前向后遍历：if (rating[i] > rating[i - 1]): candy[i] = candy[i - 1] + 1
    2. 左比右高，从后向前遍历：if (rating[i] < rating[i + 1]): candy[i] = candy[i + 1] + 1

  3. 其实就是将两侧拆成两个一侧，最后汇总使得答案能够满足两侧

import java.util.Arrays;
class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        int[] candies = new int[n];
        Arrays.fill(candies, 1);
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }

        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = Math.max(candies[i + 1] + 1, candies[i]);
            }
        }

        int res = 0;
        for (int i = 0; i < n; i++) {
            res += candies[i];
        }

        return res;
    }
}

根据身高重建队列

假设有打乱顺序的一群人站成一个队列，数组 people 表示队列中一些人的属性（不一定按顺序）。每个 people[i] = [hi, ki] 表示第 i 个人的身高为 hi ，前面 正好 有 ki 个身高大于或等于 hi 的人。

请你重新构造并返回输入数组 people 所表示的队列。返回的队列应该格式化为数组 queue ，其中 queue[j] = [hj, kj] 是队列中第 j 个人的属性（queue[0] 是排在队列前面的人）。

  1. 首先本题存在两重限制：h 和k，肯定要考虑优先选择一个限制消除。

  2. 考虑 k 发现没有用处，每个人前后身高没有关系，无法满足 k 的对应值

  3. 考虑 h，此时身高从大到小排序，且令身高相同的按照k 升序排序，如图

  4. 此时对于任何一组数据，在它之前的所有元素（如果有的话）的h 值都大于等于它，那么只需要根据k 值将其插到对应下标即为答案

    1. 假设移动 {5, 2}，它只可能往前移动，那么在它后面的元素不会受影响。对于在它之前的元素，因为按照排序都高于它，也不会受到影响。所以可以单独满足{5, 2}的条件
    2. 注意是类似插入排序，而不是交换位置

import java.util.Arrays;
import java.util.LinkedList;

class Solution {
    public int[][] reconstructQueue(int[][] people) {
        int n = people.length;
        Arrays.sort(people, (a, b) -> {
            if (a[0] == b[0]) {
                return a[1] - b[1];
            }
            return b[0] - a[0];
        });

        LinkedList<int[]> ls = new LinkedList<>();
        for (int i = 0; i < n; i++) {
            ls.add(people[i][1], people[i]);
        }

        int idx = 0;
        for (int[] a : ls) {
            people[idx++] = a;
        }

        return people;
    }
}

监督二叉树

leetcode.cn/problems/binary-tree-cameras/

给定一个二叉树，我们在树的节点上安装摄像头。

节点上的每个摄影头都可以监视其父对象、自身及其直接子对象。

计算监控树的所有节点所需的最小摄像头数量。

  1. 从底向上，优先在叶子节点的父节点放置摄像头

    1. 因为所有节点必须被覆盖，所以要么是在叶子节点自身放，要么是在叶子节点的父节点放，如果在父节点放置，肯定比在叶子节点放置要多出一个覆盖的位置，肯定优于或者等同于放在叶子节点，那么就选择放在叶子节点的父节点上。

  2. 然后依次向上，每隔两个空节点放置一个摄像头 -> 状态转移

    1. 无覆盖：0
    2. 有摄像头：1（无摄像头，则要么是 0 要么是 2）
    3. 有覆盖：2

    可以根据左右孩子是什么状态来确定父节点是什么状态
    确定空节点的状态：因为要尽可能的给叶子节点的父节点放置摄像头，如果给空节点无覆盖，那么会导致叶子节点要放置摄像头；如果给空节点有摄像头状态，那么叶子节点会变为有覆盖状态，错误放置；所以要设置空节点为有覆盖状态

  3. 于是涉及到二叉树自底向上的遍历方式 -> 后序遍历遍历方式

  4. 分类讨论

    1. 左右孩子 = 2 -> 父节点 = 0
    2. 左右孩子存在一个 = 0 -> 父节点 = 1
    3. 左右孩子存在一个 = 1 -> 父节点 = 2（注意：判断 0 应该在判断 1 之前，才能全部覆盖）
    4. 特判：全部遍历完毕，但是根节点还未被覆盖，需要额外增加一个摄像头
class Solution {
    private int res = 0;
    public int minCameraCover(TreeNode root) {
        if (travel(root) == 0) {
            res++;
        }
        return res;
    }

    private int travel(TreeNode root) {
        if (root == null) {
            return 2;
        }

        int left = travel(root.left);
        int right = travel(root.right);

        if (left == 0 || right == 0) {
            res++;
            return 1;
        } else if (left == 1 || right == 1) {
            return 2;
        } else {
            return 0;
        }
    }
}

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val; this.left = left; this.right = right;
    }
}

Java 代码的使用条件
