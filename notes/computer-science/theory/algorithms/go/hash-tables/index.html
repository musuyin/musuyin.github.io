#哈希表#Go#算法与数据结构

阅读线索

哈希题把反复查询转成集合或映射操作。先判断需要计数、去重还是查找补数，再决定数组、集合或字典是否合适；三数与四数问题还要处理重复答案。

本文件保留为历史来源。题目和可用 Go 实现已整合到算法索引对应的分类笔记，后续统一在分类笔记中维护。空白题解不作为已实现题目统计。

有效的字母异位词

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

使用哈希表统计 s 和 t 中出现的各个字母的次数，比较两者是否完全一致即可

func isAnagram(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }
    cnts := make([]int, 26)
    for i := 0; i < len(s); i++ {
        cnts[s[i]-'a']++
        cnts[t[i]-'a']--
    }

    for i := 0; i < len(cnts); i++ {
        if cnts[i] != 0 {
            return false
        }
    }
    return true
}

两个数组的交集

Given two integer arrays nums1 and nums2, return an array of their intersection. Each element in the result must be unique and you may return the result in any order.

遍历两个数组，使用哈希表记录数字的出现情况，最后统计状态为“出现 2 次”的数字

func intersection(nums1 []int, nums2 []int) []int {
    cnt := make(map[int]int, len(nums1))
    var ret []int
    for _, num := range nums1 {
        cnt[num] = 1
    }
    for _, num := range nums2 {
        if cnt[num] == 1 {
            ret = append(ret, num)
            cnt[num] = 2
        }
    }
    return ret
}

快乐数

Write an algorithm to determine if a number n is happy.

A happy number is a number defined by the following process:

  • Starting with any positive integer, replace the number by the sum of the squares of its digits.
  • Repeat the process until the number equals 1 (where it will stay), or it loops endlessly in a cycle which does not include 1.
  • Those numbers for which this process ends in 1 are happy.

Return true if n is a happy number, and false if not.

关键在于：如果不能到达 1，要如何判断循环不会终止。

所以使用哈希表记录循环中出现的数，当发现出现重复的数值时（非 1），即可判断无法到达 1

var SqrtMap = []int{0, 1, 4, 9, 16, 25, 36, 49, 64, 81}

func isHappy(n int) bool {
	exist := make(map[int]struct{})
	for n != 1 {
		if _, ok := exist[n]; ok {
			return false
		}
		exist[n] = struct{}{}
		n = calcu(n)
	}
	return true
}

func calcu(x int) int {
	ret := 0
	for x != 0 {
		ret += SqrtMap[x%10]
		x /= 10
	}
	return ret
}

两数之和

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

在遍历数组时，将 target - num 存入哈希表中，如果发现有 num 存在于哈希表中，则说明能构成两数之和为 target。所以顺势使用哈希表存储数值对应下标，就能快速查询了

func twoSum(nums []int, target int) []int {
    mp := make(map[int]int)
    for idx, num := range nums {
        if id, ok := mp[num]; ok {
            return []int{id, idx}
        }
        mp[target - num] = idx
    }
    return nil
}

四数相加 II

Given four integer arrays nums1, nums2, nums3, and nums4 all of length n, return the number of tuples (i, j, k, l) such that:

  • 0 <= i, j, k, l < n
  • nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

两数之和的进阶版

  • 将 nums1、nums2 分为一组，nums3、nums4 分为一组
  • 相当于两组进行两数之和的运算
  • 时间复杂度为：O(N2)O(N^2)O(N2)
func fourSumCount(nums1 []int, nums2 []int, nums3 []int, nums4 []int) int {
    n := len(nums1)
    mp := make(map[int]int, n * n)
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            mp[-nums1[i]-nums2[j]]++
        }
    }

    ret := 0
    for k := 0; k < n; k++ {
        for l := 0; l < n; l++ {
            ret += mp[nums3[k]+nums4[l]]
        }
    }

    return ret
}

赎金信

Given two strings ransomNote and magazine, return true if ransomNote can be constructed by using the letters from magazine and false otherwise.

Each letter in magazine can only be used once in ransomNote.

遍历两个字符串，统计每个字母出现次数是否满足 magazine 多于 ransomNote

func canConstruct(ransomNote string, magazine string) bool {
    if len(ransomNote) > len(magazine) {
        return false
    }
    cnt := make([]int, 26)
    for i := 0; i < len(ransomNote); i++ {
        cnt[ransomNote[i]-'a']--
    }
    for i := 0; i < len(magazine); i++ {
        cnt[magazine[i]-'a']++
    }
    for i := 0; i < 26; i++ {
        if cnt[i] < 0 {
            return false
        }
    }
    return true
}

三数之和

Given an integer array nums, return all the triplets [nums[i], nums[j], nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] + nums[k] == 0.

Notice that the solution set must not contain duplicate triplets.

  • 使用 i 遍历
    • 则剩下的 j 和 k 可作为两数之和解
  • 关键在于，结果为对应元素而不是索引，所以可能会存在重复，需要去重
    • 同样地，因为所需的只是对应元素，所以可以直接排序
  • 排序后
    • 实现去重：i 跳过相同元素
    • 优化 j 和 k：使用双指针，小于 -nums[i] 则左指针右移；大于 -nums[i] 则右指针左移
    • 需要注意 j 和 k 也需要去重，当加入结果后，跳过重复元素
type sInt []int

func (nums sInt) Len() int {
    return len(nums)
}
func (nums sInt) Swap(i, j int) {
    nums[i], nums[j] = nums[j], nums[i]
}
func (nums sInt) Less(i, j int) bool {
    return nums[i] < nums[j]
}

func threeSum(nums []int) [][]int {
    sort.Sort(sInt(nums))
    n := len(nums)
    var ret [][]int
    for i := 0; i < n; i++ {
        // if nums[i] > 0, then must have nums[j] + nums[k] > 0 > -nums[i]
        if nums[i] > 0 {
            break
        }
        if i > 0 && nums[i] == nums[i-1] {
            continue
        }
        for j, k := i + 1, n - 1; j < k; {
            sum := nums[j] + nums[k]
            if sum == -nums[i] {
                ret = append(ret, []int{nums[i], nums[j], nums[k]})
                j++
                k--
                for ; j < k && nums[j] == nums[j-1]; j++ {}
                for ; j < k && nums[k] == nums[k+1]; k-- {} 
            } else if sum < -nums[i] {
                j++
            } else {
                k--
            }
        }
    }
    return ret
}

四数之和

Given an array nums of n integers, return an array of all the unique quadruplets [nums[a], nums[b], nums[c], nums[d]] such that:

  • 0 <= a, b, c, d < n
  • a, b, c, and d are distinct.
  • nums[a] + nums[b] + nums[c] + nums[d] == target

You may return the answer in any order.

和三数之和的解法一致，只不过在外层多加了一层循环

type sortInt []int
func (s sortInt) Len() int { return len(s) }
func (s sortInt) Swap(x, y int) { s[x], s[y] = s[y], s[x] }
func (s sortInt) Less(x, y int) bool { return s[x] < s[y] }


func fourSum(nums []int, target int) [][]int {
    n := len(nums)
    sort.Sort(sortInt(nums))
    var ret [][]int
    for i := 0; i < n; i++ {
        if i > 0 && nums[i] == nums[i - 1] {
            continue
        }
        for j := i + 1; j < n; j++ {
            if j > i + 1 && nums[j] == nums[j - 1] {
                continue
            }
            t := target - nums[i] - nums[j]
            k, l := j+1, n-1
            for k < l {
                sum := nums[k] + nums[l]
                if sum == t {
                    ret = append(ret, []int{nums[i], nums[j], nums[k], nums[l]})
                    for k++; k < l && nums[k] == nums[k-1]; k++ {}
                    for l--; k < l && nums[l] == nums[l+1]; l-- {}
                } else if sum < t {
                    k++
                } else {
                    l--
                }
            }
        }
    }
    return ret
}
