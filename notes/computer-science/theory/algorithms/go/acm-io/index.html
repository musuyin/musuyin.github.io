ACM 模式 IO

2026-06-01

#算法与数据结构#Go#IO

阅读线索

Go 的 ACM 模式要自己处理标准输入输出。先确定题目按空白还是按行组织数据，再选 fmt 或 bufio；同一输入流的读取方式需要保持一致。

本文件保留为历史来源。题目和可用 Go 实现已整合到算法索引对应的分类笔记，后续统一在分类笔记中维护。空白题解不作为已实现题目统计。

  • ACM 输入输出

概述

LeetCode 等平台使用核心代码模式：只需实现函数，输入输出由平台处理。

但在笔试场景（牛客网、AcWing 等）通常使用 ACM 模式：需要自己处理标准输入输出，程序从 stdin 读取数据，向 stdout 输出结果。

Go 中常用两种方式：

  • fmt.Scan 系列：简单场景，自动按空白符/换行分割
  • bufio.Scanner / bufio.Reader：处理整行输入，性能更好，适合大数据量

fmt 系列

fmt.Scan

按空白符（空格、换行）分隔，依次读入变量，不关心换行。

package main

import "fmt"

func main() {
    var a, b int
    fmt.Scan(&a, &b)
    fmt.Println(a + b)
}

输入：

3 5

fmt.Scanf

按格式字符串读取，适合固定格式输入。

var a, b int
fmt.Scanf("%d %d", &a, &b)

fmt.Scanln

读取一行，遇到换行停止（与 fmt.Scan 的区别：Scan 跨行，Scanln 不跨行）。

var a, b int
fmt.Scanln(&a, &b)

bufio 系列

fmt.Scan 系列在数据量大时性能较差，推荐使用 bufio 封装。

标准模板

package main

import (
    "bufio"
    "fmt"
    "os"
)

var in = bufio.NewReader(os.Stdin)
var out = bufio.NewWriter(os.Stdout)

func main() {
    defer out.Flush()

    var a, b int
    fmt.Fscan(in, &a, &b)
    fmt.Fprintln(out, a+b)
}

defer out.Flush() 必须加，否则缓冲区内容不会实际输出。

fmt.Fscan / fmt.Fscanf / fmt.Fscanln 与对应的 fmt.Scan 系列用法完全一致，只是多了一个 io.Reader 参数。

常见输入模式

读取固定数量

2
3 5
var t int
fmt.Fscan(in, &t)
for i := 0; i < t; i++ {
    var a, b int
    fmt.Fscan(in, &a, &b)
    fmt.Fprintln(out, a+b)
}

读取到 EOF

var a, b int
for {
    _, err := fmt.Fscan(in, &a, &b)
    if err != nil {
        break
    }
    fmt.Fprintln(out, a+b)
}

读取整行字符串

使用 bufio.Scanner，默认按行分割：

scanner := bufio.NewScanner(os.Stdin)
for scanner.Scan() {
    line := scanner.Text() // 一整行，不含换行符
    fmt.Println(line)
}

默认缓冲区 64KB，若单行数据量大需手动扩容：

scanner.Buffer(make([]byte, 1024*1024), 1024*1024)

读取一行并解析为整数切片

package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func main() {
    scanner := bufio.NewScanner(os.Stdin)
    scanner.Scan()
    parts := strings.Fields(scanner.Text()) // 按空白符分割
    nums := make([]int, len(parts))
    for i, p := range parts {
        nums[i], _ = strconv.Atoi(p)
    }
    fmt.Println(nums)
}

读取矩阵

3 3
1 2 3
4 5 6
7 8 9
var n, m int
fmt.Fscan(in, &n, &m)
grid := make([][]int, n)
for i := 0; i < n; i++ {
    grid[i] = make([]int, m)
    for j := 0; j < m; j++ {
        fmt.Fscan(in, &grid[i][j])
    }
}

输出技巧

fmt.Fprintf / fmt.Fprintln / fmt.Fprint

fmt.Fprintln(out, ans)           // 输出并换行
fmt.Fprintf(out, "%d\n", ans)    // 格式化输出
fmt.Fprint(out, ans)             // 不换行

输出切片（空格分隔）

nums := []int{1, 2, 3, 4, 5}
for i, v := range nums {
    if i > 0 {
        fmt.Fprint(out, " ")
    }
    fmt.Fprint(out, v)
}
fmt.Fprintln(out)

或使用 strings.Join（需转换为字符串切片）：

import "strconv"

parts := make([]string, len(nums))
for i, v := range nums {
    parts[i] = strconv.Itoa(v)
}
fmt.Fprintln(out, strings.Join(parts, " "))

完整模板

package main

import (
    "bufio"
    "fmt"
    "os"
)

var in = bufio.NewReader(os.Stdin)
var out = bufio.NewWriter(os.Stdout)

func main() {
    defer out.Flush()

    var n int
    fmt.Fscan(in, &n)

    nums := make([]int, n)
    for i := 0; i < n; i++ {
        fmt.Fscan(in, &nums[i])
    }

    // 处理逻辑 ...

    fmt.Fprintln(out, nums[0])
}
