#Go#数论

整除、余数与算法条件

整数数论题先明确取值范围，再选择试除、辗转相除或模运算。Go 的整数除法向零截断；下面统一使用非负整数，避免把负余数与数学中的非负模混淆。除数不能为零。Go 语言规范：整数运算

最大公约数

若 a=qb+ra=qb+ra=qb+r，则 aaa 与 bbb 的公约数恰好也是 bbb 与 rrr 的公约数，因此 gcd⁡(a,b)=gcd⁡(b,a mod b)\gcd(a,b)=\gcd(b,a\bmod b)gcd(a,b)=gcd(b,amodb)。反复取余，直到第二个数为零；约定 gcd⁡(0,0)=0\gcd(0,0)=0gcd(0,0)=0。

循环每轮都把第二个数变为更小的非负余数，因而会结束。时间复杂度为 O(log⁡min⁡(a,b))O(\log\min(a,b))O(logmin(a,b))（两数都为正时），额外空间为 O(1)O(1)O(1)。

试除判定质数

质数是大于 111 且仅有 111 和自身两个正约数的整数。若 nnn 是合数，它的一对非平凡因子中至少一个不超过 n\sqrt nn​，因此只需检查到平方根。

条件写成 d <= n/d，避免直接计算 d*d 时溢出。时间复杂度为 O(n)O(\sqrt n)O(n​)，额外空间为 O(1)O(1)O(1)。

模意义下的快速幂

把指数逐位分解，每轮维护当前底数幂与尚未处理的指数：最低位为一时把对应幂乘入答案，再平方底数、右移指数。时间复杂度为 O(log⁡e)O(\log e)O(loge)，额外空间为 O(1)O(1)O(1)。

下面约定指数非负，模数满足 1≤m≤1091\le m\le10^91≤m≤109，底数非负。先取模后，每次乘积小于 101810^{18}1018，可以用 int64 保存。若放宽模数上限，需要另行处理乘法溢出。

Go 实现

package main

import "fmt"

func gcd(a, b int64) int64 {
    for b != 0 {
        a, b = b, a%b
    }
    return a
}

func isPrime(n int64) bool {
    if n < 2 {
        return false
    }
    for d := int64(2); d <= n/d; d++ {
        if n%d == 0 {
            return false
        }
    }
    return true
}

func powMod(base, exponent, modulus int64) int64 {
    result := int64(1) % modulus
    base %= modulus
    for exponent > 0 {
        if exponent&1 != 0 {
            result = result * base % modulus
        }
        base = base * base % modulus
        exponent >>= 1
    }
    return result
}

func main() {
    fmt.Println(gcd(48, 18))
    fmt.Println(isPrime(29))
    fmt.Println(powMod(2, 10, 1000))
}
