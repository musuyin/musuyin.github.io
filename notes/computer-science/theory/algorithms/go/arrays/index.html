理论

对于 Go 来说，数组长度在初始化时即固定，并不常用；一般更多使用 Slice（虽然在底层实现仍为数组）

二分

二分查找

Given an array of integers nums which is sorted in ascending order, and an integer target, write a function to search target in nums. If target exists, then return its index. Otherwise, return -1.

You must write an algorithm with O(log n) runtime complexity.

// Search 在升序整型切片中查找 target，返回索引；不存在返回 -1
func Search(nums []int, target int) int {
	// 初始化左右边界：左闭右闭区间
	left, right := 0, len(nums)-1

	// 循环条件：区间不为空
	for left <= right {
		mid := left + (right-left)/2

		switch {
		case nums[mid] == target:
			return mid // 找到目标，直接返回索引
		case nums[mid] < target:
			left = mid + 1 // 目标在右半区间
		default:
			right = mid - 1 // 目标在左半区间
		}
	}

	return -1
}

同向双指针

移除元素

Given an integer array nums and an integer val, remove all occurrences of val in nums in-place. The order of the elements may be changed. Then return the number of elements in nums which are not equal to val.

Consider the number of elements in nums which are not equal to val be k, to get accepted, you need to do the following things:

  • Change the array nums such that the first k elements of nums contain the elements which are not equal to val. The remaining elements of nums are not important as well as the size of nums.
  • Return k.

使用双指针，对数组进行原地移动：慢指针指向新数组末尾，快指针指向旧数组末尾

  • 如果 num[i] == val，则直接跳过，等待下一个值进行覆盖
  • 如果 num[i] != val，则另 nums[ed] = nums[i]，即将当前旧数组的末尾赋值到新数组末尾
func removeElement(nums []int, val int) int {
    ed := 0
    for i := 0; i < len(nums); i++ {
    	// 当为指定值时，跳过
        if nums[i] == val {
            continue
        }
        nums[ed] = nums[i]
        ed++
    }
    return ed
}

对向双指针

有序数组的平方

Given an integer array nums sorted in non-decreasing order, return an array of the squares of each number sorted in non-decreasing order.

O(nlog⁡n)O(n\log n)O(nlogn) 做法：对所有元素平方后再排序，时间复杂度取决于选用的排序方式

O(n)O(n)O(n)：

  • 使用左右指针从数组两侧向中对向移动
  • 每次将两个指针各自指向的元素中，绝对值/平方更大（可以先预处理数组，全部平方，因为不递减特性会使数组呈现一个 V 字形）的一个移到数组末尾
  • 直到两个指针相遇停止 / 选择元素个数达到 len(nums)
func sortedSquares(nums []int) []int {
    ret := make([]int, len(nums))
    ed := len(nums) - 1
    for left, right := 0, len(nums)-1; ed >= 0; ed-- {
        if nums[left] * nums[left] >= nums[right] * nums[right] {
            ret[ed] = nums[left] * nums[left]
            left++
        } else {
            ret[ed] = nums[right] * nums[right]
            right--
        }
    }
    return ret
}

最接近的三数之和

Given an integer array nums of length n and an integer target, find three integers at distinct indices in nums such that the sum is closest to target.

Return the sum of the three integers.

You may assume that each input would have exactly one solution.

type SortSlice []int

func (this SortSlice) Len() int {
    return len(this)
}

func (this SortSlice) Swap(a, b int) {
    this[a], this[b] = this[b], this[a]
}

func (this SortSlice) Less(a, b int) bool {
    return this[a] < this[b]
}


func threeSumClosest(nums []int, target int) int {
    n := len(nums)
    ret := 0x3f3f3f3f
    diff := 0x3f3f3f3f
    sortNums := SortSlice(nums)
    sort.Sort(sortNums)
    for i := 0; i < n; i++ {
        j, k := i+1, n-1
        for j < k {
            sum := sortNums[i] + sortNums[j] + sortNums[k]
            if sum < target {
                j++
            } else if sum > target {
                k--
            } else {
                return sum
            }
            if diff > Abs(sum - target) {
                diff = Abs(sum - target)
                ret = sum
            }
        }
    }
    return ret
}

func Abs(a int) int {
    if a < 0 {
        a = -a
    }
    return a
}

滑动窗口

长度最小的子数组

Given an array of positive integers nums and a positive integer target, return the minimal length of a subarray whose sum is greater than or equal to target. If there is no such subarray, return 0 instead.

使用滑动窗口思想：控制一个移动的可变长度的窗口，记录窗口内元素和 sum 当：

  • sum < target：不满足条件，需要扩大窗口（即 right 右移）
  • sum >= target：满足条件，所以可以尽可能的缩小窗口，使得结果更小（即 left 右移）
func minSubArrayLen(target int, nums []int) int {
    n := len(nums)
    ret := n + 1
    sum := 0
    left := 0
    for right, cur := range nums {
        sum += cur
        for sum >= target {
            ret = min(ret, right-left+1)
            sum -= nums[left]
            left++
        }
    }
    if ret <= n {
        return ret
    }
    return 0
}

螺旋矩阵 II

Given a positive integer n, generate an n x n matrix filled with elements from 1 to n2 in spiral order.

按照题意模拟。此处实现方法为：使用 4 个变量 top / bottom / left / right 控制四个边界，不断压缩

func generateMatrix(n int) [][]int {
    t, b, l, r := 0, n-1, 0, n-1
    ret := make([][]int, n)
    for i := 0; i < n; i++ {
        ret[i] = make([]int, n)
    }

    cnt := 1
    limit := n * n
    for cnt <= limit {
        // top: left -> right
        for i := l; i <= r; i++ {
            ret[t][i] = cnt
            cnt++
        }
        t++
        // right: top -> bottom
        for i := t; i <= b; i++ {
            ret[i][r] = cnt
            cnt++
        }
        r--
        // bottom: right -> left
        for i := r; i >= l; i-- {
            ret[b][i] = cnt
            cnt++
        }
        b--
        // left: bottom -> top
        for i := b; i >= t; i-- {
            ret[i][l] = cnt
            cnt++
        }
        l++
    }
    return ret
}
