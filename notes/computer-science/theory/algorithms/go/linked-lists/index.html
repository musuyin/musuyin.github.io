理论

链表是一种通过指针串联在一起的线性结构，每一个节点由两部分组成：

  • 数据域
  • 指针域（存放指向下一个节点的指针）
    • 最后一个节点的指针域指向 null（空指针）

链表的入口节点称为链表的头结点，即 head

常见类型

单链表

单链表中的指针域只能指向节点的下一个节点

双链表

双链表：每一个节点有两个指针域，一个指向下一个节点，一个指向上一个节点。既可以向前查询，也可以向后查询

循环链表

链表首尾相连

设计链表

Design your implementation of the linked list. You can choose to use a singly or doubly linked list.
A node in a singly linked list should have two attributes: val and next. val is the value of the current node, and next is a pointer/reference to the next node.
If you want to use the doubly linked list, you will need one more attribute prev to indicate the previous node in the linked list. Assume all nodes in the linked list are 0-indexed.

Implement the MyLinkedList class:

  • MyLinkedList() Initializes the MyLinkedList object.
  • int get(int index) Get the value of the indexth node in the linked list. If the index is invalid, return -1.
  • void addAtHead(int val) Add a node of value val before the first element of the linked list. After the insertion, the new node will be the first node of the linked list.
  • void addAtTail(int val) Append a node of value val as the last element of the linked list.
  • void addAtIndex(int index, int val) Add a node of value val before the indexth node in the linked list. If index equals the length of the linked list, the node will be appended to the end of the linked list. If index is greater than the length, the node will not be inserted.
  • void deleteAtIndex(int index) Delete the indexth node in the linked list, if the index is valid.

由于需要对头尾进行操作，所以可以设计一个双向链表。同时使用虚拟头/尾结点，简化操作

type MyLinkedList struct {
    head *Node
    tail *Node
    len int
}

type Node struct {
    Val int
    Prev *Node
    Next *Node
}

func Constructor() MyLinkedList {
    dummyHead := &Node{}
    dummyTail := &Node{}
    dummyHead.Next = dummyTail
    dummyTail.Prev = dummyHead
    return MyLinkedList{head: dummyHead, tail: dummyTail, len: 0}
}


func (this *MyLinkedList) Get(index int) int {
    if index >= this.len {
        return -1
    }
    cur := this.head.Next
    for i := 0; i < index; i++ {
        cur = cur.Next
    }
    return cur.Val
}


func (this *MyLinkedList) AddAtHead(val int)  {
    this.AddAtIndex(0, val)
}


func (this *MyLinkedList) AddAtTail(val int)  {
    this.AddAtIndex(this.len, val)
}


func (this *MyLinkedList) AddAtIndex(index int, val int)  {
    if index > this.len {
        return
    }

    cur := this.head
    for i := 0; i < index; i++ {
        cur = cur.Next
    }
    newNode := &Node{Val: val, Prev: cur, Next: cur.Next}
    cur.Next.Prev = newNode
    cur.Next = newNode
    this.len++
}


func (this *MyLinkedList) DeleteAtIndex(index int)  {
    if index >= this.len {
        return
    }
    cur := this.head
    for i := 0; i < index; i++ {
        cur = cur.Next
    }
    deleteNode := cur.Next
    cur.Next = deleteNode.Next
    deleteNode.Next.Prev = cur
    this.len--
}

翻转链表

Given the head of a singly linked list, reverse the list, and return the reversed list.

迭代法
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    for curr := head; curr != nil; {
        tmp := curr.Next
        curr.Next = prev
        prev = curr
        curr = tmp
    }
    return prev
}

两两交换链表中的结点

Given a linked list, swap every two adjacent nodes and return its head. You must solve the problem without modifying the values in the list’s nodes (i.e., only nodes themselves may be changed.)

同时要标记 3 个结点：

  • 需要交换的前一个结点：cur
  • 需要交换的后一个结点：nxt
  • 两个交换结点的前一个结点：prev
graph LR
	A((dummyHead)) --> B((B))
	B((B)) --> C((C))
	C((C)) --> D((D))
	D((D)) --> E((E))

每次操作：

  • prev.Next 指向 nxt
  • cur.Next 指向 nxt.Next
  • nxt.Next 指向 cur
graph LR
	A((dummyHead)) --> C((C))
	B((B)) --> D((D))
	C((C)) --> B((B))
	D((D)) --> E((E))
func swapPairs(head *ListNode) *ListNode {
    dummyHead := &ListNode{Next: head}

    for prev, cur := dummyHead, head; cur != nil && cur.Next != nil; prev, cur = cur, cur.Next {
        nxt := cur.Next
        prev.Next = nxt
        cur.Next = nxt.Next
        nxt.Next = cur
    }
    return dummyHead.Next
}

链表相交

Given two (singly) linked lists, determine if the two lists intersect. Return the inter­ secting node. Note that the intersection is defined based on reference, not value. That is, if the kth node of the first linked list is the exact same node (by reference) as the jth node of the second linked list, then they are intersecting.

  • 假设链表 A/B 未相交部分长度分别为 a / b，相交之后的长度为 c
  • 令两个指针 curA / curB 对各个链表遍历一次
    • 如果链表相遇，两个指针无论以什么顺序遍历两个链表，最后总步长一定为 a+b+c
    • 如果链表不相遇，两个指针总步长为 a+b+2*c，同时为 nil
  • 最后只需返回任一指针即可，如果非空则为相遇结点，空则未相遇
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    curA, curB := headA, headB
    for curA != curB {
        if curA == nil {
            curA = headB
        } else {
            curA = curA.Next
        }
        if curB == nil {
            curB = headA
        } else {
            curB = curB.Next
        }
    }
    return curA
}

环形链表 II

Given the head of a linked list, return the node where the cycle begins. If there is no cycle, return null.

There is a cycle in a linked list if there is some node in the list that can be reached again by continuously following the next pointer. Internally, pos is used to denote the index of the node that tail’s next pointer is connected to (0-indexed). It is -1 if there is no cycle. Note that pos is not passed as a parameter.

Do not modify the linked list.

mark:

  • a：非循环部分的链表长度
  • b：当 slow 和 fast 相遇时，在循环部分中经过的长度
  • c：循环部分的长度

有以下推导：

  • 由于慢指针每次移动 1 步，快指针每次移动 2 步，所以如果在第一次相遇的情况下，快指针必然且只循环了 1 圈
  • 此时慢指针移动步数为：a+ba+ba+b，则快指针移动步数为 2(a+b)=a+b+c2(a+b)=a+b+c2(a+b)=a+b+c
  • 于是有：a+b=ca+b=ca+b=c，即 a=c−ba=c-ba=c−b
  • 由于 b 的定义，此时可以得出，两指针相遇的位置，对于循环入口的距离为：c−b=ac-b=ac−b=a
  • 所以再令一个指针 ret 从 head 出发，使 ret 和 slow 同时向前移动直到重合，该重合处即为循环入口
func detectCycle(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            ret := head
            for ; ret != slow; ret, slow = ret.Next, slow.Next {}
            return ret
        }
    }
    return nil
}

移除链表元素

Given the head of a linked list and an integer val, remove all the nodes of the linked list that has Node.val == val, and return the new head.

可以使用一个虚拟头结点 dummyHead，当操作需要对 head 进行时，可以简化。即相当于把 head 结点转换为一个普通结点

func removeElements(head *ListNode, val int) *ListNode {
	var dummyNode *ListNode = &ListNode{Val: -1, Next: head}
	for cur := dummyNode; cur != nil; cur = cur.Next {
		// 需要注意，可能会有连续的多个结点需要删除
		for cur.Next != nil && cur.Next.Val == val {
			cur.Next = cur.Next.Next
		}
	}
	return dummyNode.Next
}

删除链表的倒数第 N 个结点

Given the head of a linked list, remove the nth node from the end of the list and return its head.

使用双指针，从虚拟头结点开始：

  • 慢指针先不动
  • 快指针向后移动 NNN 步

接着两个指针同时向后移动，直到 fast.Next == nil，此时 slow.Next 指向的结点即为倒数第 NNN 个结点，删除即可

原理：当 fast.Next == nil 时，fast 即为链表的倒数第一的结点，由于最开始快指针向后移动了 NNN 步，所以慢指针此时正好在倒数第 N+1N+1N+1 结点处，即 slow.Next 为要删除的倒数第 NNN 个结点

func removeNthFromEnd(head *ListNode, n int) *ListNode {
    dummyHead := &ListNode{Next: head}
    slow, fast := dummyHead, dummyHead
    for i := 0; i < n; i++ {
        fast = fast.Next
    }
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next
    }
    slow.Next = slow.Next.Next
    return dummyHead.Next
}
