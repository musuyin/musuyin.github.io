生成树与二分图

2026-10-23

#最小生成树#二分图

阅读线索

最小生成树优化连通全图的总边权，二分图关注节点能否分成两侧。Prim 从点集外扩，Kruskal 按边合并，二分染色则检查边两端颜色是否冲突。

Prim

给定一张连通无向带权图，选择 n−1n-1n−1 条边连接所有节点，使边权总和最小。

思路

维护已经加入生成树的点集，以及每个未加入节点到点集的最小边权。每轮加入距离最小的节点，再用它更新其他节点。正确性来自切分定理：连接当前点集与外部节点的最轻边必可属于某棵最小生成树。

long prim(int[][] graph) {
    int n = graph.length;
    int infinity = Integer.MAX_VALUE / 4;
    int[] minimumEdge = new int[n];
    boolean[] used = new boolean[n];
    Arrays.fill(minimumEdge, infinity);
    minimumEdge[0] = 0;
    long total = 0;
    for (int round = 0; round < n; round++) {
        int current = -1;
        for (int node = 0; node < n; node++) {
            if (!used[node] && (current == -1 || minimumEdge[node] < minimumEdge[current])) {
                current = node;
            }
        }
        used[current] = true;
        total += minimumEdge[current];
        for (int next = 0; next < n; next++) {
            if (!used[next] && graph[current][next] >= 0) {
                minimumEdge[next] = Math.min(minimumEdge[next], graph[current][next]);
            }
        }
    }
    return total;
}

Kruskal

思路

将所有边按权重从小到大排序。依次考虑每条边：若两端属于不同连通块，加入该边并合并连通块；否则加入会形成环，跳过。选满 n−1n-1n−1 条边后得到最小生成树。

long kruskal(int n, int[][] edges) {
    Arrays.sort(edges, Comparator.comparingInt(edge -> edge[2]));
    GraphUnionFind unionFind = new GraphUnionFind(n);
    long total = 0;
    int selected = 0;
    for (int[] edge : edges) {
        if (unionFind.union(edge[0], edge[1])) {
            total += edge[2];
            selected++;
            if (selected == n - 1) break;
        }
    }
    return total;
}

class GraphUnionFind {
    private final int[] parent;

    GraphUnionFind(int n) {
        parent = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    boolean union(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA == rootB) return false;
        parent[rootA] = rootB;
        return true;
    }
}

二分图判定

判断一张无向图能否把所有节点分成两个集合，使每条边的两个端点属于不同集合。

思路

用两种颜色对每个连通块染色。沿边访问邻居时，未染色节点染成相反颜色；若相邻节点已有相同颜色，则图不是二分图。无向图是二分图当且仅当不存在奇环。

boolean isBipartite(List<Integer>[] graph) {
    int[] color = new int[graph.length];
    for (int start = 0; start < graph.length; start++) {
        if (color[start] != 0) continue;
        Deque<Integer> queue = new ArrayDeque<>();
        color[start] = 1;
        queue.offer(start);
        while (!queue.isEmpty()) {
            int current = queue.poll();
            for (int next : graph[current]) {
                if (color[next] == 0) {
                    color[next] = -color[current];
                    queue.offer(next);
                } else if (color[next] == color[current]) {
                    return false;
                }
            }
        }
    }
    return true;
}

二分图最大匹配

给定二分图，求最多能够选择多少条两两没有公共端点的边。

思路

依次为左侧每个节点寻找增广路。若目标右侧节点尚未匹配，直接匹配；若已经匹配，则递归尝试为其原匹配对象寻找其他位置。每次搜索使用独立的 visited，避免在同一条增广路中重复访问右侧节点。

int maximumMatching(List<Integer>[] graph, int rightSize) {
    int[] matchedLeft = new int[rightSize];
    Arrays.fill(matchedLeft, -1);
    int answer = 0;
    for (int left = 0; left < graph.length; left++) {
        if (augment(left, graph, matchedLeft, new boolean[rightSize])) {
            answer++;
        }
    }
    return answer;
}

boolean augment(int left, List<Integer>[] graph, int[] matchedLeft, boolean[] visited) {
    for (int right : graph[left]) {
        if (visited[right]) continue;
        visited[right] = true;
        if (matchedLeft[right] == -1
                || augment(matchedLeft[right], graph, matchedLeft, visited)) {
            matchedLeft[right] = left;
            return true;
        }
    }
    return false;
}
