2026-10-28

#图论#搜索

阅读线索

图搜索题先明确是否允许重访节点。DAG 全路径枚举可以沿当前路径递归，带环图则需额外处理访问状态；路径输出与可达性判断保存的信息不同。

有向无环图的所有路径

给定一个包含 nnn 个节点的有向无环图，节点编号为 111 到 nnn，输出所有从节点 111 到节点 nnn 的路径；若不存在路径则输出 -1。

思路

维护当前路径，从节点 111 开始深度优先搜索。到达节点 nnn 时复制当前路径加入答案；返回上层前删除刚加入的节点。图是 DAG，不存在沿有向边返回当前路径祖先的情况，因此不需要访问数组。

复杂度

  • 时间复杂度：O(S+L)O(S+L)O(S+L)，SSS 为搜索调用数，LLL 为所有输出路径的节点总数。不能只按最终路径数估算，因为走向死路的搜索也有代价。
  • 空间复杂度：额外递归与当前路径为 O(n)O(n)O(n)，不计答案和输入图；存储邻接表还需要 O(n+m)O(n+m)O(n+m)。

Java 实现

List<List<Integer>> allPathsToLastNode(List<Integer>[] graph) {
    List<List<Integer>> answer = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    path.add(1);
    enumeratePaths(graph, 1, graph.length - 1, path, answer);
    return answer;
}

void enumeratePaths(List<Integer>[] graph, int current, int target,
                    List<Integer> path, List<List<Integer>> answer) {
    if (current == target) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int next : graph[current]) {
        path.add(next);
        enumeratePaths(graph, next, target, path, answer);
        path.remove(path.size() - 1);
    }
}

Go 实现：所有可达路径

Go ACM 版本统一用一个缓冲读取器读图的规模与全部边，采用邻接表；DAG 无需访问标记。若搜索调用数为 SSS、答案节点总数为 LLL，搜索用时 O(S+L)O(S+L)O(S+L)，存图空间 O(n+m)O(n+m)O(n+m)，额外递归空间 O(n)O(n)O(n)。

package main

import (
	"bufio"
	"fmt"
	"os"
)

func allPaths(graph [][]int) [][]int {
	var answer [][]int
	path := []int{1}
	var dfs func(int)
	dfs = func(node int) {
		if node == len(graph)-1 {
			answer = append(answer, append([]int(nil), path...))
			return
		}
		for _, next := range graph[node] {
			path = append(path, next)
			dfs(next)
			path = path[:len(path)-1]
		}
	}
	dfs(1)
	return answer
}
func main() {
	in := bufio.NewReader(os.Stdin)
	out := bufio.NewWriter(os.Stdout)
	defer out.Flush()
	var n, m int
	fmt.Fscan(in, &n, &m)
	graph := make([][]int, n+1)
	for i := 0; i < m; i++ {
		var from, to int
		fmt.Fscan(in, &from, &to)
		graph[from] = append(graph[from], to)
	}
	paths := allPaths(graph)
	if len(paths) == 0 {
		fmt.Fprintln(out, -1)
		return
	}
	for _, path := range paths {
		for i, node := range path {
			if i > 0 {
				fmt.Fprint(out, " ")
			}
			fmt.Fprint(out, node)
		}
		fmt.Fprintln(out)
	}
}

奶牛选美

一个字符网格中恰好有两块由 X 组成的四连通斑点。可以把 . 改成 X，求至少修改多少个格子才能使两块斑点连通。

思路

先用 Flood Fill 收集两块斑点的全部坐标。若从第一块中的格子 (x1,y1)(x_1,y_1)(x1​,y1​) 到第二块中的格子 (x2,y2)(x_2,y_2)(x2​,y2​) 修一条最短的水平、竖直路径，需要修改的格子数为曼哈顿距离减一。枚举两组坐标对并取最小值。

复杂度

  • 时间复杂度：O(nm+∣A∣∣B∣)O(nm+|A||B|)O(nm+∣A∣∣B∣)。
  • 空间复杂度：O(nm)O(nm)O(nm)。

Java 实现

int minimumCellsToConnect(char[][] grid) {
    List<List<int[]>> components = new ArrayList<>();
    for (int row = 0; row < grid.length; row++) {
        for (int column = 0; column < grid[0].length; column++) {
            if (grid[row][column] == 'X') {
                List<int[]> component = new ArrayList<>();
                collectSpot(grid, row, column, component);
                components.add(component);
            }
        }
    }
    int answer = Integer.MAX_VALUE;
    for (int[] first : components.get(0)) {
        for (int[] second : components.get(1)) {
            int distance = Math.abs(first[0] - second[0]) + Math.abs(first[1] - second[1]);
            answer = Math.min(answer, distance - 1);
        }
    }
    return answer;
}

void collectSpot(char[][] grid, int row, int column, List<int[]> component) {
    if (row < 0 || row >= grid.length || column < 0 || column >= grid[0].length
            || grid[row][column] != 'X') {
        return;
    }
    grid[row][column] = '.';
    component.add(new int[]{row, column});
    collectSpot(grid, row + 1, column, component);
    collectSpot(grid, row - 1, column, component);
    collectSpot(grid, row, column + 1, component);
    collectSpot(grid, row, column - 1, component);
}

树的直径与大臣的旅费

给定一棵带正权的无根树，求树上任意两点之间的最大距离 ddd。旅费规则为：走第一个单位距离花费 11，之后每多走一个单位距离，单位费用增加 1，求走完最长路程的总费用。

思路

从任意节点出发，找到距离最远的节点 uuu；再从 uuu 出发，能够到达的最大距离就是树的直径 ddd。因为边权均为正，第一次搜索的最远点一定是某条直径的端点。

旅费是等差数列：

11+12+⋯+(10+d)=d(21+d)2 11+12+\cdots+(10+d)=\frac{d(21+d)}{2} 11+12+⋯+(10+d)=2d(21+d)​

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

long ministerTravelCost(List<int[]>[] tree) {
    long[] first = farthestNode(tree, 1);
    long[] second = farthestNode(tree, (int) first[0]);
    long diameter = second[1];
    return diameter * (21 + diameter) / 2;
}

long[] farthestNode(List<int[]>[] tree, int start) {
    boolean[] visited = new boolean[tree.length];
    Deque<long[]> stack = new ArrayDeque<>();
    stack.push(new long[]{start, 0});
    visited[start] = true;
    long farthest = start;
    long maximumDistance = 0;
    while (!stack.isEmpty()) {
        long[] current = stack.pop();
        if (current[1] > maximumDistance) {
            farthest = current[0];
            maximumDistance = current[1];
        }
        for (int[] edge : tree[(int) current[0]]) {
            if (!visited[edge[0]]) {
                visited[edge[0]] = true;
                stack.push(new long[]{edge[0], current[1] + edge[1]});
            }
        }
    }
    return new long[]{farthest, maximumDistance};
}

母亲的牛奶

有三个容量分别为 AAA、BBB、CCC 的桶，初始时前两个桶为空，第三个桶装满。每次可以把一个桶中的牛奶倒入另一个桶，直到前者为空或后者装满。求第一个桶为空时，第三个桶中所有可能的牛奶量。

思路

把三个桶当前的牛奶量 (a,b,c)(a,b,c)(a,b,c) 看作图上的一个状态。每个状态最多有六种倒法，倒出的量是“源桶现有量”和“目标桶剩余容量”的较小值。对状态图做 BFS，并把所有满足 a=0a=0a=0 的 ccc 加入有序集合。

总牛奶量固定，因此也可以只记录两个桶的量；这里保留三元组使转移更直接。

复杂度

  • 时间复杂度：O(ABC)O(ABC)O(ABC)。
  • 空间复杂度：O(ABC)O(ABC)O(ABC)。

Java 实现

SortedSet<Integer> possibleMilkInThirdBucket(int[] capacity) {
    boolean[][][] visited = new boolean[capacity[0] + 1][capacity[1] + 1][capacity[2] + 1];
    Deque<int[]> queue = new ArrayDeque<>();
    SortedSet<Integer> answer = new TreeSet<>();
    queue.offer(new int[]{0, 0, capacity[2]});
    visited[0][0][capacity[2]] = true;

    while (!queue.isEmpty()) {
        int[] current = queue.poll();
        if (current[0] == 0) {
            answer.add(current[2]);
        }
        for (int from = 0; from < 3; from++) {
            for (int to = 0; to < 3; to++) {
                if (from == to) {
                    continue;
                }
                int[] next = current.clone();
                int amount = Math.min(next[from], capacity[to] - next[to]);
                next[from] -= amount;
                next[to] += amount;
                if (!visited[next[0]][next[1]][next[2]]) {
                    visited[next[0]][next[1]][next[2]] = true;
                    queue.offer(next);
                }
            }
        }
    }
    return answer;
}

奶酪连通

一块高度为 hhh 的奶酪中有 nnn 个半径均为 rrr 的球形空洞。若两个空洞相交或相切，人可以在它们之间移动；接触下表面的空洞可以进入，接触上表面的空洞可以离开。判断能否从下表面到达上表面。

思路

把每个球心看作节点。两个球心距离不超过 2r2r2r 时连边；球的最低点不高于下表面时把它作为 BFS 起点；球的最高点不低于上表面时视为出口。比较平方距离可以避免浮点误差。坐标差和平方运算都使用 long。

复杂度

  • 时间复杂度：O(n2)O(n^2)O(n2)。
  • 空间复杂度：O(n2)O(n^2)O(n2)。

Java 实现

boolean canPassCheese(long[][] centers, long height, long radius) {
    int n = centers.length;
    List<Integer>[] graph = new List[n];
    for (int i = 0; i < n; i++) {
        graph[i] = new ArrayList<>();
    }
    long diameterSquared = 4L * radius * radius;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            long dx = centers[i][0] - centers[j][0];
            long dy = centers[i][1] - centers[j][1];
            long dz = centers[i][2] - centers[j][2];
            if (dx * dx + dy * dy + dz * dz <= diameterSquared) {
                graph[i].add(j);
                graph[j].add(i);
            }
        }
    }

    boolean[] visited = new boolean[n];
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        if (centers[i][2] <= radius) {
            visited[i] = true;
            queue.offer(i);
        }
    }
    while (!queue.isEmpty()) {
        int current = queue.poll();
        if (centers[current][2] + radius >= height) {
            return true;
        }
        for (int next : graph[current]) {
            if (!visited[next]) {
                visited[next] = true;
                queue.offer(next);
            }
        }
    }
    return false;
}
