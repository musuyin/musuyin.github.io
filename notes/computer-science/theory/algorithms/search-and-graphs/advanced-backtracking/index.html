阅读线索

复杂回溯仍可拆成状态、候选、终止与撤销四部分。重复元素的同层去重、同一路径的使用限制和棋盘约束应分别表达，避免相互代替。

回溯框架

回溯在决策树上枚举方案，路径表示已经作出的选择，候选集合表示下一步可以选择什么。一个可靠的实现需要明确：

  • 搜索状态包含哪些变量。
  • 选择之后如何更新状态，返回时如何撤销。
  • 同一搜索层与同一路径分别如何去重。
  • 哪些条件能够证明当前分支不可能产生答案。

固定数量的组合和

从 111 到 999 中选择 kkk 个互不相同的数，使其和为目标值，返回所有组合。

思路

路径保持递增，因此同一个集合只会生成一次。剩余和小于零、剩余数字不足或路径已满时停止。

复杂度

  • 时间复杂度：O((9k)⋅k)O(\binom{9}{k}\cdot k)O((k9​)⋅k)，包括复制答案的开销。
  • 空间复杂度：O(k)O(k)O(k)，不计答案空间。

Java 实现

List<List<Integer>> combinationSumThree(int k, int target) {
    List<List<Integer>> answer = new ArrayList<>();
    searchCombinationThree(1, k, target, new ArrayList<>(), answer);
    return answer;
}

void searchCombinationThree(int start, int k, int remaining, List<Integer> path,
                            List<List<Integer>> answer) {
    if (path.size() == k) {
        if (remaining == 0) answer.add(new ArrayList<>(path));
        return;
    }
    int needed = k - path.size();
    for (int value = start; value <= 10 - needed && value <= remaining; value++) {
        path.add(value);
        searchCombinationThree(value + 1, k, remaining - value, path, answer);
        path.remove(path.size() - 1);
    }
}

Go 实现：组合总和 III

func combinationSum3(k int, n int) [][]int {
	var ret [][]int
	var path []int
	dfsCombinationSum3(k, n, 1, &path, &ret)
	return ret
}

func dfsCombinationSum3(k, rest, startIndex int, pathPtr *[]int, retPtr *[][]int) {
	if len(*pathPtr) == k {
		if rest == 0 {
			var path []int = make([]int, k)
			copy(path, *pathPtr)
			*retPtr = append(*retPtr, path)
		}
		return
	}

	for i := startIndex; i <= 9; i++ {
		if i > rest {
			return
		}
		*pathPtr = append(*pathPtr, i)
		dfsCombinationSum3(k, rest-i, i+1, pathPtr, retPtr)
		*pathPtr = (*pathPtr)[:len(*pathPtr)-1]
	}
}

电话号码字母组合

数字 2 至 9 分别映射到电话键盘上的字母，返回输入数字串能表示的所有字母组合。

思路

搜索树每一层对应一个数字，每个分支选择该数字上的一个字母。路径长度等于数字串长度时得到一个答案。

复杂度

  • 时间复杂度：O(4n⋅n)O(4^n\cdot n)O(4n⋅n)，nnn 为数字串长度。
  • 空间复杂度：O(n)O(n)O(n)，不计答案空间。

Java 实现

List<String> letterCombinations(String digits) {
    String[] letters = {"", "", "abc", "def", "ghi", "jkl",
            "mno", "pqrs", "tuv", "wxyz"};
    List<String> answer = new ArrayList<>();
    if (!digits.isEmpty()) {
        searchLetters(digits, 0, letters, new StringBuilder(), answer);
    }
    return answer;
}

void searchLetters(String digits, int index, String[] letters,
                   StringBuilder path, List<String> answer) {
    if (index == digits.length()) {
        answer.add(path.toString());
        return;
    }
    String choices = letters[digits.charAt(index) - '0'];
    for (int i = 0; i < choices.length(); i++) {
        path.append(choices.charAt(i));
        searchLetters(digits, index + 1, letters, path, answer);
        path.deleteCharAt(path.length() - 1);
    }
}

可重复选择的组合和

给定互不相同的正整数候选数组和目标值，每个候选可以选择任意次，返回所有和为目标值的不同组合。

思路

先排序。递归仍从当前下标开始，表示当前数字可以再次使用；候选值超过剩余和后，后续更大的值也不可能使用。

复杂度

  • 时间复杂度：最坏为指数级，可记为 O(nd⋅d)O(n^d\cdot d)O(nd⋅d)，其中 d=⌊target/min(candidates)⌋d=\lfloor target/min(candidates)\rfloord=⌊target/min(candidates)⌋。
  • 空间复杂度：O(d)O(d)O(d)，不计答案空间。

Java 实现

List<List<Integer>> combinationSumUnlimited(int[] candidates, int target) {
    Arrays.sort(candidates);
    List<List<Integer>> answer = new ArrayList<>();
    searchUnlimited(candidates, 0, target, new ArrayList<>(), answer);
    return answer;
}

void searchUnlimited(int[] candidates, int start, int remaining,
                     List<Integer> path, List<List<Integer>> answer) {
    if (remaining == 0) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < candidates.length && candidates[i] <= remaining; i++) {
        path.add(candidates[i]);
        searchUnlimited(candidates, i, remaining - candidates[i], path, answer);
        path.remove(path.size() - 1);
    }
}

含重复候选的组合和

候选数组可能包含重复元素，每个下标最多使用一次，返回和为目标值的不同组合。

思路

排序后，相同数字在同一搜索层只选择第一个；递归进入 i+1，保证同一下标不会重复使用。

复杂度

  • 时间复杂度：最坏为 O(2n⋅n)O(2^n\cdot n)O(2n⋅n)，包括复制答案的开销。
  • 空间复杂度：O(n)O(n)O(n)，不计答案空间。

Java 实现

List<List<Integer>> combinationSumUnique(int[] candidates, int target) {
    Arrays.sort(candidates);
    List<List<Integer>> answer = new ArrayList<>();
    searchUniqueCombination(candidates, 0, target, new ArrayList<>(), answer);
    return answer;
}

void searchUniqueCombination(int[] candidates, int start, int remaining,
                             List<Integer> path, List<List<Integer>> answer) {
    if (remaining == 0) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < candidates.length && candidates[i] <= remaining; i++) {
        if (i > start && candidates[i] == candidates[i - 1]) continue;
        path.add(candidates[i]);
        searchUniqueCombination(candidates, i + 1, remaining - candidates[i],
                path, answer);
        path.remove(path.size() - 1);
    }
}

分割回文串

把字符串切分成若干子串，使每段都是回文串，返回所有切分方案。

思路

start 表示下一段起点，枚举终点并只递归回文区间。到达字符串末尾时，路径中的分段构成一个完整方案。

复杂度

  • 时间复杂度：O(n2⋅2n)O(n^2\cdot 2^n)O(n2⋅2n)，当前实现每次用双指针判断回文并复制分段。
  • 空间复杂度：O(n)O(n)O(n)，不计答案空间。

Java 实现

List<List<String>> palindromePartitions(String text) {
    List<List<String>> answer = new ArrayList<>();
    searchPalindromePartitions(text, 0, new ArrayList<>(), answer);
    return answer;
}

void searchPalindromePartitions(String text, int start, List<String> path,
                                List<List<String>> answer) {
    if (start == text.length()) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int end = start; end < text.length(); end++) {
        if (!palindromeRange(text, start, end)) continue;
        path.add(text.substring(start, end + 1));
        searchPalindromePartitions(text, end + 1, path, answer);
        path.remove(path.size() - 1);
    }
}

boolean palindromeRange(String text, int left, int right) {
    while (left < right) {
        if (text.charAt(left++) != text.charAt(right--)) return false;
    }
    return true;
}

复原 IP 地址

在只包含数字的字符串中插入三个点，返回所有合法 IPv4 地址。每段范围为 000 至 255255255，多位数字不能有前导零。

思路

路径记录已经确定的段。每段最多三位；剩余字符数量必须能够填满剩余段，借此提前剪枝。

复杂度

  • 时间复杂度：O(1)O(1)O(1)，搜索深度固定为四且每段最多三位。
  • 空间复杂度：O(1)O(1)O(1)，不计答案空间。

Java 实现

List<String> restoreIpAddresses(String digits) {
    List<String> answer = new ArrayList<>();
    searchIpSegments(digits, 0, new ArrayList<>(), answer);
    return answer;
}

void searchIpSegments(String digits, int start, List<String> segments,
                      List<String> answer) {
    if (segments.size() == 4) {
        if (start == digits.length()) answer.add(String.join(".", segments));
        return;
    }
    int remainingSegments = 4 - segments.size();
    int remainingCharacters = digits.length() - start;
    if (remainingCharacters < remainingSegments
            || remainingCharacters > 3 * remainingSegments) return;
    int value = 0;
    for (int end = start; end < digits.length() && end < start + 3; end++) {
        if (end > start && digits.charAt(start) == '0') break;
        value = value * 10 + digits.charAt(end) - '0';
        if (value > 255) break;
        segments.add(digits.substring(start, end + 1));
        searchIpSegments(digits, end + 1, segments, answer);
        segments.remove(segments.size() - 1);
    }
}

子集

返回互不相同数组的所有子集。

思路

子集对应搜索树中的每个节点，因此进入递归时就收集当前路径，而不是只收集叶节点。

复杂度

  • 时间复杂度：O(n⋅2n)O(n\cdot 2^n)O(n⋅2n)，包括复制所有子集的开销。
  • 空间复杂度：O(n)O(n)O(n)，不计答案空间。

Java 实现

List<List<Integer>> subsets(int[] values) {
    List<List<Integer>> answer = new ArrayList<>();
    searchSubsets(values, 0, new ArrayList<>(), answer);
    return answer;
}

void searchSubsets(int[] values, int start, List<Integer> path,
                   List<List<Integer>> answer) {
    answer.add(new ArrayList<>(path));
    for (int i = start; i < values.length; i++) {
        path.add(values[i]);
        searchSubsets(values, i + 1, path, answer);
        path.remove(path.size() - 1);
    }
}

含重复元素的子集

数组可能包含重复元素，返回所有不同子集。

思路

排序后跳过同一搜索层的相同值，路径上的相同值仍可来自不同层。

复杂度

  • 时间复杂度：最坏为 O(n⋅2n)O(n\cdot 2^n)O(n⋅2n)。
  • 空间复杂度：O(n)O(n)O(n)，不计答案空间。

Java 实现

List<List<Integer>> subsetsWithDuplicates(int[] values) {
    Arrays.sort(values);
    List<List<Integer>> answer = new ArrayList<>();
    searchDuplicateSubsets(values, 0, new ArrayList<>(), answer);
    return answer;
}

void searchDuplicateSubsets(int[] values, int start, List<Integer> path,
                            List<List<Integer>> answer) {
    answer.add(new ArrayList<>(path));
    for (int i = start; i < values.length; i++) {
        if (i > start && values[i] == values[i - 1]) continue;
        path.add(values[i]);
        searchDuplicateSubsets(values, i + 1, path, answer);
        path.remove(path.size() - 1);
    }
}

非递减子序列

返回数组中所有长度至少为二的不同非递减子序列。不能改变原数组顺序。

思路

当前数字必须不小于路径末尾。每个递归节点建立本层集合，阻止相同数值从同一层产生重复分支；该集合不在回溯时撤销。

复杂度

  • 时间复杂度：最坏为 O(n⋅2n)O(n\cdot 2^n)O(n⋅2n)。
  • 空间复杂度：O(n2)O(n^2)O(n2)，来自递归路径及各层去重集合，不计答案空间。

Java 实现

List<List<Integer>> nondecreasingSubsequences(int[] values) {
    List<List<Integer>> answer = new ArrayList<>();
    searchNondecreasing(values, 0, new ArrayList<>(), answer);
    return answer;
}

void searchNondecreasing(int[] values, int start, List<Integer> path,
                         List<List<Integer>> answer) {
    if (path.size() >= 2) answer.add(new ArrayList<>(path));
    Set<Integer> usedAtLevel = new HashSet<>();
    for (int i = start; i < values.length; i++) {
        if (!path.isEmpty() && values[i] < path.get(path.size() - 1)
                || !usedAtLevel.add(values[i])) continue;
        path.add(values[i]);
        searchNondecreasing(values, i + 1, path, answer);
        path.remove(path.size() - 1);
    }
}

木棒拼接

若干小木棒来自若干根等长原木棒，求原木棒可能的最短长度。所有小木棒必须恰好使用一次。

思路

从最长小木棒开始枚举原长，原长必须整除总长度。对每个候选长度依次拼接原木棒，并使用以下剪枝：

  • 小木棒从长到短尝试。
  • 同一层跳过相同长度。
  • 新原木棒的第一段失败，当前候选长度直接无解。
  • 某段恰好补满后仍失败，换其他同层选择也无解。

复杂度

  • 时间复杂度：最坏为 O(n!)O(n!)O(n!)，剪枝会显著减少实际搜索量。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

int minimumOriginalStickLength(int[] pieces) {
    return new StickAssembler(pieces).solve();
}

static class StickAssembler {
    private final int[] pieces;
    private final boolean[] used;
    private final int total;
    private int target;

    StickAssembler(int[] input) {
        pieces = input.clone();
        Arrays.sort(pieces);
        for (int left = 0, right = pieces.length - 1; left < right; left++, right--) {
            int temporary = pieces[left];
            pieces[left] = pieces[right];
            pieces[right] = temporary;
        }
        used = new boolean[pieces.length];
        int sum = 0;
        for (int piece : pieces) sum += piece;
        total = sum;
    }

    int solve() {
        for (target = pieces[0]; target <= total; target++) {
            if (total % target == 0 && assemble(0, 0, 0)) return target;
        }
        throw new IllegalStateException();
    }

    boolean assemble(int completed, int currentLength, int start) {
        int stickCount = total / target;
        if (completed == stickCount - 1) return true;
        if (currentLength == target) return assemble(completed + 1, 0, 0);
        int previous = -1;
        for (int i = start; i < pieces.length; i++) {
            if (used[i] || pieces[i] == previous || currentLength + pieces[i] > target) {
                continue;
            }
            used[i] = true;
            if (assemble(completed, currentLength + pieces[i], i + 1)) return true;
            used[i] = false;
            previous = pieces[i];
            if (currentLength == 0 || currentLength + pieces[i] == target) return false;
        }
        return false;
    }
}

飞机降落

每架飞机最早在 tit_iti​ 时刻开始降落，最多可等待 did_idi​，降落耗时 lil_ili​。同一时刻只能有一架飞机降落，判断是否存在可行顺序。

思路

搜索下一架未安排的飞机。若当前跑道空闲时间不晚于该飞机的最晚开始时间，就让它在 max(current, earliest) 时刻开始；更早开始不会损害后续方案。

复杂度

  • 时间复杂度：最坏为 O(n!)O(n!)O(n!)。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

boolean canLandAllPlanes(int[] earliest, int[] delay, int[] duration) {
    return searchLandings(earliest, delay, duration, new boolean[earliest.length],
            0, 0);
}

boolean searchLandings(int[] earliest, int[] delay, int[] duration, boolean[] used,
                       int count, int availableTime) {
    if (count == earliest.length) return true;
    for (int i = 0; i < earliest.length; i++) {
        if (!used[i] && availableTime <= earliest[i] + delay[i]) {
            used[i] = true;
            int finish = Math.max(availableTime, earliest[i]) + duration[i];
            if (searchLandings(earliest, delay, duration, used, count + 1, finish)) {
                return true;
            }
            used[i] = false;
        }
    }
    return false;
}
