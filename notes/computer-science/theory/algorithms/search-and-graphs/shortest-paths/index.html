#图论#最短路径

阅读线索

最短路算法按边权和图规模选型。Dijkstra 依靠非负边权确定当前最近点；其他模板分别处理边数限制、负权或全源距离，不可达状态也须有明确表示。

条件 算法 复杂度
单源、边权非负、稠密图 朴素 Dijkstra O(n2)O(n^2)O(n2)
单源、边权非负、稀疏图 堆优化 Dijkstra O(mlog⁡n)O(m \log n)O(mlogn)
单源、允许负权、限制边数 Bellman-Ford O(km)O(km)O(km)
单源、允许负权、通常较稀疏 SPFA 最坏 O(nm)O(nm)O(nm)
多源汇 Floyd O(n3)O(n^3)O(n3)

朴素 Dijkstra

给定一张边权非负的有向图和起点，求起点到所有节点的最短距离。

思路

维护已确定最短距离的集合。每轮选择集合外距离最小的节点 uuu，由于边权非负，任何绕行路径都不可能再缩短它；随后用 uuu 的出边更新其他节点。邻接矩阵适合稠密图。

long[] dijkstraDense(int[][] graph, int source) {
    int n = graph.length;
    long infinity = Long.MAX_VALUE / 4;
    long[] distance = new long[n];
    boolean[] visited = new boolean[n];
    Arrays.fill(distance, infinity);
    distance[source] = 0;
    for (int round = 0; round < n; round++) {
        int current = -1;
        for (int node = 0; node < n; node++) {
            if (!visited[node] && (current == -1 || distance[node] < distance[current])) {
                current = node;
            }
        }
        visited[current] = true;
        for (int next = 0; next < n; next++) {
            if (graph[current][next] >= 0) {
                distance[next] = Math.min(distance[next],
                        distance[current] + graph[current][next]);
            }
        }
    }
    return distance;
}

矩阵中 -1 表示无边。若题目可能存在从起点不可达的节点，选择节点后应先按题目约定处理不可达状态。

堆优化 Dijkstra

思路

优先队列保存 {当前距离, 节点}。同一节点可能因多次松弛产生多个队列项；弹出时若距离不是最新值，说明它已经过期，直接跳过。

long[] dijkstra(List<int[]>[] graph, int source) {
    long infinity = Long.MAX_VALUE / 4;
    long[] distance = new long[graph.length];
    Arrays.fill(distance, infinity);
    PriorityQueue<long[]> heap = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
    distance[source] = 0;
    heap.offer(new long[]{0, source});
    while (!heap.isEmpty()) {
        long[] current = heap.poll();
        long currentDistance = current[0];
        int node = (int) current[1];
        if (currentDistance != distance[node]) continue;
        for (int[] edge : graph[node]) {
            int next = edge[0];
            long candidate = currentDistance + edge[1];
            if (candidate < distance[next]) {
                distance[next] = candidate;
                heap.offer(new long[]{candidate, next});
            }
        }
    }
    return distance;
}

Bellman-Ford

给定可能含负权边的有向图，求从起点到终点、最多经过 kkk 条边的最短距离。

思路

第 iii 轮只允许使用前一轮“最多 i−1i-1i−1 条边”的结果，因此每轮先复制距离数组，再用备份松弛所有边。否则同一轮连续更新会使用超过一条新边。

long bellmanFordWithEdgeLimit(int n, int[][] edges, int source, int target, int k) {
    long infinity = Long.MAX_VALUE / 4;
    long[] distance = new long[n];
    Arrays.fill(distance, infinity);
    distance[source] = 0;
    for (int round = 0; round < k; round++) {
        long[] previous = distance.clone();
        for (int[] edge : edges) {
            int from = edge[0];
            int to = edge[1];
            int weight = edge[2];
            if (previous[from] != infinity) {
                distance[to] = Math.min(distance[to], previous[from] + weight);
            }
        }
    }
    return distance[target];
}

SPFA

给定一张可能含负权边但不含从起点可达负环的有向图，求起点到所有节点的最短距离。

思路

只有距离刚被缩短的节点才可能继续松弛邻边，因此把它加入队列。inQueue 防止同一节点重复入队。SPFA 最坏复杂度仍为 O(nm)O(nm)O(nm)，不能仅凭平均表现替代 Bellman-Ford 的复杂度保证。

long[] spfa(List<int[]>[] graph, int source) {
    long infinity = Long.MAX_VALUE / 4;
    long[] distance = new long[graph.length];
    boolean[] inQueue = new boolean[graph.length];
    Arrays.fill(distance, infinity);
    Deque<Integer> queue = new ArrayDeque<>();
    distance[source] = 0;
    queue.offer(source);
    inQueue[source] = true;
    while (!queue.isEmpty()) {
        int current = queue.poll();
        inQueue[current] = false;
        for (int[] edge : graph[current]) {
            int next = edge[0];
            long candidate = distance[current] + edge[1];
            if (candidate < distance[next]) {
                distance[next] = candidate;
                if (!inQueue[next]) {
                    queue.offer(next);
                    inQueue[next] = true;
                }
            }
        }
    }
    return distance;
}

Floyd

给定一张有向带权图，求任意两点之间的最短距离。图中可以有负权边，但不能有负环。

状态表示

f(k,i,j)f(k,i,j)f(k,i,j) 表示从 iii 到 jjj、中间节点只允许来自 000 到 kkk 的路径集合，属性为最短距离。

状态计算

按最短路径是否经过节点 kkk 划分：

f(k,i,j)=min⁡(f(k−1,i,j),f(k−1,i,k)+f(k−1,k,j))f(k,i,j)=\min(f(k-1,i,j),f(k-1,i,k)+f(k-1,k,j))f(k,i,j)=min(f(k−1,i,j),f(k−1,i,k)+f(k−1,k,j))

第一维可以原地压缩，但循环顺序必须先枚举中间节点。

void floyd(long[][] distance) {
    int n = distance.length;
    for (int middle = 0; middle < n; middle++) {
        for (int from = 0; from < n; from++) {
            for (int to = 0; to < n; to++) {
                distance[from][to] = Math.min(distance[from][to],
                        distance[from][middle] + distance[middle][to]);
            }
        }
    }
}
