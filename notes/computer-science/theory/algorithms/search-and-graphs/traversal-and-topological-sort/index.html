图的遍历与拓扑排序

2026-10-23

#图论#深度优先搜索#广度优先搜索

阅读线索

DFS 与 BFS 按不同次序访问图，拓扑排序则表达有向依赖的可执行顺序。建图时必须先确定方向和存储方式，再决定访问标记何时设置。

图的存储

存储方式 空间 判断边 枚举邻边 适用场景
邻接矩阵 O(n2)O(n^2)O(n2) O(1)O(1)O(1) O(n)O(n)O(n) 稠密图、小规模图
邻接表 O(n+m)O(n+m)O(n+m) 通常 O(degree)O(degree)O(degree) O(degree)O(degree)O(degree) 稀疏图

Java 中可用 List<int[]>[] 存储带权邻接表，每条边表示为 {终点, 权重}。无向图需要添加两个方向。

@SuppressWarnings("unchecked")
List<int[]>[] buildGraph(int n, int[][] edges, boolean directed) {
    List<int[]>[] graph = new List[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int[] edge : edges) {
        graph[edge[0]].add(new int[]{edge[1], edge[2]});
        if (!directed) graph[edge[1]].add(new int[]{edge[0], edge[2]});
    }
    return graph;
}

深度优先遍历

DFS 沿一条路径深入到底，再回溯探索其他分支。visited 防止在图的环中重复访问；若要枚举所有简单路径，则应在递归返回时撤销当前路径上的访问标记。

void depthFirstSearch(int start, List<int[]>[] graph, boolean[] visited,
                      List<Integer> order) {
    visited[start] = true;
    order.add(start);
    for (int[] edge : graph[start]) {
        if (!visited[edge[0]]) {
            depthFirstSearch(edge[0], graph, visited, order);
        }
    }
}

广度优先遍历

BFS 按距离起点的层次扩展。无权图中，节点第一次入队时得到的距离就是最短边数；因此应在入队时标记，避免同一节点重复进入队列。

int[] breadthFirstDistances(int start, List<int[]>[] graph) {
    int[] distance = new int[graph.length];
    Arrays.fill(distance, -1);
    Deque<Integer> queue = new ArrayDeque<>();
    distance[start] = 0;
    queue.offer(start);
    while (!queue.isEmpty()) {
        int current = queue.poll();
        for (int[] edge : graph[current]) {
            int next = edge[0];
            if (distance[next] == -1) {
                distance[next] = distance[current] + 1;
                queue.offer(next);
            }
        }
    }
    return distance;
}

走迷宫

给定由可通行格和障碍格组成的矩阵，只能上下左右移动，求从左上角到右下角的最少步数。

思路

把每个可通行格视为节点，相邻格之间有一条权重为 111 的边。BFS 第一次到达终点时的层数即为最短距离。

int shortestMazePath(int[][] grid) {
    int rows = grid.length;
    int columns = grid[0].length;
    int[][] distance = new int[rows][columns];
    for (int[] row : distance) Arrays.fill(row, -1);
    int[] dr = {-1, 0, 1, 0};
    int[] dc = {0, 1, 0, -1};
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(new int[]{0, 0});
    distance[0][0] = 0;
    while (!queue.isEmpty()) {
        int[] current = queue.poll();
        for (int direction = 0; direction < 4; direction++) {
            int row = current[0] + dr[direction];
            int column = current[1] + dc[direction];
            if (row >= 0 && row < rows && column >= 0 && column < columns
                    && grid[row][column] == 0 && distance[row][column] == -1) {
                distance[row][column] = distance[current[0]][current[1]] + 1;
                queue.offer(new int[]{row, column});
            }
        }
    }
    return distance[rows - 1][columns - 1];
}

八数码

在 3×33 \times 33×3 棋盘上放置数字 111 到 888 和一个空格。每次可交换空格与相邻数字，求变成 12345678x 的最少步数；无法到达时返回 −1-1−1。

思路

每个棋盘排列是一个状态，每次交换产生一条无权边。用字符串编码状态并执行 BFS，哈希表同时记录访问与距离。

int solveEightPuzzle(String start) {
    String target = "12345678x";
    Map<String, Integer> distance = new HashMap<>();
    Deque<String> queue = new ArrayDeque<>();
    distance.put(start, 0);
    queue.offer(start);
    int[] dr = {-1, 0, 1, 0};
    int[] dc = {0, 1, 0, -1};
    while (!queue.isEmpty()) {
        String state = queue.poll();
        if (state.equals(target)) return distance.get(state);
        int position = state.indexOf('x');
        int row = position / 3;
        int column = position % 3;
        for (int direction = 0; direction < 4; direction++) {
            int nextRow = row + dr[direction];
            int nextColumn = column + dc[direction];
            if (nextRow < 0 || nextRow >= 3 || nextColumn < 0 || nextColumn >= 3) continue;
            char[] next = state.toCharArray();
            int nextPosition = nextRow * 3 + nextColumn;
            next[position] = next[nextPosition];
            next[nextPosition] = 'x';
            String encoded = new String(next);
            if (!distance.containsKey(encoded)) {
                distance.put(encoded, distance.get(state) + 1);
                queue.offer(encoded);
            }
        }
    }
    return -1;
}

岛屿数量

给定由陆地 1 和水域 0 组成的网格，陆地在上下左右方向相连，求岛屿数量。

思路

每遇到一个尚未访问的陆地，答案加一，并用 DFS 或 BFS 标记它所在的完整连通块。每个格子最多访问一次。

int countIslands(char[][] grid) {
    int answer = 0;
    for (int row = 0; row < grid.length; row++) {
        for (int column = 0; column < grid[0].length; column++) {
            if (grid[row][column] == '1') {
                answer++;
                floodIsland(row, column, grid);
            }
        }
    }
    return answer;
}

void floodIsland(int row, int column, char[][] grid) {
    if (row < 0 || row >= grid.length || column < 0 || column >= grid[0].length
            || grid[row][column] != '1') {
        return;
    }
    grid[row][column] = '0';
    floodIsland(row - 1, column, grid);
    floodIsland(row + 1, column, grid);
    floodIsland(row, column - 1, grid);
    floodIsland(row, column + 1, grid);
}

拓扑排序

给定一张有向图，求一个满足所有边 u→vu \to vu→v 中 uuu 都排在 vvv 之前的节点序列；若存在环则无解。

思路

统计每个节点的入度，把所有入度为零的节点入队。每次删除一个节点及其出边，新的零入度节点继续入队。若最终处理节点数小于 nnn，剩余部分存在有向环。

int[] topologicalSort(int n, int[][] edges) {
    @SuppressWarnings("unchecked")
    List<Integer>[] graph = new List[n];
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    int[] indegree = new int[n];
    for (int[] edge : edges) {
        graph[edge[0]].add(edge[1]);
        indegree[edge[1]]++;
    }
    Deque<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) queue.offer(i);
    int[] order = new int[n];
    int size = 0;
    while (!queue.isEmpty()) {
        int current = queue.poll();
        order[size++] = current;
        for (int next : graph[current]) {
            if (--indegree[next] == 0) queue.offer(next);
        }
    }
    return size == n ? order : new int[0];
}

树的重心

删除树中的一个节点及其相连的边后，树会分成若干连通块。求一个节点，使产生的最大连通块节点数最小。

思路

任选节点为根执行 DFS。删除节点 uuu 后，每棵子树形成一个连通块，大小为对应子树节点数；父节点方向形成的连通块大小为 n−size(u)n-size(u)n−size(u)。取这些值的最大值作为删除 uuu 后的最大连通块，再在所有节点中取最小值。

int treeCentroidBalance(List<Integer>[] tree) {
    int[] answer = {tree.length};
    centroidDfs(0, -1, tree, answer);
    return answer[0];
}

int centroidDfs(int node, int parent, List<Integer>[] tree, int[] answer) {
    int subtreeSize = 1;
    int largestPart = 0;
    for (int next : tree[node]) {
        if (next == parent) continue;
        int childSize = centroidDfs(next, node, tree, answer);
        subtreeSize += childSize;
        largestPart = Math.max(largestPart, childSize);
    }
    largestPart = Math.max(largestPart, tree.length - subtreeSize);
    answer[0] = Math.min(answer[0], largestPart);
    return subtreeSize;
}
