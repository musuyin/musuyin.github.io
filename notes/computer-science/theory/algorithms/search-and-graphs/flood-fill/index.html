网格搜索与 Flood Fill

2026-10-23

#图论#搜索#Flood Fill

阅读线索

网格可视为隐式图，方向数组定义相邻边。Flood Fill 访问一个连通块，边界搜索则把“与外界相连”转换成一组起点。

网格可以看作一张隐式图：每个格子是节点，允许移动的方向决定边。Flood Fill 从一个格子出发，将同一连通区域全部访问。

岛屿的最大面积

给定一个由 1（陆地）和 0（水域）组成的矩阵。陆地只在上下左右方向相连，求面积最大的岛屿包含多少个陆地格子。

思路

遍历网格。每遇到一个尚未访问的陆地格子，就从该格子开始 Flood Fill，并累加当前连通块的格子数。所有连通块面积的最大值即为答案。代码直接把访问过的陆地改为 0，因此不再额外维护访问数组。

复杂度

  • 时间复杂度：O(nm)O(nm)O(nm)。
  • 空间复杂度：O(nm)O(nm)O(nm)，最坏情况下递归栈包含整座岛屿。

Java 实现

int maxIslandArea(int[][] grid) {
    int answer = 0;
    for (int row = 0; row < grid.length; row++) {
        for (int column = 0; column < grid[0].length; column++) {
            if (grid[row][column] == 1) {
                answer = Math.max(answer, floodIsland(grid, row, column));
            }
        }
    }
    return answer;
}

int floodIsland(int[][] grid, int row, int column) {
    if (row < 0 || row >= grid.length || column < 0 || column >= grid[0].length
            || grid[row][column] == 0) {
        return 0;
    }
    grid[row][column] = 0;
    return 1
            + floodIsland(grid, row + 1, column)
            + floodIsland(grid, row - 1, column)
            + floodIsland(grid, row, column + 1)
            + floodIsland(grid, row, column - 1);
}

孤岛的总面积

给定一个由 1 和 0 组成的矩阵。与矩阵边界相连的陆地不算孤岛，求所有孤岛的总面积。

思路

孤岛的定义带有否定条件，直接逐个连通块判断容易反复记录状态。反过来先从四条边界上的陆地出发，将所有与边界连通的陆地淹没；再次扫描网格时，剩余陆地必然属于孤岛。

复杂度

  • 时间复杂度：O(nm)O(nm)O(nm)。
  • 空间复杂度：O(nm)O(nm)O(nm)，来自递归栈。

Java 实现

int enclaveArea(int[][] grid) {
    int rows = grid.length;
    int columns = grid[0].length;
    for (int row = 0; row < rows; row++) {
        eraseBoundaryLand(grid, row, 0);
        eraseBoundaryLand(grid, row, columns - 1);
    }
    for (int column = 0; column < columns; column++) {
        eraseBoundaryLand(grid, 0, column);
        eraseBoundaryLand(grid, rows - 1, column);
    }

    int area = 0;
    for (int[] line : grid) {
        for (int cell : line) {
            area += cell;
        }
    }
    return area;
}

void eraseBoundaryLand(int[][] grid, int row, int column) {
    if (row < 0 || row >= grid.length || column < 0 || column >= grid[0].length
            || grid[row][column] == 0) {
        return;
    }
    grid[row][column] = 0;
    eraseBoundaryLand(grid, row + 1, column);
    eraseBoundaryLand(grid, row - 1, column);
    eraseBoundaryLand(grid, row, column + 1);
    eraseBoundaryLand(grid, row, column - 1);
}

沉没孤岛

给定一个由 1 和 0 组成的矩阵，将所有不接触矩阵边界的岛屿沉没，即把孤岛中的 1 改为 0，输出处理后的矩阵。

思路

从边界陆地出发，把所有不能沉没的陆地临时标记为 2。随后统一把 1 改成 0，把 2 恢复为 1。临时标记同时承担访问标记的作用。

复杂度

  • 时间复杂度：O(nm)O(nm)O(nm)。
  • 空间复杂度：O(nm)O(nm)O(nm)，来自递归栈。

Java 实现

int[][] sinkEnclaves(int[][] grid) {
    int rows = grid.length;
    int columns = grid[0].length;
    for (int row = 0; row < rows; row++) {
        markBoundaryLand(grid, row, 0);
        markBoundaryLand(grid, row, columns - 1);
    }
    for (int column = 0; column < columns; column++) {
        markBoundaryLand(grid, 0, column);
        markBoundaryLand(grid, rows - 1, column);
    }
    for (int row = 0; row < rows; row++) {
        for (int column = 0; column < columns; column++) {
            grid[row][column] = grid[row][column] == 2 ? 1 : 0;
        }
    }
    return grid;
}

void markBoundaryLand(int[][] grid, int row, int column) {
    if (row < 0 || row >= grid.length || column < 0 || column >= grid[0].length
            || grid[row][column] != 1) {
        return;
    }
    grid[row][column] = 2;
    markBoundaryLand(grid, row + 1, column);
    markBoundaryLand(grid, row - 1, column);
    markBoundaryLand(grid, row, column + 1);
    markBoundaryLand(grid, row, column - 1);
}

水流问题

给定一个高度矩阵。水只能从较高或等高的格子流向相邻的较低或等高格子。上边界与左边界属于第一组边界，下边界与右边界属于第二组边界，求能够同时流到两组边界的所有格子。

思路

若从每个格子顺流搜索，最坏需要 O(n2m2)O(n^2m^2)O(n2m2)。逆向思考：分别从两组边界出发，只向高度更高或相等的格子逆流搜索。一个格子被两次搜索同时访问，当且仅当它能顺流到达两组边界。

复杂度

  • 时间复杂度：O(nm)O(nm)O(nm)。
  • 空间复杂度：O(nm)O(nm)O(nm)。

Java 实现

List<int[]> cellsReachingBothBorders(int[][] height) {
    int rows = height.length;
    int columns = height[0].length;
    boolean[][] first = new boolean[rows][columns];
    boolean[][] second = new boolean[rows][columns];
    Deque<int[]> firstQueue = new ArrayDeque<>();
    Deque<int[]> secondQueue = new ArrayDeque<>();

    for (int row = 0; row < rows; row++) {
        addBorderCell(first, firstQueue, row, 0);
        addBorderCell(second, secondQueue, row, columns - 1);
    }
    for (int column = 0; column < columns; column++) {
        addBorderCell(first, firstQueue, 0, column);
        addBorderCell(second, secondQueue, rows - 1, column);
    }
    reverseFlow(height, first, firstQueue);
    reverseFlow(height, second, secondQueue);

    List<int[]> answer = new ArrayList<>();
    for (int row = 0; row < rows; row++) {
        for (int column = 0; column < columns; column++) {
            if (first[row][column] && second[row][column]) {
                answer.add(new int[]{row, column});
            }
        }
    }
    return answer;
}

void addBorderCell(boolean[][] visited, Deque<int[]> queue, int row, int column) {
    if (!visited[row][column]) {
        visited[row][column] = true;
        queue.offer(new int[]{row, column});
    }
}

void reverseFlow(int[][] height, boolean[][] visited, Deque<int[]> queue) {
    int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    while (!queue.isEmpty()) {
        int[] current = queue.poll();
        for (int[] direction : directions) {
            int nextRow = current[0] + direction[0];
            int nextColumn = current[1] + direction[1];
            if (nextRow >= 0 && nextRow < height.length
                    && nextColumn >= 0 && nextColumn < height[0].length
                    && !visited[nextRow][nextColumn]
                    && height[nextRow][nextColumn] >= height[current[0]][current[1]]) {
                visited[nextRow][nextColumn] = true;
                queue.offer(new int[]{nextRow, nextColumn});
            }
        }
    }
}

扫雷最少点击次数

给定一个包含地雷 * 和安全格 . 的方阵。点击周围没有地雷的安全格会自动展开与它八方向连通的所有零格及其相邻数字格；其他未展开的安全格必须单独点击。求展开所有安全格的最少点击次数。

思路

先计算每个安全格周围八个方向的地雷数。每个由零格构成的八连通块只需点击一次，搜索时同时标记其相邻数字格。所有零连通块处理完后，仍未访问的安全格无法被自动展开，必须各点击一次。

复杂度

  • 时间复杂度：O(n2)O(n^2)O(n2)。
  • 空间复杂度：O(n2)O(n^2)O(n2)。

Java 实现

int minimumMinesweeperClicks(char[][] board) {
    int n = board.length;
    int[][] adjacentMines = new int[n][n];
    boolean[][] revealed = new boolean[n][n];
    for (int row = 0; row < n; row++) {
        for (int column = 0; column < n; column++) {
            if (board[row][column] == '*') {
                adjacentMines[row][column] = -1;
                continue;
            }
            for (int dr = -1; dr <= 1; dr++) {
                for (int dc = -1; dc <= 1; dc++) {
                    int nextRow = row + dr;
                    int nextColumn = column + dc;
                    if (nextRow >= 0 && nextRow < n && nextColumn >= 0 && nextColumn < n
                            && board[nextRow][nextColumn] == '*') {
                        adjacentMines[row][column]++;
                    }
                }
            }
        }
    }

    int clicks = 0;
    for (int row = 0; row < n; row++) {
        for (int column = 0; column < n; column++) {
            if (adjacentMines[row][column] == 0 && !revealed[row][column]) {
                clicks++;
                revealZeroRegion(adjacentMines, revealed, row, column);
            }
        }
    }
    for (int row = 0; row < n; row++) {
        for (int column = 0; column < n; column++) {
            if (adjacentMines[row][column] >= 0 && !revealed[row][column]) {
                clicks++;
            }
        }
    }
    return clicks;
}

void revealZeroRegion(int[][] mines, boolean[][] revealed, int startRow, int startColumn) {
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(new int[]{startRow, startColumn});
    revealed[startRow][startColumn] = true;
    while (!queue.isEmpty()) {
        int[] current = queue.poll();
        for (int dr = -1; dr <= 1; dr++) {
            for (int dc = -1; dc <= 1; dc++) {
                int row = current[0] + dr;
                int column = current[1] + dc;
                if (row >= 0 && row < mines.length && column >= 0 && column < mines.length
                        && mines[row][column] >= 0 && !revealed[row][column]) {
                    revealed[row][column] = true;
                    if (mines[row][column] == 0) {
                        queue.offer(new int[]{row, column});
                    }
                }
            }
        }
    }
}

全球变暖

一张地图用 # 表示陆地、. 表示海洋，地图边界均为海洋。海平面上升后，与海洋上下左右相邻的陆地会被淹没。求原有岛屿中有多少会完全消失。

思路

逐个搜索原始岛屿。搜索一个岛屿时，只需判断其中是否至少存在一个格子四周都不是海洋：这样的内部格在海平面上升后仍会保留，岛屿不会完全消失。反之，该岛所有格子都邻海，整个岛屿都会消失。

复杂度

  • 时间复杂度：O(n2)O(n^2)O(n2)。
  • 空间复杂度：O(n2)O(n^2)O(n2)。

Java 实现

int disappearingIslands(char[][] map) {
    int n = map.length;
    boolean[][] visited = new boolean[n][n];
    int answer = 0;
    for (int row = 0; row < n; row++) {
        for (int column = 0; column < n; column++) {
            if (map[row][column] == '#' && !visited[row][column]
                    && !hasSurvivingCell(map, visited, row, column)) {
                answer++;
            }
        }
    }
    return answer;
}

boolean hasSurvivingCell(char[][] map, boolean[][] visited, int startRow, int startColumn) {
    int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    Deque<int[]> queue = new ArrayDeque<>();
    queue.offer(new int[]{startRow, startColumn});
    visited[startRow][startColumn] = true;
    boolean survives = false;
    while (!queue.isEmpty()) {
        int[] current = queue.poll();
        boolean adjacentToSea = false;
        for (int[] direction : directions) {
            int row = current[0] + direction[0];
            int column = current[1] + direction[1];
            if (map[row][column] == '.') {
                adjacentToSea = true;
            } else if (!visited[row][column]) {
                visited[row][column] = true;
                queue.offer(new int[]{row, column});
            }
        }
        if (!adjacentToSea) {
            survives = true;
        }
    }
    return survives;
}
