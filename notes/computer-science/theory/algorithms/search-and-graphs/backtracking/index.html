#深度优先搜索#回溯

阅读线索

回溯依次执行选择、递归和撤销。组合中的递增起点控制枚举顺序，剪枝则依据剩余候选数量证明当前分支不可能补足答案。

回溯法在决策树上执行深度优先搜索。代码通常遵循“选择、递归、撤销选择”，剪枝则在能够证明当前分支不可能得到合法答案时提前返回。

组合

从整数 111 到 nnn 中选择 kkk 个数，返回所有不同组合。

思路

路径中数字保持递增，下一层只从当前数字之后继续选择，因此每个集合只生成一次。若剩余数字数量不足以填满路径，可缩小循环上界。

List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> answer = new ArrayList<>();
    dfsCombine(1, n, k, new ArrayList<>(), answer);
    return answer;
}

void dfsCombine(int start, int n, int k, List<Integer> path,
                List<List<Integer>> answer) {
    if (path.size() == k) {
        answer.add(new ArrayList<>(path));
        return;
    }
    int needed = k - path.size();
    for (int value = start; value <= n - needed + 1; value++) {
        path.add(value);
        dfsCombine(value + 1, n, k, path, answer);
        path.remove(path.size() - 1);
    }
}

Go 实现

func combine(n int, k int) [][]int {
	var ret [][]int
	var path []int
	dfsCombine(n, k, 1, &path, &ret)
	return ret
}

func dfsCombine(n, k, startIndex int, pathPtr *[]int, retPtr *[][]int) {
	if len(*pathPtr) == k {
		var path []int = make([]int, k)
		copy(path, *pathPtr)
		*retPtr = append(*retPtr, path)
		return
	}

	for i := startIndex; i <= n; i++ {
		*pathPtr = append(*pathPtr, i)
		dfsCombine(n, k, i+1, pathPtr, retPtr)
		*pathPtr = (*pathPtr)[:len(*pathPtr)-1]
	}
}

全排列

给定不含重复数字的数组，返回所有可能的排列。

思路

搜索树的层数表示已经确定的位置，used[i] 表示下标 iii 是否已出现在当前路径中。每一层枚举一个尚未使用的元素。

List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> answer = new ArrayList<>();
    dfsPermute(nums, new boolean[nums.length], new ArrayList<>(), answer);
    return answer;
}

void dfsPermute(int[] nums, boolean[] used, List<Integer> path,
                List<List<Integer>> answer) {
    if (path.size() == nums.length) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (!used[i]) {
            used[i] = true;
            path.add(nums[i]);
            dfsPermute(nums, used, path, answer);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}

含重复元素的排列

给定可能包含重复数字的数组，返回所有不同排列。

思路

先排序。相同数字在同一搜索层只能作为候选一次：当 nums[i] == nums[i - 1] 且前一个相同数字在当前层尚未使用时，跳过当前数字。

List<List<Integer>> permuteUnique(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> answer = new ArrayList<>();
    dfsPermuteUnique(nums, new boolean[nums.length], new ArrayList<>(), answer);
    return answer;
}

void dfsPermuteUnique(int[] nums, boolean[] used, List<Integer> path,
                      List<List<Integer>> answer) {
    if (path.size() == nums.length) {
        answer.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i] || i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) {
            continue;
        }
        used[i] = true;
        path.add(nums[i]);
        dfsPermuteUnique(nums, used, path, answer);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}

N 皇后

在 n×nn \times nn×n 棋盘上放置 nnn 个皇后，使任意两个皇后不在同一行、同一列或同一条对角线上，返回所有方案。

思路

按行放置，每行恰好选择一列。用三个布尔数组记录列、主对角线 row - column + n 和副对角线 row + column 是否被占用。

List<List<String>> solveNQueens(int n) {
    List<List<String>> answer = new ArrayList<>();
    char[][] board = new char[n][n];
    for (char[] row : board) Arrays.fill(row, '.');
    dfsQueens(0, board, new boolean[n], new boolean[2 * n],
            new boolean[2 * n], answer);
    return answer;
}

void dfsQueens(int row, char[][] board, boolean[] columns, boolean[] diagonal,
               boolean[] antiDiagonal, List<List<String>> answer) {
    if (row == board.length) {
        List<String> solution = new ArrayList<>();
        for (char[] line : board) solution.add(new String(line));
        answer.add(solution);
        return;
    }
    int n = board.length;
    for (int column = 0; column < n; column++) {
        int d = row - column + n;
        int a = row + column;
        if (columns[column] || diagonal[d] || antiDiagonal[a]) continue;
        columns[column] = diagonal[d] = antiDiagonal[a] = true;
        board[row][column] = 'Q';
        dfsQueens(row + 1, board, columns, diagonal, antiDiagonal, answer);
        board[row][column] = '.';
        columns[column] = diagonal[d] = antiDiagonal[a] = false;
    }
}

解数独

填充一个 9×99 \times 99×9 数独，使每行、每列及每个 3×33 \times 33×3 宫都包含数字 111 到 999 且不重复。题目保证存在唯一解。

思路

使用位掩码记录每行、每列和每个宫已经使用的数字。每次选择候选数字最少的空格，可以显著缩小搜索树。放入数字后更新三个掩码，递归失败时撤销。

void solveSudoku(char[][] board) {
    int[] rowMask = new int[9];
    int[] columnMask = new int[9];
    int[] boxMask = new int[9];
    for (int row = 0; row < 9; row++) {
        for (int column = 0; column < 9; column++) {
            if (board[row][column] != '.') {
                int bit = 1 << (board[row][column] - '1');
                rowMask[row] |= bit;
                columnMask[column] |= bit;
                boxMask[row / 3 * 3 + column / 3] |= bit;
            }
        }
    }
    fillSudoku(board, rowMask, columnMask, boxMask);
}

boolean fillSudoku(char[][] board, int[] rowMask, int[] columnMask, int[] boxMask) {
    int selectedRow = -1;
    int selectedColumn = -1;
    int candidates = 0;
    int minimum = 10;
    for (int row = 0; row < 9; row++) {
        for (int column = 0; column < 9; column++) {
            if (board[row][column] == '.') {
                int available = ~(rowMask[row] | columnMask[column]
                        | boxMask[row / 3 * 3 + column / 3]) & 0x1ff;
                int count = Integer.bitCount(available);
                if (count < minimum) {
                    minimum = count;
                    selectedRow = row;
                    selectedColumn = column;
                    candidates = available;
                }
            }
        }
    }
    if (selectedRow == -1) return true;
    int box = selectedRow / 3 * 3 + selectedColumn / 3;
    while (candidates != 0) {
        int bit = candidates & -candidates;
        candidates -= bit;
        board[selectedRow][selectedColumn] = (char) ('1' + Integer.numberOfTrailingZeros(bit));
        rowMask[selectedRow] |= bit;
        columnMask[selectedColumn] |= bit;
        boxMask[box] |= bit;
        if (fillSudoku(board, rowMask, columnMask, boxMask)) return true;
        rowMask[selectedRow] ^= bit;
        columnMask[selectedColumn] ^= bit;
        boxMask[box] ^= bit;
        board[selectedRow][selectedColumn] = '.';
    }
    return false;
}
