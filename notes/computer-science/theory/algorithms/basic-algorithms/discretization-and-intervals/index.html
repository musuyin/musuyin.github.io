离散化与区间合并

2026-10-23

#算法与数据结构#离散化#区间#Java

阅读线索

离散化保留坐标的相对顺序，把稀疏范围映射成紧凑下标；区间合并则在排序后维护当前覆盖范围。两者都不应混淆坐标值和数组下标。

整数离散化

当问题只关心数值之间的相对顺序，而不关心数值间距时，可以把稀疏的大坐标映射为连续下标。标准过程是：

  1. 收集所有会被访问的坐标。
  2. 排序并去重。
  3. 用二分查找原坐标在去重数组中的位置。

离散化必须保持相对大小关系，并让相同原值映射到相同下标。

static int[] discretize(int[] values) {
    int[] sorted = Arrays.stream(values).sorted().distinct().toArray();
    int[] rank = new int[values.length];
    for (int i = 0; i < values.length; i++) {
        rank[i] = Arrays.binarySearch(sorted, values[i]);
    }
    return rank;
}

离散区间和

一条无限长数轴初始全为 0。先执行若干单点增加操作 (position,delta)，再回答若干闭区间 [left,right] 的元素和。

解析与思路

只有更新位置和查询端点会影响答案，因此收集这些坐标并离散化。若同一位置被多次更新，必须累加而不是覆盖。离散化后对值数组求前缀和，每次查询仍是两个前缀之差。

设操作和查询总数为 n，排序复杂度为 O(nlogn)O(n log n)O(nlogn)，每次坐标映射为 O(logn)O(log n)O(logn)。

代码

static long[] discreteRangeSums(int[][] additions, int[][] queries) {
    int[] coordinates = new int[additions.length + queries.length * 2];
    int size = 0;
    for (int[] addition : additions) {
        coordinates[size++] = addition[0];
    }
    for (int[] query : queries) {
        coordinates[size++] = query[0];
        coordinates[size++] = query[1];
    }

    int[] sorted = Arrays.stream(coordinates, 0, size)
            .sorted()
            .distinct()
            .toArray();
    long[] values = new long[sorted.length + 1];
    for (int[] addition : additions) {
        int index = Arrays.binarySearch(sorted, addition[0]) + 1;
        values[index] += addition[1];
    }

    long[] prefix = new long[values.length];
    for (int i = 1; i < values.length; i++) {
        prefix[i] = prefix[i - 1] + values[i];
    }

    long[] result = new long[queries.length];
    for (int i = 0; i < queries.length; i++) {
        int left = Arrays.binarySearch(sorted, queries[i][0]) + 1;
        int right = Arrays.binarySearch(sorted, queries[i][1]) + 1;
        result[i] = prefix[right] - prefix[left - 1];
    }
    return result;
}

区间合并

给定若干闭区间 [left,right]，合并所有有交集的区间。端点相接也视为有交集，返回合并后的区间。

解析与思路

先按左端点升序排序。扫描时维护当前合并区间 [start,end]：

  • next.left <= end：区间相交，令 end = max(end,next.right)。
  • next.left > end：区间分离，保存当前区间并开始新区间。

排序复杂度为 O(nlogn)O(n log n)O(nlogn)，扫描为 O(n)O(n)O(n)。

代码

static int[][] mergeIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(interval -> interval[0]));
    List<int[]> result = new ArrayList<>();

    int start = intervals[0][0];
    int end = intervals[0][1];
    for (int i = 1; i < intervals.length; i++) {
        int[] interval = intervals[i];
        if (interval[0] <= end) {
            end = Math.max(end, interval[1]);
        } else {
            result.add(new int[] {start, end});
            start = interval[0];
            end = interval[1];
        }
    }
    result.add(new int[] {start, end});
    return result.toArray(int[][]::new);
}
