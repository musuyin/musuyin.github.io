字符串操作

2026-10-28

#字符串#双指针#Java

阅读线索

字符串操作先选好表示方式：Java 的 char[] 用于可变字符处理，StringBuilder 用于追加，Go 的 byte 与 rune 则对应不同字符假设。

Java 的 String 不可变。需要原地调整字符顺序时，先转成 char[]；需要连续追加时使用 StringBuilder。

Go 的字符串也不可变。下面的 Go 实现用 []byte 处理单字节字符；若题目要求按 Unicode 字符反转或旋转，应使用 []rune，并按字符数量计算下标。

反转字符串

给定字符数组 text，要求使用 O(1)O(1)O(1) 额外空间原地反转。

思路

左右指针分别指向首尾，交换后同时向中间移动。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(1)O(1)O(1)。

Java 实现

void reverseString(char[] text) {
    reverseRange(text, 0, text.length);
}

void reverseRange(char[] text, int left, int right) {
    for (int i = left, j = right - 1; i < j; i++, j--) {
        char temporary = text[i];
        text[i] = text[j];
        text[j] = temporary;
    }
}

Go 实现

func reverseString(s []byte) {
	for l, r := 0, len(s)-1; l < r; l, r = l+1, r-1 {
		s[l], s[r] = s[r], s[l]
	}
}

分段反转字符串

给定字符串 text 和正整数 kkk，每 2k2k2k 个字符反转前 kkk 个；不足 kkk 个时全部反转。

思路

每次处理起点 0, 2k, 4k, ...，反转区间右端点取 min(start + k, n)。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)，用于 Java 的可变字符数组。

Java 实现

String reverseEveryTwoBlocks(String text, int k) {
    char[] chars = text.toCharArray();
    for (int start = 0; start < chars.length; start += 2 * k) {
        reverseRange(chars, start, Math.min(start + k, chars.length));
    }
    return new String(chars);
}

Go 实现：反转字符串 II

func reverseStr(s string, k int) string {
	cs := []byte(s)
	n := len(s)
	for i := 0; i < n; i += 2 * k {
		reverse(cs, i, min(n-1, i+k-1))
	}
	return string(cs)
}

func reverse(cs []byte, x, y int) {
	for l, r := x, y; l < r; l, r = l+1, r-1 {
		cs[l], cs[r] = cs[r], cs[l]
	}
}

替换数字字符

字符串只包含小写字母和数字，把每个数字替换成 number。

思路

先统计新长度，再从原串末尾向新数组末尾填充。逆向写入不会覆盖尚未处理的字符，这也是可变数组原地扩容题的通用方式。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

String replaceDigits(String text) {
    int length = text.length();
    for (int i = 0; i < text.length(); i++) {
        if (Character.isDigit(text.charAt(i))) length += 5;
    }
    char[] answer = new char[length];
    String replacement = "number";
    for (int i = text.length() - 1, write = length - 1; i >= 0; i--) {
        char current = text.charAt(i);
        if (Character.isDigit(current)) {
            for (int j = replacement.length() - 1; j >= 0; j--) {
                answer[write--] = replacement.charAt(j);
            }
        } else {
            answer[write--] = current;
        }
    }
    return new String(answer);
}

Go 实现：替换数字

const NUMBER = "number"

func replaceStringWithNumber(s string) string {
	var length int = 0
	for i := 0; i < len(s); i++ {
		if '0' <= s[i] && s[i] <= '9' {
			length += 6
		} else {
			length++
		}
	}

	cs := make([]byte, length)
	for i, j := 0, 0; i < len(s); i++ {
		if '0' <= s[i] && s[i] <= '9' {
			j = replaceNumber(cs, j)
		} else {
			cs[j] = s[i]
			j++
		}
	}
	return string(cs)
}

func replaceNumber(cs []byte, start int) int {
	for i, j := start, 0; j < 6; i, j = i+1, j+1 {
		cs[i] = NUMBER[j]
	}
	return start + 6
}

反转单词顺序

反转句子中的单词顺序，并删除首尾空格及单词间多余空格。

思路

先把单词以单个空格紧凑写入字符数组，再整体反转，最后逐个反转单词。整体反转改变单词次序，局部反转恢复每个单词内部顺序。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)，来自字符数组。

Java 实现

String reverseWords(String text) {
    char[] chars = text.toCharArray();
    int write = 0;
    for (int read = 0; read < chars.length;) {
        while (read < chars.length && chars[read] == ' ') read++;
        if (read == chars.length) break;
        if (write > 0) chars[write++] = ' ';
        while (read < chars.length && chars[read] != ' ') {
            chars[write++] = chars[read++];
        }
    }
    reverseRange(chars, 0, write);
    for (int left = 0; left < write;) {
        int right = left;
        while (right < write && chars[right] != ' ') right++;
        reverseRange(chars, left, right);
        left = right + 1;
    }
    return new String(chars, 0, write);
}

Go 实现：翻转字符串里面的单词

func reverseWords(s string) string {
	chars := []byte(s)
	write := 0
	for read := 0; read < len(chars); {
		for read < len(chars) && chars[read] == ' ' {
			read++
		}
		if read == len(chars) {
			break
		}
		if write > 0 {
			chars[write] = ' '
			write++
		}
		for read < len(chars) && chars[read] != ' ' {
			chars[write] = chars[read]
			write++
			read++
		}
	}
	reverseWordRange(chars, 0, write-1)
	for left := 0; left < write; {
		right := left
		for right < write && chars[right] != ' ' {
			right++
		}
		reverseWordRange(chars, left, right-1)
		left = right + 1
	}
	return string(chars[:write])
}
func reverseWordRange(chars []byte, left, right int) {
	for left < right {
		chars[left], chars[right] = chars[right], chars[left]
		left++
		right--
	}
}

右旋字符串

把字符串末尾的 kkk 个字符移动到开头。

思路

先整体反转，再分别反转前 kkk 个字符和剩余字符：

abcdefg -> gfedcba -> fg edcba -> fgabcde

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)，来自字符数组。

Java 实现

String rotateRight(String text, int k) {
    char[] chars = text.toCharArray();
    k %= chars.length;
    reverseRange(chars, 0, chars.length);
    reverseRange(chars, 0, k);
    reverseRange(chars, k, chars.length);
    return new String(chars);
}

Go 实现

func rotateString(k int, s string) string {
	cs := []byte(s)
	reverseString(cs, 0, len(s)-k-1)
	reverseString(cs, len(s)-k, len(s)-1)
	reverseString(cs, 0, len(s)-1)
	return string(cs)
}

func reverseString(cs []byte, l, r int) {
	for i, j := l, r; i < j; i, j = i+1, j-1 {
		cs[i], cs[j] = cs[j], cs[i]
	}
}

重复子字符串

判断非空字符串能否由某个更短的子字符串重复若干次构成。

思路

设整个字符串长度为 nnn，前缀函数最后一项为 ppp。候选最小周期是 n−pn-pn−p；只有 p>0p>0p>0 且 nnn 能被该周期整除时，字符串才由重复单位构成。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(n)O(n)O(n)。

Java 实现

boolean isRepeatedSubstring(String text) {
    int[] prefix = new int[text.length()];
    for (int i = 1, matched = 0; i < text.length(); i++) {
        while (matched > 0 && text.charAt(i) != text.charAt(matched)) {
            matched = prefix[matched - 1];
        }
        if (text.charAt(i) == text.charAt(matched)) matched++;
        prefix[i] = matched;
    }
    int border = prefix[text.length() - 1];
    int period = text.length() - border;
    return border > 0 && text.length() % period == 0;
}
