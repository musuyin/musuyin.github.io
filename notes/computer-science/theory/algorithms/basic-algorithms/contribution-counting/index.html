贡献法

2026-10-23

#算法与数据结构#贡献法#Java

阅读线索

贡献法从单个元素参与多少个结果出发计算总量。相邻边界和出现次数把重复枚举转成一次性计数，但需要说明每个结果是否恰好被统计一次。

核心思想

直接枚举所有组合通常会重复计算。贡献法把视角从“每个结果由哪些元素组成”切换为“每个元素参与了多少个结果”，在预处理相邻边界或出现次数后一次计算单个元素的总贡献。

孤独的照片

一排奶牛的品种由 G 和 H 表示。对每个长度不少于 3 的连续区间拍照；若照片中恰好只有一头 G，或恰好只有一头 H，则照片是孤独的。求孤独照片数量。

解析与思路

每张孤独照片都能唯一对应其中那头品种不同的奶牛。对位置 i，设：

  • left[i]：左侧与 cows[i] 品种不同的连续奶牛数。
  • right[i]：右侧与 cows[i] 品种不同的连续奶牛数。

包含 cows[i] 的孤独照片分为三类：

  • 左右两侧都选择：贡献为 left[i] × right[i]。
  • 只选择左侧且总长度不少于三：贡献为 max(0,left[i]-1)。
  • 只选择右侧且总长度不少于三：贡献为 max(0,right[i]-1)。

每个位置的贡献可在 O(1)O(1)O(1) 内计算，总时间复杂度为 O(n)O(n)O(n)。

代码

static long countLonelyPhotos(String cows) {
    int n = cows.length();
    int[] left = new int[n];
    int[] right = new int[n];

    for (int i = 1, run = 1; i < n; i++) {
        if (cows.charAt(i) == cows.charAt(i - 1)) {
            run++;
        } else {
            left[i] = run;
            run = 1;
        }
    }
    for (int i = n - 2, run = 1; i >= 0; i--) {
        if (cows.charAt(i) == cows.charAt(i + 1)) {
            run++;
        } else {
            right[i] = run;
            run = 1;
        }
    }

    long result = 0;
    for (int i = 0; i < n; i++) {
        result += (long) left[i] * right[i];
        result += Math.max(0, left[i] - 1);
        result += Math.max(0, right[i] - 1);
    }
    return result;
}

牛的基因学

DNA 字符串只包含 A、C、G、T。定义两个长度为 n 的字符串在所有循环移位组合下的字符匹配次数总和为 DNA 距离。给定字符串 source，求有多少个长度为 n 的字符串能让该距离达到最大值，答案对 109+710^9+7109+7 取模。

解析与思路

固定 source，让候选字符串的某一位遍历所有循环移位。该位置选择字符 c 时，其总贡献只取决于 c 在 source 中的出现次数。候选字符串的各位置彼此独立，因此每一位都应选择出现次数最多的字符。

若并列出现次数最多的字符有 choices 个，每个位置都有 choices 种最优选择，答案为 choices^n mod (10^9 + 7)。

代码

static long countMaximumDistanceDna(String source) {
    int[] frequency = new int[4];
    for (int i = 0; i < source.length(); i++) {
        frequency[dnaIndex(source.charAt(i))]++;
    }

    int maximum = Arrays.stream(frequency).max().orElseThrow();
    int choices = 0;
    for (int count : frequency) {
        if (count == maximum) {
            choices++;
        }
    }
    return modularPower(choices, source.length(), 1_000_000_007);
}

static int dnaIndex(char value) {
    return switch (value) {
        case 'A' -> 0;
        case 'C' -> 1;
        case 'G' -> 2;
        case 'T' -> 3;
        default -> throw new IllegalArgumentException("DNA 字符非法: " + value);
    };
}

static long modularPower(long base, int exponent, int modulus) {
    long result = 1;
    while (exponent > 0) {
        if ((exponent & 1) == 1) {
            result = result * base % modulus;
        }
        base = base * base % modulus;
        exponent >>= 1;
    }
    return result;
}
