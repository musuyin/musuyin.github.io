矩阵与分治

2026-10-23

#算法与数据结构#矩阵#分治#Java

阅读线索

矩阵模型把递推写成线性变换，分治把整体问题拆为可合并的小问题。稀疏矩阵与矩阵快速幂则分别利用非零元素少、重复乘方的结构。

矩阵快速幂求斐波那契数

斐波那契数列满足 F0=0F_0=0F0​=0、F1=1F_1=1F1​=1、Fn=Fn−1+Fn−2F_n=F_{n-1}+F_{n-2}Fn​=Fn−1​+Fn−2​。给定 n，求 F[n] mod 10000。

解析与思路

递推关系可以重绘为矩阵转移：

[F[n], F[n + 1]] = [F[n - 1], F[n]] × |0 1|
                                                |1 1|

[F[n], F[n + 1]] = [0, 1] × |0 1|^n
                              |1 1|

用快速幂计算转移矩阵的 n 次幂，时间复杂度为 O(logn)O(log n)O(logn)。

代码

static int fibonacciMod(int n) {
    int modulus = 10_000;
    long[][] result = {{1, 0}, {0, 1}};
    long[][] base = {{0, 1}, {1, 1}};

    while (n > 0) {
        if ((n & 1) == 1) {
            result = multiply(result, base, modulus);
        }
        base = multiply(base, base, modulus);
        n >>= 1;
    }
    return (int) result[0][1];
}

static long[][] multiply(long[][] first, long[][] second, int modulus) {
    long[][] result = new long[2][2];
    for (int row = 0; row < 2; row++) {
        for (int column = 0; column < 2; column++) {
            for (int k = 0; k < 2; k++) {
                result[row][column] = (result[row][column]
                        + first[row][k] * second[k][column]) % modulus;
            }
        }
    }
    return result;
}

稀疏矩阵转置

稀疏矩阵使用三元组 (row,column,value) 保存非零元素，输入三元组按行优先顺序排列。求转置矩阵按行优先排列的三元组序列。

解析与思路

矩阵转置会让原列号变成新行号。先统计每个原列包含多少个非零元素，再计算各组在结果数组中的起始位置。随后按原顺序扫描三元组，将它稳定地放入对应列的分组。这就是按列号进行一次键索引计数。

设矩阵有 columns 列、entries 个非零元素，时间复杂度为 O(columns+entries)O(columns+entries)O(columns+entries)，额外空间为 O(columns+entries)O(columns+entries)O(columns+entries)。

代码

record MatrixEntry(int row, int column, int value) {}

static List<MatrixEntry> transposeSparseMatrix(
        int columns, List<MatrixEntry> entries) {
    int[] count = new int[columns];
    for (MatrixEntry entry : entries) {
        count[entry.column()]++;
    }

    int[] nextPosition = new int[columns];
    for (int column = 1; column < columns; column++) {
        nextPosition[column] = nextPosition[column - 1] + count[column - 1];
    }

    MatrixEntry[] result = new MatrixEntry[entries.size()];
    for (MatrixEntry entry : entries) {
        int position = nextPosition[entry.column()]++;
        result[position] = new MatrixEntry(
                entry.column(), entry.row(), entry.value());
    }
    return Arrays.asList(result);
}

L 型棋盘覆盖

在一个 2nimes2n2^n imes2^n2nimes2n 棋盘中指定一个不能覆盖的方格，其余方格需要用占据三个格子的 L 型骨牌完全覆盖。输出每块骨牌的编号，编号按其第一次在行优先扫描中出现的顺序递增。

解析与思路

把当前棋盘分成四个象限，其中一个象限包含真实缺口。用一块 L 型骨牌覆盖中心处属于另外三个象限的方格，相当于为它们各制造一个缺口，然后递归处理四个象限。

┌────────┬────────┐
│ 真实缺口│ 假缺口  │
│        │    ┐   │
├────────┼────────┤
│ 假缺口 │ 假缺口  │
│    └───┘        │
└────────┴────────┘

每个非缺口方格只被填写一次，时间复杂度为 O(4n)O(4^n)O(4n)，也就是与棋盘面积同阶。最后按行优先顺序重新映射骨牌编号。

代码

static int nextTileId;

static int[][] coverBoard(int exponent, int missingRow, int missingColumn) {
    int size = 1 << exponent;
    int[][] board = new int[size][size];
    nextTileId = 1;
    cover(board, 0, 0, missingRow, missingColumn, size);
    normalizeTileIds(board);
    return board;
}

static void cover(int[][] board, int startRow, int startColumn,
                  int missingRow, int missingColumn, int size) {
    if (size == 2) {
        int tileId = nextTileId++;
        for (int row = startRow; row < startRow + 2; row++) {
            for (int column = startColumn; column < startColumn + 2; column++) {
                if (row != missingRow || column != missingColumn) {
                    board[row][column] = tileId;
                }
            }
        }
        return;
    }

    int half = size / 2;
    int centerRow = startRow + half;
    int centerColumn = startColumn + half;
    int missingQuadrant = (missingRow < centerRow ? 0 : 2)
            + (missingColumn < centerColumn ? 0 : 1);
    int[][] centers = {
            {centerRow - 1, centerColumn - 1},
            {centerRow - 1, centerColumn},
            {centerRow, centerColumn - 1},
            {centerRow, centerColumn}
    };

    int tileId = nextTileId++;
    for (int quadrant = 0; quadrant < 4; quadrant++) {
        if (quadrant != missingQuadrant) {
            board[centers[quadrant][0]][centers[quadrant][1]] = tileId;
        }
    }

    cover(board, startRow, startColumn,
            missingQuadrant == 0 ? missingRow : centers[0][0],
            missingQuadrant == 0 ? missingColumn : centers[0][1], half);
    cover(board, startRow, centerColumn,
            missingQuadrant == 1 ? missingRow : centers[1][0],
            missingQuadrant == 1 ? missingColumn : centers[1][1], half);
    cover(board, centerRow, startColumn,
            missingQuadrant == 2 ? missingRow : centers[2][0],
            missingQuadrant == 2 ? missingColumn : centers[2][1], half);
    cover(board, centerRow, centerColumn,
            missingQuadrant == 3 ? missingRow : centers[3][0],
            missingQuadrant == 3 ? missingColumn : centers[3][1], half);
}

static void normalizeTileIds(int[][] board) {
    Map<Integer, Integer> mapping = new HashMap<>();
    int next = 1;
    for (int row = 0; row < board.length; row++) {
        for (int column = 0; column < board.length; column++) {
            int oldId = board[row][column];
            if (oldId != 0) {
                if (!mapping.containsKey(oldId)) {
                    mapping.put(oldId, next++);
                }
                board[row][column] = mapping.get(oldId);
            }
        }
    }
}

最近点对

平面上有 n 个点，求任意两点之间欧几里得距离的最小值。为避免浮点误差，返回距离的平方。

解析与思路

先按横坐标排序，再递归求左右两半的最近距离 distance。合并时只需检查距离分割线横向距离小于 distance 的点。候选点按纵坐标排序后，对每个点只需继续检查纵向距离平方小于当前答案的后续点。

递归过程中同时把区间合并为按纵坐标有序，避免每层重复排序，总时间复杂度为 O(nlogn)O(n log n)O(nlogn)。

代码

record Point(long x, long y) {}

static long closestPairSquared(Point[] input) {
    Point[] points = input.clone();
    Arrays.sort(points, Comparator.comparingLong(Point::x)
            .thenComparingLong(Point::y));
    Point[] buffer = new Point[points.length];
    return closest(points, buffer, 0, points.length);
}

static long closest(Point[] points, Point[] buffer, int left, int right) {
    if (right - left <= 3) {
        long best = Long.MAX_VALUE;
        for (int i = left; i < right; i++) {
            for (int j = i + 1; j < right; j++) {
                best = Math.min(best, squaredDistance(points[i], points[j]));
            }
        }
        Arrays.sort(points, left, right, Comparator.comparingLong(Point::y));
        return best;
    }

    int middle = left + (right - left) / 2;
    long middleX = points[middle].x();
    long best = Math.min(
            closest(points, buffer, left, middle),
            closest(points, buffer, middle, right));

    int i = left, j = middle, index = left;
    while (i < middle && j < right) {
        if (points[i].y() <= points[j].y()) {
            buffer[index++] = points[i++];
        } else {
            buffer[index++] = points[j++];
        }
    }
    while (i < middle) {
        buffer[index++] = points[i++];
    }
    while (j < right) {
        buffer[index++] = points[j++];
    }
    System.arraycopy(buffer, left, points, left, right - left);

    int stripSize = 0;
    for (int k = left; k < right; k++) {
        long deltaX = points[k].x() - middleX;
        if (deltaX * deltaX < best) {
            buffer[stripSize++] = points[k];
        }
    }
    for (int first = 0; first < stripSize; first++) {
        for (int second = first + 1; second < stripSize; second++) {
            long deltaY = buffer[second].y() - buffer[first].y();
            if (deltaY * deltaY >= best) {
                break;
            }
            best = Math.min(best, squaredDistance(buffer[first], buffer[second]));
        }
    }
    return best;
}

static long squaredDistance(Point first, Point second) {
    long deltaX = first.x() - second.x();
    long deltaY = first.y() - second.y();
    return deltaX * deltaX + deltaY * deltaY;
}
