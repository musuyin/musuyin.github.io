排序与选择

2026-10-23

#算法与数据结构#排序#分治

阅读线索

快速排序通过划分后递归两侧建立全序，快速选择只追踪排名所在一侧；归并则通过有序子区间的合并组织比较。

快速排序

给定一个长度为 nnn 的整数数组，使用快速排序将数组按从小到大排列。

解析与思路

快速排序选择一个基准值 pivot，用两个指针把区间划分为不大于基准值和不小于基准值的两部分，再递归处理子区间。

这里使用 Hoare 划分。递归边界必须与划分结果保持一致：划分结束后递归 [left, j] 和 [j + 1, right]。平均时间复杂度为 O(nlogn)O(n log n)O(nlogn)，最坏为 O(n2)O(n^2)O(n2)；递归栈平均占用 O(logn)O(log n)O(logn)。快速排序通常不稳定。

代码

static void quickSort(int[] values, int left, int right) {
    if (left >= right) {
        return;
    }

    int pivot = values[left + (right - left) / 2];
    int i = left - 1, j = right + 1;
    while (i < j) {
        do {
            i++;
        } while (values[i] < pivot);
        do {
            j--;
        } while (values[j] > pivot);
        if (i < j) {
            int temporary = values[i];
            values[i] = values[j];
            values[j] = temporary;
        }
    }

    quickSort(values, left, j);
    quickSort(values, j + 1, right);
}

快速选择

给定整数数组和整数 k，求数组从小到大排列后的第 k 个数。k 从 1 开始。

解析与思路

完成一次划分后，只递归包含第 k 个数的一侧。若左半部分长度为 leftSize：

  • k <= leftSize：答案位于左半部分。
  • k > leftSize：答案位于右半部分，并将问题改为寻找右半部分的第 k - leftSize 个数。

平均时间复杂度为 O(n)O(n)O(n)，最坏为 O(n2)O(n^2)O(n2)。

代码

static int quickSelect(int[] values, int left, int right, int k) {
    if (left == right) {
        return values[left];
    }

    int pivot = values[left + (right - left) / 2];
    int i = left - 1, j = right + 1;
    while (i < j) {
        do {
            i++;
        } while (values[i] < pivot);
        do {
            j--;
        } while (values[j] > pivot);
        if (i < j) {
            int temporary = values[i];
            values[i] = values[j];
            values[j] = temporary;
        }
    }

    int leftSize = j - left + 1;
    if (k <= leftSize) {
        return quickSelect(values, left, j, k);
    }
    return quickSelect(values, j + 1, right, k - leftSize);
}

归并排序

给定一个长度为 nnn 的整数数组，使用归并排序将数组按从小到大排列。

解析与思路

归并排序先递归排序左右两半，再用两个指针合并两个有序区间。合并时相等元素优先取左半部分，因此实现是稳定的。

时间复杂度始终为 O(nlogn)O(n log n)O(nlogn)，辅助数组占用 O(n)O(n)O(n) 空间。

代码

static void mergeSort(int[] values) {
    int[] temporary = new int[values.length];
    mergeSort(values, temporary, 0, values.length - 1);
}

static void mergeSort(int[] values, int[] temporary, int left, int right) {
    if (left >= right) {
        return;
    }

    int middle = left + (right - left) / 2;
    mergeSort(values, temporary, left, middle);
    mergeSort(values, temporary, middle + 1, right);

    int i = left, j = middle + 1, index = left;
    while (i <= middle && j <= right) {
        if (values[i] <= values[j]) {
            temporary[index++] = values[i++];
        } else {
            temporary[index++] = values[j++];
        }
    }
    while (i <= middle) {
        temporary[index++] = values[i++];
    }
    while (j <= right) {
        temporary[index++] = values[j++];
    }
    System.arraycopy(temporary, left, values, left, right - left + 1);
}

逆序对

给定一个长度为 nnn 的整数数组。若 i<ji < ji<j 且 values[i] > values[j]，则 (i,j) 构成一个逆序对。求数组中的逆序对数量。

解析与思路

归并时左右两半已经有序。当 values[i] > values[j] 时，左半部分从 i 到 middle 的所有元素都大于 values[j]，一次产生：

middle−i+1middle-i+1middle−i+1

个跨区间逆序对。原图表达的三类逆序对可重写为：

  • 左半部分内部的逆序对由左侧递归计算。
  • 右半部分内部的逆序对由右侧递归计算。
  • 横跨左右两半的逆序对在合并过程中计算。

时间复杂度为 O(nlogn)O(n log n)O(nlogn)，答案可能超过 int，应使用 long。

代码

static long countInversions(int[] values) {
    int[] temporary = new int[values.length];
    return countInversions(values, temporary, 0, values.length - 1);
}

static long countInversions(int[] values, int[] temporary, int left, int right) {
    if (left >= right) {
        return 0;
    }

    int middle = left + (right - left) / 2;
    long result = countInversions(values, temporary, left, middle)
            + countInversions(values, temporary, middle + 1, right);

    int i = left, j = middle + 1, index = left;
    while (i <= middle && j <= right) {
        if (values[i] <= values[j]) {
            temporary[index++] = values[i++];
        } else {
            temporary[index++] = values[j++];
            result += middle - i + 1L;
        }
    }
    while (i <= middle) {
        temporary[index++] = values[i++];
    }
    while (j <= right) {
        temporary[index++] = values[j++];
    }
    System.arraycopy(temporary, left, values, left, right - left + 1);
    return result;
}
