基础排序与外部排序

2026-10-23

#排序#外部排序#Java

阅读线索

基础排序比较的是局部插入、交换和选择策略，外部排序还要考虑数据无法全部装入内存时的读写。稳定性、额外空间与数据规模一起决定选择。

排序算法比较

稳定排序不会改变相等元素的相对顺序。选择算法时除时间复杂度外，还要考虑空间、稳定性、数据范围以及数据是否能全部放入内存。

插入与希尔排序

插入排序维护前缀有序：取出当前元素，把更大的前缀元素右移，再插入空位。希尔排序对多个间隔为 gap 的子序列执行插入排序，并逐步缩小间隔。

void insertionSort(int[] values) {
    for (int i = 1; i < values.length; i++) {
        int current = values[i];
        int j = i - 1;
        while (j >= 0 && values[j] > current) {
            values[j + 1] = values[j--];
        }
        values[j + 1] = current;
    }
}

void shellSort(int[] values) {
    for (int gap = values.length / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < values.length; i++) {
            int current = values[i];
            int j = i - gap;
            while (j >= 0 && values[j] > current) {
                values[j + gap] = values[j];
                j -= gap;
            }
            values[j + gap] = current;
        }
    }
}

选择与冒泡排序

选择排序每轮确定未排序区间的最小值；冒泡排序通过相邻交换把最大值推到末尾。如果一轮没有交换，说明数组已经有序。

void selectionSort(int[] values) {
    for (int left = 0; left + 1 < values.length; left++) {
        int minimum = left;
        for (int i = left + 1; i < values.length; i++) {
            if (values[i] < values[minimum]) minimum = i;
        }
        int temporary = values[left];
        values[left] = values[minimum];
        values[minimum] = temporary;
    }
}

void bubbleSort(int[] values) {
    for (int end = values.length - 1; end > 0; end--) {
        boolean exchanged = false;
        for (int i = 0; i < end; i++) {
            if (values[i] > values[i + 1]) {
                int temporary = values[i];
                values[i] = values[i + 1];
                values[i + 1] = temporary;
                exchanged = true;
            }
        }
        if (!exchanged) return;
    }
}

堆排序

数组下标从零开始时，节点 i 的左右孩子为 2i+1 和 2i+2。先自底向上建最大堆，再反复把堆顶交换到未排序区间末尾。

void heapSort(int[] values) {
    for (int i = values.length / 2 - 1; i >= 0; i--) {
        siftDown(values, i, values.length);
    }
    for (int end = values.length - 1; end > 0; end--) {
        int temporary = values[0];
        values[0] = values[end];
        values[end] = temporary;
        siftDown(values, 0, end);
    }
}

void siftDown(int[] values, int root, int size) {
    while (root * 2 + 1 < size) {
        int child = root * 2 + 1;
        if (child + 1 < size && values[child + 1] > values[child]) child++;
        if (values[root] >= values[child]) return;
        int temporary = values[root];
        values[root] = values[child];
        values[child] = temporary;
        root = child;
    }
}

计数与基数排序

计数排序适合值域远小于元素数量的整数。LSD 基数排序从最低位到最高位执行稳定的计数排序；下面实现只处理非负整数。

int[] countingSort(int[] values, int maximum) {
    int[] count = new int[maximum + 1];
    for (int value : values) count[value]++;
    int[] answer = new int[values.length];
    for (int value = 0, write = 0; value <= maximum; value++) {
        while (count[value]-- > 0) answer[write++] = value;
    }
    return answer;
}

void radixSort(int[] values) {
    int maximum = 0;
    for (int value : values) maximum = Math.max(maximum, value);
    int[] buffer = new int[values.length];
    for (long place = 1; maximum / place > 0; place *= 10) {
        int[] count = new int[10];
        for (int value : values) count[(int) (value / place % 10)]++;
        for (int i = 1; i < count.length; i++) count[i] += count[i - 1];
        for (int i = values.length - 1; i >= 0; i--) {
            int digit = (int) (values[i] / place % 10);
            buffer[--count[digit]] = values[i];
        }
        System.arraycopy(buffer, 0, values, 0, values.length);
    }
}

外部排序

数据无法一次装入内存时，排序分成两个阶段：

  1. 分批读入内存并生成若干有序归并段。
  2. 使用 kkk 路归并反复合并归并段，直到只剩一个有序文件。

归并趟数约为 ⌈log⁡km⌉\lceil\log_k m\rceil⌈logk​m⌉，其中 mmm 是初始归并段数量。外存读写通常远慢于内存比较，因此优化目标是减少归并趟数和磁盘读写，而不是只减少比较次数。

败者树

败者树是一棵记录比较失败者的完全二叉树，根外位置保存本轮最小元素。每输出一路的当前元素后，只需让该路的新元素沿祖先链重新比赛，把一次 kkk 路选择从 O(k)O(k)O(k) 降到 O(log⁡k)O(\log k)O(logk)。

置换选择

工作区始终保存一批候选记录。输出当前不小于上一输出值的最小记录，并从输入补入一个新记录；不满足当前归并段单调性的记录被冻结到下一段。这样生成的初始归并段平均可长于工作区容量，从而减少 mmm。
