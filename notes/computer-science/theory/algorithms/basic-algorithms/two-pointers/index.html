双指针

2026-10-28

#算法与数据结构#双指针#Java

阅读线索

双指针利用指针移动的单调性避免回退。快慢指针常维护已处理前缀，对向指针利用有序性，同向双序列扫描则比较当前候选。

核心思想

双指针利用问题中的单调性，让两个指针各自只向一个方向移动，从而把重复扫描的 O(n2)O(n^2)O(n2) 过程优化为 O(n)O(n)O(n)。常见形式包括：

  • 快慢指针：原地筛选、去重或维护窗口。
  • 对向指针：在有序数组两端向中间逼近。
  • 同向扫描多个有序数组：每个指针都不回退。

移除元素

给定整数数组 nums 和整数 value，原地删除所有等于 value 的元素，并返回新数组长度。只允许使用 O(1)O(1)O(1) 额外空间。

解析与思路

把操作理解为“将保留的元素复制到数组前部”：

  • fast 扫描原数组。
  • slow 指向下一个应写入的位置。
  • 仅当 nums[fast] != value 时写入并移动 slow。

每个元素只访问一次，时间复杂度为 O(n)O(n)O(n)。

代码

static int removeElement(int[] nums, int value) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != value) {
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}

Go 实现

func removeElement(nums []int, val int) int {
	ed := 0
	for i := 0; i < len(nums); i++ {
		// 当为指定值时，跳过
		if nums[i] == val {
			continue
		}
		nums[ed] = nums[i]
		ed++
	}
	return ed
}

有序数组的平方

给定一个按非递减顺序排列、可能包含负数的整数数组，返回每个元素平方后仍按非递减顺序排列的数组。

解析与思路

原数组两端元素的绝对值最大。用左右指针比较平方值，每次把较大的值写入结果数组末端。时间复杂度为 O(n)O(n)O(n)，结果数组占用 O(n)O(n)O(n) 空间。

代码

static int[] sortedSquares(int[] nums) {
    int[] result = new int[nums.length];
    int left = 0, right = nums.length - 1;

    for (int index = nums.length - 1; index >= 0; index--) {
        int leftSquare = nums[left] * nums[left];
        int rightSquare = nums[right] * nums[right];
        if (leftSquare > rightSquare) {
            result[index] = leftSquare;
            left++;
        } else {
            result[index] = rightSquare;
            right--;
        }
    }
    return result;
}

Go 实现

func sortedSquares(nums []int) []int {
	ret := make([]int, len(nums))
	ed := len(nums) - 1
	for left, right := 0, len(nums)-1; ed >= 0; ed-- {
		if nums[left]*nums[left] >= nums[right]*nums[right] {
			ret[ed] = nums[left] * nums[left]
			left++
		} else {
			ret[ed] = nums[right] * nums[right]
			right--
		}
	}
	return ret
}

判断子序列

给定字符串 source 和 target，判断 source 是否为 target 的子序列。子序列可以删除若干字符，但不能改变剩余字符的相对顺序。

解析与思路

指针 i 指向 source 中下一个待匹配字符，指针 j 扫描 target。字符相等时才移动 i；扫描结束后，若 i == source.length()，说明全部匹配。

代码

static boolean isSubsequence(String source, String target) {
    int i = 0;
    for (int j = 0; j < target.length() && i < source.length(); j++) {
        if (source.charAt(i) == target.charAt(j)) {
            i++;
        }
    }
    return i == source.length();
}

三数之和

给定整数数组 nums，返回所有和为 0 且互不重复的三元组。三元组中的三个元素必须来自不同下标。

解析与思路

先排序，再固定第一个元素 nums[i]，对右侧区间使用对向双指针：

  • 和小于 0：左指针右移。
  • 和大于 0：右指针左移。
  • 和等于 0：记录答案，并跳过左右两侧重复值。

固定元素和两个指针都要去重。排序耗时 O(nlogn)O(n log n)O(nlogn)，枚举耗时 O(n2)O(n^2)O(n2)，总时间复杂度为 O(n2)O(n^2)O(n2)。哈希表仍需为每个固定元素扫描其余元素，并额外处理去重，通常不如排序加双指针直接。

代码

static List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();

    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) {
            break;
        }
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }

        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            long sum = (long) nums[i] + nums[left] + nums[right];
            if (sum < 0) {
                left++;
            } else if (sum > 0) {
                right--;
            } else {
                result.add(List.of(nums[i], nums[left], nums[right]));
                int leftValue = nums[left];
                int rightValue = nums[right];
                while (left < right && nums[left] == leftValue) {
                    left++;
                }
                while (left < right && nums[right] == rightValue) {
                    right--;
                }
            }
        }
    }
    return result;
}

Go 实现

import (
	"sort"
)

type sInt []int

func (nums sInt) Len() int {
	return len(nums)
}
func (nums sInt) Swap(i, j int) {
	nums[i], nums[j] = nums[j], nums[i]
}
func (nums sInt) Less(i, j int) bool {
	return nums[i] < nums[j]
}

func threeSum(nums []int) [][]int {
	sort.Sort(sInt(nums))
	n := len(nums)
	var ret [][]int
	for i := 0; i < n; i++ {
		// if nums[i] > 0, then must have nums[j] + nums[k] > 0 > -nums[i]
		if nums[i] > 0 {
			break
		}
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}
		for j, k := i+1, n-1; j < k; {
			sum := nums[j] + nums[k]
			if sum == -nums[i] {
				ret = append(ret, []int{nums[i], nums[j], nums[k]})
				j++
				k--
				for ; j < k && nums[j] == nums[j-1]; j++ {
				}
				for ; j < k && nums[k] == nums[k+1]; k-- {
				}
			} else if sum < -nums[i] {
				j++
			} else {
				k--
			}
		}
	}
	return ret
}

四数之和

给定整数数组 nums 和目标值 target，返回所有元素下标互不相同、元素和等于 target 且互不重复的四元组。

解析与思路

在三数之和外再固定一个元素，然后对剩余有序区间使用双指针。四个整数相加可能溢出，应先转换为 long。

时间复杂度为 O(n3)O(n^3)O(n3)，额外空间不计结果为 O(1)O(1)O(1)。

代码

static List<List<Integer>> fourSum(int[] nums, int target) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();

    for (int first = 0; first < nums.length - 3; first++) {
        if (first > 0 && nums[first] == nums[first - 1]) {
            continue;
        }
        for (int second = first + 1; second < nums.length - 2; second++) {
            if (second > first + 1 && nums[second] == nums[second - 1]) {
                continue;
            }

            int left = second + 1, right = nums.length - 1;
            while (left < right) {
                long sum = (long) nums[first] + nums[second]
                        + nums[left] + nums[right];
                if (sum < target) {
                    left++;
                } else if (sum > target) {
                    right--;
                } else {
                    result.add(List.of(nums[first], nums[second],
                            nums[left], nums[right]));
                    int leftValue = nums[left];
                    int rightValue = nums[right];
                    while (left < right && nums[left] == leftValue) {
                        left++;
                    }
                    while (left < right && nums[right] == rightValue) {
                        right--;
                    }
                }
            }
        }
    }
    return result;
}

Go 实现

import (
	"sort"
)

type sortInt []int

func (s sortInt) Len() int           { return len(s) }
func (s sortInt) Swap(x, y int)      { s[x], s[y] = s[y], s[x] }
func (s sortInt) Less(x, y int) bool { return s[x] < s[y] }

func fourSum(nums []int, target int) [][]int {
	n := len(nums)
	sort.Sort(sortInt(nums))
	var ret [][]int
	for i := 0; i < n; i++ {
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}
		for j := i + 1; j < n; j++ {
			if j > i+1 && nums[j] == nums[j-1] {
				continue
			}
			t := target - nums[i] - nums[j]
			k, l := j+1, n-1
			for k < l {
				sum := nums[k] + nums[l]
				if sum == t {
					ret = append(ret, []int{nums[i], nums[j], nums[k], nums[l]})
					for k++; k < l && nums[k] == nums[k-1]; k++ {
					}
					for l--; k < l && nums[l] == nums[l+1]; l-- {
					}
				} else if sum < t {
					k++
				} else {
					l--
				}
			}
		}
	}
	return ret
}

提升后的 H 指数

给定每篇论文当前的引用次数。最多可以选择 limit 篇论文，使每篇被选论文的引用次数增加 1。求操作后能够达到的最大 H 指数。

解析与思路

若要达到 H 指数 h，排序后引用次数最高的 h 篇论文必须全部不少于 h - 1，其中恰好等于 h - 1 的论文数量不能超过 limit。

原图中的下降曲线表示：随着候选 H 指数 h 增大，引用次数不少于 h 的最后一个位置只会向左移动，因此可以使用二分或双指针维护这条边界。

但直接在有序数组中检查候选 h 更清晰。按 h 从大到小枚举，第一个可行值就是答案；借助二分统计值等于 h - 1 的论文数，总复杂度为 O(nlogn)O(n log n)O(nlogn)。

代码

static int maximumHIndex(int[] citations, int limit) {
    Arrays.sort(citations);
    int n = citations.length;

    for (int h = n; h >= 1; h--) {
        int start = n - h;
        if (citations[start] < h - 1) {
            continue;
        }
        int firstAtLeastH = lowerBound(citations, h);
        int needIncrement = Math.max(0, firstAtLeastH - start);
        if (needIncrement <= limit) {
            return h;
        }
    }
    return 0;
}

static int lowerBound(int[] values, int target) {
    int left = 0, right = values.length;
    while (left < right) {
        int middle = left + (right - left) / 2;
        if (values[middle] >= target) {
            right = middle;
        } else {
            left = middle + 1;
        }
    }
    return left;
}

最长连续不重复子序列

给定整数数组，求不包含重复元素的最长连续子数组长度。

解析与思路

右指针每加入一个元素，就增加其计数。若当前元素出现超过一次，持续右移左指针并减少移出元素的计数，直到窗口重新无重复。两个指针都只前进，时间复杂度为 O(n)O(n)O(n)。

代码

static int longestDistinctSubarray(int[] values) {
    Map<Integer, Integer> count = new HashMap<>();
    int result = 0;

    for (int left = 0, right = 0; right < values.length; right++) {
        count.merge(values[right], 1, Integer::sum);
        while (count.get(values[right]) > 1) {
            count.merge(values[left], -1, Integer::sum);
            left++;
        }
        result = Math.max(result, right - left + 1);
    }
    return result;
}

两个有序数组的目标和

给定两个升序数组 first、second 和目标值 target，求满足 first[i] + second[j] == target 的下标对。题目保证解唯一。

解析与思路

i 从第一个数组左端向右移动，j 从第二个数组右端向左移动。若当前和过大，只需左移 j；因为之后 first[i] 只会更大，j 不可能再向右回退。时间复杂度为 O(n+m)O(n+m)O(n+m)。

代码

static int[] findPair(int[] first, int[] second, int target) {
    int i = 0, j = second.length - 1;
    while (i < first.length && j >= 0) {
        int sum = first[i] + second[j];
        if (sum == target) {
            return new int[] {i, j};
        }
        if (sum < target) {
            i++;
        } else {
            j--;
        }
    }
    throw new IllegalArgumentException("题目保证存在唯一解");
}

递增三元组

给定三个长度相同的整数数组 A、B、C，统计满足 A[i] < B[j] < C[k] 的三元组数量。

解析与思路

分别排序三个数组。按升序遍历 B[j] 时：

  • 指针 i 统计 A 中小于 B[j] 的元素数量。
  • 指针 k 定位 C 中第一个大于 B[j] 的元素。

由于 B[j] 单调递增，i 和 k 都不会回退。当前 B[j] 的贡献为：

i(n−k)i(n-k)i(n−k)

排序后扫描为 O(n)O(n)O(n)，总时间复杂度为 O(nlogn)O(n log n)O(nlogn)。

代码

static long countIncreasingTriples(int[] first, int[] middle, int[] last) {
    Arrays.sort(first);
    Arrays.sort(middle);
    Arrays.sort(last);

    long result = 0;
    int i = 0, k = 0;
    for (int value : middle) {
        while (i < first.length && first[i] < value) {
            i++;
        }
        while (k < last.length && last[k] <= value) {
            k++;
        }
        result += (long) i * (last.length - k);
    }
    return result;
}

按空格分割单词

给定一行文本，按连续空格分割并返回所有非空单词。

解析与思路

外层指针跳过空格，内层指针寻找当前单词结尾。每个字符最多被访问两次，时间复杂度为 O(n)O(n)O(n)。

代码

static List<String> splitWords(String text) {
    List<String> words = new ArrayList<>();
    int index = 0;

    while (index < text.length()) {
        while (index < text.length() && text.charAt(index) == ' ') {
            index++;
        }
        int end = index;
        while (end < text.length() && text.charAt(end) != ' ') {
            end++;
        }
        if (index < end) {
            words.add(text.substring(index, end));
        }
        index = end;
    }
    return words;
}

最接近的三数之和

从至少含三个整数的数组中选出三个不同下标的数，使其和与目标值距离最小，返回这个和。题目保证答案唯一。

思路

排序后固定第一个数，另两个数用对向双指针寻找。当前和小于目标时左指针右移，大于目标时右指针左移，等于目标时直接返回。答案从前三个数的和开始更新，不用任意常量充当答案。

复杂度

  • 时间复杂度：O(n2)O(n^2)O(n2)。
  • 空间复杂度：O(log⁡n)O(\log n)O(logn)，来自排序；修改原数组。

Go 实现

import "sort"

func threeSumClosest(nums []int, target int) int {
	sort.Ints(nums)
	best := nums[0] + nums[1] + nums[2]
	for i := 0; i < len(nums)-2; i++ {
		for left, right := i+1, len(nums)-1; left < right; {
			sum := nums[i] + nums[left] + nums[right]
			if absClosest(sum-target) < absClosest(best-target) {
				best = sum
			}
			if sum < target {
				left++
			} else if sum > target {
				right--
			} else {
				return sum
			}
		}
	}
	return best
}
func absClosest(x int) int {
	if x < 0 {
		return -x
	}
	return x
}
