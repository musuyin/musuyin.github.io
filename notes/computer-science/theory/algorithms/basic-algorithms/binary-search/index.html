二分查找

2026-10-28

#算法与数据结构#二分#Java

阅读线索

二分通过判定性质持续缩小候选区间。先明确寻找首个或最后一个满足条件的位置，再把中点取整、边界更新和循环结束条件作为一套约定使用。

核心思想

二分查找需要一个能把搜索区间分成两部分的判定性质。单调性是最常见的充分条件，但实际使用时更重要的是明确寻找哪一侧的边界，并让循环不变量始终成立。

本文统一使用闭区间 [left,right]。

左边界

寻找第一个满足条件的位置时，满足条件后保留 mid 并向左收缩：

static int firstTrue(int left, int right,
                     java.util.function.IntPredicate check) {
    while (left < right) {
        int middle = left + (right - left) / 2;
        if (check.test(middle)) {
            right = middle;
        } else {
            left = middle + 1;
        }
    }
    return left;
}

右边界

寻找最后一个满足条件的位置时，满足条件后保留 mid 并向右收缩。中间值必须向上取整，避免 left = mid 时区间无法缩小：

static int lastTrue(int left, int right,
                    java.util.function.IntPredicate check) {
    while (left < right) {
        int middle = left + (right - left + 1) / 2;
        if (check.test(middle)) {
            left = middle;
        } else {
            right = middle - 1;
        }
    }
    return left;
}

搜索目标区间

给定一个按非递减顺序排列的整数数组 nums 和目标值 target，返回 target 第一次和最后一次出现的位置。若不存在，返回 [-1,-1]。要求时间复杂度为 O(logn)O(log n)O(logn)。

解析与思路

分别寻找第一个大于等于 target 的位置和第一个大于 target 的位置。后者减一就是最后一个等于 target 的位置。

这种写法使用左闭右开区间 [left,right)，允许返回 nums.length，无需额外哨兵。

代码

static int[] searchRange(int[] nums, int target) {
    int left = lowerBound(nums, target);
    if (left == nums.length || nums[left] != target) {
        return new int[] {-1, -1};
    }
    int right = upperBound(nums, target) - 1;
    return new int[] {left, right};
}

static int lowerBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int middle = left + (right - left) / 2;
        if (nums[middle] >= target) {
            right = middle;
        } else {
            left = middle + 1;
        }
    }
    return left;
}

static int upperBound(int[] nums, int target) {
    int left = 0, right = nums.length;
    while (left < right) {
        int middle = left + (right - left) / 2;
        if (nums[middle] > target) {
            right = middle;
        } else {
            left = middle + 1;
        }
    }
    return left;
}

浮点数二分

给定浮点数 value，求它的三次方根。

解析与思路

函数 f(x)=x3f(x)=x^3f(x)=x3 单调递增，可以二分答案。初始区间必须覆盖答案：绝对值小于 1 时，立方根的绝对值反而大于原数，因此正数区间应取 [min(value,1),max(value,1)]。

循环次数固定为 100 次可以避免精度阈值选择不当造成的不收敛问题。时间复杂度为 O(1)O(1)O(1)，更精确地说是 O(log(范围/精度))O(log(范围/精度))O(log(范围/精度))。

代码

static double cubeRoot(double value) {
    double left = Math.min(value, -1.0);
    double right = Math.max(value, 1.0);

    for (int iteration = 0; iteration < 100; iteration++) {
        double middle = (left + right) / 2.0;
        if (middle * middle * middle >= value) {
            right = middle;
        } else {
            left = middle;
        }
    }
    return (left + right) / 2.0;
}

冶炼金属

炉子的转换率为正整数 V。投入 A 个普通金属会得到 floor(A / V) 个特殊金属。给定多条独立记录 (A,B)，求所有可能转换率 V 的最小值和最大值。题目保证有解。

解析与思路

每条记录满足 B = floor(A / V)，等价于：

A / (B + 1) < V ≤ A / B

因此单条记录给出的整数范围是：

[floor(A / (B + 1)) + 1, floor(A / B)]

所有记录取区间交集即可，不需要再做二分。时间复杂度为 O(n)O(n)O(n)。

代码

static int[] conversionRateRange(int[][] records) {
    int minimum = 1;
    int maximum = Integer.MAX_VALUE;

    for (int[] record : records) {
        int input = record[0];
        int output = record[1];
        minimum = Math.max(minimum, input / (output + 1) + 1);
        maximum = Math.min(maximum, input / output);
    }
    return new int[] {minimum, maximum};
}

借教室

未来 n 天每天分别有一定数量的教室。第 i 份订单要求在闭区间 [start[i],end[i]] 的每一天使用 demand[i] 间教室。订单按顺序处理；若某份订单无法完整满足，立即停止。求第一份无法满足的订单，全部满足时返回 0。

解析与思路

定义 valid(k) 表示前 k 份订单全部可满足。订单越多，需求只会增加，因此判定序列具有二段性：

订单数量    0  1  2  ...  k | k+1 ... m
valid      真 真 真  ...  真 | 假  ... 假

二分最后一个可行的 k。每次判定用差分数组累加前 k 份订单，再扫描每天的总需求。时间复杂度为 O((n+m)logm)O((n+m)log m)O((n+m)logm)。

代码

static int firstUnsatisfiedOrder(long[] capacity, int[][] orders) {
    int left = 0, right = orders.length;
    while (left < right) {
        int middle = left + (right - left + 1) / 2;
        if (ordersAreValid(capacity, orders, middle)) {
            left = middle;
        } else {
            right = middle - 1;
        }
    }
    return left == orders.length ? 0 : left + 1;
}

static boolean ordersAreValid(long[] capacity, int[][] orders, int count) {
    long[] difference = new long[capacity.length + 1];
    for (int i = 0; i < count; i++) {
        int demand = orders[i][0];
        int start = orders[i][1];
        int end = orders[i][2];
        difference[start] += demand;
        difference[end + 1] -= demand;
    }

    long used = 0;
    for (int day = 1; day < capacity.length; day++) {
        used += difference[day];
        if (used > capacity[day]) {
            return false;
        }
    }
    return true;
}

切巧克力

有 n 块尺寸分别为 height[i] × width[i] 的长方形巧克力，需要切出至少 k 块大小相同、边长为整数的正方形。只能切割，不能拼接。求正方形边长的最大值。

解析与思路

若边长 side 可行，更小的边长一定可行；若不可行，更大的边长一定不可行。对答案做右边界二分。

边长为 side 时，第 i 块巧克力可以切出：

floor(height[i] / side) × floor(width[i] / side)

块正方形，对全部巧克力的结果求和即可。

判定过程中数量达到 k 即可提前结束。时间复杂度为 O(nlogV)O(n log V)O(nlogV)。

代码

static int maximumSquareSide(int[][] chocolate, long k) {
    int left = 1, right = 0;
    for (int[] piece : chocolate) {
        right = Math.max(right, Math.min(piece[0], piece[1]));
    }

    while (left < right) {
        int middle = left + (right - left + 1) / 2;
        if (canCut(chocolate, k, middle)) {
            left = middle;
        } else {
            right = middle - 1;
        }
    }
    return left;
}

static boolean canCut(int[][] chocolate, long k, int side) {
    long count = 0;
    for (int[] piece : chocolate) {
        count += (long) (piece[0] / side) * (piece[1] / side);
        if (count >= k) {
            return true;
        }
    }
    return false;
}

管道注水

一根长度为 length 的管道被分成等长的离散段。位于 position[i] 的阀门从 startTime[i] 时刻开始注水；在时刻 time，它覆盖 [position[i]-(time-startTime[i]), position[i]+(time-startTime[i])]。求所有管段都被水覆盖的最早时刻。

解析与思路

时刻越晚，已覆盖区间只会扩大，因此可以二分最早可行时刻。对于给定时刻，将每个已开启阀门的覆盖范围裁剪到 [1,length]，按左端点排序后合并区间。

离散管段相邻也算连续，因此新区间满足 nextLeft <= coveredRight + 1 时可以合并。

代码

static long earliestFullTime(int length, int[][] valves) {
    long left = 0, right = 0;
    for (int[] valve : valves) {
        right = Math.max(right, (long) valve[1] + length);
    }

    while (left < right) {
        long middle = left + (right - left) / 2;
        if (isFullyCovered(length, valves, middle)) {
            right = middle;
        } else {
            left = middle + 1;
        }
    }
    return left;
}

static boolean isFullyCovered(int length, int[][] valves, long time) {
    List<long[]> intervals = new ArrayList<>();
    for (int[] valve : valves) {
        int position = valve[0];
        int startTime = valve[1];
        if (startTime <= time) {
            long distance = time - startTime;
            long left = Math.max(1L, position - distance);
            long right = Math.min((long) length, position + distance);
            intervals.add(new long[] {left, right});
        }
    }
    intervals.sort(Comparator.comparingLong(interval -> interval[0]));

    long coveredRight = 0;
    for (long[] interval : intervals) {
        if (interval[0] > coveredRight + 1) {
            return false;
        }
        coveredRight = Math.max(coveredRight, interval[1]);
        if (coveredRight == length) {
            return true;
        }
    }
    return false;
}

最多可安排任务

给定任务所需力量 tasks、工人力量 workers、药丸数量 pills 和单颗药丸增加的力量 strength。每名工人最多完成一个任务且最多服用一颗药丸。求最多能完成多少个任务。

解析与思路

若能完成 x 个任务，则一定能完成更少的任务，因此二分答案。判定 x 时选择最容易的 x 个任务和力量最大的 x 名工人，从最难的任务开始分配：

  • 优先使用不服药即可完成任务的最弱工人。
  • 若不存在，则使用药丸，并选择服药后恰好能够完成任务的最弱工人。

TreeMap 同时保存力量值和出现次数，可以在 O(logn)O(log n)O(logn) 内寻找下界并删除一名工人。

代码

static int maxTaskAssign(int[] tasks, int[] workers, int pills, int strength) {
    Arrays.sort(tasks);
    Arrays.sort(workers);

    int left = 0, right = Math.min(tasks.length, workers.length);
    while (left < right) {
        int middle = left + (right - left + 1) / 2;
        if (canAssign(middle, tasks, workers, pills, strength)) {
            left = middle;
        } else {
            right = middle - 1;
        }
    }
    return left;
}

static boolean canAssign(int count, int[] tasks, int[] workers,
                         int pills, int strength) {
    TreeMap<Integer, Integer> available = new TreeMap<>();
    for (int i = workers.length - count; i < workers.length; i++) {
        available.merge(workers[i], 1, Integer::sum);
    }

    for (int i = count - 1; i >= 0; i--) {
        Integer worker = available.ceilingKey(tasks[i]);
        if (worker == null) {
            if (pills == 0) {
                return false;
            }
            worker = available.ceilingKey(tasks[i] - strength);
            if (worker == null) {
                return false;
            }
            pills--;
        }
        removeOne(available, worker);
    }
    return true;
}

static void removeOne(TreeMap<Integer, Integer> values, int key) {
    int count = values.get(key);
    if (count == 1) {
        values.remove(key);
    } else {
        values.put(key, count - 1);
    }
}

二分查找

给定严格升序整数数组和目标值，返回目标值的下标；不存在时返回 -1。

思路

维护左闭右闭候选区间，根据中点值排除不可能的一半；区间为空时目标不存在。

复杂度

  • 时间复杂度：O(log⁡n)O(\log n)O(logn)。
  • 空间复杂度：O(1)O(1)O(1)。

Go 实现

// Search 在升序整型切片中查找 target，返回索引；不存在返回 -1
func Search(nums []int, target int) int {
	// 初始化左右边界：左闭右闭区间
	left, right := 0, len(nums)-1

	// 循环条件：区间不为空
	for left <= right {
		mid := left + (right-left)/2

		switch {
		case nums[mid] == target:
			return mid // 找到目标，直接返回索引
		case nums[mid] < target:
			left = mid + 1 // 目标在右半区间
		default:
			right = mid - 1 // 目标在左半区间
		}
	}

	return -1
}
