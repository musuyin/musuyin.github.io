复杂度与数组基础

2026-10-28

#算法与数据结构#数组

阅读线索

数据范围用于排除明显不可行的复杂度，但运行时间还受常数与评测环境影响。数组基础再补充下标、存储和转换约定，为后面的区间算法建立共同语言。

数据范围与复杂度

竞赛中通常需要把主要运算次数控制在 10710^7107 到 10810^8108 量级，但 Java 的可接受上限还会受到常数、对象分配、输入方式和评测环境影响。下表只用于快速排除明显不可行的算法。

  • n<30n < 30n<30：可考虑 O(2n)O(2^n)O(2n) 的 DFS、剪枝或状态压缩。
  • n≤102n ≤ 10^2n≤102：可考虑 O(n3)O(n^3)O(n3) 的 Floyd、区间 DP 或高斯消元。
  • n<103n < 10^3n<103：可考虑 O(n2)O(n^2)O(n2) 的朴素图算法或二维 DP。
  • n<105n < 10^5n<105：通常需要 O(nlogn)O(n log n)O(nlogn) 的排序、堆、树状数组或二分。
  • n<106n < 10^6n<106：通常需要 O(n)O(n)O(n) 或常数较小的 O(nlogn)O(n log n)O(nlogn) 算法。
  • n<108n < 10^8n<108：通常只能接受 O(√n)O(√n)O(√n) 或更低复杂度。
  • n<1018n < 10^{18}n<1018：通常使用 O(logn)O(log n)O(logn) 的快速幂或最大公约数算法。

Java 中累计和、乘积、方案数和区间端点相加时，应先判断是否需要使用 long。计算中间值时使用 left + (right - left) / 2，避免 left + right 溢出。

循环不变量

循环不变量是在每次循环开始和结束时都成立的约束。边界类算法应先确定区间含义，再让初始化、循环条件和边界更新始终服从同一约定。

常见约定包括：

  • 左闭右闭区间 [left,right][left,right][left,right]：空区间条件为 left > right。
  • 左闭右开区间 [left,right)[left,right)[left,right)：空区间条件为 left == right。
  • 双指针窗口 [left,right][left,right][left,right]：扩张右端后，持续收缩左端，直到窗口重新满足约束。

螺旋矩阵

给定正整数 n，生成一个 n × n 的矩阵，使数字 1 到 n² 按顺时针螺旋顺序排列。

解析与思路

用 top、bottom、left、right 表示尚未填写区域的四条闭边界。每完成一条边就收缩对应边界；填写下边和左边前重新判断边界，避免奇数阶矩阵中心或单行、单列区域被重复填写。

时间复杂度为 O(n2)O(n^2)O(n2)，除结果矩阵外只使用 O(1)O(1)O(1) 空间。

代码

static int[][] generateMatrix(int n) {
    int[][] matrix = new int[n][n];
    int top = 0, bottom = n - 1;
    int left = 0, right = n - 1;
    int value = 1;

    while (top <= bottom && left <= right) {
        for (int column = left; column <= right; column++) {
            matrix[top][column] = value++;
        }
        top++;

        for (int row = top; row <= bottom; row++) {
            matrix[row][right] = value++;
        }
        right--;

        if (top <= bottom) {
            for (int column = right; column >= left; column--) {
                matrix[bottom][column] = value++;
            }
            bottom--;
        }

        if (left <= right) {
            for (int row = bottom; row >= top; row--) {
                matrix[row][left] = value++;
            }
            left++;
        }
    }
    return matrix;
}

Go 实现：螺旋矩阵 II

Go 用已填数量控制循环，四条边收缩后空的方向循环自然不执行，中心只填一次。

func generateMatrix(n int) [][]int {
	t, b, l, r := 0, n-1, 0, n-1
	ret := make([][]int, n)
	for i := 0; i < n; i++ {
		ret[i] = make([]int, n)
	}

	cnt := 1
	limit := n * n
	for cnt <= limit {
		// top: left -> right
		for i := l; i <= r; i++ {
			ret[t][i] = cnt
			cnt++
		}
		t++
		// right: top -> bottom
		for i := t; i <= b; i++ {
			ret[i][r] = cnt
			cnt++
		}
		r--
		// bottom: right -> left
		for i := r; i >= l; i-- {
			ret[b][i] = cnt
			cnt++
		}
		b--
		// left: bottom -> top
		for i := b; i >= t; i-- {
			ret[i][l] = cnt
			cnt++
		}
		l++
	}
	return ret
}
