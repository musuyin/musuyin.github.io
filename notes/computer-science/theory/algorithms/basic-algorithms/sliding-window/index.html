滑动窗口

2026-10-28

#算法与数据结构#滑动窗口#Java

阅读线索

滑动窗口维护连续区间及其摘要。正数和、字符频次和候选最大值对应不同状态，必须先证明左边界移动后哪些候选可以安全丢弃。

核心思想

滑动窗口用两个同向移动的边界维护连续区间。右边界负责加入元素，左边界在约束不满足或答案已经可更新时收缩。能够使用滑动窗口的关键是：边界移动后，窗口状态具有可维护的单调性。

长度最小的子数组

给定正整数数组 nums 和正整数 target，求元素和大于等于 target 的最短连续子数组长度。不存在时返回 0。

解析与思路

由于所有元素为正数，右边界右移时窗口和只会增加，左边界右移时窗口和只会减少。加入右端元素后，只要和仍大于等于 target，就持续更新答案并收缩左端。

时间复杂度为 O(n)O(n)O(n)。

代码

static int minSubarrayLength(int target, int[] nums) {
    int result = Integer.MAX_VALUE;
    long sum = 0;

    for (int left = 0, right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            result = Math.min(result, right - left + 1);
            sum -= nums[left++];
        }
    }
    return result == Integer.MAX_VALUE ? 0 : result;
}

Go 实现

func minSubArrayLen(target int, nums []int) int {
	n := len(nums)
	ret := n + 1
	sum := 0
	left := 0
	for right, cur := range nums {
		sum += cur
		for sum >= target {
			ret = min(ret, right-left+1)
			sum -= nums[left]
			left++
		}
	}
	if ret <= n {
		return ret
	}
	return 0
}

水果成篮

给定一排果树的种类 fruits。从任意位置开始向右连续采摘，每棵树恰好摘一个水果；只有两个篮子，每个篮子只能容纳一种水果。求最多能采摘多少个水果。

解析与思路

问题等价于求至多包含两种不同元素的最长连续子数组。窗口中新种类超过两种时，持续移出左端元素，直到种类数恢复为两种。

代码

static int totalFruit(int[] fruits) {
    Map<Integer, Integer> count = new HashMap<>();
    int result = 0;

    for (int left = 0, right = 0; right < fruits.length; right++) {
        count.merge(fruits[right], 1, Integer::sum);
        while (count.size() > 2) {
            int fruit = fruits[left++];
            int remaining = count.get(fruit) - 1;
            if (remaining == 0) {
                count.remove(fruit);
            } else {
                count.put(fruit, remaining);
            }
        }
        result = Math.max(result, right - left + 1);
    }
    return result;
}

最小覆盖子串

给定字符串 source 和 target，返回 source 中包含 target 全部字符及其重复次数的最短子串。不存在时返回空字符串。

解析与思路

need 保存目标字符还需要多少个，missing 保存尚未匹配的字符总数。右边界加入字符后，若当前字符仍是必需的，就减少 missing；当 missing == 0 时持续收缩左端并更新最短答案。

时间复杂度为 O(∣source∣+∣target∣)O(|source|+|target|)O(∣source∣+∣target∣)。

代码

static String minWindow(String source, String target) {
    Map<Character, Integer> need = new HashMap<>();
    for (int i = 0; i < target.length(); i++) {
        need.merge(target.charAt(i), 1, Integer::sum);
    }

    int missing = target.length();
    int bestStart = 0, bestLength = Integer.MAX_VALUE;
    for (int left = 0, right = 0; right < source.length(); right++) {
        char added = source.charAt(right);
        int required = need.getOrDefault(added, 0);
        if (required > 0) {
            missing--;
        }
        need.put(added, required - 1);

        while (missing == 0) {
            int length = right - left + 1;
            if (length < bestLength) {
                bestLength = length;
                bestStart = left;
            }

            char removed = source.charAt(left++);
            int afterRemoval = need.get(removed) + 1;
            need.put(removed, afterRemoval);
            if (afterRemoval > 0) {
                missing++;
            }
        }
    }

    return bestLength == Integer.MAX_VALUE
            ? ""
            : source.substring(bestStart, bestStart + bestLength);
}

完全子数组计数

给定正整数数组 nums。若某个连续子数组中的不同元素数量等于整个数组的不同元素数量，则称其为完全子数组。求完全子数组的数量。

解析与思路

先统计整个数组的不同元素数 distinct。右边界扩张到窗口包含全部种类时，以当前左边界和右边界为起点的所有更长后缀都合法，因此贡献为 nums.length - right。随后持续收缩左端，直到窗口不再完整。

代码

static int countCompleteSubarrays(int[] nums) {
    int distinct = (int) Arrays.stream(nums).distinct().count();
    Map<Integer, Integer> count = new HashMap<>();
    int result = 0;

    for (int left = 0, right = 0; right < nums.length; right++) {
        count.merge(nums[right], 1, Integer::sum);
        while (count.size() == distinct) {
            result += nums.length - right;
            int value = nums[left++];
            int remaining = count.get(value) - 1;
            if (remaining == 0) {
                count.remove(value);
            } else {
                count.put(value, remaining);
            }
        }
    }
    return result;
}

得分小于 K 的子数组

正整数数组的分数定义为“元素和乘以长度”。给定正整数数组 nums 和整数 k，求分数严格小于 k 的非空连续子数组数量。

解析与思路

所有元素为正，因此固定右边界时，右移左边界会同时减小区间和与长度。将窗口收缩到分数小于 k 后，以当前右边界结尾的所有后缀都合法，数量为 right - left + 1。

代码

static long countSubarraysWithScoreLessThanK(int[] nums, long k) {
    long result = 0, sum = 0;

    for (int left = 0, right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum * (right - left + 1L) >= k) {
            sum -= nums[left++];
        }
        result += right - left + 1L;
    }
    return result;
}

热帖统计

每条日志由时间 timestamp 和帖子编号 id 组成。若某帖子在任意左闭右开时间段 [T,T+D) 内收到不少于 K 个赞，则它是热帖。返回所有热帖编号。

解析与思路

先按帖子分组，并分别将点赞时间排序。对每个帖子的时间序列维护窗口；当 times[right] - times[left] >= D 时右移左端。若窗口长度达到 K，该帖子就是热帖。

分组后的总排序复杂度不超过 O(nlogn)O(n log n)O(nlogn)，扫描为 O(n)O(n)O(n)。

代码

static List<Integer> hotPosts(int[][] logs, int duration, int threshold) {
    Map<Integer, List<Integer>> timesByPost = new HashMap<>();
    for (int[] log : logs) {
        timesByPost.computeIfAbsent(log[1], key -> new ArrayList<>())
                .add(log[0]);
    }

    List<Integer> result = new ArrayList<>();
    for (Map.Entry<Integer, List<Integer>> entry : timesByPost.entrySet()) {
        List<Integer> times = entry.getValue();
        Collections.sort(times);
        for (int left = 0, right = 0; right < times.size(); right++) {
            while (times.get(right) - times.get(left) >= duration) {
                left++;
            }
            if (right - left + 1 >= threshold) {
                result.add(entry.getKey());
                break;
            }
        }
    }
    Collections.sort(result);
    return result;
}

和不超过 K 的子矩阵

给定只包含非负整数的 n × m 矩阵，统计元素和不超过 k 的非空子矩阵数量。

解析与思路

固定上、下边界后，把每一列在这两行之间的元素和压缩成一维数组。由于元素非负，可以用滑动窗口统计和不超过 k 的连续列区间。

对每个右边界，窗口满足条件后，以它结尾的合法区间有 right - left + 1 个。若行数较小，总时间复杂度为 O(n2m)O(n^2m)O(n2m)。

代码

static long countSubmatricesAtMostK(int[][] matrix, long k) {
    int rows = matrix.length, columns = matrix[0].length;
    long result = 0;

    for (int top = 0; top < rows; top++) {
        long[] columnSum = new long[columns];
        for (int bottom = top; bottom < rows; bottom++) {
            for (int column = 0; column < columns; column++) {
                columnSum[column] += matrix[bottom][column];
            }

            long sum = 0;
            for (int left = 0, right = 0; right < columns; right++) {
                sum += columnSum[right];
                while (sum > k) {
                    sum -= columnSum[left++];
                }
                result += right - left + 1L;
            }
        }
    }
    return result;
}
