高精度运算

2026-10-23

#算法与数据结构#高精度#Java

阅读线索

高精度加减乘除把整数拆为十进制位，再维护进位、借位或余数。手写算法用于理解位级计算，Java 的 BigInteger 则提供现成的大整数表示。

存储方式

Java 工程代码通常直接使用 BigInteger。手写高精度算法时，可以直接从字符串末尾向前扫描；这等价于把个位放在下标 0，便于处理进位和借位，同时避免额外构造反向数字数组。

高精度加法

给定两个不含前导零的非负整数，计算它们的和。

解析与思路

从个位开始逐位相加，并维护进位 carry。只要两个字符串仍有未处理位，或 carry 不为零，就继续生成结果。时间复杂度为 O(max(n,m))O(max(n,m))O(max(n,m))。

代码

static String add(String first, String second) {
    StringBuilder result = new StringBuilder();
    int i = first.length() - 1, j = second.length() - 1;
    int carry = 0;

    while (i >= 0 || j >= 0 || carry != 0) {
        int sum = carry;
        if (i >= 0) {
            sum += first.charAt(i--) - '0';
        }
        if (j >= 0) {
            sum += second.charAt(j--) - '0';
        }
        result.append(sum % 10);
        carry = sum / 10;
    }
    return result.reverse().toString();
}

高精度减法

给定两个不含前导零的非负整数，计算 first - second，结果可能为负数。

解析与思路

先比较绝对值大小，保证核心减法始终以较大数减较小数。逐位计算时维护借位，最后删除高位多余的零。时间复杂度为 O(max(n,m))O(max(n,m))O(max(n,m))。

代码

static String subtract(String first, String second) {
    int comparison = compareDecimal(first, second);
    if (comparison == 0) {
        return "0";
    }
    if (comparison < 0) {
        return "-" + subtractAbsolute(second, first);
    }
    return subtractAbsolute(first, second);
}

static String subtractAbsolute(String larger, String smaller) {
    StringBuilder result = new StringBuilder();
    int i = larger.length() - 1, j = smaller.length() - 1;
    int borrow = 0;

    while (i >= 0) {
        int digit = larger.charAt(i--) - '0' - borrow;
        if (j >= 0) {
            digit -= smaller.charAt(j--) - '0';
        }
        if (digit < 0) {
            digit += 10;
            borrow = 1;
        } else {
            borrow = 0;
        }
        result.append(digit);
    }

    while (result.length() > 1 && result.charAt(result.length() - 1) == '0') {
        result.deleteCharAt(result.length() - 1);
    }
    return result.reverse().toString();
}

static int compareDecimal(String first, String second) {
    if (first.length() != second.length()) {
        return Integer.compare(first.length(), second.length());
    }
    return first.compareTo(second);
}

高精度乘法

给定不含前导零的非负大整数 value 和非负整数 multiplier，计算它们的乘积。

解析与思路

把较小的乘数视为整体，从大整数个位开始逐位相乘。当前位由 (digit × multiplier + carry) % 10 决定，剩余部分进入下一位。

代码

static String multiply(String value, int multiplier) {
    StringBuilder result = new StringBuilder();
    long carry = 0;

    for (int i = value.length() - 1; i >= 0; i--) {
        long current = (long) (value.charAt(i) - '0') * multiplier + carry;
        result.append(current % 10);
        carry = current / 10;
    }
    while (carry != 0) {
        result.append(carry % 10);
        carry /= 10;
    }

    while (result.length() > 1 && result.charAt(result.length() - 1) == '0') {
        result.deleteCharAt(result.length() - 1);
    }
    return result.reverse().toString();
}

高精度除法

给定不含前导零的非负大整数 value 和正整数 divisor，计算商和余数。

解析与思路

除法必须从最高位开始。每读入一位，就令 remainder = remainder × 10 + digit，商的当前位为 remainder / divisor，再保留新的余数。

代码

record DivisionResult(String quotient, int remainder) {}

static DivisionResult divide(String value, int divisor) {
    StringBuilder quotient = new StringBuilder();
    long remainder = 0;

    for (int i = 0; i < value.length(); i++) {
        remainder = remainder * 10 + value.charAt(i) - '0';
        quotient.append(remainder / divisor);
        remainder %= divisor;
    }

    int firstNonZero = 0;
    while (firstNonZero + 1 < quotient.length()
            && quotient.charAt(firstNonZero) == '0') {
        firstNonZero++;
    }
    return new DivisionResult(quotient.substring(firstNonZero), (int) remainder);
}
