多数投票

2026-10-23

#Boyer-Moore#投票算法#Java

阅读线索

多数投票用抵消不同元素的方式保留候选。它能找出可能的多数元素；若题目没有保证多数存在，还必须再计数验证。

Boyer-Moore 多数投票

给定非空整数数组，其中某个元素出现次数严格大于数组长度的一半，返回该多数元素。

思路

维护候选值与票数。遇到候选值就加一，遇到其他值就减一；票数归零时，当前前缀中的候选值与其他值可以成对抵消，下一元素成为新候选。

多数元素比所有其他元素总数还多，任意成对抵消都无法把它全部消除，因此最后留下的候选值必然是多数元素。若题目不保证多数元素存在，还需要第二遍统计进行验证。

复杂度

  • 时间复杂度：O(n)O(n)O(n)。
  • 空间复杂度：O(1)O(1)O(1)。

Java 实现

int majorityElement(int[] values) {
    int candidate = 0;
    int votes = 0;
    for (int value : values) {
        if (votes == 0) candidate = value;
        votes += value == candidate ? 1 : -1;
    }
    return candidate;
}
