前缀和与差分

2026-10-23

#算法与数据结构#前缀和#差分#Java

阅读线索

前缀和把区间查询转换成端点差，差分把区间修改转换成边界增量。二维版本沿用同一思路，但必须用容斥处理重复覆盖。

一维前缀和

给定整数数组和若干询问。每次询问给出闭区间 [left,right]，求区间内所有元素之和。

解析与思路

定义 prefix[i] 为前 i 个元素之和，并令 prefix[0] = 0：

prefix[i]=prefix[i−1]+values[i−1]prefix[i]=prefix[i-1]+values[i-1]prefix[i]=prefix[i−1]+values[i−1]

原图中的数组关系可以重绘为：

原数组下标      0  1  2  3  4  5  6
values          1  2  3  3  2  1  2
prefix       0  1  3  6  9 11 12 14

闭区间 [left,right] 的和为：

prefix[right+1]−prefix[left]prefix[right+1]-prefix[left]prefix[right+1]−prefix[left]

预处理为 O(n)O(n)O(n)，每次查询为 O(1)O(1)O(1)。

代码

static long[] buildPrefixSum(int[] values) {
    long[] prefix = new long[values.length + 1];
    for (int i = 0; i < values.length; i++) {
        prefix[i + 1] = prefix[i] + values[i];
    }
    return prefix;
}

static long rangeSum(long[] prefix, int left, int right) {
    return prefix[right + 1] - prefix[left];
}

二维前缀和

给定整数矩阵和若干询问。每次询问给出左上角 (x1,y1) 与右下角 (x2,y2)，求该闭合子矩阵的元素和。

解析与思路

使用一基下标，定义 prefix[x][y] 为左上角 (1,1) 到右下角 (x,y) 的矩形和：

prefix[x][y]=matrix[x][y]+prefix[x−1][y]+prefix[x][y−1]−prefix[x−1][y−1]prefix[x][y]=matrix[x][y]+prefix[x-1][y]+prefix[x][y-1]-prefix[x-1][y-1]prefix[x][y]=matrix[x][y]+prefix[x−1][y]+prefix[x][y−1]−prefix[x−1][y−1]

查询矩形时使用容斥：

  • 加上 (1,1) 到 (x2,y2) 的区域。
  • 减去 (1,1) 到 (x1-1,y2) 的区域。
  • 减去 (1,1) 到 (x2,y1-1) 的区域。
  • 加回被重复减去的 (1,1) 到 (x1-1,y1-1) 区域。

因此：

sum=prefix[x2][y2]−prefix[x1−1][y2]−prefix[x2][y1−1]+prefix[x1−1][y1−1]sum=prefix[x_2][y_2]-prefix[x_1-1][y_2]-prefix[x_2][y_1-1]+prefix[x_1-1][y_1-1]sum=prefix[x2​][y2​]−prefix[x1​−1][y2​]−prefix[x2​][y1​−1]+prefix[x1​−1][y1​−1]

代码

static long[][] buildMatrixPrefix(int[][] matrix) {
    int rows = matrix.length, columns = matrix[0].length;
    long[][] prefix = new long[rows + 1][columns + 1];

    for (int row = 1; row <= rows; row++) {
        for (int column = 1; column <= columns; column++) {
            prefix[row][column] = matrix[row - 1][column - 1]
                    + prefix[row - 1][column]
                    + prefix[row][column - 1]
                    - prefix[row - 1][column - 1];
        }
    }
    return prefix;
}

static long matrixRangeSum(long[][] prefix,
                           int x1, int y1, int x2, int y2) {
    return prefix[x2][y2]
            - prefix[x1 - 1][y2]
            - prefix[x2][y1 - 1]
            + prefix[x1 - 1][y1 - 1];
}

壁画

一面墙被分为 n 段，每段有一个美观评分。第一天可以任选一段开始绘制，之后每天只能绘制与已完成区域相邻的墙段；每天还会从未绘制区域的一端摧毁一段墙。求无论摧毁顺序如何都能保证获得的最大总评分。

解析与思路

最终一定能保证完成长度为 ceil(n / 2) = (n + 1) / 2 的连续区间。因此问题转化为固定长度最大子数组和。用前缀和或定长窗口均可在 O(n)O(n)O(n) 内解决。

代码

static int maximumMuralScore(int[] scores) {
    int length = (scores.length + 1) / 2;
    int sum = 0;
    for (int i = 0; i < length; i++) {
        sum += scores[i];
    }

    int result = sum;
    for (int right = length; right < scores.length; right++) {
        sum += scores[right] - scores[right - length];
        result = Math.max(result, sum);
    }
    return result;
}

K 倍区间

给定整数数组和正整数 k。若某个连续区间的元素和是 k 的倍数，则称它为 K 倍区间。求这样的区间数量。

解析与思路

区间 [left,right] 的和为 prefix[right] - prefix[left-1]。它是 k 的倍数，当且仅当 prefix[right] 与 prefix[left-1] 除以 k 的余数相同。

扫描前缀和时，若当前余数此前出现过 count[remainder] 次，就新增这么多个合法区间。初始化 count[0] = 1，表示空前缀 prefix[0] = 0。

代码

static long countKMultipleRanges(int[] values, int k) {
    long[] count = new long[k];
    count[0] = 1;

    long result = 0, prefix = 0;
    for (int value : values) {
        prefix += value;
        int remainder = (int) ((prefix % k + k) % k);
        result += count[remainder];
        count[remainder]++;
    }
    return result;
}

工资调整

有 n 个人排成一列，第 i 个人工资为 salary[i]。每年只能统一选择一个方向，把任意多个非零位置各转移 1 元给相邻位置。求让所有人工资相同所需的最少年数；无法均分时返回 -1。

解析与思路

目标工资为 average = sum / n。定义 balance[i] 为前 i 个人的 salary[j] - average 之和。

balance_i > 0 表示前 i 个位置需要向右送出工资，balance_i < 0 表示需要从右侧补入。一次选择方向的操作可以同时让多个边界各转移一个单位，因此答案是所有前缀差值的最大值与最小值之差。

代码

static long minimumYearsToEqualize(long[] salary) {
    long sum = 0;
    for (long value : salary) {
        sum += value;
    }
    if (sum % salary.length != 0) {
        return -1;
    }

    long average = sum / salary.length;
    long balance = 0, minimum = 0, maximum = 0;
    for (long value : salary) {
        balance += value - average;
        minimum = Math.min(minimum, balance);
        maximum = Math.max(maximum, balance);
    }
    return maximum - minimum;
}

一维差分

给定整数数组和若干操作。每次操作把闭区间 [left,right] 内的所有元素加上 delta。输出全部操作后的数组。

解析与思路

差分是前缀和的逆运算。定义：

difference[i]=values[i]−values[i−1]difference[i]=values[i]-values[i-1]difference[i]=values[i]−values[i−1]

对 [left,right] 整体增加 delta，只需修改两个边界：

difference[left]     += delta
difference[right + 1] -= delta

全部操作完成后，对差分数组求前缀和即可恢复结果。每次更新为 O(1)O(1)O(1)，最终还原为 O(n)O(n)O(n)。

代码

static long[] applyRangeUpdates(int[] values, int[][] updates) {
    long[] difference = new long[values.length + 1];
    for (int i = 0; i < values.length; i++) {
        difference[i] += values[i];
        difference[i + 1] -= values[i];
    }

    for (int[] update : updates) {
        int left = update[0], right = update[1], delta = update[2];
        difference[left] += delta;
        difference[right + 1] -= delta;
    }

    long[] result = new long[values.length];
    long current = 0;
    for (int i = 0; i < values.length; i++) {
        current += difference[i];
        result[i] = current;
    }
    return result;
}

二维差分

给定整数矩阵和若干操作。每次把左上角 (x1,y1) 到右下角 (x2,y2) 的闭合子矩阵内所有元素加上 delta。输出全部操作后的矩阵。

解析与思路

原图中的四个角可以用符号表重绘。对矩形增加 delta 时：

  • (x1,y1) 增加 delta。
  • (x1,y2+1) 减少 delta。
  • (x2+1,y1) 减少 delta。
  • (x2+1,y2+1) 增加 delta。

这样对二维差分数组求二维前缀和时，影响范围恰好只覆盖目标矩形。

代码

static long[][] applyMatrixUpdates(int[][] matrix, int[][] updates) {
    int rows = matrix.length, columns = matrix[0].length;
    long[][] difference = new long[rows + 2][columns + 2];

    for (int row = 1; row <= rows; row++) {
        for (int column = 1; column <= columns; column++) {
            insert(difference, row, column, row, column,
                    matrix[row - 1][column - 1]);
        }
    }
    for (int[] update : updates) {
        insert(difference, update[0], update[1], update[2], update[3], update[4]);
    }

    long[][] result = new long[rows][columns];
    for (int row = 1; row <= rows; row++) {
        for (int column = 1; column <= columns; column++) {
            difference[row][column] += difference[row - 1][column]
                    + difference[row][column - 1]
                    - difference[row - 1][column - 1];
            result[row - 1][column - 1] = difference[row][column];
        }
    }
    return result;
}

static void insert(long[][] difference, int x1, int y1,
                   int x2, int y2, long delta) {
    difference[x1][y1] += delta;
    difference[x1][y2 + 1] -= delta;
    difference[x2 + 1][y1] -= delta;
    difference[x2 + 1][y2 + 1] += delta;
}

空调

一排牛栏当前温度为 current[i]，目标温度为 target[i]。每条命令可以把任意连续区间的温度统一增加或减少 1。求达到目标温度的最少命令数。

解析与思路

先定义目标变化量 delta[i] = target[i] - current[i]，问题转化为把全零数组变成 delta。对 delta 再求差分，并补上结尾哨兵，使整个差分数组元素和为零。

一次区间加减会让差分数组中的一个位置增加 1、另一个位置减少 1。因此最少操作数等于差分数组所有正数之和，也等于所有负数绝对值之和。

代码

static long minimumAirConditionerCommands(int[] target, int[] current) {
    long result = 0;
    long previousDelta = 0;

    for (int i = 0; i <= target.length; i++) {
        long delta = i == target.length ? 0L : (long) target[i] - current[i];
        long difference = delta - previousDelta;
        if (difference > 0) {
            result += difference;
        }
        previousDelta = delta;
    }
    return result;
}
