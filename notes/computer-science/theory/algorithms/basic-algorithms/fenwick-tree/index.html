树状数组

2026-10-23

#算法与数据结构#树状数组#Java

阅读线索

树状数组将前缀分成若干由 lowbit 决定的区间。查询向父区间回退，单点更新则沿所有覆盖该位置的管理节点向上累加。

结构与性质

树状数组又称 Fenwick Tree，用于维护可逆前缀信息。最常见的用途是：

  • 单点增加一个值。
  • 查询从位置 1 到位置 x 的前缀和。
  • 用两个前缀和之差查询闭区间 [left,right]。

lowbit(x) = x & -x 表示 x 的二进制最低位 1 所代表的值。树状数组的 tree[i] 管理区间：

[i−lowbit(i)+1,i][i-lowbit(i)+1,i][i−lowbit(i)+1,i]

结构可用表格表示：

  • i = 1：二进制为 0001，lowbit(i) = 1，管理 [1,1]。
  • i = 2：二进制为 0010，lowbit(i) = 2，管理 [1,2]。
  • i = 3：二进制为 0011，lowbit(i) = 1，管理 [3,3]。
  • i = 4：二进制为 0100，lowbit(i) = 4，管理 [1,4]。
  • i = 6：二进制为 0110，lowbit(i) = 2，管理 [5,6]。
  • i = 8：二进制为 1000，lowbit(i) = 8，管理 [1,8]。

查询时不断执行 i -= lowbit(i)，向前跳过已经统计的区间；更新时不断执行 i += lowbit(i)，更新所有包含当前位置的上级区间。两种操作的时间复杂度均为 O(logn)O(log n)O(logn)。

Java 实现

static final class FenwickTree {
    private final long[] tree;

    FenwickTree(int size) {
        tree = new long[size + 1];
    }

    void add(int index, long delta) {
        for (int i = index; i < tree.length; i += i & -i) {
            tree[i] += delta;
        }
    }

    long prefixSum(int index) {
        long result = 0;
        for (int i = index; i > 0; i -= i & -i) {
            result += tree[i];
        }
        return result;
    }

    long rangeSum(int left, int right) {
        return prefixSum(right) - prefixSum(left - 1);
    }
}

动态区间和

给定一个整数数组，需要反复执行两类操作：给某个位置增加一个值；查询闭区间 [left,right] 的元素和。

解析与思路

普通前缀和查询为 O(1)O(1)O(1)，但单点修改后需要更新后续所有前缀，代价为 O(n)O(n)O(n)。树状数组把两类操作平衡到 O(logn)O(log n)O(logn)。

初始化时按一基下标把每个元素加入树状数组，之后直接调用 add 与 rangeSum。

代码

static FenwickTree buildFenwickTree(int[] values) {
    FenwickTree tree = new FenwickTree(values.length);
    for (int i = 0; i < values.length; i++) {
        tree.add(i + 1, values[i]);
    }
    return tree;
}

数星星

平面上有若干坐标互不相同的星星。若一颗星星左下方，包括正左和正下，共有 k 颗星星，则它是 k 级星星。输入按纵坐标递增、纵坐标相同时按横坐标递增的顺序给出，统计每个等级的星星数量。

解析与思路

处理当前星星 (x,y) 时，已经读入的都是纵坐标不大于 y 的星星。当前等级就是此前横坐标不大于 x 的星星数量，即横坐标频率的前缀和。

树状数组下标从 1 开始，因此把横坐标整体加 1。每颗星星进行一次查询和一次更新，总时间复杂度为 O(nlogC)O(n log C)O(nlogC)，其中 C 为横坐标范围。

代码

static int[] countStarLevels(int[][] points, int maximumX) {
    FenwickTree tree = new FenwickTree(maximumX + 1);
    int[] levelCount = new int[points.length];

    for (int[] point : points) {
        int index = point[0] + 1;
        int level = (int) tree.prefixSum(index);
        levelCount[level]++;
        tree.add(index, 1);
    }
    return levelCount;
}
