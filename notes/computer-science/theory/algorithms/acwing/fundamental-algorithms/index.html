阅读线索

基础算法的共同任务是减少重复工作：排序建立顺序，二分压缩候选范围，前缀和复用累计结果，双指针利用移动不变量。应先根据数据范围选复杂度，再核对模板中的区间约定。

面试追问：三数之和

排序后固定第一个数 i，其余区间用左右双指针：和小则左移、和大则右移、等于零则记录并跳过重复值。排序 O(n log n)，外层 O(n)、双指针总 O(n)，因此总 O(n²)，额外空间（不计输出）O(1)。哈希法可做，但每个 i 仍要扫描一遍且去重、空间和常数更差；DP 不适合这种无固定值域的三元组枚举。排序后的单调性让双指针在比较模型下以更低常数完成 O(n²) 枚举。

“k log k 比 n² 好吗”不能脱离变量：同一输入规模下比较增长率，若 k=n，n log n 优于 n²；若 k 表示不同维度/候选集，必须先说明 k 与 n 的关系及常数、内存和数据规模，不能直接下结论。

排序

稳定排序：下标和数据保持对应关系。

快速排序 O(nlogn)

给定你一个长度为 nnn 的整数数列。

请你使用快速排序对这个数列按照从小到大进行排序。

并将排好序的数列按顺序输出。

基于分治的思想，核心步骤如下：

  1. 确定分界点 xxx：左边界、中间值、右边界或随机值
  2. 调整区间：划分出两个区间，使小于（等于）xxx 的元素在 xxx 的一边，大于（等于）xxx 的在另一边
  3. 递归处理左右两端

调整区间（升序）

暴力做法
  1. 创建两个临时数组 a[]、b[]
  2. 小于等于 xxx 的存入 a，大于 xxx 的存入 b
  3. 合并 a 和 b

位置交换（双指针）
  1. 定义两个指针 i 和 j，i 指向数组最左端，j 指向最右端
  2. 对 i 右移，直到 q[i] >= x 停止
  3. 对 j 左移，直到 q[j] <= x 停止
  4. 交换 q[i] 与 q[j]，然后 i、j 各向中间移动一位
  5. 重复以上步骤，直到 i 与 j 相遇；此时 i 左侧的值一定小于等于 xxx，j 右侧的值一定大于等于 xxx
#include <iostream>

using namespace std;

const int N = 1e6 + 10;

int n;
int q[N];

void quick_sort(int q[], int l, int r)
{
    if (l >= r)  //写成l == r也可以
        return;

    int i = l - 1, j = r + 1, x = q[l + r >> 1];
    while (i < j)
    {
        do i++; while (q[i] < x);
        do j--; while (q[j] > x);
        if (i < j) swap(q[i],q[j]);
    }
    quick_sort(q, l, j), quick_sort(q, j + 1, r);  //j->i-1,j+1->i
}

快速选择 O(n) 第 k 个数

给定一个长度为 nnn 的整数数列，以及一个整数 kkk，请用快速选择算法求出数列从小到大排序后的第 kkk 个数。

进行第一次划分后，可以通过比较 kkk 与左右部分的长度来判断第 kkk 大的数落在哪一侧：

  1. k≤SLk \leq S_Lk≤SL​：递归 Left
  2. k>SLk > S_Lk>SL​：递归 Right，且令 k=k−SLk = k - S_Lk=k−SL​
int quick_sort(int l, int r, int k)
{
    if (l == r) return q[l];

    int x = q[l + r >> 1], i = l - 1, j = r + 1;
    while (i < j)
    {
        do i++; while (q[i] < x);
        do j--; while (q[j] > x);
        if (i < j) swap(q[i],q[j]);
    }

    int sl = j - l + 1;  //+1视k从0开始还是1开始
    if (k <= sl) return quick_sort(l, j, k);  //k与sl进行比较，因为应该比较的是当前分治的范围
    return quick_sort(j + 1, r, k - sl);

}

归并排序 O(nlogn)

给定你一个长度为 nnn 的整数数列。

请你使用归并排序对这个数列按照从小到大进行排序。

并将排好序的数列按顺序输出。

同样基于分治的思想，步骤如下：

  1. 确定分界点，以数组中间下标来分
  2. 递归排序左边和右边
  3. 归并两个有序数组，合二为一

只要持续拆分，最终会退化为单元素排序，从而保证整体有序。

合二为一：用两个指针分别扫描左右两段，按大小顺序将元素写入第三个辅助数组。

#include <iostream>
using namespace std;

const int N = 1000010;

int n;
int q[N],temp[N]; //temp为辅助数组

void merge_sort(int q[], int l, int r)
{
    if (l >= r) return;

    int mid = l + r >> 1;  //(l+r)/2
    merge_sort(q,l,mid) , merge_sort(q, mid + 1, r);  //先递归再排序
    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r)
    {
        if (q[i] <= q[j])
            temp[k++] = q[i++];  //把这里的i换成j，把下面的j换成i，就可以实现降序排序（现在是升序）
        else
            temp[k++] = q[j++];
    }
    while (i <= mid) temp[k++] = q[i++];
    while (j <= r) temp[k++] = q[j++];

    for (i = l, j = 0; i <= r; i++, j++)
        q[i] = temp[j];
}

逆序对的数量

给定一个长度为 n 的整数数列，请你计算数列中的逆序对的数量。

逆序对的定义如下：对于数列的第 i 个和第 j 个元素，如果满足 i<j 且 a[i] > a[j]，则其为一个逆序对；否则不是。

逆序对共分三种情况：

  1. 左半边内部的逆序对：merge_sort(L, mid)

  2. 右半边内部的逆序对：merge_sort(mid + 1, R)

  3. 横跨左右两边的逆序对：

    每次取右侧的一个数 qjq_jqj​，判断左侧有多少个数大于 qjq_jqj​。

    当 qi>qjq_i > q_jqi​>qj​ 时，i 之后的所有数都大于 qjq_jqj​，故 res += mid - i + 1。

    递归至最小子问题时，只需处理这一种跨界情况。

#include <iostream>
using namespace std;

typedef long long LL;

const int N = 100010;

int n;
int q[N], tmp[N];

LL merge_sort(int l, int r)
{
    if (l >= r) return 0;

    int mid = l + r >> 1;
    LL res = merge_sort(l, mid) + merge_sort(mid + 1, r);

    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r)
    {
        if (q[i] <= q[j]) tmp[k++] = q[i++];
        else
        {
            tmp[k++] = q[j++];
            res += mid - i + 1;  //区别
        }
    }

    while (i <= mid) tmp[k++] = q[i++];
    while (j <= r) tmp[k++] = q[j++];

    for (int i = l, j = 0; i <= r; i++, j++) q[i] = tmp[j];

    return res;
}

int main(void)
{
    cin >> n;
    for (int i = 0; i < n; i++) cin >> q[i];

    cout << merge_sort(0, n - 1) << '\n';
    return 0;
}

二分

整数二分

给定一个按照升序排列的长度为 nnn 的整数数组，以及 qqq 个查询。

对于每个查询，返回一个元素 kkk 的起始位置和终止位置（位置从 0 开始计数）。

如果数组中不存在该元素，则返回 -1 -1。

二分的核心不在于单调性，而在于边界。有单调性一定可以二分，但可以二分不一定有单调性。

定义一个性质，使它能将整个区间一分为二；根据二分出的边界来判断目标值是否存在于原数组中。

右偏型

取中间值 mid = (l + r + 1) / 2，判断 check(mid)：

  • 满足：l = mid（区间缩为 [mid, r]）
  • 不满足：r = mid - 1（区间缩为 [l, mid-1]）

左偏型

取中间值 mid = (l + r) / 2，判断 check(mid)：

  • 满足：r = mid（区间缩为 [l, mid]）
  • 不满足：l = mid + 1（区间缩为 [mid+1, r]）

如何选择两种类型？

左偏型可找到目标第一次出现的下标，右偏型可找到最后一次出现的下标。

模板

关于 mid 是否 +1 的分析：

  • mid = l + r >> 1：mid 取上中位数
  • mid = l + r + 1 >> 1：mid 取下中位数
  • 若令 l = mid（即区间为 [mid, r]），则 mid 需取下中位数才能使区间收敛
  • 若令 r = mid（即区间为 [l, mid]），则 mid 取上中位数即可

以上讨论基于区间总长度为偶数的情况；长度为奇数时无法严格平分区间。

bool check(int x) {/* ... */} // 检查x是否满足某种性质

// 区间[l, r]被划分成[l, mid]和[mid + 1, r]时使用：
int bsearch_1(int l, int r)  //只要是往左找答案，就用第一个模板，mid不用加一，r=mid，l加一
{
    while (l < r)
    {
        int mid = l + r >> 1;
        if (q[mid] >= x) r = mid;    // check()判断mid是否满足性质
        else l = mid + 1;
    }
    return l;
}
// 区间[l, r]被划分成[l, mid - 1]和[mid, r]时使用：
int bsearch_2(int l, int r)  //只要是往右找答案，就用第二个模板，mid要加一，l=mid，r要减一
{
    while (l < r)
    {
        int mid = l + r + 1 >> 1;
        if (q[mid] <= x) l = mid;
        else r = mid - 1;
    }
    return l;
}

浮点数二分

给定一个浮点数 nnn，求它的三次方根。

浮点数二分常用于求数的平方根、立方根一类题目。

注意区分 0<x<10 < x < 10<x<1 与 x>1x > 1x>1 两种情况下的初始区间设置。

#include <iostream>
using namespace std;

double binary_search(double n)
{
    const double eps = 1e-8;
    double sign = 1;
    if (n < 0)
    {
        sign = -1;
        n = -n;
    }
    double l, r;
    if (n < 1) l = n, r = 1;
    else l = 0, r = n;

    while (r - l > eps)
    {
        double mid = (l + r) / 2;
        if (mid*mid*mid > n) r = mid;
        else l = mid;
    }
    return l * sign;
}

vector<int> add(vector<int> &A, vector<int> &B)
{
    vector<int> C;

    int t = 0;  //进位
    for (int i = 0; i < A.size() || i < B.size(); i++)
    {
        if (i < A.size()) t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }

    if (t) C.push_back(1);  //进位
    return C;
}

  • A<BA < BA<B：结果为 −(B−A)-(B - A)−(B−A)

#include <iostream>

    cin >> a >> b;

vector<int> sub(vector<int> &A, vector<int> &B)
{
    vector<int> C;
    for (int i = 0, t = 0; i < A.size(); i++)
    {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);
        if (t < 0) t = 1;
        else t = 0;
    }

    while (C.size() > 1 && C.back() == 0) C.pop_back();  //去除前导0，而且避免删去单个0

    return C;
}

bool cmp(vector<int> &A, vector<int> &B)
{
    if (A.size() != B.size()) return (A.size() > B.size());
    for (int i = A.size() - 1; i >= 0; i--)
        if (A[i] != B[i])
            return A[i] > B[i];
    return true;  //AB相等
}

前缀和与差分

前缀和

输入一个长度为 nnn 的整数序列。

接下来再输入 mmm 个询问，每个询问输入一对 l,rl,rl,r。

对于每个询问，输出原序列中从第 lll 个数到第 rrr 个数的和。

对于长度为 nnn 的数组，其前缀和定义为：

Si=a1+a2+⋯+aiS_i = a_1 + a_2 + \cdots + a_iSi​=a1​+a2​+⋯+ai​

如何求 SiS_iSi​
S[0] = 0;
S[i] = S[i-1] + a[i];

SiS_iSi​ 有什么用

可以在 O(1)O(1)O(1) 内求出任意区间 [l,r][l, r][l,r] 内元素的和：Sr−Sl−1S_r - S_{l-1}Sr​−Sl−1​。

#include <iostream>
using namespace std;

const int N = 10e6 + 10;

int n,m;
int a[N],s[N];

int main(void)
{
    s[0] = 0;
    scanf("%d %d",&n, &m);

}

子矩阵的和（二维前缀和）

输入一个 nnn 行 mmm 列的整数矩阵，再输入 qqq 个询问，每个询问包含四个整数 x1,y1,x2,y2x_{1},y_{1},x_{2},y_{2}x1​,y1​,x2​,y2​，表示一个子矩阵的左上角坐标和右下角坐标。

对于每个询问输出子矩阵中所有数的和。

#include <iostream>
using namespace std;

const int N = 1010;

int n,m,q;
int a[N][N], s[N][N];

int main(void)
{
    scanf("%d %d %d",&n,&m,&q);
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
            scanf("%d",&a[i][j]);
    }

    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
            s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];  //求前缀和
    }

    while (q--)
    {
        int x1,y1,x2,y2;
        scanf("%d %d %d %d",&x1,&y1,&x2,&y2);
        printf("%d\n",s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]);  //子矩阵和
    }

    return 0;
}

差分

输入一个长度为 nnn 的整数序列。

接下来输入 mmm 个操作，每个操作包含三个整数 l,r,cl,r,cl,r,c，表示将序列中 [l,r][l,r][l,r] 之间的每个数加上 ccc。

请你输出进行完所有操作后的序列。

差分是前缀和的逆运算。

对原数组 a1,a2,a3,…a_1, a_2, a_3, \ldotsa1​,a2​,a3​,…，构造差分数组 b1,b2,b3,…b_1, b_2, b_3, \ldotsb1​,b2​,b3​,…，使得：

ai=b1+b2+⋯+bia_i = b_1 + b_2 + \cdots + b_iai​=b1​+b2​+⋯+bi​

一维

b1=a1b_1 = a_1b1​=a1​，b2=a2−b1b_2 = a_2 - b_1b2​=a2​−b1​，以此类推。

在对 aaa 进行插入时，由于 aaa 的所有元素初始值为 0，可将插入 aia_iai​ 视为区间 [i,i]+ai[i, i] + a_i[i,i]+ai​，从而统一用下述方法构造 bbb 数组。

  • 对 bbb 数组求前缀和，可 O(n)O(n)O(n) 还原 aaa 的任意元素
  • 对 aaa 数组的 [l,r][l, r][l,r] 内每个元素 +c+c+c，O(1)O(1)O(1) 完成
    • 只需令 blb_lbl​ 加上 ccc，即可使 ala_lal​ 之后所有元素都加 ccc；再令 br+1b_{r+1}br+1​ 减去 ccc，使 ar+1a_{r+1}ar+1​ 之后的元素恢复。
#include <iostream>
using namespace std;

const int N = 100010;

int n,m;
int a[N],b[N];

void insert(int l, int r, int c);

int main(void)
{
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);

    for (int i = 1; i <= n; i++) insert(i, i, a[i]);

    while (m--)
    {
        int l, r, c;
        scanf("%d %d %d", &l, &r, &c);
        insert(l, r ,c);
    }

    for (int i = 1; i <= n; i++) b[i] += b[i - 1];

    for (int i = 1; i <= n; i++) printf("%d ", b[i]);

    return 0;
}

void insert(int l, int r, int c)
{
    b[l] += c;
    b[r+1] -= c;
}

输入一个 nnn 行 mmm 列的整数矩阵，再输入 qqq 个操作，每个操作包含五个整数 x1,y1,x2,y2,cx_{1},y_{1},x_{2},y_{2},cx1​,y1​,x2​,y2​,c，其中 (x1,y1)(x_{1},y_{1})(x1​,y1​) 和 (x2,y2)(x_{2},y_{2})(x2​,y2​) 表示一个子矩阵的左上角坐标和右下角坐标。

每个操作都要将选中的子矩阵中的每个元素的值加上 ccc。

            insert(i, j, i, j, a[i][j]);

{

    b[x2 + 1][y2 + 1] += c;
}

最长连续不重复子序列

给定一个长度为 nnn 的整数序列，请找出最长的不包含重复的数的连续区间，输出它的长度。

关键性质：当 i 向后移动时，j 要么不动，要么向后移动，绝不会向前退回。i 在 j 右边，j 是当前窗口左端能到达的最远位置。

#include <iostream>
using namespace std;

const int N = 100010;
int q[N], S[N];
int n;

int main(void)
{
    cin >> n;
    for (int i = 0; i < n; i++) scanf("%d",&q[i]);

    int res = 0;
    for (int i = 0, j = 0; i < n; i++)
    {
        S[q[i]]++;  //桶，把窗口内的数都放入
        while (S[q[i]] > 1)  //如果窗口内的数有复数个，则使去掉数
        {
            S[q[j]]--;
            j++;
        }

        res = max(res, i - j + 1);
    }

    cout << res;
    return 0;
}

数组元素的目标和

给定两个升序排序的有序数组 AAA 和 BBB，以及一个目标值 xxx。

数组下标从 0 开始。

请你求出满足 A[i]+B[j]=xA[i]+B[j]=xA[i]+B[j]=x 的数对 (i,j)(i,j)(i,j)。

数据保证有唯一解。

两个指针分别在两个数组中反向移动，设 xxx 从 AAA 数组的 0-index 开始移动，yyy 从 BBB 数组的 last-index 开始移动，如果当前：

  • A[x]+B[y]=xA[x]+B[y]=xA[x]+B[y]=x：返回结果
  • A[x]+B[y]>xA[x]+B[y]>xA[x]+B[y]>x：yyy 向前移动，减小和的值
  • A[x]+B[y]<xA[x]+B[y]<xA[x]+B[y]<x：xxx 向后移动，增大和的值
#include <iostream>
using namespace std;

#define read(X) scanf("%d",&X)  //学到的新写法

const int N = 100010;
int a[N], b[N];
int n, m, x;

int main(void)
{
    read(n), read(m), read(x);
    for (int i = 0; i < n; i++) read(a[i]);
    for (int i = 0; i < m; i++) read(b[i]);

    for (int i = 0, j = m - 1; i < n; i++)
    {
        while (j >= 0 && a[i] + b[j] > x) j--;  //j和i反向移动，防止漏判或者是j还需要返回的情况
        if (a[i] + b[j] == x) cout << i << ' ' << j << '\n';
    }

    return 0;
}

判断子序列

给定一个长度为 n 的整数序列 a1,a2,…,ana_{1},a_{2},\dots,a_{n}a1​,a2​,…,an​ 以及一个长度为 mmm 的整数序列 b1,b2,…,bmb_{1},b_{2},\dots,b_{m}b1​,b2​,…,bm​。

请你判断 aaa 序列是否为 bbb 序列的子序列。

子序列指序列的一部分项按原有次序排列而得的序列，例如序列 {a1,a3,a5}{a_{1},a_{3},a_{5}}{a1​,a3​,a5​} 是序列 {a1,a2,a3,a4,a5}{a_{1},a_{2},a_{3},a_{4},a_{5}}{a1​,a2​,a3​,a4​,a5​} 的一个子序列。

#include <iostream>
#include <cstdio>
using namespace std;
#define read(X) scanf("%d", &X)

const int N = 100010;
int a[N], b[N];

int main(void)
{
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++) read(a[i]);
    for (int i = 0; i < m; i++) read(b[i]);

    int i = 0, j = 0, count = 0;
    for (; i < n; i++)
    {
        while (j < m - 1 && a[i] != b[j]) j++;  //<m - 1确保最后一次j++时不会超出m，如果a[]最后一个数为0的话就会出错
        if (a[i] == b[j])
        {
            j++;
            count++;
        }
    }
    if (count == n) printf("Yes");
    else printf("No");

    return 0;
}

离散化

整数离散化适用于：数据只与相对大小有关，而与具体数值无关的场景。

离散化的本质是将差距悬殊的离散点映射为紧密的连续下标，从而大幅降低空间复杂度和时间复杂度，同时保持相对大小关系不变（原来 a>ba > ba>b，离散化后仍然 a>ba > ba>b，只是差距缩小）。

存在的问题

  • a[] 中可能存在重复元素 → 需要去重
  • 如何求出 xxx 离散化后的值 → 二分查找

去重
vector<int> alls;
sort(alls.begin(), alls.end()); //数组排序
alls.erase(unique(alls.begin(), alls.end()), alls.end());  //unique()将所有重复的元素放置到数组末尾，在通过erase()删除

区间和

假定有一个无限长的数轴，数轴上每个坐标上的数都是 0。

现在，我们首先进行 nnn 次操作，每次操作将某一位置 xxx 上的数加 ccc。

接下来，进行 mmm 次询问，每个询问包含两个整数 lll 和 rrr，你需要求出在区间 [l,r][l,r][l,r] 之间的所有数的和。

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

typedef pair<int, int> PII;

const int N = 300010;  //存放k，查询2k，开3k的空间

int n, m;
int a[N], s[N];

vector<int> alls;
vector<PII> add, query;  //分别存放需要加的数，和查询的范围

int find(int x)  //二分，查找数的下标
{
    int l = 0, r = alls.size() - 1;
    while (l < r)
    {
        int mid = l + r >> 1;
        if (alls[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return r + 1;
}

int main(void)
{
    cin >> n >> m;
    for (int i = 0; i < n; i++)
    {
        int x, c;
        cin >> x >> c;
        add.push_back({x, c});  //需要加的点

        alls.push_back(x);  //把这个点存入alls
    }

    for (int i = 0; i < m; i++)
    {
        int l, r;
        cin >> l >> r;
        query.push_back({l, r});  //需要查询的段

        alls.push_back(l);  //把两个端点存入alls
        alls.push_back(r);
    }

    sort(alls.begin(), alls.end());  //排序
    alls.erase(unique(alls.begin(), alls.end()), alls.end());  //删除重复项

    for (auto item : add)  //遍历add中的每个元素
    {
        int x = find(item.first);  //找到点
        a[x] += item.second;  //在对应下标存放该点加的数，注意此处是+=，可能会有点重复加
    }

    for (int i = 1; i <= alls.size(); i++) s[i] = s[i - 1] + a[i];  //用前缀和来应对查询

    for (auto item : query)  //遍历query中的每个元素
    {
        int l = find(item.first), r = find(item.second);  //找到查询端点所对应的下标
        cout << s[r] - s[l - 1] << '\n';  //获取该区间的和
    }

    return 0;
}

unique() 实现
vector<int>::iterator unique(vector<int> & a)
{
    int j = 0;
    for (int i = 0; i < a.size(); i++)  //双指针
    {
        if (!i || a[i] != a[i - 1])  //i为0或a[i]不等于a[i-1]-> ！(i!=0 && a[i] == a[i - 1])
            a[j++] = a[i];  //i == 0时为j加一
    }
    //a[0] ~ a[j - 1] 所有a中不重复的数

    return a.begin() + j;
}

区间合并

给定 nnn 个区间 [li,ri][li,ri][li,ri]，要求合并所有有交集的区间。

注意如果在端点处相交，也算有交集。

输出合并完成后的区间个数。

例如：[1,3][1,3][1,3] 和 [2,6][2,6][2,6] 可以合并为一个区间 [1,6][1,6][1,6]。

算法步骤：

  1. 按区间左端点排序
  2. 扫描整个区间，将有交集的区间合并：
    • 全包含：不做改动
    • 相交：将 ed 后移至较大右端点
    • 相离：将当前维护区间加入结果，更新至新区间
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;


typedef pair<int, int> PII;

const int N = 100010;

void merge(vector<PII> &segs)
{
    vector<PII> res;

    sort(segs.begin(), segs.end());

    int st = -2e9, ed = -2e9;
    for (auto seg : segs)
    {
        if (ed < seg.first)  //相离
        {
            if (st != -2e9) res.push_back({st, ed});
            st = seg.first, ed = seg.second;
        }
        else ed = max(ed, seg.second);  //有交集
    }

    if (st != -2e9) res.push_back({st, ed});

    segs = res;
}

int n;
vector<PII> segs;

int main(void)
{
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        int l, r;
        cin >> l >> r;
        segs.push_back({l, r});
    }

    merge(segs);

    cout << segs.size() << '\n';

    return 0;
}

#include <iostream>
using namespace std;

typedef pair<int, int> PII;

const int N = 100010;
int n;
PII q[N];

void quick_sort(int l, int r)
{
    if (l >= r) return ;

    int x = q[l + r >> 1].first, i = l - 1, j = r + 1;
    while (i < j)
    {
        do i++; while (q[i].first < x);
        do j--; while (q[j].first > x);
        if (i < j) swap(q[i], q[j]);
    }

    quick_sort(l, j), quick_sort(j + 1, r);
}

int main(void)
{
    cin >> n;
    for (int i = 0; i < n; i++) scanf("%d %d", &q[i].first, &q[i].second);

    quick_sort(0, n - 1);
    int count = 1, l = q[0].first, r = q[0].second;
    for (int i = 1; i < n; i++)
    {
        if (q[i].first > r)
        {
            l = q[i].first;
            r = q[i].second;
            count++;
        }
        else if (q[i].first >= l && q[i].second >= r)
        {
            r = q[i].second;
        }
        else if (q[i].first >= l && q[i].second < r) ;
    }

    printf("%d",count);
    return 0;
}
