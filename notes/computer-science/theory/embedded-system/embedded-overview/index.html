嵌入式系统概述

2025-10-24

#嵌入式

阅读线索

嵌入式系统以任务需求组织处理器、存储器、外设和软件。MPU、MCU、DSP、FPGA 等方案的取舍，应结合控制、计算、实时性及硬件集成方式理解。

冯诺依曼架构

核心组件

  • 数据通路
  • 控制器
  • 内存（存储器）
  • 输入
  • 输出

处理器

单板机：嵌入式微处理器（MPU）

  • 微处理器是一种功能较强大的 CPU，通常电路板上必须包括 ROM、RAM、总线接口、各种外设等。
  • 嵌入式微处理器及其存储器、总线、外设等安装在一块电路板上，称为单板计算机，如：树莓派。
  • 常见的例子有 ARM 微处理器（如 SamSung S3C2440，Freescale M21/MX 等），Intel 的 80x86 系列，Motorola 的 PowerPC、ARM Cortex-A 系列等

单片机：嵌入式微控制器（MCU）

  • CPU 是计算设备的“大脑”，是指令执行的最终核心。
    • 无论是 MCU 还是 MPU，最核心的计算部分都是一个或多个 CPU 核（如 ARM Cortex-M、Cortex-A、RISC-V 核心等）
  • MCU 是为控制和执行特定任务而设计的。
    • 它将 CPU 大脑、记忆单元（RAM 和 Flash）、以及各种输入输出接口（如 GPIO、串口、ADC 等）全部集成在一颗芯片上

SoC（System on Chip）

集成完备功能芯片

1 个强大的 SoC + 多个辅助的 MCU。

  • SoC 负责所有“高级智能”任务
  • MCU 负责“基础感知”任务

DSP：实时信号处理

  • 对系统结构和指令进行了特殊设计，使其适合于执行 DSP 算法，编译效率较高，指令执行速度也较高。在数字信号处理、图形处理、音频处理等方面应用广泛
    • 嵌入式应用场景：手机 Camera，自动驾驶汽车的摄像头

FPGA：硬件

  • 现场可编程门阵列，通过编程看改变硬件结构、实现所需功能的芯片
  • 嵌入式应用场景：军用雷达、芯片验证

GPU：图形处理器

  • GPU，即图形处理器，是一种专门设计用于高效处理与图像、图形显示相关的大量、并行计算任务的微处理器
  • 注意：GPU 是一个行业，除了英伟达，还有 AMD 的 Radeon 系列、Intel 的 Arc 系列显卡、ARM 的 Mali、苹果自研的 M 系列芯片等
  • 嵌入式应用场景：手机摄像头，自动驾驶汽车的摄像头

ASIC（Application Specified Integrated Circuit）

AI 加速器

  • NPU：嵌入在在手机、智能汽车 SoC 中，专门用于加速神经网络推理，实现照片优化、语音助手等功能

存储器

  • 处理器负责信息的改变，存储器负责信息的固化，固化下来的信息称之为数据
  • 存储器主要保存两样东西：狭义上的数据，以及程序（程序属于广义上的数据）

外设

  • 处理器负责信息的改变，存储器负责信息的固化，I/O 负责信息的传递
  • 外部外设：通过 I/O 相连的设备，简称外设
  • 内部外设：不通过 I/O 连接的外设，与处理器直接连接

软件

嵌入式系统软件决定上述硬件的运行规则

  • 基础软件：操作系统、编译器等
  • 应用软件：手机微信 APP、自动驾驶软件、控制无人机平衡的程序等

指令执行过程：

  • 编写程序
  • 解析成指令
  • 根据指令格式规则，逐条将指令的二进制电子序列存入晶体管
  • 需要运行时流入处理器电路
