#编译原理

阅读线索

词法分析把字符流识别为单词符号，并向语法分析提供种类与属性。正则表达式、有限自动机及其转换用于把识别规则落实成可执行扫描过程。

词法分析程序设计

词法分析程序和语法分析程序的接口方式

词法分析程序完成的是编译第一阶段的工作，可以有以下方法：

  • 独立的一遍，把字符流的源程序变成单词序列，输出到一个中间文件，这个文件作为语法分析程序的输入而继续编译过程
  • 词法分析程序每得到一次调用，就从源程序文件中读入一些字符，直到识别出一个单词，或者直到下一个单词的第一个字符为止（可以节省中间文件或存储区）

词法分析程序输出

当语法分析程序接收到下一个单词的请求时，词法分析程序从左到右读入源程序的字符流，以识别下一个单词。

识别出下一个单词后，以单词符号的形式返回；若发现词法错误则返回出错信息。

单词分类

  • 关键字/保留字
  • 标识符
  • 常数
  • 运算符
  • 界符

表达形式

使用二元式表示：

(单词种类, 单词值) (\text{单词种类},\ \text{单词值}) (单词种类, 单词值)

对于标识符，还需要记录类别、层次等属性，通常设计成：

(标识符, 指向标识符在符号表中位置的指针) (\text{标识符},\ \text{指向标识符在符号表中位置的指针}) (标识符, 指向标识符在符号表中位置的指针)

为什么拆分词法分析和语法分析

  1. 使编译程序的结构更简洁
  2. 提高编译程序的效率
  3. 增强编译程序的可移植性

识别单词的描述工具

  • 状态转换图
  • 扩展巴克斯范式（EBNF）
  • 有限状态自动机
  • 正规表达式
  • 正规文法

几乎任何一种有意义的单词种别对应的单词集合都是正规语言。

词法分析中的常见问题

关键字与标识符的冲突

问题：if、while 等关键字和标识符都满足“字母开头，后跟字母或数字”的模式，如何区分？

解决方案：先识别为标识符，再查表判断是否为关键字。

  • 最佳实践：用哈希表存储关键字，查找时间 O(1)O(1)O(1)。

向前看（Lookahead）

某些单词的识别需要“向前看”一个或多个字符。

示例：C 语言中 ++、+=、+ 的识别——读到 + 时，需要看下一个字符才能确定是哪种单词。

回退（Retract）：记录当前位置，读入下一字符判断，若不匹配则回退到记录位置。

最长匹配原则

词法分析采用最长匹配（Maximal Munch）原则：总是匹配尽可能长的单词。

例如：ifx 应识别为标识符 ifx，而不是关键字 if + 标识符 x。

实现：记录最后一次到达终止状态的位置，继续尝试匹配，最后回退到该位置。

单词的形式化描述工具

正则文法

正则文法（Regular Grammar）属于 3 型文法，分为右线性文法和左线性文法：

右线性文法：产生式形如 A→aBA\rightarrow aBA→aB 或 A→aA\rightarrow aA→a

左线性文法：产生式形如 A→BaA\rightarrow BaA→Ba 或 A→aA\rightarrow aA→a

特点：

  • 只能线性展开，不能嵌套递归
  • 右线性和左线性等价，生成同样的语言
  • 正则文法生成的语言称为正规语言（Regular Language）

描述标识符的右线性文法：

A→letter A ∣ digit AA→letter \begin{aligned} A&\rightarrow \text{letter}\ A\ |\ \text{digit}\ A \\ A&\rightarrow \text{letter} \end{aligned} AA​→letter A ∣ digit A→letter​

有限自动机

有限自动机（Finite Automaton，FA）是识别正规语言的抽象计算模型，也是词法分析器的理论基础。

定义

有限自动机是一个五元组 M=(Q,Σ,δ,q0,F)M=(Q,\Sigma,\delta,q_0,F)M=(Q,Σ,δ,q0​,F)：

  • QQQ：有限的状态集合
  • Σ\SigmaΣ：有限的输入符号字母表
  • δ\deltaδ：状态转换函数
  • q0∈Qq_0\in Qq0​∈Q：初始状态
  • F⊆QF\subseteq QF⊆Q：终止状态集合（接受状态）

确定有限自动机（DFA）

特点：

  • 对于任意状态 qqq 和输入符号 aaa，恰好有一个转换 δ(q,a)=p\delta(q,a)=pδ(q,a)=p
  • 不存在 ε\varepsilonε 转换

状态转换函数：δ:Q×Σ→Q\delta:Q\times\Sigma\rightarrow Qδ:Q×Σ→Q

工作过程：从 q0q_0q0​ 开始，逐字符转换，读完后若处于 FFF 中则接受，否则拒绝。

非确定有限自动机（NFA）

特点：

  • 对于某状态 qqq 和输入符号 aaa，可能有多个转换
  • 可能存在 ε\varepsilonε 转换（不读入任何符号就转换状态）

状态转换函数：δ:Q×(Σ∪{ε})→2Q\delta:Q\times(\Sigma\cup{\varepsilon})\rightarrow 2^Qδ:Q×(Σ∪{ε})→2Q（返回状态集合）

接受条件：只要存在一条路径能读完输入串且终止于 FFF 中的状态，就接受。

DFA 与 NFA 的关系

定理：对于任何 NFA，都存在一个等价的 DFA（接受相同的语言）。

实践意义：

  • NFA 更容易从正规表达式构造（结构直观）
  • DFA 更容易实现（执行效率高，每步状态唯一）

Thompson 构造法：正规表达式 → NFA

Thompson 构造法将任何正规表达式系统地转换为等价的 NFA。

基本规则

  1. 空串 ε\varepsilonε：→(i)→ε((f))\rightarrow(i) \xrightarrow{\varepsilon} ((f))→(i)ε​((f))

  2. 单个符号 aaa：→(i)→a((f))\rightarrow(i) \xrightarrow{a} ((f))→(i)a​((f))

归纳规则

假设 N(r)N(r)N(r) 和 N(s)N(s)N(s) 分别是正规表达式 rrr 和 sss 对应的 NFA：

1. 并（选择）r∣sr|sr∣s：

2. 连接 rsrsrs：

将 N(r)N(r)N(r) 的终止状态通过 ε\varepsilonε 连接到 N(s)N(s)N(s) 的初始状态。

子集构造法：NFA → DFA

子集构造法（Subset Construction / 幂集构造法）将 NFA 转换为等价的 DFA。

核心思想

让 DFA 的一个状态对应 NFA 的一个状态集合，从而消除不确定性。

关键概念

ε\varepsilonε-闭包（ε\varepsilonε-closure）

状态 sss 的 ε\varepsilonε-闭包：从 sss 出发，只通过 ε\varepsilonε 转换能到达的所有状态的集合（包含 sss 本身）。

ε-closure(T)=⋃s∈Tε-closure(s) \varepsilon\text{-closure}(T)=\bigcup_{s\in T}\varepsilon\text{-closure}(s) ε-closure(T)=s∈T⋃​ε-closure(s)

move 操作

move(T,a)=⋃s∈T{t ∣ s→at} \text{move}(T,a)=\bigcup_{s\in T}\{t\ |\ s\xrightarrow{a}t\} move(T,a)=s∈T⋃​{t ∣ sa​t}

从状态集合 TTT 中，读入符号 aaa 后能到达的所有状态集合。

子集构造算法

初始化：
    q₀_D = ε-closure({q₀})
    Q_D  = {q₀_D}
    WorkList = {q₀_D}

while WorkList 非空：
    T = WorkList.pop()
    for each 输入符号 a ∈ Σ：
        U = ε-closure(move(T, a))
        if U 非空：
            δ_D(T, a) = U
            if U ∉ Q_D：
                Q_D.add(U)
                WorkList.add(U)

F_D = {T | T ∈ Q_D 且 T ∩ F_N ≠ ∅}

DFA 的最小化

经过子集构造得到的 DFA 可能包含冗余状态，最小化算法通过合并等价状态得到状态数最少的等价 DFA。

等价状态与可区分状态

两个状态 ppp 和 qqq 等价，当且仅当：对于任意输入串 www，从 ppp 和 qqq 出发要么都接受，要么都拒绝。

反过来，ppp 和 qqq 可区分，当且仅当：存在某个输入串 www，使得从 ppp 出发接受而从 qqq 出发拒绝（或反之）。

最简判断：终止状态和非终止状态天然可区分——任何空串 ε\varepsilonε 就能区分它们。

最小化步骤（考试标准写法）

第一步：初始划分

将所有状态分为两组：

Π0={F, Q∖F} \Pi_0 = \{F,\ Q \setminus F\} Π0​={F, Q∖F}

即终止状态集 FFF 一组，非终止状态集 Q∖FQ \setminus FQ∖F 一组。

第二步：逐轮细分

对当前划分 Π\PiΠ 中的每一个分组 GGG，检查每个输入符号 aaa：

  • 对 GGG 中所有状态，查看读入 aaa 后转移到哪个分组
  • 如果 GGG 中的状态转移到了不同的分组，则将 GGG 按转移目标分组拆分

重复此过程，直到划分不再变化（达到不动点）。

判断是否需要拆分：同一组内的状态，对同一输入 aaa，必须全部转移到同一个分组内，才不需要拆分。只要有一个状态“去向不同”，就要拆。

第三步：构造最小 DFA

  • 每个最终的分组合并为一个状态
  • 新状态之间的转移：若原状态 p∈Gip \in G_ip∈Gi​ 读入 aaa 转到 q∈Gjq \in G_jq∈Gj​，则新状态 GiG_iGi​ 读入 aaa 转到 GjG_jGj​
  • 包含原初始状态的分组为新初始状态
  • 包含原终止状态的分组为新终止状态

对输入 aaa：A→B、B→B、C→B，全转到 {A,B,C}{A,B,C}{A,B,C} 内 ✓

对输入 bbb：A→C、C→C，转到 {A,B,C}{A,B,C}{A,B,C} 内；但 B→D，转到了 {D}{D}{D}

→ BBB 和 AAA、CCC 去向不同，拆分：

Π2={{A,C}, {B}, {D}, {E}} \Pi_2 = \{\{A,C\},\ \{B\},\ \{D\},\ \{E\}\} Π2​={{A,C}, {B}, {D}, {E}}

第二步第 3 轮：检查分组 {A,C}{A,C}{A,C}

对输入 aaa：A→B、C→B，全转到 {B}{B}{B} ✓

对输入 bbb：A→C、C→C，全转到 {A,C}{A,C}{A,C} 内 ✓

→ {A,C}{A,C}{A,C} 不需要拆分。其他分组均为单元素，也无需拆分。

Πfinal={{A,C}, {B}, {D}, {E}} \Pi_{\text{final}} = \{\{A,C\},\ \{B\},\ \{D\},\ \{E\}\} Πfinal​={{A,C}, {B}, {D}, {E}}

第三步：构造最小 DFA

用分组名替代原状态（令 [AC]={A,C}[AC]={A,C}[AC]={A,C}）：

状态 输入 aaa 输入 bbb
[AC][AC][AC]（初始） [B][B][B] [AC][AC][AC]
[B][B][B] [B][B][B] [D][D][D]
[D][D][D] [B][B][B] [E][E][E]
[E][E][E]（终止） [B][B][B] [AC][AC][AC]

原 5 个状态 → 最小 DFA 4 个状态（AAA 和 CCC 合并）。

最小化的意义

  • 减少状态数：更小的状态转换表，节省内存
  • 提高效率：词法分析器运行更快
  • 唯一性：对于给定语言，最小 DFA 在同构意义下唯一

状态转换图

状态转换图（State Transition Diagram）是有限自动机的图形化表示，也是实现词法分析器的直观工具。

组成元素

  • 圆圈：状态
  • 带入箭头的圆圈：初始状态
  • 双圆圈：终止状态（接受状态）
  • 带标记的箭头：读入某符号后的状态转换

示例：识别标识符

          letter|digit
         ┌──────────┐
         ↓          │
→(start) ─letter→ ((id))
  • start → 读入字母 → id（终止状态）
  • id → 读入字母或数字 → 保持 id
  • 读入其他字符：停止，识别成功

从状态转换图到代码

状态转换图可以直接翻译为 switch-case 结构的程序，每个状态对应一个 case 分支。

多单词类型的状态转换图

实际词法分析器将所有单词类型的状态转换图合并为一个，不同路径识别不同种类的单词：

          digit
        ┌──────┐
        ↓      │
→(start) ─digit→ ((number))
    │
    letter
    ↓
   (A) ─letter|digit→ ((id))

总结

概念 要点
正规文法 3 型文法，只能线性展开，对应正规语言
正规表达式 用 ∣
NFA 允许多条转换路径和 ε\varepsilonε 转换，构造简单
DFA 每步状态唯一，执行高效，由 NFA 子集构造得到
Thompson 构造 正规表达式 → NFA，递归构造
子集构造 NFA → DFA，DFA 状态 = NFA 状态集合
DFA 最小化 合并等价状态，得到最小等价 DFA
三者等价 正规文法 ⟺ 正规表达式 ⟺ 有限自动机
