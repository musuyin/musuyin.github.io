#计算机系统结构

阅读线索

计算机算术在固定字宽中实现整数和浮点运算。移位加法解释乘法的基本过程，浮点格式则把符号、指数和有效数分开编码；溢出行为取决于指令集规定。

Arithmetic Logic Unit (ALU)

The ALU executes all arithmetic and logical operations defined by the ISA:

  • Arithmetic: add, sub, mul, div
  • Logical: and, or, xor, shifts (sll, srl)
  • Comparisons: Used in branch instructions like beq, bne, blt, bge

Overflow Detection

  • Overflow occurs when the result of an operation cannot be represented within the fixed bit-width (e.g., 64 bits).
  • RISC-V 的基础整数加减法（如 add、addi、sub）不会因为算术溢出触发异常，结果保留低 XLEN 位。需要检测有符号溢出时，由软件另行比较或分支处理。RISC-V 整数指令规范

Multiplication

  • Implemented via shifts and adds (binary long multiplication).
  • RISC-V provides multiple multiply instructions:
    • mul: lower 64 bits of the product
    • mulh: upper 64 bits (both operands signed)
    • mulhu: upper bits (both unsigned)
    • mulhsu: one signed, one unsigned
  • Overflow check: If mulh ≠ 0 (for positive operands), 64-bit overflow likely occurred.

Division

  • Implemented via repeated subtraction and left shifts.
  • Instructions:
    • div, rem: signed division and remainder
    • divu, remu: unsigned versions
  • No exceptions are raised for:
    • Division by zero → returns a defined (but meaningless) value
    • Overflow → software must validate results

Formats

Precision Sign Exponent Fraction Bias
Single 1 8 23 127
Double 1 11 52 1023
  • Hidden bit: The leading ‘1’ in normalized numbers is implicit (not stored), increasing precision.
  • Special values:
    • ±0: exponent = 0, fraction = 0
    • Denormalized: exponent = 0, fraction ≠ 0 (for gradual underflow)
    • ±∞: exponent = all 1s, fraction = 0
    • NaN: exponent = all 1s, fraction ≠ 0 (e.g., result of 0/0)

IEEE 754-2008 contains a half precision that is only 16 bits wide. The left most bit is still the sign bit, the exponent is 5 bits wide and has a bias of 15, and the mantissa is 10 bits long. A hidden 1 is assumed.

Addition/Subtraction

  1. Restore hidden bits in both operands.
  2. Align exponents by shifting the smaller operand’s fraction right.
  3. Add/subtract fractions.
  4. Normalize result (adjust exponent so fraction∈[1,2)fraction \in [1, 2)fraction∈[1,2)).
  5. Round using Guard (G), Round (R), and Sticky (S) bits.
  6. Re-hide the leading 1 before storing.

Multiplication

  1. Add biased exponents and subtract bias.
  2. Multiply fractions → double-width result.
  3. Normalize (may require 1-bit right shift).
  4. Round and re-hide leading bit.
