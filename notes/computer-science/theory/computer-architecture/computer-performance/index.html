性能比较必须先统一工作负载与计时口径。CPU 时间由指令数、平均 CPI 和周期时间共同决定，时钟频率只是其中一个因素。

Performance

Define.

Performance=1Execution Time\text{Performance}=\frac{1}{\text{Execution Time}}Performance=Execution Time1​

PerformancexPerformancey=Execution TimeyExecution Timex=n\frac{\text{Performance}_{x}}{\text{Performance}_{y}}=\frac{\text{Execution Time}_{y}}{\text{Execution Time}_{x}}=nPerformancey​Performancex​​=Execution Timex​Execution Timey​​=n

Measuring Execution Time

  • Elapsed time
    • Total response time, including all aspects
      • Processing, I/O, OS overhread, idle time
    • Determines system performance
  • CPU time
    • Time spent processing a given job
      • Discounts I/O time, other jobs’ shares
    • Comprises user CPU time and system CPU time
    • Different programs are affected differently by CPU and system performance

CPU Clocking

Operation of digital hardware governed by a constant-rate clock.

  • Clock period: Clock Cycle Time
  • Clock frequency: Clock Rate

CPU Time

CPU Time=CPU Clock Cycles×Clock Cycle Time=CPU Clock CyclesClock Rate\text{CPU\ Time} =\text{CPU Clock\ Cycles} \times \text{Clock\ Cycle\ Time} =\frac{\text{CPU Clock\ Cycles}}{\text{Clock\ Rate}}CPU Time=CPU Clock Cycles×Clock Cycle Time=Clock RateCPU Clock Cycles​
  • CPU Clock Cycles：所有指令所需时钟周期数量
  • Clock Cycle Time：一个时钟周期时间
  • Clock Rate：时钟频率

其中：Clock Cylce Time=1Clock Rate\text{Clock Cylce Time} = \frac{1}{\text{Clock Rate}}Clock Cylce Time=Clock Rate1​

  • Reducing CPU clock cycles
  • Increasing clock rate

CPI

CPI: Cycles Per Instruction

CPU Clock Cycles=Instruction Count×CPI\text{CPU Clock\ Cycles}=\text{Instruction\ Count} \times \text{CPI}CPU Clock Cycles=Instruction Count×CPI
CPU Time=Instrcution Count×CPI×Clock Cycle Time=Instrcution Count×CPIClock Cycle Time\text{CPU Time}=\text{Instrcution Count}\times\text{CPI}\times\text{Clock Cycle Time} =\frac{\text{Instrcution Count}\times\text{CPI}}{\text{Clock Cycle Time}}CPU Time=Instrcution Count×CPI×Clock Cycle Time=Clock Cycle TimeInstrcution Count×CPI​
  • Instruction Count（IC）：指令条数，determined by program, ISA and compiler
  • CPI（Cycles Per Instruction）：每条指令平均所需时钟周期数量，determined by CPU hardware

ISA：指令集架构

If different instrcution classes take different numbers of cycles:
