OpenFeign

2025-10-07

#后端#Java#SpringCloud#微服务#OpenFeign

OpenFeign 将 HTTP 远程调用描述为 Java 接口。服务名调用还需服务发现与负载均衡依赖配合；连接超时、读取超时、重试与 fallback 都需要按照失败语义配置。

原先实现的是编程式 REST 客户端，需要手动获取地址，负载均衡，发送请求，接收响应

使用 @FeignClient 注解，指定远程调用的服务名称，会自动连接注册中心，完成服务发现

客户端负载均衡和服务端负载均衡

  • 客户端负载均衡：调用时挑选一个去访问
  • 服务端负载均衡：被请求时，选择一个服务转发

调用注册中心服务

导入依赖

<!--openfeign-->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>

启动类添加注解

// 开启Feign远程调用功能
@EnableFeignClients("com.github.musuyin.order.feign")
// 开启服务发现功能
@EnableDiscoveryClient
@SpringBootApplication
public class ServiceOrderApplication {}

FeignClient 接口实现

MVC @GetMapping / PostMapping 等注解：

  1. 在 controller 中，表示接收请求的路径。参数是从 mapping 映射到方法上
  2. 在 feign client 中，表示发送请求的路径。参数是从方法映射到 mapping 上
// feign客户端标志, value填写要发送目的地服务名
@FeignClient(value = "service-product")
public interface ProductFeignClient {
    // RequestMapping, 在controller上表示接收路径, 在feignClient上表示发送路径
    @GetMapping("/product/{id}")
    Product getProductNameById(@PathVariable("id") Long id);
}

Service 调用

@Override
public Order createOrder(Long userId, Long productId) {
    Order order = new Order();
    order.setUserId(userId);
    order.setNickName("Musuyin");
    order.setAddress("Home");
    // 需要远程调用来获取
    // 使用feign client进行远程调用
    Product product = productFeignClient.getProductNameById(productId);
    // Product product = getProductFromRemote(productId);
    order.setTotalAmount(product.getPrice().multiply(new BigDecimal(product.getNum())));
    order.setProductList(Arrays.asList(product));

    return order;
}

feign client 自带负载均衡

调用第三方网址

区别在于可以直接获取调用地址，不需要去注册中心发现

接口定义

调用第三方接口，value 可以任意指定

@FeignClient(value = "weather-client", url = "http://aliv18.data.moji.com")
public interface WeatherFeignClient {
    @PostMapping("/whapi/json/alicityweather/condition")
    String getWeather(@RequestHeader("Authorization") String auth, @RequestParam("token") String token, @RequestParam("cityId") String cityId);
}

日志

  • 配置文件：设置包下输出日志的级别（这个配置不是 OpenFeign 独有的，对于其他的模块也可以设置）
  • 在 OrderConfig 中设置日志记录组件：这里的 Logger.Level 是 feign 包下的
logging:
  level:
    com.github.musuyin.order.feign: debug
@Configuration
public class OrderServiceConfig {

	@Bean
	public Logger.Level feignLoggerLevel() {
	    return Logger.Level.FULL;
	}
}

Logger.Level.FULL  代表打印所有请求和响应的详细信息：

  • 请求方法（GET、POST 等）
  • 请求 URL
  • 请求头
  • 请求体
  • 响应状态码
  • 响应头
  • 响应体
  • 请求的执行时间

超时控制

如果不设置限时等待，大量请求可能堆积在服务端，耗尽服务器资源，导致服务雪崩

超时类型

  • 连接超时：连接建立的超时时间
  • 读取超时：发送请求、远程服务处理业务并返回数据的时间

设置超时时间

引入配置

为了更好地模块化管理，单独将 OpenFeign 的配置抽出为 application-feign.yaml，并在 application.yaml 引入 application-feign.yaml

application-feign.yaml:

spring:
  cloud:
    openfeign:
      client:
        config:
          # 默认设置
          default:
            logger-level: full
            connect-timeout: 1000
            read-timeout: 2000
          service-product:
            logger-level: full
            connect-timeout: 3000
            read-timeout: 5000

application.yaml:

spring:
  profiles:
    # 指定激活的配置环境
    active: dev
    # 引入application-feign.yaml
    include: feign

重试

远程调用超时失败后，还可以进行多次尝试，如果某次成功返回则结束调用，如果多次依然失败则结束调用，返回错误

默认是 NEVER_RETRY 模式

添加重试机制

配置文件添加

添加默认重试器：初始超时时间 100ms，每次为前一次的 1.5 倍，最大间隔 1s，最多尝试 5 次

添加在 application-feign.yaml

spring:
  cloud:
    openfeign:
      client:
        config:
          service-product:
            logger-level: full
            connect-timeout: 3000
            read-timeout: 5000
            retryer: feign.retryer.Default

组件注入

自行定义一个 Retryer，自定义参数配置，如果不传入参数，则使用默认配置

(初始超时间隔, 最大超时间隔, 最大重试次数)

@Configuration
public class OrderServiceConfig {

    @Bean
    public Retryer retryer() {
        // new Retryer.Default()
        return new Retryer.Default(1000, 10000, 5);
    }
}

拦截器

一般都是用请求拦截器，响应拦截器的使用比较少

请求拦截器

拦截所有调用的请求

拦截器编写

public class XTokenRequestInterceptor implements RequestInterceptor {
    @Override
    public void apply(RequestTemplate requestTemplate) {
        requestTemplate.header("X-Token", UUID.randomUUID().toString());
    }
}

拦截器启动

配置文件启动

仅对当前配置的客户端生效

spring:
  cloud:
    openfeign:
      client:
        config:
          service-product:
            logger-level: full
            connect-timeout: 3000
            read-timeout: 5000
            request-interceptors:
              - com.github.musuyin.order.interceptor.XTokenRequestInterceptor

组件注入

为拦截器添加 @Component，就会自动使用

@Component
public class XTokenRequestInterceptor implements RequestInterceptor {
    @Override
    public void apply(RequestTemplate requestTemplate) {
        requestTemplate.header("X-Token", UUID.randomUUID().toString());
    }
}

Fallback 兜底返回

使用

导入依赖

<!--sentinel-->
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-sentinel</artifactId>
</dependency>

开启熔断

spring:
  cloud:
    openfeign:
      client:
        config:
          service-product:
            logger-level: full
            connect-timeout: 3000
            read-timeout: 5000
            request-interceptors:
              - com.github.musuyin.order.interceptor.XTokenRequestInterceptor

feign:
  sentinel:
    enabled: true

加入回调实现

注意要加入容器

@Component
public class ProductFeignClientFallback implements ProductFeignClient {
    @Override
    public Product getProductNameById(Long id) {
        System.out.println("远程调用失败-执行兜底回调");
        Product product = new Product();
        product.setId(id);
        return product;
    }
}

关联回调函数

用 fallback 指定兜底回调

// feign客户端标志, value填写要发送目的地服务名
@FeignClient(value = "service-product", fallback = ProductFeignClientFallback.class)
public interface ProductFeignClient {
    // RequestMapping, 在controller上表示接收路径, 在feignClient上表示发送路径
    @GetMapping("/product/{id}")
    Product getProductNameById(@PathVariable("id") Long id);
}
