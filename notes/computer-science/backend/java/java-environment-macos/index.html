Java 环境配置（macOS）

2026-06-10

#Java#环境配置#Homebrew

本篇针对 macOS 上 Homebrew 与 zsh 的 Java 版本配置。先定位 JDK 的 Home 目录，再调整当前终端或 shell 启动配置，最后同时检查 java、javac 与 Maven 实际使用的版本。

Java 路径

Homebrew 安装的 Java 路径规律：

/opt/homebrew/opt/openjdk@{version}/libexec/openjdk.jdk/Contents/Home
版本 路径
Java 17 /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
Java 21 /opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
最新版（无后缀） /opt/homebrew/Cellar/openjdk/{version}/libexec/openjdk.jdk/Contents/Home

带版本号后缀（openjdk@17）装在 /opt/homebrew/opt/ 下； 不带版本号的最新版装在 /opt/homebrew/Cellar/openjdk/ 下。

切换 Java 版本

Maven 启动脚本通常读取 JAVA_HOME；终端 java 命令由 PATH 解析，因此切换后还需核对 PATH 与 java -version。

临时切换（当前终端生效）

export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"

永久切换（写入 ~/.zshrc）

echo 'export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home' >> ~/.zshrc
echo 'export PATH="$JAVA_HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

验证

echo $JAVA_HOME   # 确认路径正确
java -version     # 确认 java 版本
mvn -version      # 确认 mvn 用的 java 版本（Java home 那行）

安装指定版本

brew install openjdk@17

注意事项

  • mvn 不单独管理 java 路径，直接跟随 JAVA_HOME
  • 如果 JAVA_HOME 为空，mvn 会回退到自己找到的 java（通常是最新版）
  • 需要频繁切换多版本可以使用 jenv 管理

复习

  • JAVA_HOME 与 PATH 指向不同 JDK 时为什么可能出现版本不一致？
  • 临时 export 与写入 .zshrc 的作用范围有什么不同？
