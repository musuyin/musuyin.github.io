建造者模式（Builder Pattern）

2026-08-24

#设计模式#创建型

建造者将分步配置与最终创建集中起来，适合可选参数多或参数间有约束的对象。阅读电脑配置示例时，沿着“必需参数 → 默认值 → 链式配置 → build 校验”追踪对象如何成为可用状态。

定义

建造者模式将一个复杂对象的构建过程与其表示分离，使得同样的构建步骤可以产生不同的表示。它通过链式调用逐步构建对象，最后调用 build() 完成构造。

问题场景

假设要创建一个 Computer 类，包含多个组件配置：

// ❌ 问题方案 1：多个构造器（构造器爆炸）
public class Computer {
    private String cpu;
    private String ram;
    private String gpu;
    private String storage;
    private String motherboard;
    private String powerSupply;
    private boolean wifi;
    private boolean bluetooth;
    // ...
    
    public Computer(String cpu, String ram, String gpu) { ... }
    public Computer(String cpu, String ram, String gpu, String storage) { ... }
    public Computer(String cpu, String ram, String gpu, String storage, String motherboard) { ... }
    // ... 更多构造器
}

问题：

  • 构造器数量爆炸（n 个参数有 2^n 种组合）
  • 参数顺序容易混淆
  • 可读性差
  • 许多参数是可选的
// ❌ 问题方案 2：JavaBean 模式（可能对象不完整）
public class Computer {
    private String cpu;
    private String ram;
    // ...
    
    public void setCpu(String cpu) { this.cpu = cpu; }
    public void setRam(String ram) { this.ram = ram; }
    // ...
}

Computer computer = new Computer();
computer.setCpu("i9");
computer.setRam("32GB");
// 如果忘记设置某个属性，对象可能不完整

解决方案

标准建造者模式

// 1. 定义目标类
public class Computer {
    private String cpu;
    private String ram;
    private String gpu;
    private String storage;
    private String motherboard;
    private String powerSupply;
    private boolean wifi;
    private boolean bluetooth;
    
    // 私有构造器，只能通过 Builder 创建
    private Computer(Builder builder) {
        this.cpu = builder.cpu;
        this.ram = builder.ram;
        this.gpu = builder.gpu;
        this.storage = builder.storage;
        this.motherboard = builder.motherboard;
        this.powerSupply = builder.powerSupply;
        this.wifi = builder.wifi;
        this.bluetooth = builder.bluetooth;
    }
    
    @Override
    public String toString() {
        return "Computer{" +
                "cpu='" + cpu + '\'' +
                ", ram='" + ram + '\'' +
                ", gpu='" + gpu + '\'' +
                ", storage='" + storage + '\'' +
                ", motherboard='" + motherboard + '\'' +
                ", powerSupply='" + powerSupply + '\'' +
                ", wifi=" + wifi +
                ", bluetooth=" + bluetooth +
                '}';
    }
    
    // 2. 定义静态 Builder 类
    public static class Builder {
        // 必需参数
        private final String cpu;
        private final String ram;
        
        // 可选参数
        private String gpu = "集成显卡";
        private String storage = "256GB SSD";
        private String motherboard = "B660";
        private String powerSupply = "500W";
        private boolean wifi = false;
        private boolean bluetooth = false;
        
        // Builder 构造器（只需要必需参数）
        public Builder(String cpu, String ram) {
            this.cpu = cpu;
            this.ram = ram;
        }
        
        // 链式调用设置可选参数
        public Builder gpu(String gpu) {
            this.gpu = gpu;
            return this;
        }
        
        public Builder storage(String storage) {
            this.storage = storage;
            return this;
        }
        
        public Builder motherboard(String motherboard) {
            this.motherboard = motherboard;
            return this;
        }
        
        public Builder powerSupply(String powerSupply) {
            this.powerSupply = powerSupply;
            return this;
        }
        
        public Builder wifi(boolean wifi) {
            this.wifi = wifi;
            return this;
        }
        
        public Builder bluetooth(boolean bluetooth) {
            this.bluetooth = bluetooth;
            return this;
        }
        
        // 最后调用 build() 返回完整对象
        public Computer build() {
            return new Computer(this);
        }
    }
}

客户端使用

// 创建基础配置的电脑
Computer computer1 = new Computer.Builder("i9", "32GB")
    .build();

// 创建高配游戏电脑
Computer computer2 = new Computer.Builder("i9", "32GB")
    .gpu("RTX 4090")
    .storage("2TB SSD")
    .powerSupply("1000W")
    .wifi(true)
    .bluetooth(true)
    .build();

// 创建办公电脑
Computer computer3 = new Computer.Builder("i5", "16GB")
    .storage("512GB SSD")
    .wifi(true)
    .build();

System.out.println(computer1);
System.out.println(computer2);
System.out.println(computer3);

输出：

Computer{cpu='i9', ram='32GB', gpu='集成显卡', storage='256GB SSD', motherboard='B660', powerSupply='500W', wifi=false, bluetooth=false}
Computer{cpu='i9', ram='32GB', gpu='RTX 4090', storage='2TB SSD', motherboard='B660', powerSupply='1000W', wifi=true, bluetooth=true}
Computer{cpu='i5', ram='16GB', gpu='集成显卡', storage='512GB SSD', motherboard='B660', powerSupply='500W', wifi=true, bluetooth=false}

变体：分离 Builder 类

当 Builder 逻辑复杂时，可以分离到单独的类：

public class Computer {
    private String cpu;
    private String ram;
    // ... 其他字段
    
    private Computer(ComputerBuilder builder) {
        this.cpu = builder.cpu;
        this.ram = builder.ram;
        // ...
    }
    
    public static ComputerBuilder builder() {
        return new ComputerBuilder();
    }
}

// 分离的 Builder 类
public class ComputerBuilder {
    private String cpu;
    private String ram;
    private String gpu = "集成显卡";
    private String storage = "256GB SSD";
    
    public ComputerBuilder cpu(String cpu) {
        this.cpu = cpu;
        return this;
    }
    
    public ComputerBuilder ram(String ram) {
        this.ram = ram;
        return this;
    }
    
    public ComputerBuilder gpu(String gpu) {
        this.gpu = gpu;
        return this;
    }
    
    public ComputerBuilder storage(String storage) {
        this.storage = storage;
        return this;
    }
    
    public Computer build() {
        return new Computer(this);
    }
}

// 使用
Computer computer = Computer.builder()
    .cpu("i9")
    .ram("32GB")
    .gpu("RTX 4090")
    .build();

变体：建造者导演（Director）

当构建过程复杂且有多种固定步骤时：

// 导演类 - 封装构建步骤
public class ComputerDirector {
    private ComputerBuilder builder;
    
    public ComputerDirector(ComputerBuilder builder) {
        this.builder = builder;
    }
    
    // 构建办公电脑
    public Computer buildOfficeComputer() {
        return builder
            .cpu("i5")
            .ram("16GB")
            .storage("512GB SSD")
            .wifi(true)
            .build();
    }
    
    // 构建游戏电脑
    public Computer buildGamingComputer() {
        return builder
            .cpu("i9")
            .ram("32GB")
            .gpu("RTX 4090")
            .storage("2TB SSD")
            .powerSupply("1000W")
            .build();
    }
    
    // 构建服务器
    public Computer buildServer() {
        return builder
            .cpu("Xeon")
            .ram("128GB")
            .storage("4TB SSD")
            .motherboard("E-ATX")
            .powerSupply("2000W")
            .build();
    }
}

// 使用
ComputerBuilder builder = new ComputerBuilder();
ComputerDirector director = new ComputerDirector(builder);

Computer officePC = director.buildOfficeComputer();
Computer gamingPC = director.buildGamingComputer();
Computer server = director.buildServer();

真实应用案例

StringBuilder（Java 标准库）

// Java 本身的 StringBuilder 就是建造者模式
StringBuilder sb = new StringBuilder()
    .append("Hello")
    .append(" ")
    .append("World")
    .append("!");

String result = sb.toString();
System.out.println(result);  // Hello World!

SQL 查询构建

public class SQLBuilder {
    private StringBuilder sql = new StringBuilder();
    
    public SQLBuilder select(String... columns) {
        sql.append("SELECT ");
        sql.append(String.join(", ", columns));
        return this;
    }
    
    public SQLBuilder from(String table) {
        sql.append(" FROM ").append(table);
        return this;
    }
    
    public SQLBuilder where(String condition) {
        sql.append(" WHERE ").append(condition);
        return this;
    }
    
    public SQLBuilder orderBy(String column) {
        sql.append(" ORDER BY ").append(column);
        return this;
    }
    
    public String build() {
        return sql.toString();
    }
}

// 使用
String query = new SQLBuilder()
    .select("id", "name", "email")
    .from("users")
    .where("age > 18")
    .orderBy("id DESC")
    .build();

System.out.println(query);
// SELECT id, name, email FROM users WHERE age > 18 ORDER BY id DESC

优缺点分析

优点 ✅

  1. 清晰可读：链式调用自解释，参数清楚明了
  2. 灵活配置：支持可选参数，组合灵活
  3. 可配合不可变对象：需由产品类的字段、访问器与防御性复制共同保证；build() 本身不保证不可变
  4. 参数校验：可在 build() 时进行完整性检查
  5. 易于维护：新增字段只需在 Builder 中添加

缺点 ❌

  1. 代码冗长：需要编写大量样板代码
  2. 内存开销：创建 Builder 对象额外占用内存
  3. 额外对象与调用：是否构成可观成本取决于逃逸分析、分配频率和实际测量
  4. 学习曲线：初学者可能难以理解

何时使用

✅ 适合使用：

  • 对象有很多可选参数（3 个以上）
  • 参数之间有依赖关系，需要校验
  • 对象是不可变的（immutable）
  • 需要多种配置组合
  • 参数含义不明显

❌ 不适合使用：

  • 参数很少（1-2 个）
  • 所有参数都必须
  • 参数不需要校验
  • 性能关键的场景

与其他模式的区别

模式 目标 适用场景
建造者 构建复杂对象 参数多、配置复杂
工厂 创建对象实例 创建逻辑简单
原型 复制对象 对象创建成本高
单例 唯一实例 全局共享状态

Lombok 简化方案

采用 Lombok 的项目可减少样板代码；下面的 @Data 会生成 setter，因此该例不保证不可变：

@Builder
@Data
public class House {
    private String address;
    private int rooms;
    private int bathrooms;
    private String garage;
    private double price;
}

// Lombok 自动生成 Builder 内部类和方法
House house = House.builder()
    .address("123 Main St")
    .rooms(4)
    .bathrooms(2)
    .garage("2-car")
    .price(500000)
    .build();

实现技巧

参数校验

public Computer build() {
    if (cpu == null || cpu.isEmpty()) {
        throw new IllegalArgumentException("CPU 不能为空");
    }
    if (ram == null || ram.isEmpty()) {
        throw new IllegalArgumentException("RAM 不能为空");
    }
    return new Computer(this);
}

默认值

private String gpu = "集成显卡";
private int powerSupply = 500;
private boolean wifi = false;

嵌套 Builder

public class House {
    private Address address;
    private Kitchen kitchen;
    
    public static class Builder {
        private Address.Builder addressBuilder;
        private Kitchen.Builder kitchenBuilder;
        
        public Builder withAddress(Address.Builder addressBuilder) {
            this.addressBuilder = addressBuilder;
            return this;
        }
        
        public House build() {
            return new House(
                addressBuilder.build(),
                kitchenBuilder.build()
            );
        }
    }
}
