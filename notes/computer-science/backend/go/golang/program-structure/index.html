Go 程序结构

2025-02-15

#Go

Go 程序结构由包、声明、控制流和词法作用域共同决定。先读可执行程序的最小结构，再理解变量声明和遮蔽，最后检查包初始化与循环变量的版本差异。

基础结构

// 1. 包声明：定义当前文件属于哪个包
package main

// 2. 导入声明：引入需要的包
import (
    "fmt"
    "time"
)

// 3. 包级声明：常量、变量、类型、函数

const VERSION = "1.0.0"

var globalVar int

// 4. main 函数：程序入口（仅 main 包）
func main() {
    fmt.Println("Hello, Go!")
    time.Sleep(1 * time.Second)
}

关键概念

  • 包（Package）
    • Go 代码的基本组织单元
    • 一个目录下的所有 .go 文件属于同一个包
    • 包名通常与目录名一致（但不是强制的）
  • main 包
    • package main 声明这是一个可执行程序
    • 必须包含 main() 函数作为程序入口
    • 编译后生成可执行文件
  • 库包
    • 非 main 包的代码用于被其他包导入
    • 提供可重用的功能
  • 语法规则
    • 左花括号 { 必须和关键字在同一行
    • 语句末尾的分号可省略（推荐省略）
    • Go 编译器会自动在行尾添加分号

代码组织建议

myproject/
├── go.mod              # 模块定义
├── go.sum              # 依赖校验
├── main.go             # 主程序
├── internal/           # 内部包（不可外部导入）
│   └── config/
├── pkg/                # 可导出的库代码
│   └── utils/
└── cmd/                # 多个可执行程序 main.go
    ├── app1/
    └── app2/

控制流

if-else 语句

// 标准形式
if condition {
    // ...
}

// 带初始化语句（变量作用域仅限于 if-else）
if num := computeValue(); num < 0 {
    fmt.Println(num, "is negative")
} else if num < 10 {
    fmt.Println(num, "has 1 digit")
} else {
    fmt.Println(num, "has multiple digits")
}
// num 在这里不可访问

// 实用示例：错误处理
if err := doSomething(); err != nil {
    return err
}

关键点：

  • 条件表达式不需要括号
  • 花括号必须有，即使只有一条语句
  • else 必须和前面的 } 在同一行

switch 语句

表达式 switch

// 带表达式
switch os := runtime.GOOS; os {
case "darwin":
    fmt.Println("OS X")
case "linux":
    fmt.Println("Linux")
default:
    fmt.Printf("%s\n", os)
}

// 多个值匹配
switch day {
case "Mon", "Tue", "Wed", "Thu", "Fri":
    fmt.Println("工作日")
case "Sat", "Sun":
    fmt.Println("周末")
}

类型 switch（接口类型判断）

func describe(i interface{}) {
    switch v := i.(type) {
    case int:
        fmt.Printf("整数: %d\n", v)
    case string:
        fmt.Printf("字符串: %s\n", v)
    case nil:
        fmt.Println("nil")
    default:
        fmt.Printf("未知类型: %T\n", v)
    }
}

无表达式 switch（替代多个 if-else）

t := time.Now()
switch {
case t.Hour() < 12:
    fmt.Println("上午")
case t.Hour() < 18:
    fmt.Println("下午")
default:
    fmt.Println("晚上")
}

特性：

  • 默认自动 break，不需要显式写
  • 使用 fallthrough 强制执行下一个 case
    • 必须是当前 case 中的最后一条语句
  • case 后可以是任意表达式（不限于常量）
switch {
case 1:
	fallthrough		// continue to next case without checking its conditions
case 2:
}

for 循环

Go 只有 for 一种循环结构，但有多种形式：

标准三段式

for initialization; condition; post {
    // 循环体
}

// 示例
for i := 0; i < 10; i++ {
    fmt.Println(i)
}

while 形式

for condition {
    // 循环体
}

// 示例
i := 0
for i < 10 {
    fmt.Println(i)
    i++
}

无限循环

for {
    // 无限循环
    if shouldBreak {
        break
    }
}

range 遍历

// 遍历数组/切片
numbers := []int{1, 2, 3, 4, 5}
for index, value := range numbers {
    fmt.Printf("索引: %d, 值: %d\n", index, value)
}

// 只要索引
for i := range numbers {
    fmt.Println(i)
}

// 只要值（忽略索引）
for _, value := range numbers {
    fmt.Println(value)
}

// 遍历 map
m := map[string]int{"a": 1, "b": 2}
for key, value := range m {
    fmt.Printf("%s: %d\n", key, value)
}

// 遍历字符串（按 rune 遍历）
for i, ch := range "Hello, 世界" {
    fmt.Printf("%d: %c\n", i, ch)  // i 是字节索引，不是字符索引
}

// 遍历 channel
for msg := range ch {
    fmt.Println(msg)
}  // channel 关闭后退出

range 的重要特性：

  1. 每次迭代会产生两个值：索引/键 和 元素/值
  2. 可以用空标识符 _ 忽略不需要的值
  3. 循环变量是复用的（同一个内存地址，仅对 1.22 版本前）
  4. 循环开始前会先获取切片的长度，如果在循环遍历同时修改了切片的长度，不会影响循环的终止
  5. 会创建元素副本，修改迭代变量不影响原始切片，需要使用索引直接访问原始数据
  6. 遍历 map 为乱序，如果增删字典元素可能会导致错误（修改不影响）
  7. 遍历 string 返回 rune，如果需要 byte 则需通过遍历索引再来访问

闭包陷阱

// 错误示例：闭包捕获循环变量
var funcs []func()
for _, v := range []int{1, 2, 3} {
    funcs = append(funcs, func() {
        fmt.Println(v)  // 所有闭包共享同一个 v
    })
}
for _, f := range funcs {
    f()  // 输出: 3, 3, 3
}

// 正确方式：创建副本
for _, v := range []int{1, 2, 3} {
    v := v  // 创建局部变量副本
    funcs = append(funcs, func() {
        fmt.Println(v)
    })
}

取地址问题

func main() {
	arr := [2]int{1, 2}
	res := []*int{}
	for _, v := range arr {
		// v 每次都是同一个变量
		fmt.Println(&v)
		res = append(res, &v)
	}
	// expect: 1 2
	// but
	// result: 2 2
	fmt.Println(*res[0], *res[1])
}

旧行为（Go 1.21 及之前）

  • for _, v := range arr 中，v 是循环变量，整个循环只分配一次，每次迭代只是把新值写入同一个地址。所以 &v 每次都是同一个地址，最终所有指针都指向最后一次迭代的值 2。

新行为（Go 1.22+）

  • Go 1.22 修改了语义：每次迭代都会创建新的循环变量，相当于编译器在循环体开始时隐式做了：
for _, _v := range arr {
    v := _v  // 每次迭代一个新变量
    res = append(res, &v)
}

所以 &v 每次迭代地址不同，结果符合预期 1 2。

版本对照

版本 v 的地址 输出
≤ 1.21 每次相同 2 2
≥ 1.22 每次不同 1 2

这个改动同样适用于 for i := range n 中的 i（即闭包陷阱），是 Go 1.22 的一个重要语义变更（GOEXPERIMENT=loopvar）。

跳转语句

break 和 continue

// break: 跳出循环
for i := 0; i < 10; i++ {
    if i == 5 {
        break
    }
}

// continue: 跳过当前迭代
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue
    }
    fmt.Println(i)  // 只打印奇数
}

// 标签：跳出多层循环
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i*j > 3 {
            break outer  // 跳出外层循环
        }
    }
}

goto（不推荐，但在错误处理中有用）

func cleanup() error {
    file, err := os.Open("file.txt")
    if err != nil {
        goto failed
    }
    defer file.Close()

    // ... 其他操作

    return nil

failed:
    log.Println("cleanup failed")
    return err
}

命名规范

命名规则

  1. 基本规则

    • 必须以字母（Unicode）或下划线 _ 开头
    • 后续可包含字母、数字、下划线
    • 大小写敏感：name 和 Name 是不同的标识符

  2. 可见性规则

    • 大写字母开头：导出（public），可被其他包访问
    • 小写字母开头：未导出（private），仅包内可见
package mypackage

// 导出的（其他包可访问）
var PublicVar int
func PublicFunc() {}
type PublicStruct struct {
    ExportedField int      // 导出的字段
    unexportedField string // 未导出的字段
}

// 未导出的（仅包内可见）
var privateVar int
func privateFunc() {}

命名约定

变量命名

// 推荐：驼峰命名
userName := "Alice"
maxConnectionCount := 100

// 缩写词保持大写一致性
var HTTPServer string  // 不是 HttpServer
var URLPrefix string   // 不是 UrlPrefix

// 包内私有变量
var httpClient *http.Client

常量命名

// 普通常量：驼峰命名
const maxRetries = 3

// 导出常量
const MaxTimeout = 30 * time.Second

// 枚举类型常量
type Status int
const (
    StatusPending Status = iota
    StatusRunning
    StatusCompleted
)

函数和方法命名

// 动词开头，描述行为
func calculateTotal() int {}
func sendEmail() error {}

// Getter 不加 Get 前缀
type Person struct {
    name string
}
func (p *Person) Name() string { return p.name }

// Setter 用 Set 前缀
func (p *Person) SetName(name string) { p.name = name }

// 布尔函数用 Is/Has/Can 前缀
func isValid() bool {}
func hasPermission() bool {}

接口命名

// 单方法接口：方法名 + er
type Reader interface {
    Read(p []byte) (n int, err error)
}

type Writer interface {
    Write(p []byte) (n int, err error)
}

// 多方法接口：描述性名称
type ReadWriter interface {
    Reader
    Writer
}

包命名

// 包名：小写单词，简短清晰
package http
package json
package strings

// 不推荐：下划线或混合大小写
// package my_package  // 不推荐
// package MyPackage   // 不推荐

预定义标识符

这些名字可以重新定义，但不推荐（会失去原有功能）：

内建函数:
  make len cap new append copy close delete

特殊标识符

  • _ 空白标识符：用于忽略值
_, err := someFunction()  // 忽略第一个返回值

声明语句

Go 有四种主要的声明类型：

变量声明 var

// 1. 完整形式
var name string = "Alice"

// 2. 类型推导
var name = "Alice"

// 3. 只声明（零值初始化）
var name string  // "" (空字符串)
var count int    // 0
var active bool  // false

// 4. 批量声明
var (
    name string = "Alice"
    age  int    = 30
    active bool
)

// 5. 短变量声明（仅函数内）
name := "Alice"
age := 30

短变量声明的规则

// 必须声明至少一个新变量
x := 10
x := 20     // 错误：x 已声明

// 可以重新声明已有变量（至少有一个新变量）
x, y := 10, 20
x, z := 30, 40  // 正确：z 是新变量，x 被重新赋值

// 注意作用域陷阱
var global int = 100
func main() {
    if true {
        global := 200  // 这是新的局部变量，不是修改全局变量！
        fmt.Println(global)  // 200
    }
    fmt.Println(global)  // 100
}

常量声明 const

// 单个常量
const Pi = 3.14159

// 批量声明
const (
    StatusOK     = 200
    StatusError  = 500
)

// 使用 iota 生成枚举
const (
    Monday = iota     // 0
    Tuesday           // 1
    Wednesday         // 2
    Thursday          // 3
    Friday            // 4
    Saturday          // 5
    Sunday            // 6
)

// iota 复杂用法
const (
    _  = iota             // 跳过 0
    KB = 1 << (10 * iota) // 1 << 10 = 1024
    MB                    // 1 << 20 = 1048576
    GB                    // 1 << 30
    TB                    // 1 << 40
)

// iota 在同一行复用
const (
    a, b = iota, iota + 10  // 0, 10
    c, d                     // 1, 11
    e, f                     // 2, 12
)

类型声明 type

// 类型别名（完全等价）
type Celsius = float64
type Fahrenheit = float64

// 定义新类型（不可互换）
type Celsius float64
type Fahrenheit float64

func (c Celsius) String() string {
    return fmt.Sprintf("%.2f°C", c)
}

// 结构体类型
type Person struct {
    Name string
    Age  int
}

// 接口类型
type Reader interface {
    Read(p []byte) (n int, err error)
}

// 函数类型
type HandlerFunc func(http.ResponseWriter, *http.Request)

函数声明 func

// 基本函数
func add(a, b int) int {
    return a + b
}

// 多返回值
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

// 命名返回值
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return  // 裸返回
}

// 可变参数
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

变量详解

零值（Zero Value）

未显式初始化的变量会被赋予零值：

类型 零值
数值类型 0
布尔类型 false
字符串 "" (空字符串)
指针、切片、映射、通道、函数、接口 nil
数组、结构体 所有成员为对应类型的零值 
var i int           // 0
var f float64       // 0.0
var b bool          // false
var s string        // ""
var p *int          // nil
var slice []int     // nil
var m map[int]int   // nil

指针

Go 的指针类似 C，但不支持指针运算。

x := 10
p := &x        // 取地址
fmt.Println(*p)  // 解引用，输出 10
*p = 20        // 通过指针修改值
fmt.Println(x)   // 输出 20

关键特性：

  1. 零值为 nil
  2. 可以比较：相同类型的指针可以用 == 和 != 比较
  3. 函数可以返回局部变量的地址（Go 会自动逃逸分析）
func newInt() *int {
    var x int = 42
    return &x  // 安全！x 会分配在堆上
}

new 函数

new(T) 创建一个类型为 T 的匿名变量，初始化为零值，返回其地址 *T。

p := new(int)
fmt.Println(*p)  // 0
*p = 2
fmt.Println(*p)  // 2

// 等价于
var temp int
p := &temp

注意：new 是预定义函数，不是关键字，可以重新定义（但不推荐）。

变量生命周期

  1. 包级变量：程序整个执行期间
  2. 局部变量：从声明到不再被引用

Go 使用垃圾回收，因此不需要手动释放内存。

逃逸分析：编译器决定变量分配在栈还是堆上。

var global *int

func f() {
    var x int
    global = &x  // x 逃逸到堆上
}

func g() {
    y := 20  // y 分配在栈上（无逃逸）
    fmt.Println(y)
}

赋值操作

基本赋值

x = 10
*p = true
person.name = "Alice"
count[x] = count[x] * scale

多重赋值（元组赋值）

所有右侧表达式先求值，再赋值给左侧。

// 交换变量
x, y = y, x

// 求最大公约数
func gcd(x, y int) int {
    for y != 0 {
        x, y = y, x%y
    }
    return x
}

// 斐波那契数列
func fib(n int) int {
    x, y := 0, 1
    for i := 0; i < n; i++ {
        x, y = y, x+y
    }
    return x
}

自增自减

v++  // 等价于 v = v + 1
v--  // 等价于 v = v - 1

注意：

  • 是语句，不是表达式
  • 只有后缀形式，没有 ++v
  • 不能用于赋值：x = i++ 是错误的

复合赋值

count += 1   // count = count + 1
count -= 1
count *= 2
count /= 2
count %= 3
count &= 0xFF
count |= 0x01
count ^= 0x01
count <<= 1
count >>= 1

类型定义

type TypeName UnderlyingType

类型 vs 类型别名

// 新类型（不可隐式转换）
type Celsius float64
type Fahrenheit float64

var c Celsius = 100
var f Fahrenheit = 212
// c = f  // 错误！不同类型

// 类型别名（完全等价）
type MyInt = int
var x int = 10
var y MyInt = 20
x = y  // 正确！完全相同的类型

自定义类型的优势

  1. 类型安全：防止逻辑错误
type UserID int
type ProductID int
func getUser(id UserID) { }
func getProduct(id ProductID) { }
var uid UserID = 123
var pid ProductID = 456
// getUser(pid)  // 编译错误！
  1. 方法定义：为类型添加方法
type Celsius float64
func (c Celsius) String() string {
    return fmt.Sprintf("%.1f°C", c)
}
  1. 语义表达：代码更易读
type Duration int64  // 纳秒
const (
    Nanosecond  Duration = 1
    Microsecond = 1000 * Nanosecond
    Millisecond = 1000 * Microsecond
    Second      = 1000 * Millisecond
)

包和导入

导入包

// 单个导入
import "fmt"

// 批量导入（推荐）
import (
    "fmt"
    "os"
    "strings"
)

// 包别名
import (
    "crypto/rand"
    mrand "math/rand"  // 避免命名冲突
)

// 点导入（不推荐，会污染命名空间）
import . "fmt"
// 使用：Println() 而不是 fmt.Println()

// 匿名导入（仅执行包的 init 函数）
import _ "image/png"  // 注册 PNG 解码器

包的初始化顺序

  1. 依赖顺序：先初始化被导入的包
  2. 包内顺序：
    • 按依赖关系初始化包级变量
    • 执行 init() 函数
var a = b + c  // 第三个初始化
var b = f()    // 第二个初始化
var c = 1      // 第一个初始化

func f() int { return c + 1 }

func init() {
    // 所有包级变量初始化后执行
}

init 函数

  • 每个文件可以有多个 init() 函数
  • 不能被显式调用或引用
  • 按声明顺序自动执行
  • 常用于初始化配置、注册驱动等
func init() {
    // 初始化代码
}

内部包

一个 internal 包只能被和 internal 目录有同一个父目录的包所导入

net/http
net/http/internal/chunked

作用域

词法块

Go 的作用域基于词法块（lexical block）：

// 宇宙块：所有 Go 源代码
//   ├── 包块：整个包
//   │     ├── 文件块：单个文件
//   │     ├── 函数块
//   │     │     ├── if/for/switch 块
//   │     │     └── {...} 显式块

作用域规则

package main

var global = "包级变量"  // 包块作用域

func main() {
    local := "局部变量"  // 函数块作用域

    if x := computeValue(); x > 0 {  // if 块作用域
        fmt.Println(x)  // 可访问 x
    }
    // fmt.Println(x)  // 错误！x 不可见

    for i := 0; i < 10; i++ {  // for 块作用域
        fmt.Println(i)
    }
    // fmt.Println(i)  // 错误！i 不可见
}

变量遮蔽（Shadowing）

内层作用域可以声明同名变量，遮蔽外层变量：

var x = "global"

func main() {
    x := "local"
    fmt.Println(x)  // "local"

    {
        x := 100
        fmt.Println(x)  // 100
    }

    fmt.Println(x)  // "local"
}

常见陷阱：

var cwd string

func init() {
    cwd, err := os.Getwd()  // 错误！声明了新的局部变量 cwd
    if err != nil {
        log.Fatal(err)
    }
    // 外层的 cwd 仍然是空字符串
}

// 正确方式 1：分开声明
func init() {
    var err error
    cwd, err = os.Getwd()  // 赋值给外层的 cwd
    if err != nil {
        log.Fatal(err)
    }
}

// 正确方式 2：if 中处理
func init() {
    var err error
    if cwd, err = os.Getwd(); err != nil {
        log.Fatal(err)
    }
}
