Go Zap

2025-09-04

#Go#日志

Zap 的两类记录器在调用便利性与强类型字段之间取舍。Logger 用强类型字段表达结构化日志；SugaredLogger 支持更灵活的参数与 printf 风格。原稿的性能倍数来自特定基准，不能直接作为所有业务场景的结论。

Zap

Zap 面向低开销的结构化日志。

使用

安装

go get -u go.uber.org/zap

Logger

Zap 提供了两种类型的日志记录器— Sugared Logger 和 Logger。

  • 在性能很好但不是很关键的上下文中，使用 SugaredLogger。它支持结构化和 printf 风格的日志记录；相对性能取决于基准负载和对比库。
  • 在每一微秒和每一次内存分配都很重要的上下文中，使用 Logger。它甚至比 SugaredLogger 更快，内存分配次数也更少，但它只支持强类型的结构化日志记录。

复习

  • 日志字段是否应当先转为字符串？
  • 为什么要结合实际日志量、采样与输出介质测量性能？
