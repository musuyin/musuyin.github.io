2025-09-16

#Go#WebSocket

WebSocket 把一次握手升级为长连接，连接生命周期需要独立管理读、写、心跳、超时与关闭。先跑通客户端与服务端的最小交换，再核对并发访问约束与退出路径。

设计要点

任何使用 websocket 协议的应用程序通常都需要一个客户端和一个服务器。 服务器程序绑定到服务器上的端口，并开始侦听任何 Websocket 连接。与连接有关的详细信息由 websocket 协议定义，该协议通过原始 HTTP 连接起作用。

  1. 保证 WebSocket 逻辑的独立性，对于独有配置可以采取传入方式，降低耦合度
  2. Gorilla WebSocket 允许一个并发 reader 与一个并发 writer；同方向的多个读者或写者应自行串行化，这不是“Go 原生 WebSocket”的统一规则。见 Gorilla 并发约束

Gorilla WebSocket

Gorilla 的工作是转换原始 HTTP 连接进入一个有状态的 websocket 连接。

Quick Start

server.go

使用 go 作为服务器，使用 websocket.Upgrader。 使用全局升级程序变量通过来将任何传入的 HTTP 连接转换为 websocket 协议 upgrader.Upgrade()。 这将返回 *websocket.Conn，现在可以使用它来处理 websocket 连接。

package test
import (
    "fmt"
    "log"    "net/http"
    "github.com/gorilla/websocket")
// 直接使用默认配置
var upgrader = websocket.Upgrader{}
func socketHandler(w http.ResponseWriter, r *http.Request) {
    // 将HTTP请求升级为 websocket 请求
    conn, err := upgrader.Upgrade(w, r, nil)
    if err != nil {
       log.Println(err)
       return
    }
    defer conn.Close()
    // 监听循环
    for {
       // 读取消息
       messageType, message, err := conn.ReadMessage()
       if err != nil {
          log.Println(err)
          break
       }
       // 写入消息
       log.Printf("Received message: %s\n", message)
       if conn.WriteMessage(messageType, message) != nil {
          log.Println(err)
          break
       }
    }
}
func home(w http.ResponseWriter, r *http.Request) {
    if _, err := fmt.Fprintf(w, "Welcome to the home page!"); err != nil {
       log.Println(err)
    }
}
func main() {
    http.HandleFunc("/", home)
    http.HandleFunc("/ws", socketHandler)
    log.Fatal(http.ListenAndServe(":8080", nil))
}

client.go

go 作为客户端，使用 websocket.Dial() 进行拨号连接。

package main
import (
    "log"
    "os"    "os/signal"    "time"
    "github.com/gorilla/websocket")
var done chan any
var interrupt chan os.Signal
func receiveHandler(conn *websocket.Conn) {
    defer close(done)
    for {
       _, msg, err := conn.ReadMessage()
       if err != nil {
          log.Println("Error reading from websocket:", err)
          return
       }
       log.Printf("Received message: %s\n", msg)
    }
}
func main() {
    // receive 结束读取的标志
    done = make(chan any)
    // 监听中断信号实现优雅退出
    interrupt = make(chan os.Signal)
    // 将操作系统的 SIGINT 信号转发到 interrupt 通道上
    signal.Notify(interrupt, os.Interrupt)
    // Dial拨号连接
    socketUrl := "ws://127.0.0.1:8080/ws"
    conn, _, err := websocket.DefaultDialer.Dial(socketUrl, nil)
    if err != nil {
       log.Fatal("dial:", err)
    }
    defer conn.Close()
    // 开启监听线程
    go receiveHandler(conn)
    for {
       select {
       case <-time.After(time.Duration(1) * time.Millisecond * 1000):
          // 每秒发送回显信息
          if err := conn.WriteMessage(websocket.TextMessage, []byte("Hello World")); err != nil {
             log.Println("write:", err)
             return
          }
       case <-interrupt:
          // 接收到中断信号 Ctrl+C          log.Println("interrupt")
          // 优雅退出
          if err := conn.WriteMessage(websocket.CloseMessage, []byte{}); err != nil {
             log.Println("close:", err)
             return
          }
          select {
          case <-done:
             log.Println("done")
          case <-time.After(time.Duration(1) * time.Second):
             log.Println("timeout")
          }
       }
    }
}
  • 如果 receiveHandler 退出，则 done 会关闭
  • 如果 done 未关闭，则有超时兜底

读写消息

优雅退出

  1. 捕捉进程终止信号，如 syscall.SIGINT、syscall.SIGTERM；os.Kill 对应的强制终止不能被捕获
  2. 捕捉到信号后，开启进程退出倒计时，不管如何，必须在 n 秒后退出进程，这是底线
  3. 停止接收新的请求
  4. 等待进程内剩余请求的完成
  5. 终止时间已到，进程正式退出

API

websocket.Dialer 客户端

用于从客户端发起连接

dialer := &websocket.Dialer{
    NetDial:           nil,
    NetDialContext:    nil,
    NetDialTLSContext: nil,
    Proxy:             nil,
    TLSClientConfig:   nil,
    HandshakeTimeout:  45 * time.Second,
    ReadBufferSize:    1024,
    WriteBufferSize:   1024,
    WriteBufferPool:   nil,
    Subprotocols:      nil,
    EnableCompression: false,
    Jar:               nil,
}
  • NetDial: 指定一个自定义的  func(network, addr string) (net.Conn, error)  函数，用于建立底层 TCP 连接。已弃用。
  • NetDialContext: 指定一个自定义的  func(ctx context.Context, network, addr string) (net.Conn, error)  函数，用于建立底层 TCP 连接。这是  NetDial  的现代替代品，支持  context  超时和取消。
  • NetDialTLSContext: 指定一个自定义的  func(ctx context.Context, network, addr string) (net.Conn, error)  函数，专门用于建立 TLS (wss://) 连接。如果设置了此函数，它将优先于  NetDialContext  用于 TLS 连接。
  • Proxy: 指定一个 func(*http.Request) (*url.URL, error) 函数，用于为 WebSocket 握手请求（HTTP Upgrade）确定代理服务器。gorilla/websocket 内部会使用 http.Transport 来发送这个握手请求。
    • Proxy  用于确定握手请求应该发送到哪个代理服务器。
    • NetDialContext / NetDialTLSContext  用于建立到目标服务器或代理服务器的底层 TCP 连接。
    • 如果同时设置了  Proxy  和  NetDialContext，NetDialContext  将用于连接到  Proxy  返回的代理地址。
  • TLSClientConfig: 指定一个 *tls.Config，用于配置 TLS 连接（wss://）。这是控制 TLS 行为的核心。
    • InsecureSkipVerify: (危险!)  如果设置为  true，客户端将不验证服务器证书的有效性（如过期、域名不匹配、未知 CA）。仅用于测试环境，生产环境必须为  false。
    • ServerName: 指定期望的服务器主机名，用于 SNI (Server Name Indication) 和证书验证。通常  Dialer.Dial  会自动设置，但可以手动覆盖。
    • RootCAs: 指定一个  *x509.CertPool，包含信任的根 CA 证书。默认使用系统信任的根 CA。如果服务器使用私有 CA 签发的证书，需要将私有 CA 证书添加到此池中。
    • Certificates: 客户端证书，用于双向 TLS (mTLS) 认证。
    • MinVersion, MaxVersion: 指定支持的 TLS 版本。
    • CipherSuites: 指定支持的加密套件。
  • HandshakeTimeout: 设置完成整个 WebSocket 握手过程的最大时间。这包括 TCP 连接、TLS 握手（如果需要）和 HTTP Upgrade 请求的往返。
  • ReadBufferSize: 分配给读取缓冲区的字节数。用于存放从网络读取的原始数据，直到被  ReadMessage  解析。
  • WriteBufferSize: 分配给写入缓冲区的字节数。用于存放待发送的应用程序数据，直到被写入网络。
  • WriteBufferPool: 实现 websocket. WriteBufferPool 接口的对象。用于从一个对象池中获取写入缓冲区，避免频繁的内存分配（GC 压力）。设置了该变量则 WriteBufferSize 会被忽略。
  • Subprotocols: 指定客户端支持的子协议列表。在握手时，服务器会从这个列表中选择一个它也支持的协议，并在响应头中返回。连接建立后，通信应遵循选定的子协议。
    • 如果服务器需要特定的子协议（如  graphql-ws, json.webpubsub.azure.v1），必须在此列表中包含它。
    • 如果服务器不关心子协议，可以留空 (nil  或  [])。
    • 例如：Subprotocols: []string{"graphql-ws"}。
  • EnableCompression: 是否启用 WebSocket 的 permessage-deflate 压缩扩展。
  • Jar: 指定一个 http.CookieJar，用于在 WebSocket 握手请求中自动处理 Cookie (发送和接收)。
    • 如果 WebSocket 握手需要携带 Cookie (如会话 Cookie)，并且希望库自动管理 Cookie，需要设置一个实现了  http.CookieJar  接口的实例。
    • 常用的实现是  cookiejar.Jar。
    • 如果不需要 Cookie，保持为  nil

基本上只需要

dialer := &websocket.Dialer{
    HandshakeTimeout:  45 * time.Second,
    ReadBufferSize:    1024,
    WriteBufferSize:   1024,
}

使用 Dialer 拨号连接

// 使用Dialer拨号连接
// urlStr: WebSocket服务器的URL(ws:// or wss://)
// requestHeader: 可选的HTTP请求头
conn, response, err := dialer.Dial("ws://localhost:8000/ws", nil)
if err != nil {
    return
}
// 注意关闭连接
defer conn.Close()
// 连接成功，则conn为 *websocket.Conn

websocket.Conn 连接

代表一个打开的 WebSocket 连接，用于读写消息 写消息

代码实现

package ws

import (
    "encoding/json"
    "fmt"
    "log"
    "net/http"
    "okx_marketservice/internal/consts"
    "okx_marketservice/pkg/utils"
    "sync"
    "time"
    "github.com/gorilla/websocket")

type Client[T any] struct {
    Conn          *websocket.Conn
    Lock          sync.Mutex
    Url           string
    RequestHeader http.Header
    Response      *http.Response
}

func NewClient[T any](urlStr string, requestHeader http.Header) (*Client[T], error) {
    var client Client[T]
    client.Url = urlStr
    client.RequestHeader = requestHeader
    if err := client.Connect(); err != nil {
       return nil, err
    }
    return &client, nil
}
func (c *Client[T]) Connect() error {
    c.Lock.Lock()
    defer c.Lock.Unlock()
    var conn *websocket.Conn
    var response *http.Response
    var err error
    waitTime := time.Second
    log.Println("正在连接websocket")
    for retry := 1; ; waitTime, retry = utils.WaitingTime(waitTime, retry) {
       log.Printf("尝试第 %d 次连接websocket", retry)
       conn, response, err = websocket.DefaultDialer.Dial(c.Url, c.RequestHeader)
       if err != nil {
          log.Printf("websocket第 %d 次连接失败: ", retry)
          time.Sleep(waitTime)
          continue
       }
       break
    }
    log.Println("websocket连接成功")
    c.Conn = conn
    c.Response = response
    return nil
}
func (c *Client[T]) Ping() {
    log.Println("开启心跳线程")
    for {
       time.Sleep(consts.PingInterval)
       if err := func() (err error) {
          c.Lock.Lock()
          defer c.Lock.Unlock()
          defer func() {
             if r := recover(); r != nil {
                err = fmt.Errorf("heartbeat operation panicked: %v", r)
             }
          }()
          err = c.Conn.WriteMessage(websocket.TextMessage, []byte("ping"))
          return err
       }(); err != nil {
          log.Println("心跳发生错误: ", err)
          break
       }
    }
}
func (c *Client[T]) Receive() (*T, error) {
    for {
       messageType, message, err := c.Conn.ReadMessage()
       if err != nil {
          log.Println("websocket 读取消息错误", err)
          return nil, err
       }

       messageStr := string(message)
       if "pong" == messageStr {
          // log.Println("websocket 连接正常")
          continue
       }
       switch messageType {
       case websocket.TextMessage, websocket.BinaryMessage:
          var data T
          if err := json.Unmarshal(message, &data); err != nil {
             log.Println("websocket 数据解析错误", err)
             continue
          }
          return &data, nil
       case websocket.PongMessage:
          log.Println("websocket 收到Pong消息")
       case websocket.CloseMessage:
          log.Println("websocket 收到关闭消息")
       }
    }
}
func (c *Client[T]) Send(data any) (err error) {
    if c.Conn == nil {
       err = fmt.Errorf("websocket connection is nil")
       return err
    }
    jsonData, err := json.Marshal(data)
    if err != nil {
       log.Println("JSON转换失败:", err)
       return err
    }
    c.Lock.Lock()
    defer c.Lock.Unlock()
    defer func() {
       if r := recover(); r != nil {
          err = fmt.Errorf("websocket write panicked: %v", r)
       }
    }()
    return c.Conn.WriteMessage(websocket.TextMessage, jsonData)
}
func (c *Client[T]) Close() error {
    c.Lock.Lock()
    defer c.Lock.Unlock()
    if c.Conn == nil {
       return fmt.Errorf("websocket connection is nil")
    }
    log.Println("正在关闭websocket")
    if err := c.Conn.WriteMessage(websocket.CloseMessage, websocket.FormatCloseMessage(websocket.CloseNormalClosure, "")); err != nil {
       log.Printf("发送关闭消息失败: %v", err)
       return err
    }
    return c.Conn.Close()
}
