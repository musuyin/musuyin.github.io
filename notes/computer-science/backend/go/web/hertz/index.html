L04-Hertz

2026-08-06

Hertz 的定位

Hertz 是 CloudWeGo 的 Go HTTP 框架。它接收 HTTP 请求，通过路由分发给处理函数，并提供中间件等扩展。与 Gin 对照时，可先比较路由注册、请求上下文和服务启动方式。

本页原稿为空，以下为依据官方文档新增的入门内容，尚未在本仓库运行验证。

启动一个接口

先建立模块，创建 main.go：

package main

import (
    "context"
    "github.com/cloudwego/hertz/pkg/app"
    "github.com/cloudwego/hertz/pkg/app/server"
)

func main() {
    h := server.Default()
    h.GET("/ping", func(ctx context.Context, c *app.RequestContext) {
        c.String(200, "pong")
    })
    h.Spin()
}

随后安装依赖并运行：

go mod init example.com/hertz-demo
go mod tidy
go run .

在另一个终端请求接口：

curl http://127.0.0.1:8888/ping

预期响应体为 pong。server.Default() 建立服务，GET 绑定路由，Spin() 启动并管理服务生命周期。

下一步

最小接口只证明请求分发流程。实际服务还需配置超时、输入校验、错误处理和优雅关闭。若采用接口描述生成工程，可继续了解配套的 hz 工具。

来源：CloudWeGo Hertz 入门。
